# 4 矩和矩母函数

## 重点
- 矩的数学定义和基本性质
- 矩母函数的概念和计算方法
- 矩母函数在概率论中的重要作用
- 矩和矩母函数在实际问题中的应用

## 4.1 矩的基本概念

### 4.1.1 矩的定义

**k阶矩**：对于随机变量X，其k阶矩定义为：

$$E[X^k] = \begin{cases}
\sum_{x} x^k \cdot P(X = x), & \text{离散情况} \\
\int_{-\infty}^{\infty} x^k \cdot f_X(x) dx, & \text{连续情况}
\end{cases}$$

**k阶中心矩**：对于随机变量X，其k阶中心矩定义为：

$$\mu_k = E[(X - E[X])^k]$$

### 4.1.2 重要矩的含义

**一阶矩**：$\mu_1 = E[X]$ （期望）
- 表示随机变量的"中心"位置

**二阶中心矩**：$\mu_2 = E[(X - E[X])^2] = Var(X)$ （方差）
- 表示随机变量的离散程度

**三阶中心矩**：$\mu_3 = E[(X - E[X])^3]$ （偏度）
- 表示分布的对称性

**四阶中心矩**：$\mu_4 = E[(X - E[X])^4]$ （峰度）
- 表示分布的尖峭程度

### 4.1.3 矩的计算

**原始矩与中心矩的关系**：

$$\mu_k = E[(X - \mu)^k] = \sum_{i=0}^{k} \binom{k}{i} (-1)^{k-i} \mu_1^i E[X^{k-i}]$$

其中 $\mu = E[X]$ 是期望。

**示例**：计算正态分布的矩
- 对于标准正态分布 $X \sim N(0,1)$
- $\mu_1 = 0$，$\mu_2 = 1$，$\mu_3 = 0$，$\mu_4 = 3$

## 4.2 矩母函数的基本概念

### 4.2.1 矩母函数的定义

**矩母函数**（Moment Generating Function, MGF）：对于随机变量X，其矩母函数定义为：

$$M_X(t) = E[e^{tX}] = \begin{cases}
\sum_{x} e^{tx} \cdot P(X = x), & \text{离散情况} \\
\int_{-\infty}^{\infty} e^{tx} \cdot f_X(x) dx, & \text{连续情况}
\end{cases}$$

### 4.2.2 矩母函数的性质

1. **存在性**：矩母函数可能不存在（如柯西分布）
2. **唯一性**：如果存在，则唯一确定分布
3. **连续性**：在定义域内连续
4. **凸性**：$\log M_X(t)$ 是凸函数

### 4.2.3 矩母函数与矩的关系

**矩的生成**：矩母函数的k阶导数在t=0处的值等于k阶矩：

$$E[X^k] = M_X^{(k)}(0) = \left.\frac{d^k}{dt^k} M_X(t)\right|_{t=0}$$

**泰勒展开**：
$$M_X(t) = \sum_{k=0}^{\infty} \frac{E[X^k]}{k!} t^k$$

## 4.3 常见分布的矩母函数

### 4.3.1 离散分布的矩母函数

**伯努利分布**：
$$M_X(t) = pe^t + (1-p) = 1 + p(e^t - 1)$$

**二项分布**：
$$M_X(t) = (pe^t + 1-p)^n$$

**泊松分布**：
$$M_X(t) = e^{\lambda(e^t - 1)}$$

**几何分布**：
$$M_X(t) = \frac{pe^t}{1 - (1-p)e^t}, \quad t < -\ln(1-p)$$

### 4.3.2 连续分布的矩母函数

**正态分布**：
$$M_X(t) = e^{\mu t + \frac{1}{2}\sigma^2 t^2}$$

**指数分布**：
$$M_X(t) = \frac{\lambda}{\lambda - t}, \quad t < \lambda$$

**伽马分布**：
$$M_X(t) = \left(\frac{\lambda}{\lambda - t}\right)^{\alpha}, \quad t < \lambda$$

**均匀分布**：
$$M_X(t) = \frac{e^{bt} - e^{at}}{(b-a)t}, \quad t \neq 0$$

## 4.4 矩母函数的应用

### 4.4.1 矩的计算

**示例**：计算泊松分布的矩

泊松分布的矩母函数：
$$M_X(t) = e^{\lambda(e^t - 1)}$$

计算各阶导数：
- $M_X'(t) = \lambda e^t e^{\lambda(e^t - 1)}$
- $M_X''(t) = \lambda e^t e^{\lambda(e^t - 1)} + \lambda^2 e^{2t} e^{\lambda(e^t - 1)}$

在t=0处求值：
- $E[X] = M_X'(0) = \lambda$
- $E[X^2] = M_X''(0) = \lambda + \lambda^2$

因此：
- $Var(X) = E[X^2] - (E[X])^2 = \lambda$

### 4.4.2 独立随机变量的和

**定理**：如果X和Y独立，则：
$$M_{X+Y}(t) = M_X(t) \cdot M_Y(t)$$

**证明**：
$$M_{X+Y}(t) = E[e^{t(X+Y)}] = E[e^{tX} \cdot e^{tY}] = E[e^{tX}] \cdot E[e^{tY}] = M_X(t) \cdot M_Y(t)$$

**应用**：计算二项分布的矩母函数
- 二项分布是n个独立伯努利分布的和
- $M_X(t) = (pe^t + 1-p)^n$

### 4.4.3 分布的唯一性

**定理**：如果两个随机变量有相同的矩母函数，则它们有相同的分布。

**应用**：
- 证明分布的性质
- 验证分布的正确性
- 推导新的分布

## 4.5 特征函数

### 4.5.1 特征函数的定义

**特征函数**：对于随机变量X，其特征函数定义为：

$$\phi_X(t) = E[e^{itX}]$$

其中 $i = \sqrt{-1}$ 是虚数单位。

### 4.5.2 特征函数的性质

1. **存在性**：特征函数总是存在
2. **有界性**：$|\phi_X(t)| \leq 1$
3. **连续性**：在实数域上连续
4. **唯一性**：唯一确定分布

### 4.5.3 特征函数与矩母函数的关系

如果矩母函数存在，则：
$$\phi_X(t) = M_X(it)$$

**示例**：正态分布
- 矩母函数：$M_X(t) = e^{\mu t + \frac{1}{2}\sigma^2 t^2}$
- 特征函数：$\phi_X(t) = e^{i\mu t - \frac{1}{2}\sigma^2 t^2}$

## 4.6 累积量

### 4.6.1 累积量的定义

**累积量**：对于随机变量X，其累积量定义为矩母函数对数的泰勒展开系数：

$$\log M_X(t) = \sum_{k=1}^{\infty} \frac{\kappa_k}{k!} t^k$$

其中 $\kappa_k$ 是k阶累积量。

### 4.6.2 累积量的性质

1. **一阶累积量**：$\kappa_1 = E[X]$ （期望）
2. **二阶累积量**：$\kappa_2 = Var(X)$ （方差）
3. **三阶累积量**：$\kappa_3 = \mu_3$ （偏度相关）
4. **四阶累积量**：$\kappa_4 = \mu_4 - 3\mu_2^2$ （峰度相关）

### 4.6.3 累积量的优势

**加性**：独立随机变量之和的累积量等于各累积量之和：
$$\kappa_k(X + Y) = \kappa_k(X) + \kappa_k(Y)$$

**不变性**：累积量对线性变换有简单的关系：
$$\kappa_k(aX + b) = a^k \kappa_k(X)$$

## 4.8 矩的估计

### 4.8.1 样本矩

**样本k阶矩**：
$$m_k = \frac{1}{n} \sum_{i=1}^{n} X_i^k$$

**样本k阶中心矩**：
$$m_k' = \frac{1}{n} \sum_{i=1}^{n} (X_i - \bar{X})^k$$

### 4.8.2 矩估计法

**原理**：用样本矩估计总体矩，然后求解参数。

**示例**：正态分布的矩估计
- 样本均值：$\hat{\mu} = \bar{X}$
- 样本方差：$\hat{\sigma}^2 = \frac{1}{n} \sum_{i=1}^{n} (X_i - \bar{X})^2$

### 4.8.3 矩估计的性质

**一致性**：在大样本下收敛到真值
**无偏性**：某些矩估计是无偏的
**有效性**：通常不如最大似然估计有效
