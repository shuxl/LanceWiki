## 控制器概念或介绍

### 什么是控制器
控制器是Spring MVC框架中的核心组件，负责处理HTTP请求并返回响应。它是MVC模式中的Controller层，连接用户请求和业务逻辑。

**控制器的职责：**
- 接收HTTP请求
- 调用业务逻辑
- 返回响应结果
- 处理异常情况

### 控制器设计模式
Spring MVC控制器采用多种设计模式：

1. **命令模式**：每个请求映射到一个处理方法
2. **策略模式**：不同的控制器处理不同类型的请求
3. **模板方法模式**：定义了请求处理的标准流程

## 控制器类型和注解

### 1. 基于注解的控制器

#### @Controller注解
```java
@Controller
public class UserController {
    
    @RequestMapping("/users")
    public String listUsers(Model model) {
        // 处理逻辑
        return "user/list";
    }
}
```

**底层实现：**
```java
@Target({ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Component
public @interface Controller {
    @AliasFor(annotation = Component.class)
    String value() default "";
}
```

#### @RestController注解
```java
@RestController
@RequestMapping("/api/users")
public class UserRestController {
    
    @GetMapping("/{id}")
    public ResponseEntity<User> getUser(@PathVariable Long id) {
        User user = userService.findById(id);
        return ResponseEntity.ok(user);
    }
}
```

**底层实现：**
```java
@Target({ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Controller
@ResponseBody
public @interface RestController {
    @AliasFor(annotation = Controller.class)
    String value() default "";
}
```

### 2. 请求映射注解

#### @RequestMapping注解
```java
@Controller
@RequestMapping("/users")
public class UserController {

    @RequestMapping(value = "/create", method = {RequestMethod.GET, RequestMethod.POST})
    public String create() {
        return "user/create";
```

**底层实现：**
```java
@Target({ElementType.METHOD, ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Mapping
public @interface RequestMapping {
    String name() default "";
    String[] value() default {};
    String[] path() default {};
    RequestMethod[] method() default {};
    String[] params() default {};
    String[] headers() default {};
    String[] consumes() default {};
    String[] produces() default {};
}
```

### 3. 参数绑定注解

#### @RequestParam注解
```java
@GetMapping("/search")
public String search(@RequestParam("keyword") String keyword,
                    @RequestParam(value = "page", defaultValue = "1") int page,
                    @RequestParam(value = "size", required = false) Integer size) {
    // 处理逻辑
    return "search/result";
}
```

**底层实现：**
```java
@Target({ElementType.PARAMETER})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface RequestParam {
    @AliasFor("name")
    String value() default "";
    @AliasFor("value")
    String name() default "";
    boolean required() default true;
    String defaultValue() default ValueConstants.DEFAULT_NONE;
}
```

#### @PathVariable注解
```java
@GetMapping("/users/{id}/orders/{orderId}")
public String getOrder(@PathVariable Long id,
                      @PathVariable("orderId") Long orderId) {
    // 处理逻辑
    return "order/detail";
}
```

#### @RequestBody注解
```java
@PostMapping("/users")
public ResponseEntity<User> createUser(@RequestBody User user) {
    User savedUser = userService.save(user);
    return ResponseEntity.status(HttpStatus.CREATED).body(savedUser);
}
```

#### @ModelAttribute注解
```java
@ModelAttribute("user")
public User getUser() {
    return new User();
}

@PostMapping("/users")
public String createUser(@ModelAttribute("user") User user) {
    userService.save(user);
    return "redirect:/users";
}
```

## 参数绑定机制

### 1. 参数解析器链

#### HandlerMethodArgumentResolver接口
```java
public interface HandlerMethodArgumentResolver {
    // 判断是否支持该参数类型
    boolean supportsParameter(MethodParameter parameter);
    
    // 解析参数
    Object resolveArgument(MethodParameter parameter, 
                         ModelAndViewContainer mavContainer,
                         NativeWebRequest webRequest, 
                         WebDataBinderFactory binderFactory) throws Exception;
}
```

#### 常用参数解析器
```java
// 1. RequestParamMethodArgumentResolver - 处理@RequestParam
public class RequestParamMethodArgumentResolver implements HandlerMethodArgumentResolver {
    
    @Override
    public Object resolveArgument(MethodParameter parameter,
                                ModelAndViewContainer mavContainer,
                                NativeWebRequest webRequest,
                                WebDataBinderFactory binderFactory) throws Exception {
        // 从请求中获取参数值
        String paramName = getParamName(parameter);
        String paramValue = webRequest.getParameter(paramName);
        
        // 类型转换
        return convertToType(paramValue, parameter.getParameterType());
    }
}

// 2. PathVariableMethodArgumentResolver - 处理@PathVariable
public class PathVariableMethodArgumentResolver implements HandlerMethodArgumentResolver {
    
    @Override
    public Object resolveArgument(MethodParameter parameter,
                                ModelAndViewContainer mavContainer,
                                NativeWebRequest webRequest,
                                WebDataBinderFactory binderFactory) throws Exception {
        // 从路径变量中获取值
        String pathVarName = getPathVariableName(parameter);
        String pathVarValue = getPathVariables(webRequest).get(pathVarName);
        
        // 类型转换
        return convertToType(pathVarValue, parameter.getParameterType());
    }
}
```

### 2. 类型转换机制

#### ConversionService接口
```java
public interface ConversionService {
    // 判断是否可以进行类型转换
    boolean canConvert(Class<?> sourceType, Class<?> targetType);
    
    // 执行类型转换
    <T> T convert(Object source, Class<T> targetType);
}
```

#### 自定义类型转换器
```java
@Component
public class StringToUserConverter implements Converter<String, User> {
    
    @Autowired
    private UserService userService;
    
    @Override
    public User convert(String source) {
        if (source == null || source.isEmpty()) {
            return null;
        }
        return userService.findById(Long.valueOf(source));
    }
}
```

## 返回值处理

### 1. 返回值类型

#### 视图名称
```java
@GetMapping("/users")
public String listUsers(Model model) {
    List<User> users = userService.findAll();
    model.addAttribute("users", users);
    return "user/list"; // 返回视图名称
}
```

#### ModelAndView对象
```java
@GetMapping("/users")
public ModelAndView listUsers() {
    List<User> users = userService.findAll();
    ModelAndView mav = new ModelAndView("user/list");
    mav.addObject("users", users);
    return mav;
}
```

#### ResponseEntity对象
```java
@GetMapping("/users/{id}")
public ResponseEntity<User> getUser(@PathVariable Long id) {
    User user = userService.findById(id);
    if (user == null) {
        return ResponseEntity.notFound().build();
    }
    return ResponseEntity.ok(user);
}
```

### 2. 返回值解析器

#### HandlerMethodReturnValueHandler接口
```java
public interface HandlerMethodReturnValueHandler {
    // 判断是否支持该返回值类型
    boolean supportsReturnType(MethodParameter returnType);
    
    // 处理返回值
    void handleReturnValue(Object returnValue, 
                          MethodParameter returnType,
                          ModelAndViewContainer mavContainer,
                          NativeWebRequest webRequest) throws Exception;
}
```

#### 常用返回值解析器
```java
// 1. ViewNameMethodReturnValueHandler - 处理视图名称
public class ViewNameMethodReturnValueHandler implements HandlerMethodReturnValueHandler {
    
    @Override
    public void handleReturnValue(Object returnValue,
                                MethodParameter returnType,
                                ModelAndViewContainer mavContainer,
                                NativeWebRequest webRequest) throws Exception {
        String viewName = (String) returnValue;
        mavContainer.setViewName(viewName);
    }
}

// 2. RequestResponseBodyMethodProcessor - 处理@ResponseBody
public class RequestResponseBodyMethodProcessor implements HandlerMethodReturnValueHandler {
    
    @Override
    public void handleReturnValue(Object returnValue,
                                MethodParameter returnType,
                                ModelAndViewContainer mavContainer,
                                NativeWebRequest webRequest) throws Exception {
        // 序列化返回值
        HttpServletResponse response = webRequest.getNativeResponse(HttpServletResponse.class);
        writeWithMessageConverters(returnValue, returnType, response);
    }
}
```

## 性能优化

### 1. 控制器单例模式
```java
@Controller
@Scope("singleton") // 默认单例
public class UserController {
    // 控制器实例在应用启动时创建，所有请求共享
}
```

### 2. 方法级缓存
```java
@Controller
public class UserController {
    
    @Cacheable("users")
    @GetMapping("/users/{id}")
    public User getUser(@PathVariable Long id) {
        return userService.findById(id);
    }
}
```

### 3. 异步处理
```java
@Controller
public class UserController {
    
    @Async
    @GetMapping("/users/async")
    public CompletableFuture<List<User>> getUsersAsync() {
        return CompletableFuture.supplyAsync(() -> userService.findAll());
    }
}
```
