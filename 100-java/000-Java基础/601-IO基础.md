# 2 IO概念或介绍

## 2.1 什么是IO

IO（Input/Output）即输入输出，是计算机与外部世界进行数据交换的过程。在Java中，IO操作主要通过流（Stream）来实现。

## 2.2 IO流的分类

1. **按数据流向分类**：
   - 输入流（Input Stream）：从外部读取数据到程序中
   - 输出流（Output Stream）：从程序向外部写入数据

2. **按数据类型分类**：
   - 字节流：以字节为单位进行数据传输，适用于所有类型的数据
   - 字符流：以字符为单位进行数据传输，适用于文本数据

3. **按功能分类**：
   - 节点流：直接与数据源相连的流
   - 处理流：对节点流进行包装，提供增强功能的流

# 3 字节流

## 3.1 字节输入流

```java
// FileInputStream - 文件字节输入流
public class FileInputStreamExample {
    public static void main(String[] args) {
        try (FileInputStream fis = new FileInputStream("test.txt")) {
            byte[] buffer = new byte[1024];
            int bytesRead;
            while ((bytesRead = fis.read(buffer)) != -1) {
                // 处理读取的数据
                System.out.write(buffer, 0, bytesRead);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 3.2 字节输出流

```java
// FileOutputStream - 文件字节输出流
public class FileOutputStreamExample {
    public static void main(String[] args) {
        try (FileOutputStream fos = new FileOutputStream("output.txt")) {
            String data = "Hello, Java IO!";
            fos.write(data.getBytes());
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

public class BufferedStreamExample {

# 6 数据流

## 6.1 DataInputStream 和 DataOutputStream

```java
// 用于读写基本数据类型
public class DataStreamExample {
    public static void main(String[] args) {
        // 写入数据
        try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("data.txt"))) {
            dos.writeInt(100);
            dos.writeDouble(3.14);
            dos.writeUTF("Hello");
        } catch (IOException e) {
            e.printStackTrace();
        }
        
        // 读取数据
        try (DataInputStream dis = new DataInputStream(new FileInputStream("data.txt"))) {
            int intValue = dis.readInt();
            double doubleValue = dis.readDouble();
            String stringValue = dis.readUTF();
            
            System.out.println("Int: " + intValue);
            System.out.println("Double: " + doubleValue);
            System.out.println("String: " + stringValue);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

# 7 对象流

## 7.1 ObjectInputStream 和 ObjectOutputStream

```java
// 用于序列化和反序列化对象
public class ObjectStreamExample {
    public static void main(String[] args) {
        // 写入对象
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("object.dat"))) {
            Person person = new Person("张三", 25);
            oos.writeObject(person);
        } catch (IOException e) {
            e.printStackTrace();
        }
        
        // 读取对象
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("object.dat"))) {
            Person person = (Person) ois.readObject();
            System.out.println("Name: " + person.getName() + ", Age: " + person.getAge());
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}

// 可序列化的类
class Person implements Serializable {
    private String name;
    private int age;
    
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // getters and setters
    public String getName() { return name; }
    public int getAge() { return age; }
}
```

# 8 File类

## 8.1 文件和目录操作

```java
public class FileExample {
    public static void main(String[] args) {
        File file = new File("test.txt");
        
        // 检查文件是否存在
        if (file.exists()) {
            System.out.println("文件存在");
            System.out.println("文件大小: " + file.length() + " 字节");
            System.out.println("是否为文件: " + file.isFile());
            System.out.println("是否为目录: " + file.isDirectory());
        }
        
        // 创建目录
        File dir = new File("newDirectory");
        if (dir.mkdir()) {
            System.out.println("目录创建成功");
        }
        
        // 列出目录内容
        File currentDir = new File(".");
        File[] files = currentDir.listFiles();
        if (files != null) {
            for (File f : files) {
                System.out.println(f.getName() + (f.isDirectory() ? " [目录]" : " [文件]"));
            }
        }
    }
}
```

# 9 IO操作最佳实践

## 9.1 使用try-with-resources

```java
// 推荐：自动资源管理
try (FileInputStream fis = new FileInputStream("file.txt")) {
    // 使用流
} catch (IOException e) {
    // 异常处理
}

// 不推荐：手动关闭
FileInputStream fis = null;
try {
    fis = new FileInputStream("file.txt");
    // 使用流
} catch (IOException e) {
    // 异常处理
} finally {
    if (fis != null) {
        try {
            fis.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 9.2 选择合适的缓冲区大小

```java
// 根据文件大小选择合适的缓冲区
public static void copyFile(String source, String target) throws IOException {
    File sourceFile = new File(source);
    int bufferSize = (int) Math.min(sourceFile.length(), 8192);
    
    try (FileInputStream fis = new FileInputStream(source);
         FileOutputStream fos = new FileOutputStream(target)) {
        
        byte[] buffer = new byte[bufferSize];
        int bytesRead;
        while ((bytesRead = fis.read(buffer)) != -1) {
            fos.write(buffer, 0, bytesRead);
        }
    }
}
```

## 9.3 使用缓冲流提高性能

```java
// 对于大文件，使用缓冲流可以显著提高性能
public static void copyLargeFile(String source, String target) throws IOException {
    try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(source));
         BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(target))) {
        
        byte[] buffer = new byte[8192];
        int bytesRead;
        while ((bytesRead = bis.read(buffer)) != -1) {
            bos.write(buffer, 0, bytesRead);
        }
    }
}
```

# 10 装饰器模式在IO中的应用

Java IO流的设计使用了装饰器模式，通过组合不同的流类来实现功能的扩展：

```java
// 装饰器模式示例
InputStream fis = new FileInputStream("file.txt");           // 基础流
InputStream bis = new BufferedInputStream(fis);              // 缓冲装饰
InputStream gis = new GZIPInputStream(bis);                  // 解压装饰
InputStream dis = new DataInputStream(gis);                  // 数据装饰
```
