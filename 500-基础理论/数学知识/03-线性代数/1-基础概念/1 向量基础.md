# 向量基础

## 重点内容

本文档介绍向量的基本概念和性质，包括：
- 向量的定义和表示方法
- 向量的基本运算（加法、数乘）
- 向量的几何意义
- 向量的线性组合和线性相关性

## 1. 向量的定义

### 1.1 向量的概念

**向量**是具有大小和方向的量，在数学中通常用有序数组表示。

**定义**：n维向量是一个有序的n元组 $(a_1, a_2, \ldots, a_n)$，其中 $a_i$ 是实数。

**表示方法**：
- 列向量：$\mathbf{v} = \begin{pmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{pmatrix}$
- 行向量：$\mathbf{v} = (v_1, v_2, \ldots, v_n)$

### 1.2 向量的几何意义

在二维空间中，向量 $\mathbf{v} = (x, y)$ 表示从原点 $(0,0)$ 到点 $(x,y)$ 的有向线段。

在三维空间中，向量 $\mathbf{v} = (x, y, z)$ 表示从原点 $(0,0,0)$ 到点 $(x,y,z)$ 的有向线段。

## 2. 向量的基本运算

### 2.1 向量加法

**定义**：两个向量 $\mathbf{a} = (a_1, a_2, \ldots, a_n)$ 和 $\mathbf{b} = (b_1, b_2, \ldots, b_n)$ 的和为：
$$\mathbf{a} + \mathbf{b} = (a_1 + b_1, a_2 + b_2, \ldots, a_n + b_n)$$

**性质**：
- 交换律：$\mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}$
- 结合律：$(\mathbf{a} + \mathbf{b}) + \mathbf{c} = \mathbf{a} + (\mathbf{b} + \mathbf{c})$
- 零向量：存在零向量 $\mathbf{0}$，使得 $\mathbf{a} + \mathbf{0} = \mathbf{a}$

### 2.2 数乘运算

**定义**：向量 $\mathbf{a} = (a_1, a_2, \ldots, a_n)$ 与标量 $k$ 的数乘为：
$$k\mathbf{a} = (ka_1, ka_2, \ldots, ka_n)$$

**性质**：
- 分配律：$k(\mathbf{a} + \mathbf{b}) = k\mathbf{a} + k\mathbf{b}$
- 结合律：$(kl)\mathbf{a} = k(l\mathbf{a})$
- 单位元：$1\mathbf{a} = \mathbf{a}$

## 3. 向量的线性组合

### 3.1 线性组合的定义

**定义**：向量 $\mathbf{v}$ 是向量组 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\}$ 的线性组合，如果存在标量 $c_1, c_2, \ldots, c_k$，使得：
$$\mathbf{v} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k$$

### 3.2 线性相关性

**定义**：向量组 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\}$ 线性相关，如果存在不全为零的标量 $c_1, c_2, \ldots, c_k$，使得：
$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k = \mathbf{0}$$

**线性无关**：如果向量组不是线性相关的，则称其为线性无关。

## 4. 向量的范数

### 4.1 欧几里得范数

**定义**：向量 $\mathbf{v} = (v_1, v_2, \ldots, v_n)$ 的欧几里得范数（长度）为：
$$\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$$

### 4.2 单位向量

**定义**：长度为1的向量称为单位向量。

**单位化**：向量 $\mathbf{v}$ 的单位化向量为：
$$\hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|}$$

## 5. 向量的应用

### 5.1 物理学中的应用

- **力向量**：表示力的大小和方向
- **速度向量**：表示物体运动的速度和方向
- **位移向量**：表示物体位置的变化

### 5.2 计算机图形学中的应用

- **位置向量**：表示物体在空间中的位置
- **方向向量**：表示物体的朝向
- **法向量**：表示表面的法线方向
