# 伽马分布

## 重点

- **定义**：连续概率分布，描述多个独立指数分布随机变量和的分布
- **应用场景**：可靠性工程、排队论、金融风险、生物统计
- **数学性质**：两个参数（形状参数k、尺度参数θ）、可加性、再生性
- **与其他分布关系**：指数分布的特例、卡方分布的特例、威布尔分布的推广
- **参数意义**：形状参数控制分布形状，尺度参数控制分布尺度

## 伽马分布概念

伽马分布（Gamma Distribution）是连续概率分布的一种，它描述的是多个独立指数分布随机变量之和的分布。伽马分布具有两个参数：形状参数（shape parameter）和尺度参数（scale parameter），这使得它比指数分布更加灵活。

### 基本思想

伽马分布描述的是：等待k个独立事件发生所需时间的分布，其中每个事件的发生间隔服从指数分布。例如：
- 等待k个顾客到达的时间
- 设备发生k次故障所需的时间
- 完成k个任务所需的时间

## 数学定义

### 概率密度函数

伽马分布的概率密度函数为：

$$f(x) = \frac{x^{k-1} e^{-x/\theta}}{\theta^k \Gamma(k)}, \quad x > 0$$

其中：
- $k > 0$：形状参数（shape parameter）
- $\theta > 0$：尺度参数（scale parameter）
- $\Gamma(k)$：伽马函数，定义为 $\Gamma(k) = \int_0^{\infty} t^{k-1} e^{-t} dt$

### 参数说明

- **形状参数k**：控制分布的形状，k=1时为指数分布
- **尺度参数θ**：控制分布的尺度，影响分布的分散程度
- **伽马函数**：当k为正整数时，$\Gamma(k) = (k-1)!$

### 累积分布函数

伽马分布的累积分布函数为：

$$F(x) = \frac{\gamma(k, x/\theta)}{\Gamma(k)}$$

其中 $\gamma(k, x)$ 是不完全伽马函数：

$$\gamma(k, x) = \int_0^x t^{k-1} e^{-t} dt$$

## 分布性质

### 1. 基本性质

- **定义域**：$x > 0$（正实数）
- **形状**：当 $k < 1$ 时单调递减，当 $k > 1$ 时先增后减
- **峰值**：当 $k > 1$ 时，峰值位于 $x = (k-1)\theta$
- **渐近性**：$\lim_{x \to \infty} f(x) = 0$

### 2. 数字特征

- **期望值**：$E(X) = k\theta$
- **方差**：$Var(X) = k\theta^2$
- **标准差**：$\sigma = \sqrt{k}\theta$
- **偏度**：$\gamma_1 = \frac{2}{\sqrt{k}}$（右偏）
- **峰度**：$\gamma_2 = \frac{6}{k}$

### 3. 可加性（Additivity）

如果 $X_1 \sim Gamma(k_1, \theta)$ 和 $X_2 \sim Gamma(k_2, \theta)$ 独立，则：

$$X_1 + X_2 \sim Gamma(k_1 + k_2, \theta)$$

**解释**：形状参数相加，尺度参数保持不变。

### 4. 再生性（Reproductivity）

伽马分布具有再生性，即伽马分布随机变量的和仍服从伽马分布。

## 应用场景

### 1. 可靠性工程

**设备寿命分析**：
- 系统完成k个阶段所需的时间
- 设备经过k次维护后的寿命
- 多组件系统的故障时间

**示例**：
```python
# 某系统需要经过3个阶段才能完成，每个阶段时间服从指数分布
# 总时间服从Gamma(3, θ)分布
import numpy as np
k = 3  # 形状参数
theta = 10  # 尺度参数
total_time = np.random.gamma(k, theta, 1000)
```

### 2. 排队论

**服务系统分析**：
- 等待k个顾客到达的时间
- 完成k个服务任务的时间
- 系统状态转换的时间

### 3. 金融风险

**风险建模**：
- 股票价格跳跃的累积效应
- 信用风险的累积损失
- 投资组合的收益分布

### 4. 生物统计

**生存分析**：
- 疾病进展的时间模型
- 药物代谢的时间分布
- 生物过程的阶段时间

### 5. 信号处理

**噪声建模**：
- 雷达信号的强度分布
- 通信系统中的干扰
- 图像处理中的噪声

## 与其他分布的关系

### 1. 与指数分布的关系

指数分布是伽马分布的特例：
- 指数分布：$X \sim Exponential(\lambda)$
- 伽马分布：$X \sim Gamma(1, \frac{1}{\lambda})$

### 2. 与卡方分布的关系

卡方分布是伽马分布的特例：
- 卡方分布：$X \sim \chi^2(\nu)$
- 伽马分布：$X \sim Gamma(\frac{\nu}{2}, 2)$

### 3. 与正态分布的关系

当形状参数k很大时，伽马分布近似于正态分布：
$$Gamma(k, \theta) \approx N(k\theta, k\theta^2)$$

### 4. 与泊松分布的关系

伽马分布与泊松分布有重要关系：
- 如果事件的发生服从泊松过程
- 则等待k个事件发生的时间服从伽马分布

### 5. 与威布尔分布的关系

威布尔分布是伽马分布的推广，具有更灵活的分布形状。

## 参数估计

### 极大似然估计

对于样本 $x_1, x_2, \ldots, x_n$，伽马分布参数的极大似然估计需要数值方法求解：

**尺度参数**：
$$\hat{\theta} = \frac{\bar{x}}{\hat{k}}$$

**形状参数**：
$$\ln(\hat{k}) - \psi(\hat{k}) = \ln(\bar{x}) - \frac{1}{n}\sum_{i=1}^{n} \ln(x_i)$$

其中 $\psi(k)$ 是双伽马函数。

### 矩估计

**方法**：
1. 计算样本均值和样本方差
2. 利用期望和方差公式求解参数

**公式**：
$$\hat{k} = \frac{\bar{x}^2}{s^2}$$
$$\hat{\theta} = \frac{s^2}{\bar{x}}$$

## 实际计算示例

### 示例1：可靠性分析

**问题**：某设备需要经过3个阶段才能完成，每个阶段时间服从指数分布（λ=0.1），求总时间超过50的概率。

**解答**：
1. 总时间服从 $Gamma(3, 10)$ 分布
2. $P(X > 50) = 1 - F(50)$
3. 使用不完全伽马函数计算

### 示例2：期望和方差

**问题**：设 $X \sim Gamma(5, 2)$，求 $E(X)$ 和 $Var(X)$。

**解答**：
1. 期望：$E(X) = 5 \times 2 = 10$
2. 方差：$Var(X) = 5 \times 2^2 = 20$

### 示例3：可加性验证

**问题**：设 $X_1 \sim Gamma(2, 3)$ 和 $X_2 \sim Gamma(3, 3)$ 独立，求 $X_1 + X_2$ 的分布。

**解答**：
- $X_1 + X_2 \sim Gamma(5, 3)$
- 期望：$E(X_1 + X_2) = 5 \times 3 = 15$
- 方差：$Var(X_1 + X_2) = 5 \times 3^2 = 45$

### 示例4：形状参数的影响

**问题**：比较 $Gamma(1, 2)$、$Gamma(2, 2)$ 和 $Gamma(5, 2)$ 的分布形状。

**解答**：
- $k=1$：指数分布，单调递减
- $k=2$：单峰分布，峰值在 $x=2$
- $k=5$：更接近正态分布，峰值在 $x=8$
