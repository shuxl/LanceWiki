# 投影

## 重点内容

本文档介绍向量投影的核心概念，包括：
- 投影的定义和性质
- 投影的计算方法
- 投影的几何意义
- 投影的应用

## 1. 投影的定义

### 1.1 向量投影

**定义**：向量 $\mathbf{a}$ 在向量 $\mathbf{b}$ 上的投影定义为：
$$\text{proj}_{\mathbf{b}}\mathbf{a} = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|^2} \mathbf{b}$$

**几何意义**：投影向量是 $\mathbf{a}$ 在 $\mathbf{b}$ 方向上的分量。

### 1.2 投影的性质

**性质**：
- 投影向量与 $\mathbf{b}$ 平行
- 投影向量的长度：$\|\text{proj}_{\mathbf{b}}\mathbf{a}\| = \frac{|\mathbf{a} \cdot \mathbf{b}|}{\|\mathbf{b}\|}$
- 投影向量与 $\mathbf{b}$ 同向（当 $\mathbf{a} \cdot \mathbf{b} > 0$）或反向（当 $\mathbf{a} \cdot \mathbf{b} < 0$）
- $\mathbf{a} - \text{proj}_{\mathbf{b}}\mathbf{a}$ 与 $\mathbf{b}$ 正交

### 1.3 投影矩阵

**定义**：投影矩阵 $P$ 定义为：
$$P = \frac{\mathbf{b}\mathbf{b}^T}{\|\mathbf{b}\|^2}$$

**性质**：
- $P^2 = P$（幂等性）
- $P^T = P$（对称性）
- $\text{proj}_{\mathbf{b}}\mathbf{a} = P\mathbf{a}$

## 2. 投影的计算

### 2.1 直接计算

**步骤**：
1. 计算点积：$\mathbf{a} \cdot \mathbf{b}$
2. 计算 $\mathbf{b}$ 的平方长度：$\|\mathbf{b}\|^2$
3. 计算投影系数：$c = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|^2}$
4. 计算投影向量：$\text{proj}_{\mathbf{b}}\mathbf{a} = c\mathbf{b}$

**示例**：$\mathbf{a} = (1, 2, 3)$，$\mathbf{b} = (1, 0, 0)$
1. $\mathbf{a} \cdot \mathbf{b} = 1 \times 1 + 2 \times 0 + 3 \times 0 = 1$
2. $\|\mathbf{b}\|^2 = 1^2 + 0^2 + 0^2 = 1$
3. $c = \frac{1}{1} = 1$
4. $\text{proj}_{\mathbf{b}}\mathbf{a} = 1 \times (1, 0, 0) = (1, 0, 0)$

### 2.2 数值实现

**Python实现**：
```python
import numpy as np

def vector_projection(a, b):
    """计算向量a在向量b上的投影"""
    dot_product = np.dot(a, b)
    b_norm_squared = np.dot(b, b)
    
    if b_norm_squared == 0:
        raise ValueError("Cannot project onto zero vector")
    
    projection_coefficient = dot_product / b_norm_squared
    projection = projection_coefficient * b
    
    return projection

# 示例
a = np.array([1, 2, 3])
b = np.array([1, 0, 0])
proj = vector_projection(a, b)
print(f"Projection of {a} onto {b}: {proj}")
```

### 2.3 特殊情况

**零向量**：无法投影到零向量上。

**正交向量**：如果 $\mathbf{a}$ 与 $\mathbf{b}$ 正交，则投影为零向量。

**平行向量**：如果 $\mathbf{a}$ 与 $\mathbf{b}$ 平行，则投影等于 $\mathbf{a}$ 本身。

## 3. 投影的几何意义

### 3.1 二维投影

**几何解释**：在二维平面中，投影是向量 $\mathbf{a}$ 在直线 $\mathbf{b}$ 上的垂直投影。

**距离**：$\mathbf{a}$ 到直线 $\mathbf{b}$ 的距离为：
$$d = \|\mathbf{a} - \text{proj}_{\mathbf{b}}\mathbf{a}\|$$

### 3.2 三维投影

**几何解释**：在三维空间中，投影是向量 $\mathbf{a}$ 在直线 $\mathbf{b}$ 上的垂直投影。

**平面投影**：向量 $\mathbf{a}$ 在平面上的投影可以通过投影到平面的法向量来计算。

### 3.3 高维投影

**几何解释**：在高维空间中，投影仍然保持相同的几何意义。

**子空间投影**：可以投影到子空间，而不仅仅是直线。

## 4. 投影的应用

### 4.1 物理学应用

**力的分解**：将力向量分解为平行和垂直分量：
$$\mathbf{F} = \mathbf{F}_{\parallel} + \mathbf{F}_{\perp}$$

其中 $\mathbf{F}_{\parallel} = \text{proj}_{\mathbf{v}}\mathbf{F}$ 是平行分量。

**功的计算**：力沿位移做的功等于力在位移方向上的投影乘以位移长度：
$$W = \mathbf{F} \cdot \mathbf{s} = \|\text{proj}_{\mathbf{s}}\mathbf{F}\| \cdot \|\mathbf{s}\|$$

### 4.2 计算机图形学

**阴影计算**：物体的阴影是物体在光源方向上的投影。

**光照计算**：漫反射光照强度与表面法向量在光照方向上的投影相关。

**相机投影**：3D物体投影到2D屏幕上的过程。

### 4.3 机器学习

**特征选择**：通过投影到主成分方向进行特征降维。

**相似度计算**：使用投影计算向量之间的相似度。

**正则化**：通过投影到特定子空间进行正则化。

### 4.4 信号处理

**信号分解**：将信号分解为不同频率成分的投影。

**滤波**：通过投影到特定子空间进行信号滤波。

**压缩**：通过保留主要投影分量进行信号压缩。

## 5. 投影的扩展

### 5.1 子空间投影

**定义**：向量 $\mathbf{a}$ 在子空间 $S$ 上的投影是 $S$ 中与 $\mathbf{a}$ 最接近的向量。

**计算方法**：
1. 找到子空间 $S$ 的正交基 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\}$
2. 计算投影：$\text{proj}_S\mathbf{a} = \sum_{i=1}^{k} \frac{\mathbf{a} \cdot \mathbf{v}_i}{\|\mathbf{v}_i\|^2} \mathbf{v}_i$

### 5.2 正交投影

**定义**：正交投影是投影到子空间的正交补空间。

**性质**：正交投影与子空间投影的和等于原向量。

### 5.3 斜投影

**定义**：斜投影是投影到非正交方向。

**应用**：在斜坐标系中的投影计算。

## 6. 投影矩阵的性质

### 6.1 基本性质

**性质**：
- $P^2 = P$（幂等性）
- $P^T = P$（对称性）
- $\text{rank}(P) = 1$（对于向量投影）
- $\text{tr}(P) = 1$（对于向量投影）

### 6.2 子空间投影矩阵

**定义**：对于子空间 $S$ 的正交基矩阵 $V$，投影矩阵为：
$$P = V(V^TV)^{-1}V^T$$

**性质**：
- $P^2 = P$
- $P^T = P$
- $\text{rank}(P) = \dim(S)$

### 6.3 投影矩阵的应用

**最小二乘**：线性回归中的投影矩阵用于计算最小二乘解。

**数据压缩**：通过投影矩阵进行数据降维。

**信号处理**：使用投影矩阵进行信号滤波。

## 7. 投影的数值稳定性

### 7.1 条件数

**问题**：当投影方向接近零向量时，投影计算可能数值不稳定。

**解决方案**：
- 检查投影方向的长度
- 使用正交化方法
- 使用SVD分解

### 7.2 正交化

**Gram-Schmidt正交化**：通过正交化过程计算投影。

**QR分解**：使用QR分解计算投影矩阵。
