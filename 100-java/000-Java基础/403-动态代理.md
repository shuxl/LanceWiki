## 1.1 什么是动态代理

动态代理（Dynamic Proxy）是Java中一种在运行时动态创建代理类的机制，它允许在不修改原有代码的情况下，为接口或类添加额外的功能，如日志记录、事务管理、权限控制等。

## 1.2 动态代理的优势

1. **灵活性**：运行时动态创建代理，无需手动编写代理类
2. **解耦**：代理逻辑与业务逻辑分离
3. **可扩展性**：可以轻松添加或移除代理功能
4. **代码复用**：一个代理类可以代理多个目标对象

## 2.2 InvocationHandler 接口

```java
public interface InvocationHandler {
    /**
     * 代理对象的方法调用都会转发到这里
     * @param proxy 代理对象
     * @param method 被调用的方法
     * @param args 方法参数
     * @return 方法返回值
     */
    Object invoke(Object proxy, Method method, Object[] args) throws Throwable;
}
```

# 3 JDK动态代理

## 3.1 基本实现

```java
// 1. 定义接口
public interface UserService {
    void addUser(String name);
    String getUser(String id);
}

// 2. 实现类
public class UserServiceImpl implements UserService {
    @Override
    public void addUser(String name) {
        System.out.println("添加用户: " + name);
    }
    
    @Override
    public String getUser(String id) {
        System.out.println("获取用户: " + id);
        return "User-" + id;
    }
}

// 3. 代理处理器
public class LoggingInvocationHandler implements InvocationHandler {
    private final Object target;
    
    public LoggingInvocationHandler(Object target) {
        this.target = target;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        // 前置处理
        System.out.println("方法调用前: " + method.getName());
        long startTime = System.currentTimeMillis();
        
        try {
            // 调用目标方法
            Object result = method.invoke(target, args);
            
            // 后置处理
            long endTime = System.currentTimeMillis();
            System.out.println("方法调用后: " + method.getName() + 
                             ", 耗时: " + (endTime - startTime) + "ms");
            
            return result;
        } catch (Exception e) {
            // 异常处理
            System.out.println("方法调用异常: " + method.getName() + ", 异常: " + e.getMessage());
            throw e;
        }
    }
}

// 4. 使用动态代理
public class DynamicProxyDemo {
    public static void main(String[] args) {
        UserService userService = new UserServiceImpl();
        
        // 创建代理对象
        UserService proxy = (UserService) Proxy.newProxyInstance(
            UserService.class.getClassLoader(),
            new Class<?>[] { UserService.class },
            new LoggingInvocationHandler(userService)
        );
        
        // 调用代理方法
        proxy.addUser("张三");
        proxy.getUser("001");
    }
}
```

## 3.2 代理类生成原理

JDK动态代理通过以下步骤生成代理类：

1. **生成代理类字节码**：在内存中生成代理类的字节码
2. **定义代理类**：使用 `ClassLoader` 加载代理类
3. **创建代理对象**：通过反射创建代理对象实例

```java
// 代理类的简化结构
public final class $Proxy0 extends Proxy implements UserService {
    private InvocationHandler h;
    
    public $Proxy0(InvocationHandler h) {
        super(h);
        this.h = h;
    }
    
    @Override
    public void addUser(String name) {
        try {
            Method method = UserService.class.getMethod("addUser", String.class);
            h.invoke(this, method, new Object[] { name });
        } catch (Throwable e) {
            throw new RuntimeException(e);
        }
    }
    
    @Override
    public String getUser(String id) {
        try {
            Method method = UserService.class.getMethod("getUser", String.class);
            return (String) h.invoke(this, method, new Object[] { id });
        } catch (Throwable e) {
            throw new RuntimeException(e);
        }
    }
}
```

# 5 JDK动态代理 vs CGLIB动态代理

| 特性 | JDK动态代理 | CGLIB动态代理 |
|------|-------------|---------------|
| 代理对象 | 接口 | 类 |
| 性能 | 较慢 | 较快 |
| 依赖 | JDK自带 | 需要额外依赖 |
| 限制 | 只能代理接口 | 不能代理final类和方法 |
| 生成方式 | 运行时生成字节码 | 运行时生成字节码 |

# 6 实际应用场景

## 6.1 AOP（面向切面编程）

```java
// 事务代理
public class TransactionInvocationHandler implements InvocationHandler {
    private final Object target;
    
    public TransactionInvocationHandler(Object target) {
        this.target = target;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        Connection conn = null;
        try {
            // 开启事务
            conn = getConnection();
            conn.setAutoCommit(false);
            
            // 调用目标方法
            Object result = method.invoke(target, args);
            
            // 提交事务
            conn.commit();
            return result;
        } catch (Exception e) {
            // 回滚事务
            if (conn != null) {
                conn.rollback();
            }
            throw e;
        } finally {
            // 关闭连接
            if (conn != null) {
                conn.close();
            }
        }
    }
}
```

## 6.2 远程调用代理

```java
// RPC代理
public class RpcInvocationHandler implements InvocationHandler {
    private final String host;
    private final int port;
    
    public RpcInvocationHandler(String host, int port) {
        this.host = host;
        this.port = port;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        // 序列化请求
        RpcRequest request = new RpcRequest();
        request.setClassName(method.getDeclaringClass().getName());
        request.setMethodName(method.getName());
        request.setParameters(args);
        
        // 发送网络请求
        RpcResponse response = sendRequest(request);
        
        // 反序列化响应
        return response.getResult();
    }
}
```

## 6.3 缓存代理

```java
// 缓存代理
public class CacheInvocationHandler implements InvocationHandler {
    private final Object target;
    private final Map<String, Object> cache = new ConcurrentHashMap<>();
    
    public CacheInvocationHandler(Object target) {
        this.target = target;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        // 生成缓存键
        String cacheKey = generateCacheKey(method, args);
        
        // 检查缓存
        if (cache.containsKey(cacheKey)) {
            return cache.get(cacheKey);
        }
        
        // 调用目标方法
        Object result = method.invoke(target, args);
        
        // 存入缓存
        cache.put(cacheKey, result);
        
        return result;
    }
    
    private String generateCacheKey(Method method, Object[] args) {
        StringBuilder key = new StringBuilder();
        key.append(method.getDeclaringClass().getName());
        key.append(".").append(method.getName());
        for (Object arg : args) {
            key.append(".").append(arg);
        }
        return key.toString();
    }
}
```

# 7 高级特性

## 7.1 代理链

```java
public class ProxyChain {
    private final List<InvocationHandler> handlers;
    private final Object target;
    private int currentIndex = 0;
    
    public ProxyChain(Object target, List<InvocationHandler> handlers) {
        this.target = target;
        this.handlers = handlers;
    }
    
    public Object proceed(Method method, Object[] args) throws Throwable {
        if (currentIndex >= handlers.size()) {
            // 调用目标方法
            return method.invoke(target, args);
        }
        
        InvocationHandler handler = handlers.get(currentIndex++);
        return handler.invoke(this, method, args);
    }
}
```

## 7.3 性能监控

```java
public class PerformanceMonitorInvocationHandler implements InvocationHandler {
    private final Object target;
    private final Map<String, Long> methodCallCount = new ConcurrentHashMap<>();
    private final Map<String, Long> methodTotalTime = new ConcurrentHashMap<>();
    
    public PerformanceMonitorInvocationHandler(Object target) {
        this.target = target;
    }
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        long startTime = System.nanoTime();
        
        try {
            return method.invoke(target, args);
        } finally {
            long endTime = System.nanoTime();
            long duration = endTime - startTime;
            
            String methodName = method.getName();
            methodCallCount.merge(methodName, 1L, Long::sum);
            methodTotalTime.merge(methodName, duration, Long::sum);
        }
    }
    
    public void printStatistics() {
        System.out.println("方法调用统计:");
        for (String methodName : methodCallCount.keySet()) {
            long count = methodCallCount.get(methodName);
            long totalTime = methodTotalTime.get(methodName);
            double avgTime = (double) totalTime / count;
            System.out.printf("%s: 调用次数=%d, 平均耗时=%.2f纳秒%n", 
                            methodName, count, avgTime);
        }
    }
}
```

# 8 最佳实践

## 8.1 性能优化

- 缓存代理类，避免重复生成
- 合理使用代理链，避免过度嵌套
- 在不需要代理的场景下避免使用动态代理

## 8.2 错误处理

- 在 `InvocationHandler` 中妥善处理异常
- 提供有意义的错误信息
- 考虑异常传播的影响

## 8.3 内存管理

- 及时清理不再使用的代理对象
- 避免在代理对象中持有大量数据
- 注意代理对象的生命周期管理

## 9.1 代理对象识别

```java
public class ProxyUtils {
    public static boolean isProxy(Object obj) {
        return Proxy.isProxyClass(obj.getClass());
    }
    
    public static InvocationHandler getInvocationHandler(Object proxy) {
        if (!isProxy(proxy)) {
            throw new IllegalArgumentException("不是代理对象");
        }
        return Proxy.getInvocationHandler(proxy);
    }
    
    public static Class<?> getTargetClass(Object proxy) {
        if (!isProxy(proxy)) {
            return proxy.getClass();
        }
        
        InvocationHandler handler = getInvocationHandler(proxy);
        if (handler instanceof TargetAware) {
            return ((TargetAware) handler).getTargetClass();
        }
        
        return null;
    }
}
```

## 10.2 循环代理问题

```java
// 解决方案：检查代理链
public class CycleDetectionInvocationHandler implements InvocationHandler {
    private final Object target;
    private final ThreadLocal<Set<Object>> callStack = new ThreadLocal<>();
    
    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        Set<Object> stack = callStack.get();
        if (stack == null) {
            stack = new HashSet<>();
            callStack.set(stack);
        }
        
        if (stack.contains(target)) {
            throw new IllegalStateException("检测到循环代理调用");
        }
        
        stack.add(target);
        try {
            return method.invoke(target, args);
        } finally {
            stack.remove(target);
        }
    }
}
```

# 11 动态代理关联的其它知识

## 11.1 与静态代理的关系

动态代理和静态代理都是代理模式的实现：
- **静态代理**：编译时确定代理类，需要手动编写
- **动态代理**：运行时生成代理类，自动创建

参考：[Java 静态代理](../old/100-Java基础-old/代理/Java%20静态代理.md)

## 11.2 与反射的关系

动态代理基于反射机制实现：
- **反射**：提供运行时访问类信息的能力
- **动态代理**：利用反射实现方法调用拦截

参考：[java 反射杂谈](../old/100-Java基础-old/反射/java%20反射杂谈.md)
