# 2 Java基础概念

## 2.1 Java的特点和优势

**Q: Java语言有哪些特点？**

A: Java语言具有以下特点：
- **面向对象**：支持封装、继承、多态
- **平台无关性**：一次编写，到处运行（Write Once, Run Anywhere）
- **安全性**：强类型检查、自动内存管理、异常处理
- **多线程**：内置多线程支持
- **动态性**：反射机制、动态加载
- **垃圾回收**：自动内存管理

## 2.2 JDK、JRE、JVM的关系

**Q: 请解释JDK、JRE、JVM三者的关系？**

A: 
- **JVM（Java Virtual Machine）**：Java虚拟机，负责执行字节码
- **JRE（Java Runtime Environment）**：Java运行环境，包含JVM和运行Java程序所需的核心类库
- **JDK（Java Development Kit）**：Java开发工具包，包含JRE和开发工具（编译器、调试器等）

关系：JDK ⊃ JRE ⊃ JVM

## 2.3 Java的数据类型

**Q: Java有哪些基本数据类型？**

A: Java有8种基本数据类型：
- **整数类型**：byte(8位)、short(16位)、int(32位)、long(64位)
- **浮点类型**：float(32位)、double(64位)
- **字符类型**：char(16位)
- **布尔类型**：boolean

**Q: 基本数据类型和包装类的区别？**

A: 
- **基本数据类型**：直接存储数据值，效率高
- **包装类**：对象形式，可以调用方法，支持null值
- **自动装箱/拆箱**：Java 5引入，自动转换基本类型和包装类

# 3 面向对象编程

## 3.1 面向对象的三大特性

**Q: 什么是封装、继承、多态？**

A: 
- **封装**：将数据和方法绑定在一起，隐藏内部实现细节
- **继承**：子类继承父类的属性和方法，实现代码复用
- **多态**：同一个接口，不同的实现方式（编译时多态、运行时多态）

## 3.2 抽象类和接口

**Q: 抽象类和接口的区别？**

A:

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 构造方法 | 可以有 | 不能有 |
| 方法实现 | 可以有具体方法 | Java 8前只能有抽象方法 |
| 访问修饰符 | 任意 | 默认public abstract |
| 继承 | 单继承 | 多实现 |
| 成员变量 | 任意 | 默认public static final |

## 3.3 重载和重写

**Q: 方法重载和重写的区别？**

A: 
- **重载（Overload）**：同一类中，方法名相同，参数不同
- **重写（Override）**：子类重写父类方法，方法签名相同

**重写规则**：
- 访问权限不能比父类更严格
- 返回类型相同或是子类
- 异常不能比父类更宽泛

# 4 Java集合框架

## 4.1 集合框架的层次结构

**Q: Java集合框架的主要接口和实现类？**

A: 
- **Collection接口**：
  - List：ArrayList、LinkedList、Vector
  - Set：HashSet、TreeSet、LinkedHashSet
  - Queue：LinkedList、PriorityQueue
- **Map接口**：HashMap、TreeMap、LinkedHashMap、Hashtable

## 4.2 ArrayList和LinkedList

**Q: ArrayList和LinkedList的区别？**

A: 
- **ArrayList**：基于动态数组，随机访问快，插入删除慢
- **LinkedList**：基于双向链表，插入删除快，随机访问慢

详细对比请参考：[ArrayList 和 LinkedList 的性能差异](../001-Java扩展/ArrayList%20和%20LinkedList%20的性能差异.md)

## 4.3 HashMap原理

**Q: HashMap的底层实现原理？**

A: 
- **JDK 1.8前**：数组+链表
- **JDK 1.8后**：数组+链表+红黑树（链表长度>8时转换）
- **扩容机制**：负载因子0.75，容量翻倍
- **哈希冲突**：拉链法解决
	- **拉链法的核心思想是：** 将每个哈希桶（哈希数组的每个元素）设计为一个链表（或者链表+树结构），**所有哈希值相同的元素都放到这个链表中**。

# 5 异常处理

## 5.1 异常分类

**Q: Java异常体系是怎样的？**

A: 
- **Throwable**：所有异常的父类
	- **Error**：系统错误，不可恢复。OutOfMemoryError、StackOverflowError、NoClassDefFoundError、UnknownError
	- **Exception**：程序异常，可处理
	    - **RuntimeException**：运行时异常。NullPointerException、ArrayIndexOutOfBoundsException、等
	    - **Checked Exception**：检查异常，必须显式 throws 或用 try-catch 捕获，否则编译报错。IOException、SQLException、ClassNotFoundException、等

## 5.2 异常处理机制

**Q: try-catch-finally的执行顺序？**

A: 
1. 执行try块
2. 如果发生异常，执行catch块
3. 无论是否发生异常，都执行finally块
4. 如果finally中有return，会覆盖try/catch中的return

# 6 Java内存模型

## 6.1 JVM内存结构

**Q: JVM内存分为哪些区域？**

A: 
- **堆（Heap）**：存储对象实例，垃圾回收主要区域
- **方法区（Method Area）**：存储类信息、常量、静态变量
- **虚拟机栈（VM Stack）**：存储局部变量、方法调用
- **本地方法栈（Native Method Stack）**：本地方法调用
- **程序计数器（Program Counter Register）**：当前线程执行字节码的行号

## 6.2 垃圾回收机制

**Q: 垃圾回收算法有哪些？**

A: 
- **标记-清除**：标记垃圾对象，然后清除
- **复制算法**：将内存分为两块，复制存活对象
- **标记-整理**：标记后整理内存碎片
- **分代收集**：新生代用复制算法，老年代用标记-整理

# 7 多线程编程

## 7.1 线程创建方式

**Q: 创建线程有几种方式？**

A: 
1. **继承Thread类**
2. **实现Runnable接口**
3. **实现Callable接口**（有返回值）
4. **使用线程池**

## 7.2 线程同步

**Q: 如何实现线程同步？**

A: 
- **synchronized关键字**：方法同步、代码块同步
- **ReentrantLock**：可重入锁，更灵活
- **volatile关键字**：保证可见性，不保证原子性
- **Atomic类**：原子操作类

## 7.3 线程池

**Q: 线程池的核心参数有哪些？**

A: 
- **corePoolSize**：核心线程数
- **maximumPoolSize**：最大线程数
- **keepAliveTime**：线程空闲时间
- **workQueue**：工作队列
- **threadFactory**：线程工厂
- **handler**：拒绝策略

# 8 Java I/O

## 8.1 I/O流分类

**Q: Java I/O流有哪些分类？**

A: 
- **按流向**：输入流、输出流
- **按单位**：字节流、字符流
- **按功能**：节点流、处理流

## 8.2 NIO

**Q: NIO与传统I/O的区别？**

A: 
- **传统I/O**：面向流，阻塞I/O
- **NIO**：面向缓冲区，非阻塞I/O，支持多路复用

# 10 注解和泛型

## 10.1 注解

**Q: Java注解的作用和分类？**

A: 
- **编译时注解**：@Override、@Deprecated
- **运行时注解**：@Test、@Autowired
- **元注解**：@Target、@Retention、@Documented、@Inherited

## 10.2 泛型

**Q: 泛型的作用和擦除机制？**

A: 
- **作用**：类型安全，避免类型转换
- **擦除**：编译时擦除类型信息，运行时无泛型信息
- **限制**：不能创建泛型数组，不能使用基本类型

# 11 常见面试题

## 11.1 String相关

**Q: String、StringBuilder、StringBuffer的区别？**

A: 
- **String**：不可变，线程安全
- **StringBuilder**：可变，非线程安全，性能最好
- **StringBuffer**：可变，线程安全，性能次之

## 11.2 设计模式

**Q: 常用的设计模式有哪些？**

A: 
- **创建型**：单例、工厂、建造者
- **结构型**：代理、装饰器、适配器
- **行为型**：观察者、策略、模板方法

## 11.3 性能优化

**Q: Java性能优化的方法有哪些？**

A: 
- **JVM调优**：堆内存、垃圾回收器选择
- **代码优化**：避免创建过多对象、使用StringBuilder
- **算法优化**：选择合适的数据结构和算法
- **并发优化**：使用线程池、避免锁竞争
