# 2 AOP切面类型概念或介绍

## 2.1 切面类型概述
Spring AOP中的切面类型主要基于通知（Advice）的类型来分类。通知定义了"何时"执行横切关注点，是AOP的核心概念之一。根据执行时机的不同，Spring AOP提供了五种主要的通知类型。

## 2.2 切面设计原则
- **单一职责**：每个切面只负责一个横切关注点
- **可复用性**：切面应该能够在多个模块中复用
- **可配置性**：切面的行为应该可以通过配置进行调整
- **性能考虑**：切面的执行不应该显著影响系统性能

# 3 通知类型详解

## 3.1 前置通知（@Before）

### 3.1.1 定义和特点
前置通知在目标方法执行之前执行，是最常用的通知类型之一。

```java
@Aspect
@Component
public class LoggingAspect {
    
    @Before("execution(* com.example.service.*.*(..))")
    public void beforeAdvice(JoinPoint joinPoint) {
        String methodName = joinPoint.getSignature().getName();
        String className = joinPoint.getTarget().getClass().getSimpleName();
        System.out.println("【前置通知】执行方法：" + className + "." + methodName);
        
        // 获取方法参数
        Object[] args = joinPoint.getArgs();
        System.out.println("【前置通知】方法参数：" + Arrays.toString(args));
    }
}
```

### 3.1.2 使用场景
- **日志记录**：记录方法调用的开始
- **参数验证**：在方法执行前验证参数
- **权限检查**：检查用户是否有权限执行该方法
- **性能监控**：记录方法开始执行的时间

```java
@Aspect
@Component
public class SecurityAspect {
    
    @Before("@annotation(secured)")
    public void checkPermission(JoinPoint joinPoint, Secured secured) {
        String[] roles = secured.roles();
        String currentUser = getCurrentUser();
        
        if (!hasRole(currentUser, roles)) {
            throw new SecurityException("用户 " + currentUser + " 没有权限执行此操作");
        }
    }
}
```

## 3.2 后置通知（@AfterReturning）

### 3.2.1 定义和特点
后置通知在目标方法成功执行后执行，可以获取方法的返回值。

```java
@Aspect
@Component
public class LoggingAspect {
    
    @AfterReturning(
        pointcut = "execution(* com.example.service.*.*(..))",
        returning = "result"
    )
    public void afterReturningAdvice(JoinPoint joinPoint, Object result) {
        String methodName = joinPoint.getSignature().getName();
        System.out.println("【后置通知】方法 " + methodName + " 执行成功，返回值：" + result);
    }
}
```

### 3.2.2 使用场景
- **结果日志**：记录方法的执行结果
- **数据转换**：对方法返回值进行转换
- **缓存更新**：更新缓存数据
- **统计信息**：统计方法执行的成功次数

```java
@Aspect
@Component
public class CacheAspect {
    
    @AfterReturning(
        pointcut = "execution(* com.example.service.UserService.findById(..))",
        returning = "user"
    )
    public void updateCache(JoinPoint joinPoint, User user) {
        if (user != null) {
            String cacheKey = "user:" + user.getId();
            cacheManager.put(cacheKey, user);
        }
    }
}
```

## 3.3 异常通知（@AfterThrowing）

### 3.3.1 定义和特点
异常通知在目标方法抛出异常时执行，可以获取异常信息。

```java
@Aspect
@Component
public class ExceptionAspect {
    
    @AfterThrowing(
        pointcut = "execution(* com.example.service.*.*(..))",
        throwing = "ex"
    )
    public void afterThrowingAdvice(JoinPoint joinPoint, Exception ex) {
        String methodName = joinPoint.getSignature().getName();
        String className = joinPoint.getTarget().getClass().getSimpleName();
        
        System.err.println("【异常通知】方法 " + className + "." + methodName + " 抛出异常：" + ex.getMessage());
        
        // 记录异常日志
        logger.error("方法执行异常", ex);
        
        // 发送异常通知
        sendExceptionNotification(methodName, ex);
    }
}
```

### 3.3.2 使用场景
- **异常日志**：记录异常信息
- **异常处理**：统一处理异常
- **错误通知**：发送错误通知
- **降级处理**：提供降级方案

```java
@Aspect
@Component
public class CircuitBreakerAspect {
    
    @AfterThrowing(
        pointcut = "execution(* com.example.service.ExternalService.*(..))",
        throwing = "ex"
    )
    public void handleExternalServiceException(JoinPoint joinPoint, Exception ex) {
        // 记录失败次数
        String serviceName = joinPoint.getSignature().getDeclaringType().getSimpleName();
        circuitBreaker.recordFailure(serviceName);
        
        // 如果失败次数过多，触发熔断
        if (circuitBreaker.shouldOpen(serviceName)) {
            circuitBreaker.open(serviceName);
        }
    }
}
```

## 3.4 最终通知（@After）

### 3.4.1 定义和特点
最终通知无论目标方法是否成功执行都会执行，类似于try-finally块。

```java
@Aspect
@Component
public class ResourceAspect {
    
    @After("execution(* com.example.service.*.*(..))")
    public void afterAdvice(JoinPoint joinPoint) {
        String methodName = joinPoint.getSignature().getName();
        System.out.println("【最终通知】方法 " + methodName + " 执行完成");
        
        // 清理资源
        cleanupResources();
    }
}
```

### 3.4.2 使用场景
- **资源清理**：清理临时资源
- **连接关闭**：关闭数据库连接
- **锁释放**：释放分布式锁
- **统计信息**：记录方法执行次数

```java
@Aspect
@Component
public class LockAspect {
    
    @After("@annotation(distributedLock)")
    public void releaseLock(JoinPoint joinPoint, DistributedLock distributedLock) {
        String lockKey = distributedLock.key();
        try {
            // 释放分布式锁
            lockManager.releaseLock(lockKey);
        } catch (Exception e) {
            logger.error("释放锁失败：" + lockKey, e);
        }
    }
}
```

## 3.5 环绕通知（@Around）

### 3.5.1 定义和特点
环绕通知包围目标方法的执行，可以完全控制目标方法的执行。

```java
@Aspect
@Component
public class PerformanceAspect {
    
    @Around("execution(* com.example.service.*.*(..))")
    public Object aroundAdvice(ProceedingJoinPoint joinPoint) throws Throwable {
        String methodName = joinPoint.getSignature().getName();
        long startTime = System.currentTimeMillis();
        
        try {
            // 执行目标方法
            Object result = joinPoint.proceed();
            
            long endTime = System.currentTimeMillis();
            System.out.println("【环绕通知】方法 " + methodName + " 执行时间：" + (endTime - startTime) + "ms");
            
            return result;
        } catch (Exception e) {
            long endTime = System.currentTimeMillis();
            System.err.println("【环绕通知】方法 " + methodName + " 执行异常，耗时：" + (endTime - startTime) + "ms");
            throw e;
        }
    }
}
```

### 3.5.2 使用场景
- **性能监控**：监控方法执行时间
- **事务管理**：控制事务的开始和提交
- **缓存管理**：实现缓存逻辑
- **重试机制**：实现方法重试

```java
@Aspect
@Component
public class CacheAspect {
    
    @Around("@annotation(cacheable)")
    public Object cacheAround(ProceedingJoinPoint joinPoint, Cacheable cacheable) throws Throwable {
        String cacheKey = generateCacheKey(joinPoint, cacheable);
        
        // 尝试从缓存获取
        Object cachedValue = cacheManager.get(cacheKey);
        if (cachedValue != null) {
            return cachedValue;
        }
        
        // 执行目标方法
        Object result = joinPoint.proceed();
        
        // 将结果放入缓存
        if (result != null) {
            cacheManager.put(cacheKey, result, cacheable.expire());
        }
        
        return result;
    }
}
```

# 5 通知执行顺序

## 5.1 执行顺序规则
Spring AOP中通知的执行顺序遵循以下规则：
1. **环绕通知的前半部分**
2. **前置通知**
3. **目标方法执行**
4. **后置通知**
5. **环绕通知的后半部分**
6. **最终通知**
7. **异常通知**（如果发生异常）

## 5.2 优先级控制
```java
@Aspect
@Component
@Order(1)  // 数字越小，优先级越高
public class SecurityAspect {
    // 安全相关的切面，优先级最高
}

@Aspect
@Component
@Order(5)
public class LoggingAspect {
    // 日志相关的切面，中等优先级
}

@Aspect
@Component
@Order(10)
public class StatisticsAspect {
    // 统计相关的切面，优先级最低
}
```

## 5.3 切面内部顺序
```java
@Aspect
@Component
public class ComprehensiveAspect {
    
    @Before("execution(* com.example.service.*.*(..))")
    public void beforeAdvice1() {
        System.out.println("前置通知1");
    }
    
    @Before("execution(* com.example.service.*.*(..))")
    public void beforeAdvice2() {
        System.out.println("前置通知2");
    }
    
    // 同一类型的通知按方法名排序执行
}
```

# 6 切面类型的最佳实践

## 6.1 切面设计原则
- **单一职责**：每个切面只负责一个关注点
- **可配置性**：通过注解或配置控制切面行为
- **性能考虑**：避免在切面中执行耗时操作
- **异常处理**：在切面中正确处理异常

## 6.2 切点表达式优化
```java
// 好的切点表达式
@Pointcut("execution(* com.example.service.*.*(..))")
public void serviceLayer() {}

@Pointcut("execution(* com.example.controller.*.*(..))")
public void controllerLayer() {}

// 避免过于复杂的切点表达式
@Pointcut("execution(* com.example.*.*.*(..)) && !execution(* com.example.util.*.*(..))")
public void complexPointcut() {}
```

## 6.3 通知方法设计
```java
@Aspect
@Component
public class BestPracticeAspect {
    
    // 使用JoinPoint获取上下文信息
    @Before("serviceLayer()")
    public void beforeAdvice(JoinPoint joinPoint) {
        String methodName = joinPoint.getSignature().getName();
        String className = joinPoint.getTarget().getClass().getSimpleName();
        Object[] args = joinPoint.getArgs();
        
        // 记录详细的上下文信息
        logger.info("执行方法：{}.{}，参数：{}", className, methodName, Arrays.toString(args));
    }
    
    // 使用ProceedingJoinPoint控制方法执行
    @Around("serviceLayer()")
    public Object aroundAdvice(ProceedingJoinPoint joinPoint) throws Throwable {
        try {
            return joinPoint.proceed();
        } catch (Exception e) {
            // 处理异常
            logger.error("方法执行异常", e);
            throw e;
        }
    }
}
```
