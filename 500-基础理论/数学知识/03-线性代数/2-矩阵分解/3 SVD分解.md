# SVD分解

## 重点内容

本文档介绍奇异值分解（SVD）的核心概念，包括：
- SVD分解的定义和性质
- SVD分解的计算方法
- SVD分解的几何意义
- SVD分解的应用

## 1. SVD分解的定义

### 1.1 基本定义

**定义**：对于任意m×n矩阵 $A$，存在分解：
$$A = U\Sigma V^T$$

其中：
- $U$ 是m×m正交矩阵（$U^TU = I$）
- $\Sigma$ 是m×n对角矩阵，对角元素 $\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r \geq 0$，$r = \min(m,n)$
- $V$ 是n×n正交矩阵（$V^TV = I$）

### 1.2 奇异值

**定义**：$\Sigma$ 的对角元素 $\sigma_1, \sigma_2, \ldots, \sigma_r$ 称为矩阵 $A$ 的**奇异值**。

**性质**：
- 奇异值是非负实数
- 奇异值按降序排列：$\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r \geq 0$
- 非零奇异值的个数等于矩阵的秩

### 1.3 左右奇异向量

**定义**：
- $U$ 的列向量称为**左奇异向量**
- $V$ 的列向量称为**右奇异向量**

**关系**：
- $A\mathbf{v}_i = \sigma_i \mathbf{u}_i$（$i = 1, 2, \ldots, r$）
- $A^T\mathbf{u}_i = \sigma_i \mathbf{v}_i$（$i = 1, 2, \ldots, r$）

## 2. SVD分解的性质

### 2.1 基本性质

**性质**：
- $A^TA = V\Sigma^T\Sigma V^T$，$AA^T = U\Sigma\Sigma^T U^T$
- $A^TA$ 的特征值是 $\sigma_i^2$，特征向量是 $V$ 的列向量
- $AA^T$ 的特征值是 $\sigma_i^2$，特征向量是 $U$ 的列向量
- $\|A\|_2 = \sigma_1$（矩阵的2范数等于最大奇异值）
- $\|A\|_F = \sqrt{\sigma_1^2 + \sigma_2^2 + \cdots + \sigma_r^2}$（Frobenius范数）

### 2.2 矩阵的秩

**定理**：矩阵 $A$ 的秩等于非零奇异值的个数。

**推论**：如果 $\sigma_k > 0$ 且 $\sigma_{k+1} = 0$，则 $rank(A) = k$。

### 2.3 伪逆

**定义**：矩阵 $A$ 的伪逆定义为：
$$A^+ = V\Sigma^+ U^T$$

其中 $\Sigma^+$ 是将 $\Sigma$ 的非零对角元素取倒数得到的对角矩阵。

## 3. SVD分解的计算

### 3.1 基本算法

**步骤**：
1. 计算 $A^TA$ 和 $AA^T$
2. 求 $A^TA$ 的特征值和特征向量
3. 奇异值 $\sigma_i = \sqrt{\lambda_i}$（$\lambda_i$ 是 $A^TA$ 的特征值）
4. 右奇异向量是 $A^TA$ 的特征向量
5. 左奇异向量通过 $A\mathbf{v}_i = \sigma_i \mathbf{u}_i$ 计算

### 3.2 数值算法

**QR算法**：使用QR分解和Householder变换的迭代算法。

**分治算法**：将大矩阵分解为小矩阵，分别计算SVD。

**随机算法**：对于大矩阵，使用随机投影加速计算。

## 4. SVD分解的几何意义

### 4.1 线性变换的分解

SVD分解将任意线性变换分解为：
1. **旋转/反射**（$V^T$）：将输入向量旋转到标准坐标系
2. **缩放**（$\Sigma$）：沿各坐标轴进行缩放
3. **旋转/反射**（$U$）：将结果旋转到输出坐标系

### 4.2 最佳低秩近似

**定理**（Eckart-Young）：对于矩阵 $A$ 的SVD分解 $A = U\Sigma V^T$，最佳k秩近似为：
$$A_k = U_k \Sigma_k V_k^T$$

其中 $U_k$ 是 $U$ 的前k列，$\Sigma_k$ 是 $\Sigma$ 的k×k子矩阵，$V_k$ 是 $V$ 的前k列。

## 5. SVD分解的应用

### 5.1 数据压缩

**图像压缩**：将图像矩阵进行SVD分解，保留前k个奇异值进行压缩。

**示例**：
```python
# 伪代码
U, S, Vt = svd(image_matrix)
compressed = U[:, :k] @ diag(S[:k]) @ Vt[:k, :]
```

### 5.2 主成分分析（PCA）

**关系**：PCA可以通过SVD实现：
- 数据矩阵 $X$ 的SVD：$X = U\Sigma V^T$
- PCA的主成分是 $V$ 的列向量
- 主成分的方差是 $\sigma_i^2$

### 5.3 推荐系统

**协同过滤**：使用SVD分解用户-物品评分矩阵，预测缺失的评分。

**矩阵补全**：通过SVD分解补全不完整的矩阵。

### 5.4 信号处理

**降噪**：通过保留主要奇异值去除噪声。

**特征提取**：从数据矩阵中提取主要特征。

### 5.5 机器学习

**特征降维**：使用SVD进行特征选择和降维。

**文本分析**：潜在语义分析（LSA）使用SVD分解词-文档矩阵。

## 6. SVD分解的数值稳定性

### 6.1 条件数

**定义**：矩阵 $A$ 的条件数定义为：
$$\kappa(A) = \frac{\sigma_1}{\sigma_r}$$

**意义**：条件数越大，矩阵越接近奇异，数值计算越不稳定。

### 6.2 正则化

**截断SVD**：通过截断小的奇异值来正则化矩阵。

**Tikhonov正则化**：在SVD分解中添加正则化项。

## 7. 特殊矩阵的SVD

### 7.1 对称矩阵

**性质**：对于对称矩阵 $A$，SVD分解与特征值分解相同：
$$A = U\Lambda U^T$$

其中 $\Lambda$ 是特征值对角矩阵。

### 7.2 正交矩阵

**性质**：对于正交矩阵 $Q$，SVD分解为：
$$Q = Q \cdot I \cdot I^T$$

即所有奇异值都等于1。
