
蓄水池算法（Reservoir Sampling）是一种在**数据总量未知或数据流场景**下随机抽取$k$个样本的算法，保证每个元素被选中的概率均为$k/n$（$n$为数据总量）。以下是其原理、证明及实现详解：

---

# 0.1 ​**一、算法原理与步骤**​

## 0.1.1 ​**核心场景**​

- 数据总量$n$未知或极大（如实时数据流、大型日志文件）。
- 仅需遍历数据一次，空间复杂度为$O(k)$。

## 0.1.2 ​**算法步骤**​

1. ​**初始化蓄水池**​：读取前$k$个元素，直接存入数组$reservoir$。
2. ​**处理后续元素**​：
    - 从第$i$个元素开始（$i = k+1, k+2, ..., n$）。
    - 生成随机数$j ∈ [0, i-1]$。
    - ​**若$j < k$**​：用第$i$个元素替换$reservoir[j]$。
    - ​**否则**​：跳过该元素。

## 0.1.3 ​**伪代码**​

```
import random

def reservoir_sampling(stream, k):
    reservoir = []
    # 步骤1：初始化蓄水池
    for i in range(k):
        reservoir.append(stream[i])
    
    # 步骤2：处理后续元素
    for i in range(k, len(stream)):
        j = random.randint(0, i)  # 生成[0, i]的随机整数
        if j < k:
            reservoir[j] = stream[i]  # 替换蓄水池中的元素
    return reservoir
```

# 0.2 ​**二、等概率证明：所有元素被选中的概率均为$k/n$**​

## 0.2.1 ​**证明思路**​

- ​**前$k$个元素**​：需计算其最终保留的概率。
- ​**第$k+1$到$n$个元素**​：需计算其被选中且保留的概率。
- ​**核心工具**​：概率乘法公式与数学归纳法。

## 0.2.2 ​**证明过程**​

1. ​**对前$k$个元素中的任意元素$x$（设$x ≤ k$）​**​
    
    - $x$在初始化时必然被选中（概率=1）。
    - ​**后续每个元素$i$（$i > k$）不替换$x$的条件**​：
        - 若$i$未被选中（概率$1 - k/i$），或$i$被选中但替换了其他元素（概率$(k/i) * (1 - 1/k)$）。
    - ​**$x$存活到最后的概率**​：
        
        $$
        P(x) = 1 \times \prod_{i=k+1}^{n} \left(1 - \frac{k}{i} \cdot \frac{1}{k}\right) = \prod_{i=k+1}^{n} \frac{i-1}{i} = \frac{k}{n}
        $$
        
        > ​**推导细节**​：
        > 
        > - 连乘项化简：$∏[i=k+1→n] (1 - 1/i) = ∏[i=k+1→n] (i-1)/i$
        > - 展开后分子分母相消：$(k/k+1) * (k+1/k+2) * ... * (n-1/n) = k/n$。
        
2. ​**对第$m$个元素（$m > k$）​**​
    
    - ​**被选中的概率**​：$P(选中) = k/m$（当$i = m$时$j < k$的概率）。
    - ​**后续不被替换的概率**​：
        
        $$
        P(保留) = \prod_{i=m+1}^{n} \left(1 - \frac{k}{i} \cdot \frac{1}{k}\right) = \prod_{i=m+1}^{n} \frac{i-1}{i} = \frac{m}{n}
        $$
        
    - ​**最终被选中的概率**​：
        
        $$
        P(m) = \frac{k}{m} \times \frac{m}{n} = \frac{k}{n}
        $$
        
        > ​**关键点**​：被选中后仍需避免被后续元素替换。

# 0.3 ​**三、算法特点与应用**​

## 0.3.1 ​**优势**​

- ​**空间效率**​：仅需存储$k$个元素，适合海量数据。
- ​**时间效率**​：单次遍历，时间复杂度$O(n)$。

## 0.3.2 ​**应用场景**​

1. ​**流式数据随机抽样**​（如实时日志分析）。
2. ​**机器学习中的在线样本采样**。
3. ​**分布式系统中全局随机抽样**​（如Spark的$sample$算子）。

# 0.4 ​**四、完整Python实现（含注释）​**​

```
import random

class ReservoirSampler:
    def __init__(self, k):
        self.k = k
        self.reservoir = []
        self.count = 0  # 当前已处理元素总数

    def add(self, element):
        self.count += 1
        # 初始化蓄水池
        if len(self.reservoir) < self.k:
            self.reservoir.append(element)
        else:
            # 以 k/i 的概率决定是否替换
            j = random.randint(0, self.count - 1)
            if j < self.k:
                self.reservoir[j] = element

    def sample(self):
        return self.reservoir

1 示例：从1~1000的数据流中抽取10个样本
sampler = ReservoirSampler(10)
for i in range(1, 1001):
    sampler.add(i)
print(sampler.sample())  # 输出随机抽样的10个数
```

# 0.5 ​**总结**​

蓄水池算法通过**动态调整替换概率**​（$k/i$）和**避免重复遍历**，在未知数据规模下实现了严格的等概率抽样（$k/n$）。其数学本质是**概率连乘的约简**，核心在于替换策略的对称性。该算法在大数据、实时计算中具有不可替代的价值，理解其证明能更深入掌握随机算法的设计思想。
