
# 1 有向无环图-重点
- 有向无环图（DAG）是一种特殊的有向图，不包含任何环
- 具有拓扑排序性质，可以表示任务依赖关系和执行顺序
- 广泛应用于任务调度、编译系统、数据流分析等领域
- 检测DAG的关键是判断是否存在环，可以使用DFS或拓扑排序
- 空间复杂度O(V+E)，时间复杂度O(V+E)

# 2 有向无环图概念或介绍

## 2.1 基本概念
有向无环图（Directed Acyclic Graph，DAG）是一种特殊的有向图，它不包含任何有向环。也就是说，从任何一个顶点出发，沿着有向边无法回到该顶点。

## 2.2 核心特征
1. **有向性**：图中的边都有方向
2. **无环性**：不存在任何有向环
3. **传递性**：如果存在路径A→B和B→C，则存在A→C的传递关系
4. **拓扑排序性**：可以进行[拓扑排序](../算法/拓扑排序.md)

## 2.3 数学性质
- **偏序关系**：DAG可以表示偏序关系
- **传递闭包**：可以通过传递闭包表示所有可达关系
- **最长路径**：在DAG中可以高效计算最长路径
- **最短路径**：可以使用动态规划高效求解

# 3 有向无环图的表示方法

## 3.1 邻接表表示
```python
class DAG:
    """
    有向无环图的邻接表表示
    """
    def __init__(self, vertices):
        self.vertices = vertices
        self.adjacency_list = {i: [] for i in range(vertices)}
    
    def add_edge(self, u, v):
        """
        添加有向边 u -> v
        """
        if u < self.vertices and v < self.vertices:
            self.adjacency_list[u].append(v)
    
    def get_neighbors(self, vertex):
        """
        获取顶点的邻居节点
        """
        return self.adjacency_list[vertex]
    
    def print_graph(self):
        """
        打印图结构
        """
        for vertex in range(self.vertices):
            print(f"顶点 {vertex}: {self.adjacency_list[vertex]}")
```

## 3.2 邻接矩阵表示
```python
class DAGMatrix:
    """
    有向无环图的邻接矩阵表示
    """
    def __init__(self, vertices):
        self.vertices = vertices
        self.matrix = [[0] * vertices for _ in range(vertices)]
    
    def add_edge(self, u, v):
        """
        添加有向边 u -> v
        """
        if u < self.vertices and v < self.vertices:
            self.matrix[u][v] = 1
    
    def has_edge(self, u, v):
        """
        检查是否存在边 u -> v
        """
        return self.matrix[u][v] == 1
    
    def get_neighbors(self, vertex):
        """
        获取顶点的邻居节点
        """
        neighbors = []
        for i in range(self.vertices):
            if self.matrix[vertex][i] == 1:
                neighbors.append(i)
        return neighbors
```

# 4 有向无环图的检测算法

## 4.1 DFS检测环
```python
def has_cycle_dfs(graph):
    """
    使用DFS检测图中是否存在环
    """
    def dfs(vertex, visited, rec_stack):
        visited[vertex] = True
        rec_stack[vertex] = True
        
        for neighbor in graph.get_neighbors(vertex):
            if not visited[neighbor]:
                if dfs(neighbor, visited, rec_stack):
                    return True
            elif rec_stack[neighbor]:
                return True
        
        rec_stack[vertex] = False
        return False
    
    visited = [False] * graph.vertices
    rec_stack = [False] * graph.vertices
    
    for vertex in range(graph.vertices):
        if not visited[vertex]:
            if dfs(vertex, visited, rec_stack):
                return True
    
    return False
```

## 4.2 拓扑排序检测环
```python
def is_dag_topological(graph):
    """
    使用拓扑排序检测是否为DAG
    """
    def topological_sort():
        # 计算入度
        in_degree = [0] * graph.vertices
        for vertex in range(graph.vertices):
            for neighbor in graph.get_neighbors(vertex):
                in_degree[neighbor] += 1
        
        # 找到入度为0的顶点
        queue = []
        for vertex in range(graph.vertices):
            if in_degree[vertex] == 0:
                queue.append(vertex)
        
        count = 0
        while queue:
            vertex = queue.pop(0)
            count += 1
            
            for neighbor in graph.get_neighbors(vertex):
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        
        return count == graph.vertices
    
    return topological_sort()
```

# 6 有向无环图的算法应用

## 6.1 最长路径算法
```python
def longest_path_dag(graph, start):
    """
    在DAG中计算从起点到所有顶点的最长路径
    """
    def topological_sort():
        # 拓扑排序实现
        in_degree = [0] * graph.vertices
        for vertex in range(graph.vertices):
            for neighbor in graph.get_neighbors(vertex):
                in_degree[neighbor] += 1
        
        queue = []
        for vertex in range(graph.vertices):
            if in_degree[vertex] == 0:
                queue.append(vertex)
        
        topo_order = []
        while queue:
            vertex = queue.pop(0)
            topo_order.append(vertex)
            
            for neighbor in graph.get_neighbors(vertex):
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        
        return topo_order
    
    # 获取拓扑排序
    topo_order = topological_sort()
    
    # 初始化距离数组
    distances = [float('-inf')] * graph.vertices
    distances[start] = 0
    
    # 按拓扑顺序计算最长路径
    for vertex in topo_order:
        if distances[vertex] != float('-inf'):
            for neighbor in graph.get_neighbors(vertex):
                if distances[neighbor] < distances[vertex] + 1:  # 假设边权重为1
                    distances[neighbor] = distances[vertex] + 1
    
    return distances
```

## 6.2 传递闭包算法
```python
def transitive_closure(graph):
    """
    计算有向图的传递闭包
    传递闭包表示图中任意两个顶点之间是否存在路径（直接或间接可达）

    参数:
        graph: 图对象，需要包含以下属性和方法:
            - vertices: 整数，表示图中顶点的数量
            - get_neighbors(vertex): 返回顶点的所有直接邻居列表

    返回:
        closure: 二维布尔数组，closure[i][j]为True表示从顶点i到j存在路径
    """
    # 初始化闭包矩阵，size为vertices x vertices，初始值均为False
    closure = [[False] * graph.vertices for _ in range(graph.vertices)]
    
    # 初始化直接可达关系
    for vertex in range(graph.vertices):
        # 设置顶点到自身可达
        closure[vertex][vertex] = True
        # 设置顶点到其直接邻居可达
        for neighbor in graph.get_neighbors(vertex):
            closure[vertex][neighbor] = True
    
    # 使用Floyd-Warshall算法计算传递闭包
    # k为中间顶点，i为起始顶点，j为目标顶点
    for k in range(graph.vertices):
        for i in range(graph.vertices):
            for j in range(graph.vertices):
                # 如果i到k可达且k到j可达，则i到j可达
                closure[i][j] = closure[i][j] or (closure[i][k] and closure[k][j])
    
    return closure
```
