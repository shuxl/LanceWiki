#设计模式 
# 1. 设计模式概述

## 1.1 什么是设计模式
设计模式是软件开发中常见问题的最佳实践解决方案，是经过反复验证的、用于解决特定上下文中常见设计问题的最佳实践。

## 1.2 设计模式的分类
Java设计模式主要分为三大类：
- 创建型模式（Creational）
- 结构型模式（Structural）
- 行为型模式（Behavioral）

## 1.3 设计模式的六大原则
1. 单一职责原则：一个类应该只有一个引起它变化的原因
2. 开放-封闭原则：对扩展开放，对修改封闭
3. 里氏替换原则：子类必须能够替换掉它们的父类型
4. 依赖倒置原则：依赖于抽象，而不是具体实现
5. 接口隔离原则：使用多个专门的接口，而不是单一的总接口
6. 迪米特法则：一个对象应该对其他对象有最少的了解

# 2. 创建型设计模式

## 2.1 单例模式（Singleton）
**定义**：确保一个类只有一个实例，并提供一个全局访问点。
**应用场景**：线程池、缓存、日志对象等
**代码示例**：
```java
public class Singleton {
    private static Singleton instance = new Singleton();
    private Singleton() {}
    public static Singleton getInstance() {
        return instance;
    }
}
```
**Spring中的应用**：
- Spring Bean 默认单例

---

## 2.2 工厂模式（Factory）
**定义**：定义一个创建对象的接口，但让实现这个接口的类来决定实例化哪个类。
**应用场景**：日志记录器、数据库访问、UI组件创建
**代码示例**：
```java
public interface Shape { void draw(); }
public class Circle implements Shape { public void draw() { System.out.println("绘制圆形"); } }
public class Rectangle implements Shape { public void draw() { System.out.println("绘制矩形"); } }
public class ShapeFactory {
    public Shape getShape(String type) {
        if ("CIRCLE".equalsIgnoreCase(type)) return new Circle();
        if ("RECTANGLE".equalsIgnoreCase(type)) return new Rectangle();
        return null;
    }
}
```
**Spring中的应用**：
- BeanFactory、ApplicationContext

---

## 2.3 抽象工厂模式（Abstract Factory）
**定义**：提供一个创建一系列相关或相互依赖对象的接口，而无需指定它们具体的类。
**应用场景**：跨平台UI、产品族对象创建
**代码示例**：
```java
public interface GUIFactory { Button createButton(); TextField createTextField(); }
public class WindowsFactory implements GUIFactory {
    public Button createButton() { return new WindowsButton(); }
    public TextField createTextField() { return new WindowsTextField(); }
}
```
**Spring中的应用**：
- BeanFactory的多种实现

---

## 2.4 建造者模式（Builder）
**定义**：将一个复杂对象的构建与它的表示分离，使同样的构建过程可以创建不同的表示。
**应用场景**：复杂对象的创建，如StringBuilder、SQL构建
**代码示例**：
```java
public class User {
    private String name;
    private int age;
    public static class Builder {
        private String name;
        private int age;
        public Builder setName(String name) { this.name = name; return this; }
        public Builder setAge(int age) { this.age = age; return this; }
        public User build() { return new User(this); }
    }
    private User(Builder builder) { this.name = builder.name; this.age = builder.age; }
}
```
**Spring中的应用**：
- BeanDefinitionBuilder、UriComponentsBuilder

---

## 2.5 原型模式（Prototype）
**定义**：通过复制现有的实例来创建新的实例，而不是通过new。
**应用场景**：对象创建成本较高，且对象状态变化不大
**代码示例**：
```java
public class Prototype implements Cloneable {
    public Prototype clone() throws CloneNotSupportedException {
        return (Prototype) super.clone();
    }
}
```
**Spring中的应用**：
- @Scope("prototype")

---

# 3. 结构型设计模式

## 3.1 适配器模式（Adapter）
**定义**：将一个类的接口转换成客户期望的另一个接口，使原本接口不兼容的类可以一起工作。
**应用场景**：旧系统集成、第三方库适配
**代码示例**：
```java
public interface Target { void request(); }
public class Adaptee { public void specificRequest() { System.out.println("适配者中的业务代码被调用"); } }
public class Adapter implements Target {
    private Adaptee adaptee;
    public Adapter(Adaptee adaptee) { this.adaptee = adaptee; }
    public void request() { adaptee.specificRequest(); }
}
```
**Spring中的应用**：
- HandlerAdapter、SpringMVC适配器

---

## 3.2 装饰器模式（Decorator）
**定义**：动态地给一个对象添加一些额外的职责，就增加功能来说，装饰器模式比生成子类更为灵活。
**应用场景**：IO流、功能增强
**代码示例**：
```java
public interface Component { void operation(); }
public class ConcreteComponent implements Component { public void operation() { System.out.println("基本操作"); } }
public class Decorator implements Component {
    private Component component;
    public Decorator(Component component) { this.component = component; }
    public void operation() {
        component.operation();
        System.out.println("扩展操作");
    }
}
```
**Spring中的应用**：
- BeanWrapper、AOP增强

---

## 3.3 代理模式（Proxy）
**定义**：为其他对象提供一种代理以控制对这个对象的访问。
**应用场景**：权限控制、AOP、远程代理
**代码示例**：
```java
public interface Service { void doWork(); }
public class RealService implements Service { public void doWork() { System.out.println("实际工作"); } }
public class ServiceProxy implements Service {
    private RealService realService = new RealService();
    public void doWork() {
        System.out.println("前置处理");
        realService.doWork();
        System.out.println("后置处理");
    }
}
```
**Spring中的应用**：
- Spring AOP、事务、远程调用

---

## 3.4 桥接模式（Bridge）
**定义**：将抽象部分与实现部分分离，使它们可以独立变化。
**应用场景**：多维度变化的系统、数据库驱动适配
**代码示例**：
```java
public interface DrawAPI { void drawCircle(); }
public class RedCircle implements DrawAPI { public void drawCircle() { System.out.println("红色圆"); } }
public abstract class Shape { protected DrawAPI drawAPI; public Shape(DrawAPI drawAPI) { this.drawAPI = drawAPI; } }
public class Circle extends Shape { public Circle(DrawAPI drawAPI) { super(drawAPI); } public void draw() { drawAPI.drawCircle(); } }
```
**Spring中的应用**：
- JdbcTemplate与不同数据库驱动

---

## 3.5 组合模式（Composite）
**定义**：将对象组合成树形结构以表示“部分-整体”的层次结构。
**应用场景**：树形菜单、组织结构
**代码示例**：
```java
public abstract class Component { public void add(Component c) {} }
public class Leaf extends Component { }
public class Composite extends Component {
    private List<Component> children = new ArrayList<>();
    public void add(Component c) { children.add(c); }
}
```
**Spring中的应用**：
- ApplicationContext的层次结构

---

## 3.6 外观模式（Facade）
**定义**：为子系统中的一组接口提供一个统一的高层接口。
**应用场景**：简化复杂系统调用
**代码示例**：
```java
public class Facade {
    private SubSystemA a = new SubSystemA();
    private SubSystemB b = new SubSystemB();
    public void operation() { a.doA(); b.doB(); }
}
```
**Spring中的应用**：
- JdbcTemplate、RestTemplate

---

## 3.7 享元模式（Flyweight）
**定义**：运用共享技术有效地支持大量细粒度对象的复用。
**应用场景**：池技术、常量池
**代码示例**：
```java
public class FlyweightFactory {
    private Map<String, Flyweight> pool = new HashMap<>();
    public Flyweight get(String key) {
        if (!pool.containsKey(key)) pool.put(key, new ConcreteFlyweight());
        return pool.get(key);
    }
}
```
**Spring中的应用**：
- Bean单例池、String常量池

---

# 4. 行为型设计模式

## 4.1 观察者模式（Observer）
**定义**：定义对象间的一种一对多依赖关系，当一个对象状态发生改变时，所有依赖它的对象都会得到通知并被自动更新。
**应用场景**：事件监听、消息通知
**代码示例**：
```java
public interface Subject {
    void registerObserver(Observer o);
    void removeObserver(Observer o);
    void notifyObservers();
}
public interface Observer {
    void update(float temperature, float humidity, float pressure);
}
public class WeatherData implements Subject {
    private List<Observer> observers = new ArrayList<>();
    private float temperature, humidity, pressure;
    public void registerObserver(Observer o) { observers.add(o); }
    public void removeObserver(Observer o) { observers.remove(o); }
    public void notifyObservers() {
        for (Observer observer : observers) {
            observer.update(temperature, humidity, pressure);
        }
    }
    public void setMeasurements(float temperature, float humidity, float pressure) {
        this.temperature = temperature;
        this.humidity = humidity;
        this.pressure = pressure;
        notifyObservers();
    }
}
```
**Spring中的应用**：
- ApplicationEvent、事件监听

---

## 4.2 策略模式（Strategy）
**定义**：定义一系列算法，将每个算法封装起来，并使它们可以相互替换。
**应用场景**：排序算法、支付方式选择
**代码示例**：
```java
public interface Strategy { int doOperation(int a, int b); }
public class AddStrategy implements Strategy { public int doOperation(int a, int b) { return a + b; } }
public class Context {
    private Strategy strategy;
    public Context(Strategy strategy) { this.strategy = strategy; }
    public int execute(int a, int b) { return strategy.doOperation(a, b); }
}
```
**Spring中的应用**：
- BeanPostProcessor、ResourceLoader

---

## 4.3 模板方法模式（Template Method）
**定义**：定义一个操作中的算法骨架，将一些步骤延迟到子类实现。
**应用场景**：通用流程控制、钩子方法
**代码示例**：
```java
public abstract class AbstractClass {
    public final void templateMethod() {
        step1();
        step2();
    }
    protected abstract void step1();
    protected abstract void step2();
}
```
**Spring中的应用**：
- JdbcTemplate、TransactionTemplate

---

## 4.4 命令模式（Command）
**定义**：将一个请求封装为一个对象，从而使你可用不同的请求对客户进行参数化。
**应用场景**：任务队列、事务
**代码示例**：
```java
public interface Command { void execute(); }
public class ConcreteCommand implements Command { public void execute() { System.out.println("执行命令"); } }
public class Invoker {
    private Command command;
    public void setCommand(Command c) { this.command = c; }
    public void invoke() { command.execute(); }
}
```
**Spring中的应用**：
- ApplicationEvent、Spring Batch

---

## 4.5 职责链模式（Chain of Responsibility）
**定义**：使多个对象都有机会处理请求，避免请求的发送者和接收者之间的耦合。
**应用场景**：过滤器、审批流
**代码示例**：
```java
public abstract class Handler {
    protected Handler next;
    public void setNext(Handler next) { this.next = next; }
    public abstract void handle();
}
```
**Spring中的应用**：
- FilterChain、Spring Security过滤器链

---

## 4.6 迭代器模式（Iterator）
**定义**：提供一种方法顺序访问一个集合对象中的各个元素，而又不暴露该对象的内部表示。
**应用场景**：集合遍历
**代码示例**：
```java
public interface Iterator { boolean hasNext(); Object next(); }
```
**Spring中的应用**：
- BeanFactory、Resource

---

## 4.7 中介者模式（Mediator）
**定义**：用一个中介对象来封装一系列的对象交互。
**应用场景**：消息总线、事件调度
**代码示例**：
```java
public class Mediator { /* 省略 */ }
```
**Spring中的应用**：
- ApplicationContext事件机制

---

## 4.8 备忘录模式（Memento）
**定义**：在不破坏封装性的前提下，捕获一个对象的内部状态，并在该对象之外保存这个状态。
**应用场景**：撤销、恢复
**代码示例**：
```java
public class Memento { /* 省略 */ }
```
**Spring中的应用**：
- 事务回滚点

---

## 4.9 解释器模式（Interpreter）
**定义**：给定一个语言，定义它的文法的一种表示，并定义一个解释器。
**应用场景**：表达式计算、规则引擎
**代码示例**：
```java
public interface Expression { boolean interpret(String context); }
```
**Spring中的应用**：
- Spring EL

---

## 4.10 状态模式（State）
**定义**：允许对象在内部状态改变时改变它的行为。
**应用场景**：工作流、状态机
**代码示例**：
```java
public interface State { void handle(); }
public class Context { private State state; public void setState(State s) { this.state = s; } }
```
**Spring中的应用**：
- Spring State Machine

---

## 4.11 访问者模式（Visitor）
**定义**：表示一个作用于某对象结构中的各元素的操作。
**应用场景**：对象结构遍历、编译器
**代码示例**：
```java
public interface Visitor { void visit(Element e); }
```
**Spring中的应用**：
- BeanDefinitionVisitor

# 5. 设计模式优缺点

## 优点：
- 提高代码可重用性和可维护性
- 提供标准的解决方案和最佳实践
- 增加代码可读性，便于团队协作

## 缺点：
- 增加系统复杂度
- 过度使用会导致设计变得僵化
- 学习曲线陡峭
