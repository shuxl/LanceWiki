# 函数极限

## 📚 函数极限概述

函数极限是微积分的核心概念，描述了函数在某个点附近的行为。极限概念为导数、积分等高级概念奠定了基础。

## 🔗 极限的定义

### 1.1 ε-δ定义

设函数 $f(x)$ 在点 $a$ 的某个去心邻域内有定义，如果对于任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，有 $|f(x) - L| < \varepsilon$，则称 $L$ 是函数 $f(x)$ 在 $x \rightarrow a$ 时的**极限**，记作：

$$\lim_{x \rightarrow a} f(x) = L$$

### 1.2 几何意义

极限 $L$ 表示当 $x$ 无限接近 $a$ 时，函数值 $f(x)$ 无限接近 $L$。

### 1.3 示例

```python
import math

def limit_example(x):
    """函数 f(x) = (x² - 1)/(x - 1) 在 x = 1 处的极限"""
    if x == 1:
        return 2  # 极限值
    else:
        return (x**2 - 1) / (x - 1)

# 验证极限
x_values = [0.9, 0.99, 0.999, 1.001, 1.01, 1.1]
for x in x_values:
    print(f"f({x}) = {limit_example(x)}")
```

## 📖 极限的性质

### 2.1 基本性质

#### 唯一性
如果极限存在，则它是唯一的。

#### 局部有界性
如果 $\lim_{x \rightarrow a} f(x) = L$，则存在 $\delta > 0$，使得 $f(x)$ 在 $(a - \delta, a + \delta)$ 内有界。

#### 保号性
如果 $\lim_{x \rightarrow a} f(x) = L > 0$，则存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，$f(x) > 0$。

### 2.2 极限运算

#### 四则运算
设 $\lim_{x \rightarrow a} f(x) = L$，$\lim_{x \rightarrow a} g(x) = M$，则：

- **加法**：$\lim_{x \rightarrow a} (f(x) + g(x)) = L + M$
- **减法**：$\lim_{x \rightarrow a} (f(x) - g(x)) = L - M$
- **乘法**：$\lim_{x \rightarrow a} (f(x) \cdot g(x)) = L \cdot M$
- **除法**：$\lim_{x \rightarrow a} \frac{f(x)}{g(x)} = \frac{L}{M}$（$M \neq 0$）

#### 复合运算
设 $\lim_{x \rightarrow a} f(x) = L$，$\lim_{y \rightarrow L} g(y) = M$，则：

$$\lim_{x \rightarrow a} g(f(x)) = M$$

## 🔗 特殊极限

### 3.1 无穷极限

#### 定义
如果对于任意 $M > 0$，存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，$f(x) > M$，则称：

$$\lim_{x \rightarrow a} f(x) = +\infty$$

#### 示例
- $\lim_{x \rightarrow 0} \frac{1}{x^2} = +\infty$
- $\lim_{x \rightarrow +\infty} x^2 = +\infty$

### 3.2 单侧极限

#### 左极限
$$\lim_{x \rightarrow a^-} f(x) = L$$

#### 右极限
$$\lim_{x \rightarrow a^+} f(x) = L$$

#### 关系
$$\lim_{x \rightarrow a} f(x) = L \Leftrightarrow \lim_{x \rightarrow a^-} f(x) = \lim_{x \rightarrow a^+} f(x) = L$$

### 3.3 重要极限

#### 第一个重要极限
$$\lim_{x \rightarrow 0} \frac{\sin x}{x} = 1$$

#### 第二个重要极限
$$\lim_{x \rightarrow +\infty} \left(1 + \frac{1}{x}\right)^x = e$$

#### 第三个重要极限
$$\lim_{x \rightarrow 0} \frac{e^x - 1}{x} = 1$$

## 📖 极限的计算方法

### 4.1 直接代入法

如果函数在点 $a$ 处连续，则：

$$\lim_{x \rightarrow a} f(x) = f(a)$$

### 4.2 因式分解法

对于 $\frac{0}{0}$ 型极限，可以通过因式分解消去零因子。

#### 示例
$$\lim_{x \rightarrow 1} \frac{x^2 - 1}{x - 1} = \lim_{x \rightarrow 1} \frac{(x - 1)(x + 1)}{x - 1} = \lim_{x \rightarrow 1} (x + 1) = 2$$

### 4.3 有理化法

对于含有根式的极限，可以通过有理化处理。

#### 示例
$$\lim_{x \rightarrow 0} \frac{\sqrt{1 + x} - 1}{x} = \lim_{x \rightarrow 0} \frac{(\sqrt{1 + x} - 1)(\sqrt{1 + x} + 1)}{x(\sqrt{1 + x} + 1)} = \lim_{x \rightarrow 0} \frac{x}{x(\sqrt{1 + x} + 1)} = \frac{1}{2}$$

### 4.4 夹逼准则

如果 $f(x) \leq g(x) \leq h(x)$ 在点 $a$ 的某个去心邻域内成立，且：

$$\lim_{x \rightarrow a} f(x) = \lim_{x \rightarrow a} h(x) = L$$

则：

$$\lim_{x \rightarrow a} g(x) = L$$

## 🔗 极限的应用

### 5.1 在微积分中的应用

#### 导数定义
$$f'(a) = \lim_{h \rightarrow 0} \frac{f(a + h) - f(a)}{h}$$

#### 积分定义
$$\int_a^b f(x) dx = \lim_{n \rightarrow \infty} \sum_{i=1}^n f(x_i) \Delta x$$

### 5.2 在级数中的应用

#### 收敛性判断
级数 $\sum_{n=1}^{\infty} a_n$ 收敛的必要条件是：

$$\lim_{n \rightarrow \infty} a_n = 0$$

### 5.3 在数值分析中的应用

#### 迭代法
许多数值方法基于极限概念，如牛顿法、二分法等。
