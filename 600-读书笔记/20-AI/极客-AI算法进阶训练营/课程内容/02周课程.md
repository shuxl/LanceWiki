# ​**模块一: 监督学习基础**​

- ​**回归第一性原理: 机器如何“学习”?​**​
    
    - 想象一下，我们如何教一个孩子认识“猫”?
        - 提供带标签的例子(Labeled Examples):
            - 指着一只虎斑猫，告诉他: “这是猫。”
            - 指着一只布偶猫，告诉他: “这也是猫。”
            - 指着一只金毛犬，告诉他: “这不是猫，这是狗。”
        - 孩子自主学习规律(Learning the Pattern):
            - 孩子的大脑会自己总结: “哦，有胡须、尖耳朵、会喵喵叫的，很可能就是猫。”
        - 测试泛化能力(Testing Generalization):
            - 当他看到一只从未见过的暹罗猫时，他能凭已学到的规律，正确地认出: “妈妈，看，猫!”
    - 这个过程，就是监督学习(Supervised Learning)的核心思想。
        - 监督(Supervised): “标签”(猫/狗)就像老师或家长提供的“标准答案”，全程监督着模型的学习过程。
        - 学习(Learning): 模型的目标，就是从大量的“问题-答案”对中，自动寻找出从“问题”推导出“答案”的内在规律。
- ​**从一个价值万亿的产业问题开始: 点击率(CTR)预估**​
    
    - CTR预测就是一个经典的监督学习任务。
    - AI团队土话小课堂开讲啦: 点击率(CTR)预估:
        - 什么是用户团队? 什么是商业化团队?
        - 什么是自然量(自然推荐)? 什么是商业量(推荐广告)?
        - 两个团队动作一致(CTR预估)但是目的不同:
            - 用户团队通过提高点击率让用户留下来。
            - 商业化团队通过提高点击率让客户多花钱。
    - CTR预估的真实场景: 特征和标签是什么?
        - 假设你是一名电商平台的AI工程师，拿到原始数据: 海量曝光日志(Impression Logs) + 点击日志(Click Logs)。
        - 示例日志:
            - 日志1: 用户使用APP发起请求→服务器下发内容→APP展示成功→APP发回日志: `{"timestamp":"2025-06-30 08:52:10","user_id":"u1a2b3c4","ad_id":"ad_xyz_789","page":"homepage_feed","device":"iphone_15_pro"}`
            - 日志2: 用户在APP中看到下发内容→用户点击下发内容→APP发回日志: `{"timestamp":"2025-06-30 08:52:21","user_id":"u1a2b3c4","ad_id":"ad_xyz_789","page":"homepage_feed","device":"iphone_15_pro","clicked":1}`
        - 构建训练样本: `{"impression_timestamp":"2025-06-30 08:52:10","click_timestamp":"2025-06-30 08:52:21","user_id":"u1a2b3c4","ad_id":"ad_xyz_789","page":"homepage_feed","device":"iphone_15_pro","clicked":1}`
        - 特征工程框架(U-I-C):
            - 用户(U)特征: 描述“谁在看?”:
                - 静态/人口属性特征(Relatively Static): `user_id`, `gender`, `age`, `city_tier`。
            - 物品(I)特征: 描述“看的是什么?”:
                - 物品身份特征(Identity): `ad_id`, `advertiser_id`。
                - 物品属性特征(Content): `ad_category`, `brand_id`, `material_type`。
            - 场景(C)特征: 描述“在什么情况下看?”:
                - 时间特征(Temporal): `hour_of_day`, `day_of_week`。
                - 位置特征(Positional): `page_id`, `position_in_feed`。
                - 环境特征(Environmental): `device_type`, `network_type`。
- ​**监督学习的第一步: 定义“映射关系”​**​
    
    - 学习目标: 找到一个函数 y=f(x)，描述特征 x 和标签 y 之间的真实关系。
    - 核心问题: 如何知道函数 f 到底“好不好”? 它凭什么能学到东西?
- ​**监督学习的第二步: 监督效果的损失函数**​
    
    - 损失函数(Loss Function)将“预测错误”转化为可量化的数值。
    - 从最直观的任务开始: 回归问题的“损失”是什么?
        - 预测房价示例: 真实价格 ytrue​=300 万。
        - 模型预测误差:
            - 模型A预测290万，误差10万。
            - 模型B预测310万，误差10万。
            - 模型C预测500万，误差200万。
        - 残差(Residual): ytrue​−ypred​。
        - 问题: 直接使用残差会导致正负误差抵消。
        - 解决方案:
            - 平均绝对误差(MAE/L1损失): MAE=N1​∑i=1N​∣yi​−y^​i​∣.
                - 优点: 对离群点不敏感。
                - 缺点: 在 x=0 处不可导，优化不便。
            - 均方误差(MSE/L2损失): MSE=N1​∑i=1N​(yi​−y^​i​)2.
                - 优点: 数学性质优秀，易于优化。
                - 缺点: 对离群点敏感。
        - 对比:
            
            |维度|MAE (L1 Loss)|MSE (L2 Loss)|
            |---|---|---|
            |核心思想|公平对待所有误差|严厉惩罚巨大误差|
            |对离群点|鲁棒(Robust)|敏感(Sensitive)|
            |数学性质|x=0处不可导|处处光滑可导,易于优化|
            |适用场景|数据存在离群点|数据干净或不能容忍极端错误|
            
- ​**分类损失的初探: 0-1损失**​
    
    - 0-1损失: L(y,y^​)={01​if y^​=yif y^​=y​
        - 优点: 符合直觉。
        - 缺点: 无法为梯度下降提供方向，忽略模型置信度。
- ​**切换世界观: 分类问题即“概率分布的匹配”​**​
    
    - 真实分布 p: 对于一个样本，其真实类别是唯一的（例如，猫的图片： p={P(是猫)=1.0,P(是狗)=0.0,P(是鸟)=0.0})。
    - 模型预测分布 q: 模型输出的概率（例如， q={P(是猫)=0.7,P(是狗)=0.2,P(是鸟)=0.1})。
    - 目标: 让 q 逼近 p.
- ​**度量分布差异的“标尺”: KL散度**​
    
    - KL散度衡量两个分布的不相似度。
    - 最小化KL散度等价于最小化交叉熵。
    - 交叉熵损失: 用于分类任务（如CTR预估）。
- ​**最终的答案: Log Loss是CTR预估的“标准配置”​**​
    
    - 对于CTR预估，交叉熵损失是最适合的损失函数。

# ​**模块二: 线性模型**​

- ​**现代AI的“两阶段”工作范式**​
    
    - 阶段一: 表示学习(Representation Learning)
        - 目标: 使用预训练模型（如BERT处理语言，ResNet处理图像）将原始数据转换为特征向量 h。
        - 角色: 预训练模型作为特征提取器。
    - 阶段二: 任务决策(Task Decision)
        - 目标: 将特征向量 h 输入下游模型完成分类或回归。
        - 角色: 小模型作为“任务模型”。
- ​**一个直接的例子: 用Embedding做情感分析**​
    
    - 任务: 判断电影评论的情感（正面/负面）。
    - 代码示例:
        
        ```
        # 正面和负面的文本例子
        pos_texts = [
            "这部电影的剧情和演技让我完全沉浸其中。",
            "我很喜欢这个故事，情感充沛，打动人心。",
            "看完觉得非常温暖，推荐大家观看。",
            "主角的表演令人惊艳，情节引人入胜。",
            "这是一部难得的佳作，让人感动。"
        ]
        neg_texts = [
            "剧情毫无亮点，看得很无聊。",
            "浪费时间，完全没有期待中的好。",
            "表演很尴尬，故事也很俗套。",
            "剧情拖沓，结局让人失望。",
            "看完之后非常后悔，不推荐。"
        ]
        texts = pos_texts + neg_texts
        labels = [1] * len(pos_texts) + [0] * len(neg_texts)
        
        # 获取embedding
        print("Loading BGE-M3 model...")
        model = BGEM3FlagModel('BAAI/bge-m3', use_fp16=True)
        embeddings = model.encode(texts, batch_size=5, max_length=128)['dense_vecs']
        
        # 训练Logistic Regression
        clf = LogisticRegression(max_iter=1000)
        clf.fit(embeddings, labels)
        
        # 获取权重
        weights = clf.coef_.flatten()
        top_k = 10
        top_indices = np.argsort(np.abs(weights))[-top_k:][::-1]
        ```
        
- ​**几何的直觉: 在语义空间中“画一条线”​**​
    
    - 线性分类器任务: 在高维特征空间中找到一个决策超平面。
    - 决策函数: Score = w1​h1​+w2​h2​+⋯+wn​hn​+b.
    - 当 Score > 0 时预测正类，Score < 0 时预测负类。
- ​**概率映射: Sigmoid与Softmax函数**​
    
    - Sigmoid函数将任意实数压缩到 (0,1) 区间表示概率。
    - 逻辑回归模型: p=1+e−Score1​.
- ​**扩展: GPT在早期就是这种二阶段的模式**​
    
    - 示例代码:
        
        ```
        import torch
        from transformers import AutoTokenizer, GPT2ForSequenceClassification
        tokenizer = AutoTokenizer.from_pretrained("openai-community/gpt2")
        model = GPT2ForSequenceClassification.from_pretrained("openai-community/gpt2", problem_type="multi_label_classification")
        inputs = tokenizer("Hello, my dog is cute", return_tensors="pt")
        with torch.no_grad():
            logits = model(**inputs).logits
        predicted_class_ids = torch.arange(0, logits.shape[-1])[torch.sigmoid(logits).squeeze(dim=0) > 0.5]
        ```
        
- ​**价值再探与回归战场**​
    
    - 线性模型价值: 简单、高效、可解释。
    - 应用于CTR预估: 逻辑回归是经典解决方案。
- ​**一个棘手但致命的问题**​
    
    - 问题: 类别特征（如 city='北京'）不能直接用于数值计算。
    - 错误方案: 数值编码（例如 {"北京":1,"上海":2}）会引入虚假序数关系。
    - 正确方案: 独热编码(One-Hot Encoding)
        - 例如: ["北京","上海","广州"] → [1,0,0] for "北京", [0,1,0] for "上海"。
        - 优点: 解决虚假序数问题。
        - 缺点: 语义信息完全丧失。
- ​**一个更好的方法: 将类别投影到“语义空间”​**​
    
    - 嵌入(Embedding): 将类别投影为稠密向量（如 "北京" → [0.32,-0.15,0.89,...,-0.41]）。
        - 优点: 捕捉语义相似性（如 "北京" 和 "上海" 向量接近）。
- ​**现代CTR模型的解决之道**​
    
    - 工作流:
        1. 输入与嵌入: 离散特征通过Embedding层转换。
        2. 拼接与堆叠: Embedding向量拼接为长向量。
        3. 学习: 更新线性权重。
        4. 输出: 通过Sigmoid预测CTR。
- ​**监督学习的第三步: 用梯度下降“自动调参”​**​
    
    - 损失函数: C(θ)=N1​∑i=1N​L(fθ​(xi​),yi​).
    - 梯度下降: 沿负梯度方向更新参数。
    - 代码示例:
        
        ```
        clf = LogisticRegression(max_iter=1000)
        clf.fit(embeddings, labels)  # 每次迭代更新权重
        ```

# ​**模块三: 决策树与集成学习**​

- ​**决策树: 像人类一样思考**​
    
    - 决策树模型通过一系列“是/否”问题逐步锁定答案。
    - 示例: "猜猜他是谁"游戏。
- ​**学习的核心: 如何进行“最优分裂”?​**​
    
    - 纯度(Purity): 好问题能最大化信息增益。
    - 衡量标准: 信息熵(Entropy)或基尼不纯度(Gini Impurity)。
    - 算法: 遍历特征和分割点，选择信息增益最大的方案。
- ​**决策树的局限性: 一个“天才”的偏科生**​
    
    - 致命缺陷一: 过拟合(Overfitting): 模型在训练数据上表现好，但泛化能力差。
    - 致命缺陷二: 不稳定性(High Variance): 数据微小变动导致树结构剧变。
- ​**集体智慧的力量: 从“一个专家”到“智囊团”​**​
    
    - 集成学习(Ensemble Learning)核心思想: 组合多个模型取长补短。
- ​**Boosting: “三个臭皮匠，顶个诸葛亮”​**​
    
    - 策略: 串行迭代，从错误中学习。
        - 训练第一个弱学习器。
        - 关注错题，提高权重。
        - 训练后续模型纠正错误。
        - 加权融合预测。
    - 经典案例: Facebook《Practical Lessons from Predicting Clicks on Ads at Facebook》
        - 引用摘要: "Online advertising allows advertisers to only bid and pay for measurable user responses, such as clicks on ads. As a consequence, click prediction systems are central to most online advertising systems. With over 750 million daily active users and over 1 million active advertisers, predicting clicks on Facebook ads is a challenging machine learning task. In this paper we introduce a model which combines decision trees with logistic regression, outperforming either of these methods on its own by over 3%, an improvement with significant impact to the overall system performance."
        - 混合模型结构: 输入特征通过决策树转换，输出作为线性分类器的输入。

# ​**模块四: 无监督学习**​

- ​**无监督学习: 在没有地图的世界里寻宝**​
    
    - 与监督学习的区别: 无标签数据。
    - 目标: 发现隐藏结构（如聚类、降维、关联规则）。
    - 任务类型:
        - 聚类(Clustering): “这些用户可以被分成哪些天然的群体?”
        - 降维(Dimensionality Reduction): “用更少特征抓住数据精髓。”
        - 关联规则(Association Rule): “购买了‘啤酒’的顾客，是否也倾向于购买‘尿布’?”
- ​**​“物以类聚”: 从KNN到向量检索**​
    
    - KNN核心思想: 样本特性由最近邻居决定。
    - 应用于向量检索:
        - 万物皆可Embedding: 数据转换为向量。
        - 构建索引: 存入向量数据库（如Faiss）。
        - 查询与检索: 找到与查询向量最近的K个邻居。
- ​**K-Means: 为数据找到天然的群体中心**​
    
    - 目标: 划分数据为K个紧凑簇。
    - 步骤:
        1. 随机初始化K个质心。
        2. 分配步骤: 每个点分配到最近质心。
        3. 更新步骤: 重新计算簇中心。
        4. 迭代: 重复直到收敛。
    - 示例: 电商客户分组（年龄、消费金额、购买频率）。
- ​**PCA降维: 用更少的变量，讲好同一个故事**​
    
    - 问题: 维数灾难(Curse of Dimensionality)。
    - 目标: 保留方差最大方向。
    - 核心思想: 主成分(PC)捕捉最大方差。
        - PC1: 方差最大方向。
        - PC2: 方差次大方向。
    - 过程: 矩阵分解找到正交坐标轴。

# ​**模块五: 模型评估**​

- ​**回到监督的话题: 我们如何评判一个模型?​**​
    
    - 监督的“一体两面”:
        - 过程监督(Process Supervision): 训练中指导优化。
        - 结果监督(Outcome Supervision): 评估模型业务价值。
    - 评估指标服务对象是“人类”: 直观、可解释、业务挂钩。
- ​**回归问题的“成绩单”​**​
    
    - 平均绝对误差(MAE): “平均误差是5.5万元”。
    - 均方根误差(RMSE): 惩罚巨大误差。
    - 决定系数(R-squared, R²): “模型解释了房价变化原因的85%”。
- ​**评估分类模型: 我们到底在关心哪种“错”?​**​
    
    - 误报(False Alarm): 模型预测“会点击”但实际未点击（代价: 浪费资源）。
    - 漏报(A Miss): 模型预测“不会点击”但实际点击了（代价: 错失收入）。
    - 指标:
        - 精确率(Precision): 衡量误报代价。公式: Precision=TP+FPTP​.
            - 应用: 垃圾邮件审核（优先低误报）。
        - 召回率(Recall): 衡量漏报代价。公式: Recall=TP+FNTP​.
            - 应用: 医疗诊断（优先低漏报）。
        - AUC: 衡量排序能力（黄金标准）。公式: AUC = P(正样本分数>负样本分数).
            - 优点: 全局评估所有阈值。
            - 工业应用: CTR预估（模型能把点击广告排在未点击广告前面）。

# ​**练习**​

- ​**练习一: 基于语义理解的文本分类器**​
    
    - 任务: 构建二元分类器（如情感分析）。
    - 步骤:
        1. 定义任务（e.g., 情感分析）。
        2. 准备样本（10-15条正/负样本）。
        3. 特征提取: 用BGE-M3生成Embedding。
        4. 模型训练: 逻辑回归分类器。
        5. 评估: 预测新句子。
- ​**练习二: 基于K-Means的用户分群与画像洞察**​
    
    - 任务: 用户数据聚类。
    - 步骤:
        1. 加载数据。
        2. 执行K-Means分组。
        3. 找到群体代表（离质心最近用户）。
        4. 分析画像（e.g., “群体A: 高消费年轻用户”）。
- ​**练习三: 基于PCA的用户数据可视化探索**​
    
    - 任务: 降维可视化。
    - 步骤:
        1. 加载数据。
        2. 执行PCA降维（二维/三维）。
        3. 绘制散点图（二维/三维）。
        4. 联动可视化: 用K-Means分组颜色标记点。
