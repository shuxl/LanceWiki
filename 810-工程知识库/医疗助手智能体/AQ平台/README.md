## 关键信息汇总

### 产品基本信息
- **产品名称**：AQ平台（AI健康管家）
- **开发公司**：蚂蚁集团（阿里巴巴旗下）
- **发布时间**：2025年6月26日
- **用户规模**：累计服务用户数已超过1亿（截至2025年7月）

### 核心能力
1. **智能问诊**：多轮对话，基于蚂蚁医疗大模型
2. **报告解读**：解读99%常见医学报告，准确率超90%
3. **多模态识别**：识别50种皮肤疾病，分析25000余种药品
4. **名医AI分身**：近200位三甲名医的AI分身，7×24小时服务
5. **医疗资源连接**：5000+公立医院，近百万医生资源
6. **云陪诊服务**：200+医院提供云陪诊服务

### 技术特点
- **医疗大模型**：基于超万亿tokens专业医疗信息训练
- **知识图谱**：千万级医疗知识图谱
- **多模态支持**：支持文本、语音、图像等多种交互方式
- **RAG架构**：检索增强生成，融合向量检索和知识图谱

### 生态特色
- **资源整合**：整合大量医院和医生资源
- **名医合作**：与三甲名医合作打造AI分身
- **全流程服务**：从咨询到就医的全流程覆盖
