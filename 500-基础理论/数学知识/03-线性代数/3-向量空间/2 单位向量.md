# 单位向量

## 重点内容

本文档介绍单位向量的核心概念，包括：
- 单位向量的定义和性质
- 单位向量的计算方法
- 单位向量的应用
- 标准基向量

## 1. 单位向量的定义

### 1.1 基本定义

**定义**：长度为1的向量称为**单位向量**。

**数学表示**：向量 $\mathbf{v}$ 是单位向量当且仅当：
$$\|\mathbf{v}\| = 1$$

其中 $\|\mathbf{v}\|$ 表示向量 $\mathbf{v}$ 的欧几里得范数（长度）。

### 1.2 单位化

**定义**：对于非零向量 $\mathbf{v}$，其单位化向量定义为：
$$\hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|}$$

**性质**：
- $\|\hat{\mathbf{v}}\| = 1$
- $\hat{\mathbf{v}}$ 与 $\mathbf{v}$ 方向相同
- 零向量无法单位化

### 1.3 方向向量

**定义**：单位向量也称为**方向向量**，因为它只表示方向，不表示大小。

**应用**：在物理学中，单位向量常用于表示力的方向、速度方向等。

## 2. 单位向量的性质

### 2.1 基本性质

**性质**：
- 单位向量的长度始终为1
- 单位向量的平方等于其自身：$\hat{\mathbf{v}} \cdot \hat{\mathbf{v}} = 1$
- 两个单位向量的点积等于它们夹角的余弦：$\hat{\mathbf{u}} \cdot \hat{\mathbf{v}} = \cos\theta$

### 2.2 线性组合

**定理**：单位向量的线性组合不一定是单位向量。

**示例**：$\mathbf{u} = (1, 0)$ 和 $\mathbf{v} = (0, 1)$ 都是单位向量，但 $\mathbf{u} + \mathbf{v} = (1, 1)$ 的长度是 $\sqrt{2} \neq 1$。

### 2.3 正交性

**定义**：两个单位向量 $\hat{\mathbf{u}}$ 和 $\hat{\mathbf{v}}$ 正交当且仅当：
$$\hat{\mathbf{u}} \cdot \hat{\mathbf{v}} = 0$$

**性质**：正交的单位向量组可以构成正交基。

## 3. 标准基向量

### 3.1 二维标准基

**定义**：二维空间中的标准基向量为：
$$\mathbf{e}_1 = (1, 0), \quad \mathbf{e}_2 = (0, 1)$$

**性质**：
- $\|\mathbf{e}_1\| = \|\mathbf{e}_2\| = 1$
- $\mathbf{e}_1 \cdot \mathbf{e}_2 = 0$（正交）
- 任意二维向量可以表示为：$\mathbf{v} = v_1\mathbf{e}_1 + v_2\mathbf{e}_2$

### 3.2 三维标准基

**定义**：三维空间中的标准基向量为：
$$\mathbf{e}_1 = (1, 0, 0), \quad \mathbf{e}_2 = (0, 1, 0), \quad \mathbf{e}_3 = (0, 0, 1)$$

**性质**：
- 所有标准基向量都是单位向量
- 标准基向量两两正交
- 任意三维向量可以表示为：$\mathbf{v} = v_1\mathbf{e}_1 + v_2\mathbf{e}_2 + v_3\mathbf{e}_3$

### 3.3 n维标准基

**定义**：n维空间中的标准基向量为：
$$\mathbf{e}_i = (0, \ldots, 0, 1, 0, \ldots, 0)$$

其中1在第i个位置。

**性质**：
- $\|\mathbf{e}_i\| = 1$（单位向量）
- $\mathbf{e}_i \cdot \mathbf{e}_j = \delta_{ij}$（正交）
- 任意n维向量可以表示为：$\mathbf{v} = \sum_{i=1}^{n} v_i\mathbf{e}_i$

## 4. 单位向量的计算

### 4.1 直接计算

**步骤**：
1. 计算向量的长度：$\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$
2. 将向量除以其长度：$\hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|}$

**示例**：$\mathbf{v} = (3, 4)$
1. $\|\mathbf{v}\| = \sqrt{3^2 + 4^2} = 5$
2. $\hat{\mathbf{v}} = \frac{1}{5}(3, 4) = (\frac{3}{5}, \frac{4}{5})$

### 4.2 数值实现

**Python实现**：
```python
import numpy as np

def normalize_vector(v):
    norm = np.linalg.norm(v)
    if norm == 0:
        raise ValueError("Cannot normalize zero vector")
    return v / norm

# 示例
v = np.array([3, 4])
v_unit = normalize_vector(v)
print(f"Original vector: {v}")
print(f"Unit vector: {v_unit}")
print(f"Norm of unit vector: {np.linalg.norm(v_unit)}")
```

### 4.3 特殊情况

**零向量**：零向量无法单位化，因为其长度为0。

**数值稳定性**：当向量长度很小时，单位化可能数值不稳定。

## 5. 单位向量的应用

### 5.1 物理学应用

**力的分解**：将力向量分解为大小和方向：
$$\mathbf{F} = F \hat{\mathbf{F}}$$

其中 $F = \|\mathbf{F}\|$ 是力的大小，$\hat{\mathbf{F}}$ 是力的方向。

**速度向量**：速度可以表示为：
$$\mathbf{v} = v \hat{\mathbf{v}}$$

其中 $v$ 是速度大小，$\hat{\mathbf{v}}$ 是速度方向。

### 5.2 计算机图形学

**法向量**：表面的法向量通常是单位向量。

**方向向量**：物体的朝向用单位向量表示。

**光照计算**：光照方向、视线方向等都是单位向量。

### 5.3 机器学习

**特征标准化**：将特征向量单位化，消除尺度影响。

**相似度计算**：使用单位向量的点积计算余弦相似度。

**神经网络**：权重向量的单位化用于正则化。

### 5.4 信号处理

**信号方向**：信号的传播方向用单位向量表示。

**滤波器**：某些滤波器的系数是单位向量。

## 6. 单位向量的几何意义

### 6.1 单位球面

**定义**：所有单位向量的集合构成单位球面。

**二维**：单位圆 $x^2 + y^2 = 1$

**三维**：单位球面 $x^2 + y^2 + z^2 = 1$

### 6.2 方向表示

**极坐标**：二维单位向量可以用角度表示：
$$\hat{\mathbf{v}} = (\cos\theta, \sin\theta)$$

**球坐标**：三维单位向量可以用球坐标表示：
$$\hat{\mathbf{v}} = (\sin\phi\cos\theta, \sin\phi\sin\theta, \cos\phi)$$

### 6.3 旋转

**旋转矩阵**：单位向量可以通过旋转矩阵进行旋转。

**二维旋转**：
$$\hat{\mathbf{v}}' = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \hat{\mathbf{v}}$$

## 7. 单位向量的扩展

### 7.1 复数单位向量

**定义**：复数向量 $\mathbf{z}$ 的单位化：
$$\hat{\mathbf{z}} = \frac{\mathbf{z}}{\|\mathbf{z}\|}$$

其中 $\|\mathbf{z}\| = \sqrt{\sum_{i=1}^{n} |z_i|^2}$

### 7.2 函数空间

**定义**：在函数空间中，单位函数满足：
$$\|f\| = \sqrt{\int_a^b |f(x)|^2 dx} = 1$$

**示例**：三角函数 $\sin(x)$ 和 $\cos(x)$ 在适当区间上是单位函数。

### 7.3 概率分布

**定义**：概率向量是单位向量，因为其分量和为1。

**性质**：概率向量的所有分量都是非负的，且和为1。
