## 三角积分技巧

### 基本三角积分
$$\int \sin x dx = -\cos x + C$$
$$\int \cos x dx = \sin x + C$$
$$\int \tan x dx = -\ln|\cos x| + C$$

### 幂次三角积分
**当 $n$ 为奇数时：**
- 对于 $\int \sin^n x dx$，提取一个 $\sin x$，其余用 $\cos^2 x = 1 - \sin^2 x$ 替换
- 对于 $\int \cos^n x dx$，提取一个 $\cos x$，其余用 $\sin^2 x = 1 - \cos^2 x$ 替换

**当 $n$ 为偶数时：**
使用倍角公式：
- $\sin^2 x = \frac{1 - \cos 2x}{2}$
- $\cos^2 x = \frac{1 + \cos 2x}{2}$

### 三角换元技巧
- $\sqrt{a^2 - x^2}$：设 $x = a\sin \theta$
- $\sqrt{a^2 + x^2}$：设 $x = a\tan \theta$
- $\sqrt{x^2 - a^2}$：设 $x = a\sec \theta$

## 有理函数积分

### 部分分式分解
**基本步骤：**
1. 确保分子次数小于分母次数
2. 将分母分解为不可约因式
3. 根据分母因式类型写出部分分式形式
4. 通过比较系数确定待定系数

**分母因式类型：**
- 线性因式 $(ax + b)$：$\frac{A}{ax + b}$
- 重线性因式 $(ax + b)^n$：$\frac{A_1}{ax + b} + \frac{A_2}{(ax + b)^2} + \cdots + \frac{A_n}{(ax + b)^n}$
- 二次因式 $ax^2 + bx + c$：$\frac{Ax + B}{ax^2 + bx + c}$

## 无理函数积分

### $\sqrt{ax + b}$ 型积分
设 $u = \sqrt{ax + b}$，则 $x = \frac{u^2 - b}{a}$，$dx = \frac{2u}{a} du$

### $\sqrt{ax^2 + bx + c}$ 型积分
根据判别式 $\Delta = b^2 - 4ac$ 的情况：
- $\Delta > 0$：可以分解为线性因式
- $\Delta = 0$：可以写成完全平方形式
- $\Delta < 0$：使用三角换元

## 积分表的使用

### 常用积分公式
$$\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$$
$$\int e^x dx = e^x + C$$
$$\int \ln x dx = x \ln x - x + C$$
$$\int \sin ax dx = -\frac{1}{a} \cos ax + C$$
$$\int \cos ax dx = \frac{1}{a} \sin ax + C$$

## 数值积分方法

### 矩形法
$$\int_a^b f(x) dx \approx \sum_{i=1}^n f(x_i) \Delta x$$

### 梯形法
$$\int_a^b f(x) dx \approx \frac{\Delta x}{2} [f(x_0) + 2f(x_1) + 2f(x_2) + \cdots + 2f(x_{n-1}) + f(x_n)]$$

### 辛普森法
$$\int_a^b f(x) dx \approx \frac{\Delta x}{3} [f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + 4f(x_{n-1}) + f(x_n)]$$

**误差估计：**
- 矩形法误差：$O(\Delta x)$
- 梯形法误差：$O(\Delta x^2)$
- 辛普森法误差：$O(\Delta x^4)$

## 特殊积分技巧

### 对称性利用
- 偶函数：$\int_{-a}^a f(x) dx = 2\int_0^a f(x) dx$
- 奇函数：$\int_{-a}^a f(x) dx = 0$

### 周期性利用
如果被积函数具有周期性，可以利用周期性质。

### 参数积分
对于含有参数的积分，可以通过对参数求导来简化计算。

## 积分技巧关联的其它知识

### 与微分方程的关系
积分技巧在求解微分方程时起到重要作用，特别是分离变量法和积分因子法。

### 与复变函数的关系
某些实积分可以通过复变函数的方法来计算，如留数定理。

### 与傅里叶分析的关系
积分技巧在傅里叶变换和傅里叶级数中广泛应用。

### 与概率论的关系
在概率论中，积分技巧用于计算概率密度函数的各种统计量。

### 与物理学的关系
在物理学中，积分技巧用于计算各种物理量的分布和累积效果。

### 与机器学习的关系
在机器学习中，积分技巧用于计算损失函数、正则化项等，特别是在贝叶斯推断和变分推断中。
