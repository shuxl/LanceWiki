# 2 Java性能调优概念或介绍

Java性能调优是一个系统性的过程，涉及JVM参数调优、垃圾回收器选择、代码优化等多个层面。性能调优的目标是在保证系统稳定性的前提下，最大化应用程序的执行效率。

## 2.1 性能调优的基本原则
1. **测量优先**：在优化前必须先进行性能测量
2. **瓶颈定位**：找到真正的性能瓶颈
3. **渐进优化**：逐步优化，避免过度优化
4. **回归测试**：每次优化后都要验证效果

# 3 JVM内存调优

## 3.1 堆内存调优
```bash
设置堆内存大小
-Xms2g -Xmx2g

设置新生代大小
-Xmn1g

设置Eden和Survivor比例
-XX:SurvivorRatio=8
```

## 3.2 非堆内存调优
```bash
设置元空间大小
-XX:MetaspaceSize=256m
-XX:MaxMetaspaceSize=512m

设置直接内存大小
-XX:MaxDirectMemorySize=1g
```

## 3.3 内存分配策略调优
```bash
设置对象晋升阈值
-XX:MaxTenuringThreshold=15

设置大对象阈值
-XX:G1MixedGCLiveThresholdPercent=85
```

# 4 垃圾回收器选择与调优

## 4.1 G1垃圾回收器（推荐）
```bash
启用G1
-XX:+UseG1GC

设置目标暂停时间
-XX:MaxGCPauseMillis=200

设置G1区域大小
-XX:G1HeapRegionSize=16m
```

## 4.2 CMS垃圾回收器
```bash
启用CMS
-XX:+UseConcMarkSweepGC

设置CMS触发阈值
-XX:CMSInitiatingOccupancyFraction=70
```

## 4.3 ZGC垃圾回收器（低延迟）
```bash
启用ZGC
-XX:+UseZGC

设置最大暂停时间
-XX:ZCollectionInterval=5
```

# 5 代码层面性能优化

## 5.1 字符串优化
```java
// 避免在循环中使用字符串拼接
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append("item").append(i);
}
String result = sb.toString();
```

## 5.2 集合使用优化
```java
// 预分配集合容量
List<String> list = new ArrayList<>(1000);
Map<String, Object> map = new HashMap<>(1000);

// 使用合适的集合类型
// 频繁查找用HashMap，有序用LinkedHashMap
```

## 5.3 对象创建优化
```java
// 对象池模式
public class ObjectPool<T> {
    private final Queue<T> pool;
    
    public T borrow() {
        T obj = pool.poll();
        return obj != null ? obj : createNew();
    }
    
    public void returnObject(T obj) {
        pool.offer(obj);
    }
}
```

# 7 常见性能问题诊断

## 7.1 内存泄漏
```java
// 常见内存泄漏场景
public class MemoryLeakExample {
    private static final List<Object> cache = new ArrayList<>();
    
    public void addToCache(Object obj) {
        cache.add(obj); // 可能导致内存泄漏
    }
}
```

## 7.2 CPU使用率过高
```java
// 避免无限循环
while (true) {
    // 添加适当的休眠
    Thread.sleep(100);
}
```

## 7.3 线程死锁
```java
// 避免死锁的锁顺序
public class DeadlockPrevention {
    private final Object lock1 = new Object();
    private final Object lock2 = new Object();
    
    public void method1() {
        synchronized (lock1) {
            synchronized (lock2) {
                // 操作
            }
        }
    }
    
    public void method2() {
        synchronized (lock1) { // 保持相同的锁顺序
            synchronized (lock2) {
                // 操作
            }
        }
    }
}
```
