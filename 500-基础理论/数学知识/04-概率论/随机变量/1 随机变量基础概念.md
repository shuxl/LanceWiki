# 1 随机变量基础概念

## 重点
- 随机变量的数学定义和基本性质
- 离散随机变量和连续随机变量的区别
- 分布函数和概率密度函数的概念
- 随机变量在概率论中的核心地位

## 1.1 随机变量的基本概念

### 1.1.1 随机变量的定义

**随机变量**：定义在样本空间Ω上的实值函数X，使得对于任意实数x，集合 $\{\omega \in \Omega : X(\omega) \leq x\}$ 都是事件。

**数学表示**：
$$X: \Omega \rightarrow \mathbb{R}$$

**直观理解**：
- 随机变量是将随机试验的结果映射到实数的函数
- 每个可能的结果对应一个数值
- 这个数值本身是随机的，因此称为"随机变量"

### 1.1.2 随机变量的例子

**示例1**：抛掷硬币
- 样本空间：Ω = {正面, 反面}
- 随机变量X：正面为1，反面为0
- X(正面) = 1，X(反面) = 0

**示例2**：掷骰子
- 样本空间：Ω = {1, 2, 3, 4, 5, 6}
- 随机变量X：直接记录点数
- X(1) = 1，X(2) = 2，...，X(6) = 6

**示例3**：测量身高
- 样本空间：Ω = 所有可能的身高值
- 随机变量X：直接记录身高值
- X(ω) = ω，其中ω是具体的身高值

## 1.2 随机变量的分类

### 1.2.1 离散随机变量

**定义**：如果随机变量X只能取有限个或可数无限个值，则称X为离散随机变量。

**特点**：
- 取值是离散的（如整数、有限小数）
- 可以用概率质量函数（PMF）描述
- 分布函数是阶梯函数

**示例**：
- 抛硬币的次数
- 掷骰子的点数
- 某天接到的电话数量

### 1.2.2 连续随机变量

**定义**：如果随机变量X的分布函数是连续的，则称X为连续随机变量。

**特点**：
- 取值是连续的（如实数区间）
- 可以用概率密度函数（PDF）描述
- 单个点的概率为0

**示例**：
- 人的身高
- 温度测量值
- 股票价格

### 1.2.3 混合随机变量

**定义**：既不是纯离散也不是纯连续的随机变量。

**特点**：
- 部分取值是离散的，部分是连续的
- 需要分段描述分布

**示例**：
- 保险赔付金额（有免赔额）
- 设备故障时间（有最小维修时间）

## 1.3 分布函数

### 1.3.1 分布函数的定义

**分布函数**（Cumulative Distribution Function, CDF）：对于随机变量X，其分布函数定义为：

$$F_X(x) = P(X \leq x)$$

**性质**：
1. **非递减性**：如果 $x_1 < x_2$，则 $F_X(x_1) \leq F_X(x_2)$
2. **右连续性**：$\lim_{x \to a^+} F_X(x) = F_X(a)$
3. **极限性质**：$\lim_{x \to -\infty} F_X(x) = 0$，$\lim_{x \to \infty} F_X(x) = 1$

### 1.3.2 分布函数的计算

**离散随机变量**：
$$F_X(x) = \sum_{k \leq x} P(X = k)$$

**连续随机变量**：
$$F_X(x) = \int_{-\infty}^{x} f_X(t) dt$$

其中 $f_X(t)$ 是概率密度函数。

### 1.3.3 分布函数的应用

**概率计算**：
- $P(X \leq a) = F_X(a)$
- $P(X > a) = 1 - F_X(a)$
- $P(a < X \leq b) = F_X(b) - F_X(a)$

## 1.4 概率质量函数（PMF）

### 1.4.1 PMF的定义

**概率质量函数**：对于离散随机变量X，其PMF定义为：

$$p_X(x) = P(X = x)$$

**性质**：
1. **非负性**：$p_X(x) \geq 0$ 对于所有x
2. **归一性**：$\sum_{x} p_X(x) = 1$
3. **概率性**：$0 \leq p_X(x) \leq 1$

### 1.4.2 PMF的例子

**伯努利分布**：
$$p_X(x) = \begin{cases}
p, & x = 1 \\
1-p, & x = 0 \\
0, & \text{其他}
\end{cases}$$

**二项分布**：
$$p_X(x) = \binom{n}{x} p^x (1-p)^{n-x}, \quad x = 0, 1, \ldots, n$$

## 1.5 概率密度函数（PDF）

### 1.5.1 PDF的定义

**概率密度函数**：对于连续随机变量X，其PDF定义为：

$$f_X(x) = \frac{d}{dx} F_X(x)$$

**性质**：
1. **非负性**：$f_X(x) \geq 0$ 对于所有x
2. **归一性**：$\int_{-\infty}^{\infty} f_X(x) dx = 1$
3. **概率计算**：$P(a \leq X \leq b) = \int_{a}^{b} f_X(x) dx$

### 1.5.2 PDF的例子

**均匀分布**：
$$f_X(x) = \begin{cases}
\frac{1}{b-a}, & a \leq x \leq b \\
0, & \text{其他}
\end{cases}$$

**正态分布**：
$$f_X(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

## 1.6 随机变量的变换

### 1.6.1 线性变换

对于随机变量X和常数a、b，定义Y = aX + b：

**期望**：$E[Y] = aE[X] + b$
**方差**：$Var(Y) = a^2 Var(X)$
**分布函数**：$F_Y(y) = F_X\left(\frac{y-b}{a}\right)$

### 1.6.2 一般变换

对于随机变量X和函数g，定义Y = g(X)：

**离散情况**：
$$p_Y(y) = \sum_{x: g(x) = y} p_X(x)$$

**连续情况**：
$$f_Y(y) = \sum_{i} \frac{f_X(x_i)}{|g'(x_i)|}$$

其中 $x_i$ 是方程 $g(x) = y$ 的解。

## 1.7 随机变量的独立性

### 1.7.1 独立性的定义

两个随机变量X和Y称为独立，如果对于所有实数x和y：

$$P(X \leq x, Y \leq y) = P(X \leq x) \cdot P(Y \leq y)$$

**等价条件**：
- $F_{X,Y}(x,y) = F_X(x) \cdot F_Y(y)$
- $f_{X,Y}(x,y) = f_X(x) \cdot f_Y(y)$ （连续情况）
- $p_{X,Y}(x,y) = p_X(x) \cdot p_Y(y)$ （离散情况）

### 1.7.2 独立性的性质

1. **对称性**：如果X与Y独立，则Y与X独立
2. **函数独立性**：如果X与Y独立，则g(X)与h(Y)独立
3. **期望性质**：如果X与Y独立，则E[XY] = E[X]E[Y]

## 1.8 随机变量的应用

### 1.8.1 在统计学中的应用

- **参数估计**：估计总体参数
- **假设检验**：检验统计假设
- **置信区间**：构造参数区间

### 1.8.2 在机器学习中的应用

- **特征工程**：将原始数据转换为随机变量
- **模型训练**：学习随机变量的分布
- **预测**：基于随机变量进行预测

### 1.8.3 在金融中的应用

- **风险评估**：建模金融风险
- **期权定价**：Black-Scholes模型
- **投资组合**：资产配置优化
