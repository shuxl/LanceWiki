

# 一、基本原理与作用
- 哈希表是一种通过**哈希函数**将 Key 映射为数组下标的数据结构，支持 O(1) 平均复杂度的插入、查找、删除。
- 典型应用：计数统计、缓存（如 [LRU](../算法/LRU缓存淘汰算法.md)）、唯一性判断、数据库索引、[图的邻接表](图的邻接表.md)等。

## 哈希函数设计
- 目标：分布均匀、计算高效、可重复。
- 常见方式：
  - 数字：`key % table_size`
  - 字符串：多项式哈希（如 `hash = hash * 31 + c`）
  - Python：实现 `__hash__()` 方法
  - Java：重写 `hashCode()`

---

# 二、哈希冲突与解决策略
- 哈希冲突：不同 Key 经过哈希函数后映射到同一数组下标。

## 主要解决方式
1. **链地址法（Separate Chaining）**
   - 每个槽位存一个链表（或[红黑树](红黑树.md)，Java 8+）。
   - Java HashMap、Redis dict 采用此法。
1. **[开放寻址法（Open Addressing）](../算法/开放寻址法（Open%20Addressing）.md)**
   - 冲突时在数组内探查下一个空位。
   - Python dict 采用伪随机探查。
3. **再哈希（Rehashing）**
   - 扩容时重新分配数组并迁移元素。

---

# 三、性能分析与负载因子
- **时间复杂度**：
  - 理想 O(1)，冲突严重时最坏 O(n)。
- **空间复杂度**：
  - 需预留空间以降低冲突。
- **负载因子（load factor）**：
  - 定义：元素数量 / 哈希表容量。
  - 过高会导致冲突增多，查找变慢。
  - Java 默认 0.75，Python dict 约 2/3。
  - 超过阈值自动扩容并 rehash。

# 四、主流语言实现对比
## 1. Java HashMap
- 底层为数组+链表/红黑树（JDK8+）。
- 链表长度>8时转为红黑树，提升极端场景性能。
- 初始容量、负载因子可配置。
- HashSet 底层直接用 HashMap 存储 key。
- 并发场景用 ConcurrentHashMap。

## 2. Python dict
- 采用开放寻址法，伪随机探查。
- key-value 分离，稀疏数组。
- 插入/删除有探查状态管理。

## 3. Redis dict
- 采用链地址法，节点为链表。
- 支持[渐进式 rehash](../算法/渐进式%20rehash.md)，避免一次性迁移带来的卡顿。
- 负载因子>1时扩容，<0.1时收缩。

# 五、工程实践与高级话题
- **动态扩容与[渐进式 rehash](../算法/渐进式%20rehash.md)**：
  - Java/Redis等扩容时采用新表迁移，Redis支持渐进式迁移，保证高可用。
- **自定义哈希函数**：
  - Python 需实现 `__hash__` 和 `__eq__`，Java 需重写 `hashCode` 和 `equals`。
- **哈希攻击与安全性**：
  - 恶意构造大量冲突可导致 DoS，Python 3.3+ 加入哈希随机种子防护。
- **内存局部性**：
  - 链地址法易 cache miss，开放寻址法更友好。
- **与其他结构对比**：
  - 哈希表查找快但无序，树结构有序且支持范围查找。

---

# 六、常见陷阱与注意事项
- Key 必须可哈希且不可变（Python: 实现 `__hash__`/`__eq__`，Java: `hashCode`/`equals`）。
- 插入过多未扩容，查找性能急剧下降。
- 开放寻址法删除需“删除标记”避免探查链断裂。
- HashSet/HashMap 判断唯一性依赖 hashCode+equals，TreeSet/TreeMap 依赖 compareTo/Comparator。
- 链表过长时性能退化，JDK8+用红黑树优化。

# 七、学习建议与面试高频
1. 理解哈希表原理与典型应用。
2. 熟悉链地址法与[开放寻址法（Open Addressing）](../算法/开放寻址法（Open%20Addressing）.md)的优缺点。
3. 阅读 Java HashMap、Python dict、Redis dict 源码（建议先看 Java）。
4. 实现简单哈希表（建议用 Java/Python）。
5. 理解扩容机制与 rehash 细节。
6. 掌握哈希表与树、数组等结构的对比。
7. 面试常考：HashSet/TreeSet 区别、hashCode/equals 机制、哈希冲突处理、扩容原理等。
