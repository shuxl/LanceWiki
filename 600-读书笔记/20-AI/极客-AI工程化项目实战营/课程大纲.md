### 第四周
智能检索系统架构设计
1. 智能客服系统整体架构解析：整体分层架构、关键子系统
2. 意图识别与槽位填充：Rule - based 方法、ML - based 方法、Slot Filling 流程：
3. 意图识别流水线（Pipeline Design）：多阶段融合策略、模型热更新机制、意图识别服务 API 设计（RESTful / gRPC）
4. 上下文理解与状态追踪（Dialogue State Tracking）：状态表示方式、Session Context 管理：
5. 多轮对话设计与管理：Slot Filling 机制：对话流程控制、错误处理
6. 工具调用引擎（Tool Calling Pipeline）：工具注册与发现机制、工具调度流程、异常处理机制
7. 自定义 Agent 设计：Agent 组件设计、Agent 行为建模
8. 插件化架构设计（支持动态加载新功能）：插件结构设计、动态加载机制、插件热更新机制、插件生命周期管理：
9. 多模态输入处理：图像输入处理、语音输入处理、多模态融合策略：

实践练习
+ 实践一：设计一个支持多轮对话的订单查询客服流程

### 第五周

多 Agent 协作与通信机制
1. 多 Agent 系统基础概念：Agent 定义、合作 vs 竞争、通信机制、Agent 状态管理；
2. 主流 Agent 协作框架对比：AutoGen（微软开源）、CrewAI（社区活跃）、LangGraph（LangChain 新推出的 Graph - based Agent 框架）
3. MCP 与 A2A 协议详解
4. 构建基于 MCP 的 Client - Server 架构
5. 多 Agent 任务调度策略：并行调度、依赖图调度、优先级调度、资源感知调度
6. 使用 Ray 实现分布式 Agent 调度
7. 多 Agent 系统的异常处理与恢复机制：错误类型、恢复策略、日志记录与追踪；

实践练习：  
+ 实践一：开发一个基于 MCP 协议的多 Agent 协作系统  
+ 实践二：支持 gRPC 通信 + 状态同步 + 任务队列持久化（Redis）

### 第六周
DSL语言设计与执行引起
1. DSL 设计原则与应用场景、DSL 的定义、优势对比传统硬编码、应用场景
2. 使用 ANTLR / Lark 解析 DSL 语法
3. 构建 DSL 解释器与执行引擎：抽象语法树 (AST) 遍历、执行引擎核心组件、上下文管理器 (保存变量状态)
4. 将 DSL 集成到 Agent 框架中 (LangChain / CrewAI/AutoGen)
5. 支持 DSL 动态生成与运行时参数注入：动态生成 DSL、参数注入机制、热更新机制、版本控制

实践练习:  
+ 实践一: 设计并实现一套面向 Agent 任务规划的 DSL 语言  
+ 实践二: 开发对应的解析器与执行引擎, 支持动态加载与运行
