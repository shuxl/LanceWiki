# 1 重点
- 深度优先搜索（DFS）和广度优先搜索（BFS）是两种基本的图遍历算法
- DFS使用栈（递归或显式栈）实现，BFS使用队列实现
- DFS适合寻找所有解或路径，BFS适合寻找最短路径
- 时间复杂度通常为O(V+E)，空间复杂度取决于搜索深度

# 2 深度优先搜索（DFS- Breadth-First Search）

## 2.1 概念介绍
深度优先搜索是一种用于遍历或搜索树或图的算法。它沿着树的深度遍历树的节点，尽可能深的搜索树的分支。当节点v的所在边都已被探寻过，搜索将回溯到发现节点v的那条边的起始节点。

## 2.2 算法特点
- **搜索策略**：优先向深处搜索，直到无法继续前进才回溯
- **数据结构**：使用栈（递归调用栈或显式栈）
- **空间复杂度**：O(h)，h为树的高度
- **时间复杂度**：O(V+E)，V为顶点数，E为边数

## 2.3 实现方式

### 2.3.1 递归实现
```python
def dfs_recursive(graph, start, visited=None):
    """
    深度优先搜索 - 递归实现
    """
    if visited is None:
        visited = set()
    
    visited.add(start)
    print(f"访问节点: {start}")
    
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs_recursive(graph, neighbor, visited)
    
    return visited
```

### 2.3.2 迭代实现（使用栈）
```python
def dfs_iterative(graph, start):
    """
    深度优先搜索 - 迭代实现
    """
    visited = set()
    stack = [start]
    
    while stack:
        vertex = stack.pop()
        
        if vertex not in visited:
            visited.add(vertex)
            print(f"访问节点: {vertex}")
            
            # 将未访问的邻居节点压入栈中
            for neighbor in reversed(graph[vertex]):
                if neighbor not in visited:
                    stack.append(neighbor)
    
    return visited
```

## 2.4 应用场景
- **路径查找**：寻找从起点到终点的所有可能路径
- **拓扑排序**：对[有向无环图](../数据结构/有向无环图.md)进行[拓扑排序](拓扑排序.md)
- **连通分量**：寻找图中的[连通分量](../数据结构/连通分量.md)
- **[回溯算法](回溯算法.md)**：解决组合问题、排列问题等
- **迷宫求解**：寻找迷宫中的路径

# 3 广度优先搜索（BFS-Depth-First Search）

## 3.1 概念介绍
广度优先搜索是一种用于遍历或搜索树或图的算法。它从根节点开始，逐层遍历所有节点，先访问所有相邻节点，再访问下一层的节点。

## 3.2 算法特点
- **搜索策略**：按层次遍历，先访问所有相邻节点
- **数据结构**：使用队列
- **空间复杂度**：O(w)，w为树的最大宽度
- **时间复杂度**：O(V+E)，V为顶点数，E为边数

## 3.3 实现方式

### 3.3.1 基本BFS实现
```python
from collections import deque

def bfs(graph, start):
    """
    广度优先搜索算法实现
    参数:
        graph: 图或树的邻接表表示
        start: 起始节点
    返回:
        visited: 按BFS顺序访问的节点集合
    """
    visited = set()  # 用于记录已访问的节点
    queue = deque([start])  # 使用队列存储待访问节点
    visited.add(start)  # 标记起始节点为已访问
    
    while queue:  # 当队列不为空时
        vertex = queue.popleft()  # 从队列左侧取出一个节点
        print(f"访问节点: {vertex}")
        
        for neighbor in graph[vertex]:  # 遍历当前节点的所有邻居
            if neighbor not in visited:  # 如果邻居未被访问
                visited.add(neighbor)  # 标记为已访问
                queue.append(neighbor)  # 添加到队列末尾
    
    return visited

# 示例树结构定义
# 这是一个简单的二叉树
#       A
#      / \
#     B   C
#    / \   \
#   D   E   F
tree = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': [],
    'F': []
}
```

### 3.3.2 带层级的BFS实现
```python
from collections import deque

def bfs_with_levels(graph, start):
    """
    带层级信息的广度优先搜索算法实现
    参数:
        graph: 图或树的邻接表表示，字典类型 {节点: [相邻节点列表]}
        start: 起始节点
    返回:
        visited: 按BFS顺序访问的节点集合
        levels: 字典，存储每个节点的层级信息（起始节点为0级）
    """
    visited = set()  # 记录已访问节点
    queue = deque([(start, 0)])  # 队列存储(节点, 层级)元组
    visited.add(start)
    levels = {start: 0}  # 记录每个节点的层级
    
    while queue:
        vertex, level = queue.popleft()  # 取出队首节点及其层级
        print(f"访问节点: {vertex}, 层级: {level}")
        
        # 遍历所有邻居节点
        for neighbor in graph[vertex]:
            if neighbor not in visited:
                visited.add(neighbor)
                levels[neighbor] = level + 1  # 子节点层级=当前节点层级+1
                queue.append((neighbor, level + 1))
    
    return visited, levels
```

# 4 算法比较

## 4.1 搜索策略对比
| 特性 | DFS | BFS |
|------|-----|-----|
| 搜索策略 | 深度优先 | 广度优先 |
| 数据结构 | 栈 | 队列 |
| 空间复杂度 | O(h) | O(w) |
| 最短路径 | 不一定最优 | 保证最优 |
| 内存使用 | 较少 | 较多 |

## 4.2 选择建议
- **选择DFS当**：
  - 需要找到所有解
  - 图很深但宽度不大
  - 内存有限
  - 需要回溯

- **选择BFS当**：
  - 需要找到最短路径
  - 图很宽但深度不大
  - 需要按层次处理
  - 寻找最近的目标

## 5.1 迷宫求解
```python
def solve_maze_dfs(maze, start, end):
    """
    使用深度优先搜索(DFS)算法求解迷宫路径

    算法原理：
        从起点开始，递归探索四个方向(上、下、左、右)的可行路径，
        遇到墙壁或已访问的单元格则回溯，直至找到终点或遍历所有可能路径

    参数：
        maze (list[list[int]]): 二维列表表示的迷宫
                               0表示可通行单元格，1表示墙壁(不可通行)
        start (tuple[int, int]): 起点坐标，格式为(x, y)
        end (tuple[int, int]): 终点坐标，格式为(x, y)

    返回值：
        list[tuple[int, int]] or None: 从起点到终点的路径坐标列表，
                                      按行走顺序排列；若无路径则返回None

    示例：
        >>> maze = [[0,0,0],[1,1,0],[0,0,0]]
        >>> solve_maze_dfs(maze, (0,0), (2,2))
        [(0,0), (0,1), (0,2), (1,2), (2,2)]
    """
    def dfs(x, y, path):
        if x < 0 or x >= len(maze) or y < 0 or y >= len(maze[0]):
            return None
        if maze[x][y] == 1:  # 墙
            return None
        if (x, y) in visited:
            return None
        
        visited.add((x, y))
        path.append((x, y))
        
        if (x, y) == end:
            return path
        
        # 四个方向：上、下、左、右
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        for dx, dy in directions:
            result = dfs(x + dx, y + dy, path)
            if result:
                return result
        
        path.pop()
        return None
    
    visited = set()
    return dfs(start[0], start[1], [])
```

## 5.2 最短路径查找
```python
from collections import deque  # 添加缺失的导入

def shortest_path_bfs(graph, start, end):
    """
    使用广度优先搜索(BFS)算法寻找图中两点间的最短路径

    算法特点：
        BFS算法保证找到的路径是边数最少的最短路径，适用于无权图或等权图
        通过队列实现逐层探索，访问过的节点会被标记以避免重复处理

    参数：
        graph (dict): 图的邻接表表示，格式为{节点: [相邻节点列表]}
                      例如: {'A': ['B', 'C'], 'B': ['A', 'D']}
        start: 起点节点（可哈希类型，如字符串、整数等）
        end: 终点节点（可哈希类型，与起点类型一致）

    返回值：
        list or None: 从起点到终点的最短路径节点列表（包含起终点），
                      路径不存在时返回None

    异常：
        KeyError: 当起点或图中节点的邻居不在图的键中时触发
    """
    if start == end:
        return [start]
    
    queue = deque([(start, [start])])
    visited = {start}
    
    while queue:
        vertex, path = queue.popleft()
        
        for neighbor in graph[vertex]:
            if neighbor == end:
                return path + [neighbor]
            
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    
    return None  # 没有找到路径
```

# 6 性能优化技巧

## 6.1 DFS优化
- **剪枝**：在搜索过程中提前终止不可能的分支
- **记忆化**：缓存已计算的结果避免重复计算
- **迭代加深**：结合DFS和BFS的优点

## 6.2 BFS优化
- **双向BFS**：从起点和终点同时开始搜索
- **A\*算法**：使用启发式函数指导搜索方向
- **分层处理**：按层次处理减少内存使用
