## 凸集和凸函数

### 凸集

**定义：** 集合 $C \subseteq \mathbb{R}^n$ 是凸集，当且仅当对于任意 $x, y \in C$ 和任意 $\lambda \in [0, 1]$，都有：

$$\lambda x + (1 - \lambda) y \in C$$

**常见凸集：**
1. **超平面：** $\{x \mid a^T x = b\}$
2. **半空间：** $\{x \mid a^T x \leq b\}$
3. **多面体：** 有限个半空间的交集
4. **球：** $\{x \mid \|x - x_0\| \leq r\}$

### 凸函数

**定义：** 函数 $f: \mathbb{R}^n \rightarrow \mathbb{R}$ 是凸函数，当且仅当对于任意 $x, y \in \mathbb{R}^n$ 和任意 $\lambda \in [0, 1]$，都有：

$$f(\lambda x + (1 - \lambda) y) \leq \lambda f(x) + (1 - \lambda) f(y)$$

**等价条件：**
1. **一阶条件：** $f(y) \geq f(x) + \nabla f(x)^T(y - x)$
2. **二阶条件：** $\nabla^2 f(x) \succeq 0$（Hessian矩阵半正定）

**常见凸函数：**
1. **线性函数：** $f(x) = a^T x + b$
2. **二次函数：** $f(x) = x^T A x + b^T x + c$（$A \succeq 0$）
3. **指数函数：** $f(x) = e^{ax}$
4. **负对数：** $f(x) = -\log(x)$
5. **范数：** $f(x) = \|x\|_p$

## 凸优化问题的标准形式

### 标准形式

凸优化问题的标准形式为：

$$\begin{align}
\min_{x} & \quad f_0(x) \\
\text{subject to} & \quad f_i(x) \leq 0, \quad i = 1, 2, \ldots, m \\
& \quad h_j(x) = 0, \quad j = 1, 2, \ldots, p
\end{align}$$

其中：
- $f_0$ 是凸函数（目标函数）
- $f_i$ 是凸函数（不等式约束）
- $h_j$ 是仿射函数（等式约束）

### 最优解性质

1. 局部最优解就是全局最优解
2. 如果目标函数是严格凸函数，则最优解是唯一的

## 拉格朗日对偶

### 拉格朗日函数

拉格朗日函数定义为：

$$L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^{m} \lambda_i f_i(x) + \sum_{j=1}^{p} \nu_j h_j(x)$$

其中 $\lambda \geq 0$ 是拉格朗日乘数。

### 对偶函数

对偶函数定义为：

$$g(\lambda, \nu) = \inf_{x} L(x, \lambda, \nu)$$

**性质：** 对偶函数是凹函数，提供了原问题最优值的下界。

### 对偶问题

对偶问题定义为：

$$\begin{align}
\max_{\lambda, \nu} & \quad g(\lambda, \nu) \\
\text{subject to} & \quad \lambda \geq 0
\end{align}$$

### 强对偶性

如果原问题和对偶问题的最优值相等，则称满足强对偶性。

**Slater条件：** 如果存在严格可行点 $x$（即 $f_i(x) < 0$ 对所有 $i$），则满足强对偶性。

## 内点法

### 基本思想

内点法通过引入障碍函数将约束优化问题转化为无约束问题：

$$\min_{x} f_0(x) - \mu \sum_{i=1}^{m} \log(-f_i(x))$$

其中 $\mu > 0$ 是障碍参数。

### 算法步骤

1. 选择初始点 $x^{(0)}$ 和初始障碍参数 $\mu^{(0)}$
2. 对于 $k = 0, 1, 2, \ldots$：
   - 求解障碍问题得到 $x^{(k+1)}$
   - 更新障碍参数：$\mu^{(k+1)} = \gamma \mu^{(k)}$
   - 检查收敛条件

### 代码示例

```python
import numpy as np
from scipy.optimize import minimize

def barrier_function(x, f0, constraints, mu):
    """障碍函数"""
    barrier = f0(x)
    for f in constraints:
        barrier -= mu * np.log(-f(x))
    return barrier

def interior_point_method(f0, constraints, x0, max_iter=100):
    """内点法实现"""
    x = x0.copy()
    mu = 1.0
    
    for k in range(max_iter):
        # 求解障碍问题
        def objective(x):
            return barrier_function(x, f0, constraints, mu)
        
        result = minimize(objective, x, method='BFGS')
        x = result.x
        
        # 更新障碍参数
        mu *= 0.1
        
        # 检查收敛
        if mu < 1e-6:
            break
    
    return x
```

## 在机器学习中的应用

### 线性回归

线性回归可以表示为凸优化问题：

$$\min_{w} \frac{1}{2} \|Xw - y\|_2^2$$

这是一个二次规划问题，目标函数是凸函数。

### 支持向量机

SVM的对偶问题：

$$\begin{align}
\max_{\alpha} & \quad \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i,j=1}^{n} \alpha_i \alpha_j y_i y_j K(x_i, x_j) \\
\text{subject to} & \quad 0 \leq \alpha_i \leq C, \quad i = 1, 2, \ldots, n \\
& \quad \sum_{i=1}^{n} \alpha_i y_i = 0
\end{align}$$

### 逻辑回归

逻辑回归的优化问题：

$$\min_{w} \sum_{i=1}^{n} \log(1 + e^{-y_i w^T x_i}) + \frac{\lambda}{2} \|w\|_2^2$$

### 代码示例

```python
import numpy as np

def logistic_regression_optimization(X, y, lambda_reg=0.1):
    """逻辑回归的凸优化实现"""
    n_samples, n_features = X.shape
    
    def objective(w):
        z = X.dot(w)
        loss = np.mean(np.log(1 + np.exp(-y * z)))
        reg = (lambda_reg / 2) * np.sum(w**2)
        return loss + reg
    
    def gradient(w):
        z = X.dot(w)
        p = 1 / (1 + np.exp(-y * z))
        grad_loss = -X.T.dot(y * (1 - p)) / n_samples
        grad_reg = lambda_reg * w
        return grad_loss + grad_reg
    
    # 使用梯度下降求解
    w = np.zeros(n_features)
    alpha = 0.01
    
    for i in range(1000):
        w -= alpha * gradient(w)
    
    return w
```

## 凸优化的优势

### 理论优势

1. **全局最优：** 局部最优解就是全局最优解
2. **唯一性：** 严格凸函数的最优解是唯一的
3. **对偶性：** 可以利用对偶理论进行分析

### 算法优势

1. **高效算法：** 有专门的高效算法（内点法、ADMM等）
2. **收敛保证：** 有理论收敛保证
3. **数值稳定性：** 数值计算更稳定
