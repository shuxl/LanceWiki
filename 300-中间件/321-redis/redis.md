# Redis知识大纲

## A. Redis基础概念
### [A01 - Redis概念和基础](A01-Redis概念和基础.md)
**核心内容概括：** Redis是一款内存高速缓存数据库，全称为Remote Dictionary Server，使用C语言编写，是一个key-value存储系统。支持丰富的数据类型，具有读写性能优异、数据类型丰富、原子性、持久化等特性。广泛应用于缓存、分布式锁、计数器、排行榜等场景。

### [A02 - Redis安装配置](A02-Redis安装配置.md)
**核心内容概括：** Redis的安装方法（源码编译、Docker、包管理器），配置文件详解，启动参数说明，环境变量设置，安全配置等。

### [A03 - Redis命令基础](A03-Redis命令基础.md)
**核心内容概括：** Redis通用命令（keys、exists、del、expire等），连接命令，服务器管理命令，客户端工具使用等。
