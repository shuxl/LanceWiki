**本文重点：**
- 理解并发容器的基本概念和分类
- 掌握ConcurrentHashMap的实现原理和使用
- 熟悉CopyOnWriteArrayList的适用场景
- 了解BlockingQueue的各种实现
- 掌握并发容器的性能特点
- 理解线程安全集合的选择策略

## 1.1 什么是并发容器

并发容器是专门为多线程环境设计的集合类，它们提供了线程安全的操作，避免了使用synchronized关键字带来的性能问题。Java并发包（java.util.concurrent）提供了丰富的并发容器实现。

## 1.2 并发容器的分类

1. **Map类**：ConcurrentHashMap、ConcurrentSkipListMap
2. **List类**：CopyOnWriteArrayList、Vector
3. **Set类**：CopyOnWriteArraySet、ConcurrentSkipListSet
4. **Queue类**：BlockingQueue的各种实现
5. **Deque类**：ConcurrentLinkedDeque、LinkedBlockingDeque

# 2 ConcurrentHashMap

## 2.1 基本用法

```java
import java.util.concurrent.ConcurrentHashMap;

public class ConcurrentHashMapExample {
    private ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();
    
    public void putValue(String key, Integer value) {
        map.put(key, value);
    }
    
    public Integer getValue(String key) {
        return map.get(key);
    }
    
    // 原子操作
    public Integer putIfAbsent(String key, Integer value) {
        return map.putIfAbsent(key, value);
    }
    
    // 原子更新
    public Integer computeIfAbsent(String key, Function<String, Integer> mappingFunction) {
        return map.computeIfAbsent(key, mappingFunction);
    }
    
    // 原子替换
    public boolean replace(String key, Integer oldValue, Integer newValue) {
        return map.replace(key, oldValue, newValue);
    }
}
```

## 2.2 ConcurrentHashMap原理

ConcurrentHashMap在JDK 1.8中的实现基于分段锁和CAS操作：

```java
// 内部结构简化示意
public class ConcurrentHashMap<K, V> {
    // 使用Node数组存储数据
    transient volatile Node<K, V>[] table;
    
    // 使用CAS操作进行无锁更新
    static class Node<K, V> {
        final int hash;
        final K key;
        volatile V val;
        volatile Node<K, V> next;
    }
    
    // 扩容时使用transfer方法
    private final void transfer(Node<K, V>[] tab, Node<K, V>[] nextTab) {
        // 多线程协作扩容
    }
}
```

## 2.3 性能特点

1. **读操作无锁**：大多数读操作不需要加锁
2. **分段锁**：写操作只锁定相关的段
3. **CAS操作**：使用Compare-And-Swap进行原子更新
4. **扩容优化**：多线程协作扩容，减少阻塞

# 3 CopyOnWriteArrayList

## 3.1 基本用法

```java
import java.util.concurrent.CopyOnWriteArrayList;

public class CopyOnWriteArrayListExample {
    private CopyOnWriteArrayList<String> list = new CopyOnWriteArrayList<>();
    
    public void addElement(String element) {
        list.add(element); // 写时复制
    }
    
    public String getElement(int index) {
        return list.get(index); // 读操作无锁
    }
    
    public void removeElement(String element) {
        list.remove(element); // 写时复制
    }
    
    // 迭代器是快照，不会抛出ConcurrentModificationException
    public void iterate() {
        for (String item : list) {
            System.out.println(item);
        }
    }
}
```

## 3.2 适用场景

1. **读多写少**：读操作频繁，写操作较少
2. **迭代器安全**：需要安全的迭代器
3. **内存敏感**：对内存使用要求不高

## 3.3 性能特点

1. **写时复制**：写操作时复制整个数组
2. **读操作无锁**：读操作不需要加锁
3. **迭代器安全**：迭代器基于快照，不会抛出异常
4. **内存开销**：写操作时会有额外的内存开销

# 4 BlockingQueue

## 4.1 基本概念

BlockingQueue是一个支持阻塞操作的队列接口，当队列满时，插入操作会被阻塞；当队列空时，获取操作会被阻塞。

## 4.2 ArrayBlockingQueue

```java
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.BlockingQueue;

public class ArrayBlockingQueueExample {
    private BlockingQueue<String> queue = new ArrayBlockingQueue<>(10);
    
    // 生产者
    public void producer() {
        try {
            queue.put("item"); // 阻塞直到有空间
            queue.offer("item", 1, TimeUnit.SECONDS); // 限时等待
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
    
    // 消费者
    public String consumer() {
        try {
            return queue.take(); // 阻塞直到有元素
            return queue.poll(1, TimeUnit.SECONDS); // 限时等待
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        return null;
    }
}
```

## 4.3 LinkedBlockingQueue

```java
import java.util.concurrent.LinkedBlockingQueue;

public class LinkedBlockingQueueExample {
    private LinkedBlockingQueue<String> queue = new LinkedBlockingQueue<>();
    
    // 无界队列，不会因为容量限制而阻塞
    public void addItem(String item) {
        try {
            queue.put(item);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}
```

## 4.4 PriorityBlockingQueue

```java
import java.util.concurrent.PriorityBlockingQueue;

public class PriorityBlockingQueueExample {
    private PriorityBlockingQueue<Integer> queue = new PriorityBlockingQueue<>();
    
    public void addWithPriority() {
        queue.put(5);
        queue.put(1);
        queue.put(10);
        // 取出时会按照自然顺序：1, 5, 10
    }
    
    public Integer take() {
        try {
            return queue.take(); // 总是取出最小的元素
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        return null;
    }
}
```

## 4.5 DelayQueue

```java
import java.util.concurrent.DelayQueue;
import java.util.concurrent.Delayed;
import java.util.concurrent.TimeUnit;

public class DelayQueueExample {
    private DelayQueue<DelayedTask> queue = new DelayQueue<>();
    
    static class DelayedTask implements Delayed {
        private String name;
        private long startTime;
        
        public DelayedTask(String name, long delay) {
            this.name = name;
            this.startTime = System.currentTimeMillis() + delay;
        }
        
        @Override
        public long getDelay(TimeUnit unit) {
            return unit.convert(startTime - System.currentTimeMillis(), TimeUnit.MILLISECONDS);
        }
        
        @Override
        public int compareTo(Delayed other) {
            return Long.compare(this.startTime, ((DelayedTask) other).startTime);
        }
        
        public String getName() {
            return name;
        }
    }
    
    public void addTask(String name, long delay) {
        queue.put(new DelayedTask(name, delay));
    }
    
    public DelayedTask takeTask() {
        try {
            return queue.take(); // 只有到期的任务才能被取出
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        return null;
    }
}
```

# 5 ConcurrentSkipListMap

## 5.1 基本用法

```java
import java.util.concurrent.ConcurrentSkipListMap;

public class ConcurrentSkipListMapExample {
    private ConcurrentSkipListMap<String, Integer> map = new ConcurrentSkipListMap<>();
    
    public void addEntry(String key, Integer value) {
        map.put(key, value);
    }
    
    public Integer getEntry(String key) {
        return map.get(key);
    }
    
    // 获取第一个元素
    public Map.Entry<String, Integer> getFirst() {
        return map.firstEntry();
    }
    
    // 获取最后一个元素
    public Map.Entry<String, Integer> getLast() {
        return map.lastEntry();
    }
    
    // 获取小于指定key的最大元素
    public Map.Entry<String, Integer> getLower(String key) {
        return map.lowerEntry(key);
    }
}
```

## 5.2 特点

1. **有序**：键值对按照键的自然顺序排序
2. **线程安全**：支持并发访问
3. **跳跃表**：基于跳跃表实现，查找效率高
4. **无锁读**：读操作不需要加锁

# 7 ConcurrentLinkedQueue

## 7.1 基本用法

```java
import java.util.concurrent.ConcurrentLinkedQueue;

public class ConcurrentLinkedQueueExample {
    private ConcurrentLinkedQueue<String> queue = new ConcurrentLinkedQueue<>();
    
    public void offer(String element) {
        queue.offer(element); // 非阻塞添加
    }
    
    public String poll() {
        return queue.poll(); // 非阻塞获取
    }
    
    public String peek() {
        return queue.peek(); // 查看但不移除
    }
    
    public boolean isEmpty() {
        return queue.isEmpty();
    }
}
```

## 7.2 特点

1. **无界队列**：没有容量限制
2. **非阻塞**：操作不会阻塞线程
3. **CAS操作**：基于CAS实现，性能高
4. **FIFO**：先进先出顺序

# 8 并发容器的选择策略

## 8.1 选择指南

1. **Map的选择**：
   - 需要排序：ConcurrentSkipListMap
   - 不需要排序：ConcurrentHashMap

2. **List的选择**：
   - 读多写少：CopyOnWriteArrayList
   - 读写均衡：Vector（已过时，不推荐）

3. **Set的选择**：
   - 需要排序：ConcurrentSkipListSet
   - 不需要排序：CopyOnWriteArraySet

4. **Queue的选择**：
   - 有界队列：ArrayBlockingQueue
   - 无界队列：LinkedBlockingQueue
   - 优先级队列：PriorityBlockingQueue
   - 延迟队列：DelayQueue
   - 非阻塞队列：ConcurrentLinkedQueue

# 9 并发容器的注意事项

## 9.1 常见问题

1. **迭代器一致性**：某些容器的迭代器可能不是强一致性的
2. **原子操作**：单个操作是原子的，但复合操作不是
3. **性能考虑**：不同场景下性能差异很大

## 9.2 最佳实践

```java
public class BestPractices {
    // 1. 选择合适的容器
    private ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();
    
    // 2. 使用原子操作
    public void atomicOperation() {
        map.computeIfAbsent("key", k -> 1);
        map.merge("key", 1, Integer::sum);
    }
    
    // 3. 避免复合操作
    public void avoidCompoundOperation() {
        // 错误：复合操作不是原子的
        if (map.containsKey("key")) {
            map.put("key", map.get("key") + 1);
        }
        
        // 正确：使用原子操作
        map.merge("key", 1, Integer::sum);
    }
}
```
