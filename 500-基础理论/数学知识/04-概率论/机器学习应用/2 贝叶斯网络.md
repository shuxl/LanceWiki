## 贝叶斯网络概念

### 1. 基本定义

贝叶斯网络（Bayesian Network，BN）是一种概率图模型，用有向无环图（DAG）表示变量之间的条件依赖关系。

**数学表示：**
$$P(X_1, X_2, ..., X_n) = \prod_{i=1}^{n} P(X_i|Pa(X_i))$$

其中：
- $X_i$ 是第i个随机变量
- $Pa(X_i)$ 是$X_i$的父节点集合
- $P(X_i|Pa(X_i))$ 是条件概率分布

### 2. 贝叶斯网络的核心思想

- **条件独立性**：利用图结构表示变量间的条件独立关系
- **分解性**：联合概率分布可以分解为局部条件概率的乘积
- **因果性**：有向边表示因果关系
- **不确定性**：用概率分布表示不确定性

## 贝叶斯网络的结构

### 1. 图结构

#### 节点 (Nodes)
- 表示随机变量
- 每个节点对应一个概率分布

#### 边 (Edges)
- 表示变量间的依赖关系
- 有向边表示因果关系

#### 条件独立性
- **局部马尔可夫性**：给定父节点，节点与其非后代节点条件独立
- **全局马尔可夫性**：给定分离集，两个节点集合条件独立

### 2. 常见的网络结构

#### 链式结构
```
A → B → C → D
```

#### 树形结构
```
    A
   / \
  B   C
 / \   \
D   E   F
```

#### 星形结构
```
    A
   /|\
  B C D
```

#### 完全连接
```
A → B → C
↓   ↓   ↓
D → E → F
```

## 贝叶斯网络的数学基础

### 1. 条件概率

$$P(A|B) = \frac{P(A, B)}{P(B)}$$

### 2. 链式法则

$$P(X_1, X_2, ..., X_n) = P(X_1)P(X_2|X_1)P(X_3|X_1, X_2)...P(X_n|X_1, X_2, ..., X_{n-1})$$

### 3. 贝叶斯定理

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

### 4. 条件独立性

如果 $X \perp Y | Z$，则：
$$P(X, Y|Z) = P(X|Z)P(Y|Z)$$

## 贝叶斯网络的学习

### 1. 结构学习

#### 基于约束的方法
- **PC算法**：基于条件独立性测试
- **SGS算法**：基于统计独立性测试

#### 基于评分的方法
- **K2算法**：贪心搜索
- **BIC评分**：贝叶斯信息准则
- **AIC评分**：赤池信息准则

#### 混合方法
- **MMHC算法**：结合约束和评分方法

### 2. 参数学习

#### 最大似然估计 (MLE)
$$\hat{\theta}_{ijk} = \frac{N_{ijk}}{N_{ij}}$$

其中：
- $N_{ijk}$ 是满足条件的样本数
- $N_{ij}$ 是父节点配置的样本数

#### 贝叶斯估计
$$P(\theta_{ijk}|D) \propto P(D|\theta_{ijk})P(\theta_{ijk})$$

#### 狄利克雷先验
$$P(\theta_{ij}) \sim Dir(\alpha_{ij1}, \alpha_{ij2}, ..., \alpha_{ijr_i})$$

## 贝叶斯网络的优缺点

### 优点

1. **可解释性**：网络结构直观，易于理解
2. **不确定性处理**：自然处理不确定性
3. **因果推理**：支持因果推理
4. **先验知识整合**：可以融入领域知识
5. **小样本学习**：在小数据集上表现良好

### 缺点

1. **结构学习困难**：网络结构学习是NP难问题
2. **计算复杂度**：精确推理是NP难问题
3. **参数数量**：参数数量随节点数指数增长
4. **假设限制**：需要假设条件独立性

## 贝叶斯网络的实现工具

### 1. Python库

- **pgmpy**：纯Python实现的概率图模型库
- **bnlearn**：R语言的贝叶斯网络库
- **BayesServer**：商业贝叶斯网络软件

### 2. 示例代码

```python
import pgmpy
from pgmpy.models import BayesianNetwork
from pgmpy.factors.discrete import TabularCPD

# 创建贝叶斯网络
model = BayesianNetwork([('A', 'B'), ('B', 'C')])

# 定义条件概率分布
cpd_a = TabularCPD('A', 2, [[0.6], [0.4]])
cpd_b = TabularCPD('B', 2, [[0.7, 0.3], [0.3, 0.7]], evidence=['A'], evidence_card=[2])
cpd_c = TabularCPD('C', 2, [[0.8, 0.2], [0.2, 0.8]], evidence=['B'], evidence_card=[2])

# 添加CPD到模型
model.add_cpds(cpd_a, cpd_b, cpd_c)
```
