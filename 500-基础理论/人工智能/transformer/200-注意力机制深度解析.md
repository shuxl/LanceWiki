# 3 缩放点积注意力（Scaled Dot-Product Attention）

## 3.1 缩放点积注意力的数学原理

**数学公式：**
$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

**其中：**
- Q：查询矩阵（Query）
- K：键矩阵（Key）
- V：值矩阵（Value）
- d_k：键的维度
- √d_k：缩放因子

**计算步骤：**
1. 计算查询和键的点积：$QK^T$
2. 应用缩放因子：$\frac{QK^T}{\sqrt{d_k}}$
3. 应用softmax函数：$\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)$
4. 与值矩阵相乘：$\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$

## 3.2 缩放因子的作用

**为什么需要缩放：**
1. **梯度稳定**：防止softmax函数饱和
2. **数值稳定**：避免梯度消失或爆炸
3. **训练稳定**：提供更稳定的训练过程

**数学原理：**
```python
当d_k较大时，点积的方差会变得很大
这会导致softmax函数饱和，梯度接近0
缩放因子√d_k可以稳定方差
```

## 3.3 缩放点积注意力的实现

**核心实现：**
```python
def scaled_dot_product_attention(query, key, value, mask=None):
    """
    计算缩放点积注意力
    
    Args:
        query: 查询张量 (batch_size, num_heads, seq_len, d_k)
        key: 键张量 (batch_size, num_heads, seq_len, d_k)
        value: 值张量 (batch_size, num_heads, seq_len, d_v)
        mask: 掩码张量 (可选)
    
    Returns:
        output: 注意力输出
        attention_weights: 注意力权重
    """
    # 计算注意力分数
    scores = torch.matmul(query, key.transpose(-2, -1))
    
    # 应用缩放因子
    d_k = query.size(-1)
    scores = scores / math.sqrt(d_k)
    
    # 应用掩码（如果有）
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    
    # 计算注意力权重
    attention_weights = torch.softmax(scores, dim=-1)
    
    # 应用注意力权重
    output = torch.matmul(attention_weights, value)
    
    return output, attention_weights
```

**详细实现：**
```python
class ScaledDotProductAttention(nn.Module):
    def __init__(self, temperature, attn_dropout=0.1):
        super().__init__()
        self.temperature = temperature
        self.dropout = nn.Dropout(attn_dropout)
        
    def forward(self, q, k, v, mask=None):
        # 计算注意力分数
        attn = torch.matmul(q, k.transpose(2, 3)) / self.temperature
        
        # 应用掩码
        if mask is not None:
            attn = attn.masked_fill(mask == 0, -1e9)
        
        # 计算注意力权重
        attn = torch.softmax(attn, dim=-1)
        attn = self.dropout(attn)
        
        # 应用注意力权重
        output = torch.matmul(attn, v)
        
        return output, attn
```

# 4 多头注意力的并行计算

## 4.1 多头注意力的设计思想

**基本概念：**
- 将注意力机制并行化
- 每个头关注不同的子空间
- 最后将所有头的输出合并

**数学公式：**
$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,...,\text{head}_h)W^O$$
$$\text{where } \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

**设计优势：**
1. **并行处理**：多个头同时计算
2. **子空间建模**：每个头关注不同的特征
3. **表达能力**：增加模型的表达能力
4. **稳定性**：减少单个头的偏差

## 4.2 多头注意力的实现

**完整实现：**
```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        assert d_model % num_heads == 0
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # 线性变换层
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)
        
        self.attention = ScaledDotProductAttention(
            temperature=self.d_k ** 0.5, 
            attn_dropout=dropout
        )
        
        self.dropout = nn.Dropout(dropout)
        self.layer_norm = nn.LayerNorm(d_model)
        
    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)
        
        # 线性变换
        q = self.w_q(query).view(batch_size, -1, self.num_heads, self.d_k)
        k = self.w_k(key).view(batch_size, -1, self.num_heads, self.d_k)
        v = self.w_v(value).view(batch_size, -1, self.num_heads, self.d_k)
        
        # 转置以便并行计算
        q = q.transpose(1, 2)  # (batch_size, num_heads, seq_len, d_k)
        k = k.transpose(1, 2)
        v = v.transpose(1, 2)
        
        # 计算注意力
        if mask is not None:
            mask = mask.unsqueeze(1).unsqueeze(1)  # 扩展维度
        
        output, attention_weights = self.attention(q, k, v, mask)
        
        # 合并多头
        output = output.transpose(1, 2).contiguous().view(
            batch_size, -1, self.d_model
        )
        
        # 最终线性变换
        output = self.w_o(output)
        
        return output, attention_weights
```

## 4.3 并行计算的优化

**计算优化策略：**
```python
def optimized_multi_head_attention(query, key, value, num_heads, mask=None):
    """
    优化的多头注意力实现
    """
    batch_size, seq_len, d_model = query.size()
    d_k = d_model // num_heads
    
    # 重塑张量以支持并行计算
    q = query.view(batch_size, seq_len, num_heads, d_k).transpose(1, 2)
    k = key.view(batch_size, seq_len, num_heads, d_k).transpose(1, 2)
    v = value.view(batch_size, seq_len, num_heads, d_k).transpose(1, 2)
    
    # 并行计算注意力
    scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k)
    
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    
    attention_weights = torch.softmax(scores, dim=-1)
    output = torch.matmul(attention_weights, v)
    
    # 合并输出
    output = output.transpose(1, 2).contiguous().view(
        batch_size, seq_len, d_model
    )
    
    return output, attention_weights
```

# 5 注意力掩码（Attention Mask）

## 5.1 注意力掩码的作用

**掩码的类型：**
1. **填充掩码（Padding Mask）**：忽略填充token
2. **因果掩码（Causal Mask）**：防止看到未来信息
3. **组合掩码**：同时使用多种掩码

**掩码的作用：**
- **控制注意力范围**：限制模型能看到哪些位置
- **防止信息泄露**：在训练时防止看到未来信息
- **处理变长序列**：忽略填充部分

## 5.2 填充掩码的实现

**填充掩码创建：**
```python
def create_padding_mask(seq, pad_idx=0):
    """
    创建填充掩码
    
    Args:
        seq: 输入序列 (batch_size, seq_len)
        pad_idx: 填充token的索引
    
    Returns:
        mask: 填充掩码 (batch_size, 1, 1, seq_len)
    """
    mask = (seq != pad_idx).unsqueeze(1).unsqueeze(2)
    return mask

def create_padding_mask_for_attention(seq, pad_idx=0):
    """
    为注意力机制创建填充掩码
    """
    # 创建序列掩码
    seq_mask = (seq != pad_idx).unsqueeze(1).unsqueeze(2)
    
    # 创建注意力掩码
    attn_mask = seq_mask & seq_mask.transpose(-2, -1)
    
    return attn_mask
```

## 5.3 因果掩码的实现

**因果掩码创建：**
```python
def create_causal_mask(seq_len):
    """
    创建因果掩码（下三角矩阵）
    
    Args:
        seq_len: 序列长度
    
    Returns:
        mask: 因果掩码 (seq_len, seq_len)
    """
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
    mask = mask.masked_fill(mask == 1, float('-inf'))
    return mask

def create_causal_mask_for_batch(batch_size, seq_len):
    """
    为批次创建因果掩码
    """
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
    mask = mask.masked_fill(mask == 1, float('-inf'))
    mask = mask.unsqueeze(0).unsqueeze(0)  # (1, 1, seq_len, seq_len)
    mask = mask.expand(batch_size, -1, -1, -1)
    return mask
```

## 5.4 掩码在注意力中的应用

**在注意力计算中使用掩码：**
```python
def attention_with_mask(query, key, value, mask=None):

    带掩码的注意力计算
```

# 6 相对位置编码

## 6.1 相对位置编码的概念

**基本思想：**
- 在注意力计算中直接融入相对位置信息
- 关注token之间的相对距离
- 比绝对位置编码更灵活

**优势：**
1. **更好的泛化**：相对位置比绝对位置更稳定
2. **长序列友好**：对长序列处理更好
3. **迁移学习**：在不同任务间迁移更好

## 6.2 Shaw相对位置编码

**数学公式：**
$$a_{ij}^K = w_{\text{clip}(j-i,k)}^K$$
$$a_{ij}^V = w_{\text{clip}(j-i,k)}^V$$

**实现：**
```python
class RelativePositionalEncoding(nn.Module):
    def __init__(self, d_model, max_relative_position=32):
        super().__init__()
        self.max_relative_position = max_relative_position
        self.relative_attention_bias = nn.Embedding(
            2 * max_relative_position + 1, d_model)
        
    def forward(self, length):
        """
        计算相对位置编码
        
        Args:
            length: 序列长度
        
        Returns:
            relative_positions: 相对位置编码
        """
        range_vec = torch.arange(length)
        range_mat = range_vec.unsqueeze(0).repeat(length, 1)
        distance_mat = range_mat - range_mat.transpose(0, 1)
        distance_mat_clipped = torch.clamp(
            distance_mat, -self.max_relative_position, self.max_relative_position)
        final_mat = distance_mat_clipped + self.max_relative_position
        
        return self.relative_attention_bias(final_mat)
```

## 6.3 相对位置编码在注意力中的应用

**集成到注意力计算中：**
```python
def relative_attention(query, key, value, relative_pos_emb):
    """
    带相对位置编码的注意力计算
    """
    # 计算标准注意力分数
    scores = torch.matmul(query, key.transpose(-2, -1))
    
    # 添加相对位置信息
    rel_pos_scores = torch.matmul(query, relative_pos_emb.transpose(-2, -1))
    scores = scores + rel_pos_scores
    
    # 应用缩放
    scores = scores / math.sqrt(query.size(-1))
    
    # 计算注意力权重
    attention_weights = torch.softmax(scores, dim=-1)
    
    # 应用注意力权重
    output = torch.matmul(attention_weights, value)
    
    return output, attention_weights
```

# 7 底层原理和关键代码讲解

## 7.1 注意力机制的核心数学原理

**注意力机制的数学基础：**
```python
def attention_mathematics(query, key, value):
    """
    注意力机制的数学原理演示
    """
    # 1. 计算相似度（点积）
    similarity = torch.matmul(query, key.transpose(-2, -1))
    
    # 2. 缩放
    scaled_similarity = similarity / math.sqrt(key.size(-1))
    
    # 3. 归一化（softmax）
    attention_weights = torch.softmax(scaled_similarity, dim=-1)
    
    # 4. 加权求和
    output = torch.matmul(attention_weights, value)
    
    return output, attention_weights
```

## 7.2 多头注意力的并行实现

**完整的并行实现：**
```python
class ParallelMultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.1):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # 线性变换
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)
        
        # 线性变换并重塑
        q = self.w_q(query).view(batch_size, -1, self.num_heads, self.d_k)
        k = self.w_k(key).view(batch_size, -1, self.num_heads, self.d_k)
        v = self.w_v(value).view(batch_size, -1, self.num_heads, self.d_k)
        
        # 转置以支持并行计算
        q = q.transpose(1, 2)
        k = k.transpose(1, 2)
        v = v.transpose(1, 2)
        
        # 并行计算注意力
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attention_weights = torch.softmax(scores, dim=-1)
        attention_weights = self.dropout(attention_weights)
        
        output = torch.matmul(attention_weights, v)
        
        # 合并多头
        output = output.transpose(1, 2).contiguous().view(
            batch_size, -1, self.d_model
        )
        
        output = self.w_o(output)
        
        return output, attention_weights
```

## 7.3 注意力机制的优化技巧

**内存优化：**
```python
def memory_efficient_attention(query, key, value, mask=None):
    """
    内存高效的注意力计算
    """
    # 分块计算以减少内存使用
    chunk_size = 1024
    batch_size, num_heads, seq_len, d_k = query.size()
    
    output = torch.zeros_like(query)
    
    for i in range(0, seq_len, chunk_size):
        end_i = min(i + chunk_size, seq_len)
        
        # 计算当前块的注意力
        q_chunk = query[:, :, i:end_i, :]
        scores = torch.matmul(q_chunk, key.transpose(-2, -1)) / math.sqrt(d_k)
        
        if mask is not None:
            mask_chunk = mask[:, :, i:end_i, :]
            scores = scores.masked_fill(mask_chunk == 0, -1e9)
        
        attention_weights = torch.softmax(scores, dim=-1)
        chunk_output = torch.matmul(attention_weights, value)
        
        output[:, :, i:end_i, :] = chunk_output
    
    return output
```
