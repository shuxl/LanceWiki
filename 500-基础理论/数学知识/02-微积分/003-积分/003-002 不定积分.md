## 不定积分概念

### 定义
不定积分是导数的逆运算。如果 $F'(x) = f(x)$，那么 $F(x)$ 是 $f(x)$ 的一个原函数，记作：

$$\int f(x) dx = F(x) + C$$

其中 $C$ 是任意常数，称为积分常数。

### 几何意义
不定积分表示一族曲线，这些曲线在每一点的斜率都等于被积函数在该点的值。

### 基本性质

#### 线性性质
$$\int [af(x) + bg(x)] dx = a\int f(x) dx + b\int g(x) dx$$

#### 积分常数
$$\int f(x) dx = F(x) + C$$

其中 $C$ 是任意常数。

## 基本积分公式

### 幂函数积分
$$\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$$

$$\int \frac{1}{x} dx = \ln|x| + C$$

### 指数函数积分
$$\int e^x dx = e^x + C$$

$$\int a^x dx = \frac{a^x}{\ln a} + C \quad (a > 0, a \neq 1)$$

### 三角函数积分
$$\int \sin x dx = -\cos x + C$$

$$\int \cos x dx = \sin x + C$$

$$\int \tan x dx = -\ln|\cos x| + C$$

$$\int \cot x dx = \ln|\sin x| + C$$

$$\int \sec x dx = \ln|\sec x + \tan x| + C$$

$$\int \csc x dx = -\ln|\csc x + \cot x| + C$$

### 反三角函数积分
$$\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$$

$$\int \frac{1}{1+x^2} dx = \arctan x + C$$

## 换元积分法

### 第一类换元法（凑微分法）
如果 $u = g(x)$ 且 $g(x)$ 可导，则：

$$\int f(g(x))g'(x) dx = \int f(u) du$$

**步骤：**
1. 识别被积函数中的复合函数
2. 选择合适的换元 $u = g(x)$
3. 计算 $du = g'(x) dx$
4. 将原积分转化为关于 $u$ 的积分
5. 积分后回代

**示例：**
$$\int 2x e^{x^2} dx$$

设 $u = x^2$，则 $du = 2x dx$，所以：

$$\int 2x e^{x^2} dx = \int e^u du = e^u + C = e^{x^2} + C$$

### 第二类换元法（三角换元）
用于处理含有 $\sqrt{a^2-x^2}$、$\sqrt{a^2+x^2}$、$\sqrt{x^2-a^2}$ 的积分。

**常见换元：**
- $\sqrt{a^2-x^2}$：设 $x = a\sin \theta$
- $\sqrt{a^2+x^2}$：设 $x = a\tan \theta$
- $\sqrt{x^2-a^2}$：设 $x = a\sec \theta$

## 分部积分法

### 公式
$$\int u dv = uv - \int v du$$

### 选择原则
通常选择 $u$ 和 $dv$ 时遵循以下优先级：
1. $u$ 选择容易求导的函数
2. $dv$ 选择容易积分的函数

**优先级顺序：**
- 对数函数 $\ln x$
- 反三角函数 $\arcsin x, \arctan x$
- 幂函数 $x^n$
- 三角函数 $\sin x, \cos x$
- 指数函数 $e^x$

**示例：**
$$\int x \ln x dx$$

设 $u = \ln x$，$dv = x dx$，则 $du = \frac{1}{x} dx$，$v = \frac{x^2}{2}$，所以：

$$\int x \ln x dx = \frac{x^2}{2} \ln x - \int \frac{x^2}{2} \cdot \frac{1}{x} dx = \frac{x^2}{2} \ln x - \frac{1}{2} \int x dx = \frac{x^2}{2} \ln x - \frac{x^2}{4} + C$$

## 有理函数积分

### 部分分式分解
对于有理函数 $\frac{P(x)}{Q(x)}$，如果 $P(x)$ 的次数小于 $Q(x)$ 的次数，可以进行部分分式分解。

**步骤：**
1. 将分母 $Q(x)$ 分解为不可约因式的乘积
2. 根据分母的因式类型，写出部分分式的形式
3. 通过比较系数或赋值法确定待定系数
4. 对每个部分分式进行积分

**示例：**
$$\int \frac{1}{x^2-1} dx$$

首先分解分母：$x^2-1 = (x-1)(x+1)$

设 $\frac{1}{x^2-1} = \frac{A}{x-1} + \frac{B}{x+1}$，则：

$$1 = A(x+1) + B(x-1) = (A+B)x + (A-B)$$

比较系数得：$A+B=0$，$A-B=1$，所以 $A=\frac{1}{2}$，$B=-\frac{1}{2}$

因此：

$$\int \frac{1}{x^2-1} dx = \frac{1}{2} \int \frac{1}{x-1} dx - \frac{1}{2} \int \frac{1}{x+1} dx = \frac{1}{2} \ln|x-1| - \frac{1}{2} \ln|x+1| + C = \frac{1}{2} \ln\left|\frac{x-1}{x+1}\right| + C$$

## 积分技巧总结

### 1. 观察法
通过观察被积函数的形式，直接应用基本积分公式。

### 2. 代数变形
通过代数运算将被积函数变形为已知的积分形式。

### 3. 三角恒等式
利用三角恒等式简化被积函数。

### 4. 递推公式
对于某些复杂积分，可以建立递推关系。

## 积分与导数的关系

### 基本关系
如果 $F(x)$ 是 $f(x)$ 的一个原函数，则：

$$F'(x) = f(x)$$

$$\int f(x) dx = F(x) + C$$

### 验证方法
可以通过求导来验证积分结果是否正确：

$$\frac{d}{dx} \left[ \int f(x) dx \right] = f(x)$$

## 积分关联的其它知识

### 与定积分的关系
不定积分是定积分的基础，定积分可以通过不定积分来计算：

$$\int_a^b f(x) dx = F(b) - F(a)$$

其中 $F(x)$ 是 $f(x)$ 的一个原函数。

### 与微分方程的关系
不定积分是求解一阶微分方程的基础工具。

### 与物理应用的关系
在物理学中，不定积分用于计算位移、速度、加速度等物理量之间的关系。

### 与概率论的关系
在概率论中，不定积分用于计算概率密度函数的累积分布函数。

### 与机器学习的关系
在机器学习中，不定积分用于计算损失函数的梯度，以及在某些优化算法中的应用。
