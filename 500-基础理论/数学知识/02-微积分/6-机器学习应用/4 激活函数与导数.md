## 激活函数概念或介绍

### 激活函数的作用

激活函数（Activation Function）是神经网络中的非线性变换函数，它引入非线性性，使神经网络能够学习复杂的模式。

### 激活函数的重要性

1. **引入非线性**：使网络能够学习非线性关系
2. **控制输出范围**：限制神经元输出的范围
3. **梯度传播**：影响反向传播中的梯度计算

## Sigmoid函数及其导数

### 函数定义

Sigmoid函数定义为：

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

### 函数性质

1. **输出范围**：$(0, 1)$
2. **单调性**：单调递增
3. **对称性**：关于点$(0, 0.5)$对称
4. **平滑性**：处处可微

### 导数计算

Sigmoid函数的导数：

$$\sigma'(x) = \sigma(x)(1 - \sigma(x))$$

这个性质使得Sigmoid函数的导数可以用函数值本身表示。

### 代码实现

```python
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(x):
    """Sigmoid激活函数"""
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    """Sigmoid函数的导数"""
    s = sigmoid(x)
    return s * (1 - s)

# 可视化
x = np.linspace(-5, 5, 100)
y_sigmoid = sigmoid(x)
y_derivative = sigmoid_derivative(x)

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(x, y_sigmoid, label='Sigmoid', linewidth=2)
plt.xlabel('x')
plt.ylabel('σ(x)')
plt.title('Sigmoid函数')
plt.legend()
plt.grid(True)

plt.subplot(1, 2, 2)
plt.plot(x, y_derivative, label='Sigmoid导数', linewidth=2)
plt.xlabel('x')
plt.ylabel('σ\'(x)')
plt.title('Sigmoid函数的导数')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()
```

### 优缺点分析

#### 优点
- 输出范围固定，便于解释
- 平滑可微，便于梯度下降
- 在二分类问题中表现良好

#### 缺点
- 梯度消失问题：当输入很大或很小时，导数接近0
- 输出不是零中心的
- 计算相对复杂

## ReLU函数及其导数

### 函数定义

ReLU（Rectified Linear Unit）函数定义为：

$$\text{ReLU}(x) = \max(0, x)$$

### 函数性质

1. **输出范围**：$[0, +\infty)$
2. **单调性**：单调递增
3. **稀疏性**：负输入产生零输出，增加网络稀疏性

### 导数计算

ReLU函数的导数：

$$\text{ReLU}'(x) = \begin{cases}
1 & \text{if } x > 0 \\
0 & \text{if } x \leq 0
\end{cases}$$

### 代码实现

```python
def relu(x):
    """ReLU激活函数"""
    return np.maximum(0, x)

def relu_derivative(x):
    """ReLU函数的导数"""
    return np.where(x > 0, 1, 0)

# 可视化
x = np.linspace(-3, 3, 100)
y_relu = relu(x)
y_derivative = relu_derivative(x)

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(x, y_relu, label='ReLU', linewidth=2)
plt.xlabel('x')
plt.ylabel('ReLU(x)')
plt.title('ReLU函数')
plt.legend()
plt.grid(True)

plt.subplot(1, 2, 2)
plt.plot(x, y_derivative, label='ReLU导数', linewidth=2)
plt.xlabel('x')
plt.ylabel('ReLU\'(x)')
plt.title('ReLU函数的导数')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()
```

### 优缺点分析

#### 优点
- 计算简单，训练速度快
- 缓解梯度消失问题
- 产生稀疏激活，提高效率
- 生物学上更合理

#### 缺点
- 死亡ReLU问题：某些神经元可能永远不激活
- 输出不是零中心的

## Tanh函数及其导数

### 函数定义

Tanh（双曲正切）函数定义为：

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

### 函数性质

1. **输出范围**：$(-1, 1)$
2. **单调性**：单调递增
3. **零中心**：输出以0为中心
4. **平滑性**：处处可微

### 导数计算

Tanh函数的导数：

$$\tanh'(x) = 1 - \tanh^2(x)$$

### 代码实现

```python
def tanh(x):
    """Tanh激活函数"""
    return np.tanh(x)

def tanh_derivative(x):
    """Tanh函数的导数"""
    return 1 - np.tanh(x)**2

# 可视化
x = np.linspace(-3, 3, 100)
y_tanh = tanh(x)
y_derivative = tanh_derivative(x)

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(x, y_tanh, label='Tanh', linewidth=2)
plt.xlabel('x')
plt.ylabel('tanh(x)')
plt.title('Tanh函数')
plt.legend()
plt.grid(True)

plt.subplot(1, 2, 2)
plt.plot(x, y_derivative, label='Tanh导数', linewidth=2)
plt.xlabel('x')
plt.ylabel('tanh\'(x)')
plt.title('Tanh函数的导数')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()
```

### 优缺点分析

#### 优点
- 零中心输出，训练更稳定
- 平滑可微
- 在RNN中表现良好

#### 缺点
- 仍然存在梯度消失问题
- 计算相对复杂

## Softmax函数及其导数

### 函数定义

Softmax函数定义为：

$$\text{Softmax}(x_i) = \frac{e^{x_i}}{\sum_{j=1}^{n} e^{x_j}}$$

其中$n$是输入向量的维度。

### 函数性质

1. **输出范围**：$(0, 1)$
2. **概率分布**：输出和为1，可解释为概率
3. **单调性**：保持输入的顺序关系

### 导数计算

Softmax函数的导数比较复杂，对于第$i$个输出对第$j$个输入的导数：

$$\frac{\partial \text{Softmax}_i}{\partial x_j} = \text{Softmax}_i(\delta_{ij} - \text{Softmax}_j)$$

其中$\delta_{ij}$是克罗内克函数。

### 代码实现

```python
def softmax(x):
    """Softmax激活函数"""
    exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))  # 数值稳定性
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)

def softmax_derivative(x):
    """Softmax函数的导数（雅可比矩阵）"""
    s = softmax(x)
    n = s.shape[-1]
    jacobian = np.zeros((n, n))
    
    for i in range(n):
        for j in range(n):
            if i == j:
                jacobian[i, j] = s[i] * (1 - s[i])
            else:
                jacobian[i, j] = -s[i] * s[j]
    
    return jacobian

# 示例
x = np.array([1.0, 2.0, 3.0])
y_softmax = softmax(x)
print(f"输入: {x}")
print(f"Softmax输出: {y_softmax}")
print(f"输出和: {np.sum(y_softmax)}")
```

### 优缺点分析

#### 优点
- 输出为概率分布
- 在多分类问题中表现良好
- 与交叉熵损失函数配合良好

#### 缺点
- 计算相对复杂
- 对数值稳定性要求高

## 激活函数的选择策略

### 选择考虑因素

1. **任务类型**：分类、回归、生成等
2. **网络深度**：深层网络需要考虑梯度传播
3. **计算效率**：训练和推理速度
4. **数值稳定性**：避免梯度消失/爆炸

### 推荐策略

#### 1. 隐藏层
- **ReLU**：大多数情况的首选
- **Leaky ReLU**：解决死亡ReLU问题
- **ELU**：更好的梯度传播

#### 2. 输出层
- **Sigmoid**：二分类问题
- **Softmax**：多分类问题
- **线性**：回归问题

### 代码示例

```python
class ActivationFunctions:
    @staticmethod
    def relu(x):
        return np.maximum(0, x)
    
    @staticmethod
    def leaky_relu(x, alpha=0.01):
        return np.where(x > 0, x, alpha * x)
    
    @staticmethod
    def elu(x, alpha=1.0):
        return np.where(x > 0, x, alpha * (np.exp(x) - 1))
    
    @staticmethod
    def sigmoid(x):
        return 1 / (1 + np.exp(-x))
    
    @staticmethod
    def tanh(x):
        return np.tanh(x)
    
    @staticmethod
    def softmax(x):
        exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
        return exp_x / np.sum(exp_x, axis=-1, keepdims=True)

# 比较不同激活函数
def compare_activation_functions():
    x = np.linspace(-3, 3, 100)
    
    functions = {
        'ReLU': ActivationFunctions.relu,
        'Leaky ReLU': lambda x: ActivationFunctions.leaky_relu(x),
        'ELU': lambda x: ActivationFunctions.elu(x),
        'Sigmoid': ActivationFunctions.sigmoid,
        'Tanh': ActivationFunctions.tanh
    }
    
    plt.figure(figsize=(15, 5))
    
    for i, (name, func) in enumerate(functions.items()):
        plt.subplot(1, 3, i+1)
        plt.plot(x, func(x), label=name, linewidth=2)
        plt.xlabel('x')
        plt.ylabel('f(x)')
        plt.title(f'{name}函数')
        plt.legend()
        plt.grid(True)
    
    plt.tight_layout()
    plt.show()
```
