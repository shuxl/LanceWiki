# 面向对象核心概念

## 1. 面向对象编程思想
面向对象编程（Object-Oriented Programming，OOP）是一种以对象为中心的编程范式，它将数据和操作数据的方法封装在一起，通过类和对象的概念来描述现实世界中的事物和关系。

Java是一种纯粹的面向对象编程语言，其核心思想包括：
- 万物皆为对象
- 程序由对象组成，对象通过消息交互
- 每个对象都有自己的状态和行为
- 对象属于某个类，类是对象的模板

## 2. 类与对象
### 2.1 类的定义
类是对象的抽象模板，定义了对象所具有的属性（成员变量）和行为（成员方法）。

```java
// 类的定义示例
public class Person {
    // 属性（成员变量）
    private String name;  // 姓名
    private int age;      // 年龄
    private String gender; // 性别

    // 构造方法
    public Person(String name, int age, String gender) {
        this.name = name;
        this.age = age;
        this.gender = gender;
    }

    // 行为（成员方法）
    public void eat() {
        System.out.println(name + "正在吃饭");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉");
    }

    public void introduce() {
        System.out.println("大家好，我叫" + name + "，今年" + age + "岁，是一名" + gender + "生");
    }

    // Getter和Setter方法
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }

    public String getGender() {
        return gender;
    }

    public void setGender(String gender) {
        this.gender = gender;
    }
}
```

### 2.2 对象的创建与使用
对象是类的实例，通过`new`关键字创建。

```java
// 创建对象
Person person = new Person("张三", 20, "男");

// 调用对象方法
person.introduce(); // 输出：大家好，我叫张三，今年20岁，是一名男生
person.eat();      // 输出：张三正在吃饭

// 修改对象属性
person.setAge(21);
System.out.println(person.getName() + "现在" + person.getAge() + "岁了"); // 输出：张三现在21岁了
```

## 3. 面向对象三大特性
### 3.1 封装
封装是指将对象的状态信息隐藏在对象内部，不允许外部直接访问，而是通过指定的方法来访问和修改。

**封装的好处**：
- 提高代码安全性
- 提高代码可维护性
- 实现数据访问控制

**Java中的封装实现**：
- 使用访问修饰符（private、default、protected、public）
- 为私有属性提供public的getter和setter方法

前面的`Person`类就是一个封装的典型例子。

### 3.2 继承
继承是指一个类（子类）可以继承另一个类（父类）的属性和方法，并可以添加新的属性和方法或重写父类的方法。

**继承的好处**：
- 提高代码复用性
- 实现多态

**Java中的继承实现**：
- 使用`extends`关键字
- 一个类只能继承一个父类（单继承）
- 可以多层继承

```java
// 父类
public class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + "正在吃东西");
    }

    public void sleep() {
        System.out.println(name + "正在睡觉");
    }
}

// 子类 - 继承Animal
public class Dog extends Animal {
    // 子类特有属性
    private String breed;

    // 子类构造方法
    public Dog(String name, int age, String breed) {
        super(name, age); // 调用父类构造方法
        this.breed = breed;
    }

    // 子类特有方法
    public void bark() {
        System.out.println(name + "汪汪叫");
    }

    // 重写父类方法
    @Override
    public void eat() {
        System.out.println(name + "正在吃狗粮");
    }
}
```

### 3.3 多态
多态是指同一个方法调用可以有不同的实现方式，具体取决于对象的实际类型。

**多态的实现方式**：
- 方法重写（Override）
- 方法重载（Overload）
- 接口实现

```java
// 方法重写示例（已在Dog类中展示）
Animal animal = new Dog("旺财", 3, "金毛");
animal.eat(); // 输出：旺财正在吃狗粮（调用的是Dog类中的eat方法）

// 方法重载示例
public class Calculator {
    // 两个整数相加
    public int add(int a, int b) {
        return a + b;
    }

    // 三个整数相加（重载add方法）
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 两个double类型相加（重载add方法）
    public double add(double a, double b) {
        return a + b;
    }
}
```

## 4. 抽象
### 4.1 抽象类
抽象类是不能实例化的类，用于定义子类的共同属性和方法，使用`abstract`关键字修饰。

```java
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法（没有方法体，需要子类实现）
    public abstract double calculateArea();

    // 普通方法
    public void showColor() {
        System.out.println("颜色：" + color);
    }
}

// 子类实现抽象类
public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    // 实现抽象方法
    @Override
    public double calculateArea() {
        return Math.PI * radius * radius; // 圆的面积公式：πr²
    }
}
```

### 4.2 接口
接口是一种特殊的抽象类型，只包含抽象方法和常量，使用`interface`关键字定义。

```java
// 定义接口
public interface Flyable {
    // 常量
    int MAX_HEIGHT = 10000; // 默认public static final

    // 抽象方法（默认public abstract）
    void fly();
    void land();
}

// 实现接口
public class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鸟儿在天空飞翔");
    }

    @Override
    public void land() {
        System.out.println("鸟儿落在树枝上");
    }
}
```

## 5. 访问修饰符
Java提供四种访问修饰符，用于控制类、属性和方法的访问权限：

| 修饰符 | 同一类中 | 同一包中 | 不同包的子类 | 不同包的非子类 |
|--------|----------|----------|--------------|----------------|
| private | √ | × | × | × |
| 默认 | √ | √ | × | × |
| protected | √ | √ | √ | × |
| public | √ | √ | √ | √ |

## 6. 总结
面向对象编程是Java的核心思想，通过类与对象、封装、继承、多态和抽象等概念，可以构建出模块化、可维护、可扩展的程序。掌握这些核心概念对于Java编程至关重要，它们是理解和使用更高级Java特性的基础。
