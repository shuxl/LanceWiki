## .cursorrules

在项目根目录创建 `.cursorrules` 文件，统一开发规范：

```
# 接口开发规范
- 所有接口定义必须符合 OpenAPI 3.0 规范
- 接口文档存放在 docs/api/ 目录
- 前后端代码生成必须基于 OpenAPI 规范文件（docs/api/openapi.yaml）
- 数据模型定义使用独立的 schema 文件，放在 docs/api/schemas/ 目录

# 代码生成规范

## 后端代码生成
- Controller 必须使用 SpringDoc 注解（@Tag、@Operation、@Parameter 等）
- 所有接口必须使用 @Valid 进行参数校验
- 使用统一的响应格式 ApiResponse<T>
- 异常处理使用 @ControllerAdvice 统一处理
- 所有 DTO 类必须包含完整的 Swagger 注解

## 前端代码生成
- 所有 API 调用必须使用 TypeScript 类型定义
- API 调用函数使用 axios，统一错误处理
- React Hook 封装 API 调用，提供 loading、error 状态
- 类型定义必须与 OpenAPI 规范中的 schemas 保持一致

# 命名规范
- API 路径使用小写字母和连字符（kebab-case），如：/api/users/{id}
- 数据模型使用 PascalCase，如：User、CreateUserRequest
- TypeScript 接口使用 PascalCase，如：User、ApiResponse
- Java 类使用 PascalCase，如：UserController、UserDTO
- 变量和方法使用 camelCase，如：getUserList、userId

# 代码风格
- 所有代码注释和文档使用简体中文
- 函数和类必须有完整的文档注释
- 异常处理要完善，提供有用的错误信息
- 遵循项目现有的代码风格和目录结构

# 文件组织
- 后端代码：backend/src/main/java/com/example/
- 前端代码：frontend/src/
- 类型定义：frontend/src/types/
- API 调用：frontend/src/api/
- React Hooks：frontend/src/hooks/
- 接口规范：docs/api/
```

## .vscode/settings.json

```json
{
  "maven.executable.path": "/path/to/maven/bin/mvn",
  "python.defaultInterpreterPath": "/path/to/python",
  "java.configuration.maven.userSettings": "/path/to/settings.xml",
  "files.exclude": {
    "**/node_modules": true,
    "**/target": true,
    "**/.git": true
  },
  "search.exclude": {
    "**/node_modules": true,
    "**/target": true,
    "**/dist": true
  }
}
```

## package.json（前端）

如果使用 OpenAPI Generator 生成前端代码，可以在 `package.json` 中添加脚本：

```json
{
  "name": "frontend",
  "version": "1.0.0",
  "scripts": {
    "generate:api": "openapi-generator-cli generate -i ../docs/api/openapi.yaml -g typescript-axios -o src/generated/api",
    "generate:types": "openapi-generator-cli generate -i ../docs/api/openapi.yaml -g typescript -o src/generated/types"
  },
  "devDependencies": {
    "@openapitools/openapi-generator-cli": "^2.7.0"
  },
  "dependencies": {
    "axios": "^1.6.0"
  }
}
```

## pom.xml（后端）

SpringDoc OpenAPI 依赖配置：

```xml
<dependencies>
    <!-- SpringDoc OpenAPI -->
    <dependency>
        <groupId>org.springdoc</groupId>
        <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
        <version>2.2.0</version>
    </dependency>
    
    <!-- Bean Validation -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-validation</artifactId>
    </dependency>
</dependencies>
```

## application.yml（后端）

SpringDoc 配置：

```yaml
springdoc:
  api-docs:
    path: /api-docs
    enabled: true
  swagger-ui:
    path: /swagger-ui.html
    enabled: true
    try-it-out-enabled: true
  default-consumes-media-type: application/json
  default-produces-media-type: application/json
```

## 使用说明

1. **创建配置文件**：
   - 在项目根目录创建 `.cursorignore` 和 `.cursorrules`
   - 根据项目实际情况调整配置内容

2. **配置工具路径**（可选）：
   - 在 `.vscode/settings.json` 中配置 Maven、Python 等工具路径
   - 确保 Cursor 能正确识别和使用这些工具

3. **安装依赖**：
   - 前端：`npm install` 或 `yarn install`
   - 后端：`mvn install` 或使用 IDE 自动导入

4. **验证配置**：
   - 检查 Cursor 是否能正确索引项目文件
   - 验证 Agent 是否能正确读取 OpenAPI 规范文件
   - 测试代码生成是否符合规范
