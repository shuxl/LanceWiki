# 有理数系

## 📚 有理数系概述

有理数系是整数系的扩展，包含了所有可以表示为两个整数之比的数。有理数系解决了整数系中除法运算不封闭的问题，为数学分析提供了重要的数系基础。

## 🔗 有理数的定义

### 1.1 直观定义
有理数是可以表示为分数 $\frac{p}{q}$ 的数，其中 $p$ 和 $q$ 是整数，且 $q \neq 0$。

### 1.2 符号表示
有理数集记作：$\mathbb{Q} = \{\frac{p}{q} | p, q \in \mathbb{Z}, q \neq 0\}$

### 1.3 构造定义
有理数可以通过整数有序对来构造：
- 有理数 $(a, b)$ 表示 $\frac{a}{b}$
- 两个有序对 $(a, b)$ 和 $(c, d)$ 相等当且仅当 $ad = bc$

## 📖 有理数的性质

### 2.1 基本性质
- **有序性**：有理数有大小关系
- **稠密性**：任意两个有理数之间都有无穷多个有理数
- **可数性**：有理数集是可数集

### 2.2 运算性质

#### 加法运算
- **封闭性**：两个有理数的和仍是有理数
- **交换律**：$a + b = b + a$
- **结合律**：$(a + b) + c = a + (b + c)$
- **单位元**：$a + 0 = a$
- **逆元**：$a + (-a) = 0$

#### 乘法运算
- **封闭性**：两个有理数的积仍是有理数
- **交换律**：$a \times b = b \times a$
- **结合律**：$(a \times b) \times c = a \times (b \times c)$
- **分配律**：$a \times (b + c) = a \times b + a \times c$
- **单位元**：$a \times 1 = a$
- **逆元**：$a \times \frac{1}{a} = 1$（$a \neq 0$）

#### 除法运算
- **定义**：$a \div b = a \times \frac{1}{b}$（$b \neq 0$）
- **封闭性**：两个有理数的商仍是有理数（除数不为0）

### 2.3 序的性质
- **自反性**：$a \leq a$
- **反对称性**：如果 $a \leq b$ 且 $b \leq a$，则 $a = b$
- **传递性**：如果 $a \leq b$ 且 $b \leq c$，则 $a \leq c$
- **完全性**：任意非空有上界的有理数集合都有最小上界

## 🔗 有理数的表示

### 3.1 分数表示
有理数最基本的表示方法是分数：$\frac{p}{q}$

#### 最简分数
如果 $\gcd(p, q) = 1$，则称 $\frac{p}{q}$ 为**最简分数**。

#### 示例
- $\frac{2}{4} = \frac{1}{2}$（约分）
- $\frac{-3}{6} = \frac{-1}{2}$（约分）

### 3.2 小数表示
有理数可以表示为有限小数或无限循环小数。

#### 有限小数
- $\frac{1}{2} = 0.5$
- $\frac{3}{4} = 0.75$

#### 无限循环小数
- $\frac{1}{3} = 0.\overline{3}$
- $\frac{2}{7} = 0.\overline{285714}$

### 3.3 连分数表示
有理数可以表示为有限连分数。

#### 示例
- $\frac{13}{5} = 2 + \frac{1}{1 + \frac{1}{1 + \frac{1}{2}}} = [2; 1, 1, 2]$

## 📖 有理数的稠密性

### 4.1 稠密性定义
对于任意两个有理数 $a < b$，存在有理数 $c$ 使得 $a < c < b$。

### 4.2 构造方法
给定 $a < b$，可以构造：
$$c = \frac{a + b}{2}$$

### 4.3 推论
- 任意两个有理数之间都有无穷多个有理数
- 有理数在数轴上是稠密的

## 🔗 有理数的应用

### 5.1 在测量中的应用
- **长度测量**：$\frac{1}{2}$ 米、$\frac{3}{4}$ 米
- **时间测量**：$\frac{1}{4}$ 小时、$\frac{2}{3}$ 分钟
- **重量测量**：$\frac{1}{2}$ 千克、$\frac{3}{4}$ 磅

### 5.2 在金融中的应用
- **利率**：$5\% = \frac{5}{100} = \frac{1}{20}$
- **汇率**：$\frac{1}{6.5}$ 美元兑换1元人民币
- **折扣**：$25\%$ 折扣 = $\frac{1}{4}$ 折扣

### 5.3 在概率论中的应用
- **概率值**：概率通常用有理数表示
- **统计比例**：$\frac{3}{4}$ 的学生通过了考试

## 📖 有理数的计算

### 6.1 基本运算

#### 加法
$$\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$$

#### 减法
$$\frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}$$

#### 乘法
$$\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$$

#### 除法
$$\frac{a}{b} \div \frac{c}{d} = \frac{ad}{bc}$$（$c \neq 0$）

### 6.2 示例
```python
def add_fractions(a, b, c, d):
    """有理数加法"""
    numerator = a * d + b * c
    denominator = b * d
    return simplify_fraction(numerator, denominator)

def multiply_fractions(a, b, c, d):
    """有理数乘法"""
    numerator = a * c
    denominator = b * d
    return simplify_fraction(numerator, denominator)

def simplify_fraction(numerator, denominator):
    """约分"""
    gcd_value = gcd(numerator, denominator)
    return (numerator // gcd_value, denominator // gcd_value)
```

## 🔗 与其他数系的联系

### 7.1 与整数系的联系
- 整数是有理数的子集
- 整数可以表示为分数：$n = \frac{n}{1}$

### 7.2 与实数系的联系
- 有理数是实数的子集
- 有理数在实数中是稠密的
- 有理数不满足完备性

### 7.3 与复数系的联系
- 有理数是复数的子集
- 有理数可以表示为复数：$q = q + 0i$

## 📖 有理数的局限性

### 8.1 不完备性
有理数集不满足完备性，即存在有上界的非空有理数集合没有最小上界。

#### 示例
集合 $\{x \in \mathbb{Q} | x^2 < 2\}$ 在有理数中没有最小上界。

### 8.2 代数不完备性
有理数集在代数运算下不完备，例如 $\sqrt{2}$ 不是有理数。
