## 概率编程概念

### 1. 基本定义

概率编程（Probabilistic Programming）是一种编程范式，它将概率模型表示为计算机程序，通过编程语言来描述复杂的概率分布和推理过程。

**核心思想：**
- **模型即程序**：概率模型用程序代码表示
- **自动推理**：推理算法自动处理
- **不确定性建模**：自然处理不确定性
- **可解释性**：模型结构清晰可读

### 2. 概率编程的核心思想

- **声明式建模**：描述"是什么"而不是"怎么做"
- **自动推理**：推理算法自动处理复杂计算
- **不确定性量化**：自然处理模型和预测的不确定性
- **可组合性**：模型可以组合和重用
- **可解释性**：模型结构直观易懂

## 概率编程的数学基础

### 1. 贝叶斯定理

$$P(\theta|D) = \frac{P(D|\theta)P(\theta)}{P(D)}$$

其中：
- $P(\theta|D)$ 是后验概率
- $P(D|\theta)$ 是似然函数
- $P(\theta)$ 是先验概率
- $P(D)$ 是证据

### 2. 变分推断

$$\log P(D) \geq E_{q(\theta)}[\log P(D, \theta) - \log q(\theta)]$$

### 3. 马尔可夫链蒙特卡洛

$$P(\theta^{(t+1)}|\theta^{(t)}) = P(\theta^{(t+1)}|\theta^{(t)})$$

### 4. 重要性采样

$$E[f(X)] = \int f(x)p(x)dx \approx \frac{1}{N} \sum_{i=1}^{N} f(x_i) \frac{p(x_i)}{q(x_i)}$$

## 概率编程的推理算法

### 1. 采样方法

#### 马尔可夫链蒙特卡洛 (MCMC)
- **Metropolis-Hastings**：通用MCMC算法
- **Gibbs采样**：条件采样
- **Hamiltonian Monte Carlo (HMC)**：梯度信息
- **No-U-Turn Sampler (NUTS)**：自适应HMC

#### 粒子方法
- **粒子滤波**：序列蒙特卡洛
- **重要性采样**：加权采样
- **序列重要性重采样 (SIR)**：粒子更新

### 2. 变分方法

#### 变分推断
- **平均场近似**：独立因子
- **结构化变分**：保持依赖关系
- **随机变分推断 (SVI)**：随机优化

#### 期望传播
- **消息传递**：局部近似
- **信念传播**：树结构
- **循环信念传播**：一般图

### 3. 确定性方法

#### 拉普拉斯近似
- **二阶泰勒展开**：高斯近似
- **最大后验估计**：点估计
- **不确定性量化**：协方差矩阵

#### 期望最大化 (EM)
- **E步**：计算期望
- **M步**：最大化参数
- **收敛性**：局部最优

def bayesian_nn(x, layer_sizes):
    for i, size in enumerate(layer_sizes):
        w = tfp.distributions.Normal(0, 1).sample([x.shape[-1], size])

#### TensorFlow Probability
```python
import tensorflow_probability as tfp

# 贝叶斯线性回归
def bayesian_linear_regression(x, y):
    model = tfp.distributions.JointDistributionSequential([
        tfp.distributions.Normal(0., 1.),  # alpha
        tfp.distributions.Normal(0., 1.),  # beta
        tfp.distributions.HalfNormal(1.),  # sigma
        lambda sigma, beta, alpha: tfp.distributions.Normal(
            alpha + beta * x, sigma)
    ])
    return model
```

### 2. R生态

#### Stan
```r
library(rstan)

# Stan模型
stan_code <- "
data {
  int<lower=0> N;
  vector[N] x;
  vector[N] y;
}
parameters {
  real alpha;
  real beta;
  real<lower=0> sigma;
}
model {
  y ~ normal(alpha + beta * x, sigma);
}
"

fit <- stan(model_code = stan_code, data = data)
```

### 3. Julia生态

#### Turing.jl
```julia
using Turing

@model function linear_regression(x, y)
    α ~ Normal(0, 1)
    β ~ Normal(0, 1)
    σ ~ HalfNormal(1)
    
    for i in 1:length(y)
        y[i] ~ Normal(α + β * x[i], σ)
    end
end

model = linear_regression(x, y)
chain = sample(model, NUTS(0.65), 1000)
```
