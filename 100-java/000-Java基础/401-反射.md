## 1.1 什么是反射

反射（Reflection）是Java语言的一种机制，允许程序在运行时：
- 获取类的信息（类名、方法、字段、构造器等）
- 创建对象实例
- 调用方法和访问字段
- 修改字段值
- 动态代理等

反射机制使得Java程序具有了"自省"能力，可以在运行时分析和操作类、接口、字段和方法。

## 1.2 反射的核心类

Java反射机制主要涉及以下几个核心类：

1. **Class类**：表示类的类型信息
2. **Constructor类**：表示构造方法
3. **Field类**：表示字段
4. **Method类**：表示方法
5. **Modifier类**：表示修饰符

# 2 Class类详解

## 2.1 获取Class对象的方式

```java
// 方式1：通过类名.class
Class<?> clazz1 = String.class;
```

## 2.2 Class类的常用方法

```java
public class ReflectionDemo {
    public static void main(String[] args) {
        Class<?> clazz = String.class;

        for (Class<?> interfaceClass : interfaces) {
            System.out.println("接口: " + interfaceClass.getName());
        }
    }
}
```

# 3 反射操作构造方法

## 3.1 获取构造方法

```java
public class ConstructorDemo {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Person.class;
        
        // 获取所有公共构造方法
        Constructor<?>[] publicConstructors = clazz.getConstructors();
        
        // 获取所有构造方法（包括私有）
        Constructor<?>[] allConstructors = clazz.getDeclaredConstructors();
        
        // 获取指定参数的公共构造方法
        Constructor<?> constructor = clazz.getConstructor(String.class, int.class);
        
        // 获取指定参数的构造方法（包括私有）
        Constructor<?> declaredConstructor = clazz.getDeclaredConstructor(String.class);
    }
}

class Person {
    private String name;
    private int age;
    
    public Person() {}
    
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    private Person(String name) {
        this.name = name;
    }
```

## 3.2 创建对象实例

```java
public class CreateInstanceDemo {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Person.class;
        
        // 方式1：使用无参构造方法
        Person person1 = (Person) clazz.newInstance(); // 已废弃，推荐使用getDeclaredConstructor().newInstance()
        
        // 方式2：使用有参构造方法
        Constructor<?> constructor = clazz.getConstructor(String.class, int.class);
        Person person2 = (Person) constructor.newInstance("张三", 25);
        
        // 方式3：使用私有构造方法
        Constructor<?> privateConstructor = clazz.getDeclaredConstructor(String.class);
        privateConstructor.setAccessible(true); // 设置可访问
        Person person3 = (Person) privateConstructor.newInstance("李四");
    }
}
```

# 4 反射操作字段

## 4.1 获取和设置字段值

```java
public class FieldDemo {
    public static void main(String[] args) throws Exception {
        Person person = new Person("张三", 25);
        Class<?> clazz = person.getClass();
        
        // 获取所有公共字段
        Field[] publicFields = clazz.getFields();
        
        // 获取所有字段（包括私有）
        Field[] allFields = clazz.getDeclaredFields();
        
        // 获取指定名称的公共字段
        Field publicField = clazz.getField("publicField");
        
        // 获取指定名称的字段（包括私有）
        Field nameField = clazz.getDeclaredField("name");
        
        // 设置字段可访问
        nameField.setAccessible(true);
        
        // 获取字段值
        String name = (String) nameField.get(person);
        System.out.println("姓名: " + name);
        
        // 设置字段值
        nameField.set(person, "李四");
        System.out.println("修改后姓名: " + nameField.get(person));
    }
}
```

# 5 反射操作方法

## 5.1 获取和调用方法

```java
public class MethodDemo {
    public static void main(String[] args) throws Exception {
        Person person = new Person("张三", 25);
        Class<?> clazz = person.getClass();
        
        // 获取所有公共方法（包括继承的）
        Method[] publicMethods = clazz.getMethods();
        
        // 获取所有方法（不包括继承的）
        Method[] allMethods = clazz.getDeclaredMethods();
        
        // 获取指定名称和参数的公共方法
        Method publicMethod = clazz.getMethod("publicMethod", String.class);
        
        // 获取指定名称和参数的方法（包括私有）
        Method privateMethod = clazz.getDeclaredMethod("privateMethod", int.class);
        
        // 调用公共方法
        Object result1 = publicMethod.invoke(person, "参数");
        
        // 调用私有方法
        privateMethod.setAccessible(true);
        Object result2 = privateMethod.invoke(person, 100);
        
        // 调用静态方法
        Method staticMethod = clazz.getDeclaredMethod("staticMethod");
        Object result3 = staticMethod.invoke(null); // 静态方法传入null
    }
}
```

# 6 反射的性能影响

## 6.1 性能对比

```java
public class PerformanceDemo {
    public static void main(String[] args) throws Exception {
        int iterations = 1000000;
        
        // 直接调用
        long start1 = System.currentTimeMillis();
        for (int i = 0; i < iterations; i++) {
            new Person("张三", 25);
        }
        long end1 = System.currentTimeMillis();
        System.out.println("直接调用耗时: " + (end1 - start1) + "ms");
        
        // 反射调用
        Class<?> clazz = Person.class;
        Constructor<?> constructor = clazz.getConstructor(String.class, int.class);
        long start2 = System.currentTimeMillis();
        for (int i = 0; i < iterations; i++) {
            constructor.newInstance("张三", 25);
        }
        long end2 = System.currentTimeMillis();
        System.out.println("反射调用耗时: " + (end2 - start2) + "ms");
    }
}
```

## 6.2 性能优化建议

1. **缓存反射对象**：避免重复获取Class、Constructor、Method、Field对象
2. **使用setAccessible(true)**：减少访问检查开销
3. **避免在循环中使用反射**：在性能敏感的场景下
4. **考虑使用字节码增强**：如CGLIB、Javassist等

# 7 反射的实际应用

## 7.1 框架开发

```java
public class SimpleContainer {
    private Map<String, Object> beans = new HashMap<>();
    
    public void register(String name, Class<?> clazz) throws Exception {
        Constructor<?> constructor = clazz.getDeclaredConstructor();
        Object instance = constructor.newInstance();
        beans.put(name, instance);
    }
    
    public Object getBean(String name) {
        return beans.get(name);
    }
}
```

## 7.2 配置文件解析

```java
public class ConfigLoader {
    public static <T> T loadConfig(String className, Properties props) throws Exception {
        Class<?> clazz = Class.forName(className);
        T instance = (T) clazz.newInstance();
        
        for (String key : props.stringPropertyNames()) {
            try {
                Field field = clazz.getDeclaredField(key);
                field.setAccessible(true);
                
                String value = props.getProperty(key);
                // 根据字段类型进行转换
                if (field.getType() == String.class) {
                    field.set(instance, value);
                } else if (field.getType() == int.class) {
                    field.set(instance, Integer.parseInt(value));
                }
                // 其他类型转换...
            } catch (NoSuchFieldException e) {
                // 忽略不存在的字段
            }
        }
        
        return instance;
    }
}
```

# 9 反射与注解

## 9.1 获取注解信息

```java
@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})
public @interface MyAnnotation {
    String value() default "";
    int count() default 0;
}

@MyAnnotation(value = "测试类", count = 10)
public class AnnotatedClass {
    @MyAnnotation("测试字段")
    private String field;
    
    @MyAnnotation("测试方法")
    public void method() {}
}

public class AnnotationDemo {
    public static void main(String[] args) {
        Class<?> clazz = AnnotatedClass.class;
        
        // 获取类上的注解
        MyAnnotation classAnnotation = clazz.getAnnotation(MyAnnotation.class);
        if (classAnnotation != null) {
            System.out.println("类注解值: " + classAnnotation.value());
            System.out.println("类注解计数: " + classAnnotation.count());
        }
        
        // 获取方法上的注解
        try {
            Method method = clazz.getDeclaredMethod("method");
            MyAnnotation methodAnnotation = method.getAnnotation(MyAnnotation.class);
            if (methodAnnotation != null) {
                System.out.println("方法注解值: " + methodAnnotation.value());
            }
        } catch (NoSuchMethodException e) {
            e.printStackTrace();
        }
    }
}
```

# 10 反射与泛型

## 10.1 泛型类型擦除

```java
public class GenericDemo {
    public static void main(String[] args) {
        // 泛型类型擦除
        List<String> stringList = new ArrayList<>();
        Class<?> clazz = stringList.getClass();
        System.out.println("实际类型: " + clazz.getName()); // java.util.ArrayList
        
        // 获取泛型信息（需要特殊处理）
        try {
            Field field = GenericClass.class.getDeclaredField("list");
            Type genericType = field.getGenericType();
            if (genericType instanceof ParameterizedType) {
                ParameterizedType paramType = (ParameterizedType) genericType;
                Type[] actualTypes = paramType.getActualTypeArguments();
                System.out.println("泛型类型: " + actualTypes[0]);
            }
        } catch (NoSuchFieldException e) {
            e.printStackTrace();
        }
    }
}

class GenericClass {
    private List<String> list;
}
```
