# 集合基础概念

## 📚 集合的定义

集合是数学中最基本的概念之一，是某些确定对象的总体。集合中的每个对象称为该集合的**元素**。

### 1.1 集合的表示方法

#### 列举法
将集合中的所有元素一一列举出来，用花括号 `{}` 包围。

**示例**：
- $A = \{1, 2, 3, 4, 5\}$ 表示包含1到5的自然数集合
- $B = \{a, b, c\}$ 表示包含字母a、b、c的集合
- $C = \{\}$ 表示空集

#### 描述法
通过描述集合中元素的共同特征来表示集合。

**示例**：
- $A = \{x | x \text{ 是自然数且 } 1 \leq x \leq 5\}$
- $B = \{x | x \text{ 是实数且 } x^2 - 1 = 0\}$ 等价于 $\{-1, 1\}$

#### 图示法
用韦恩图（Venn Diagram）直观地表示集合及其关系。

### 1.2 集合的分类

#### 按元素个数分类
- **有限集**：元素个数有限的集合
- **无限集**：元素个数无限的集合
- **空集**：不包含任何元素的集合，记作 $\emptyset$ 或 $\{\}$

#### 按元素性质分类
- **数集**：元素都是数的集合
- **点集**：元素都是点的集合
- **函数集**：元素都是函数的集合

### 1.3 集合的包含关系

#### 子集
如果集合A的每一个元素都是集合B的元素，则称A是B的**子集**，记作 $A \subseteq B$。

**性质**：
- 任何集合都是自己的子集：$A \subseteq A$
- 空集是任何集合的子集：$\emptyset \subseteq A$

#### 真子集
如果 $A \subseteq B$ 且 $A \neq B$，则称A是B的**真子集**，记作 $A \subset B$。

#### 集合相等
如果 $A \subseteq B$ 且 $B \subseteq A$，则称集合A与B**相等**，记作 $A = B$。

## 🔗 与其他数学概念的联系

### 与数系的联系
- 自然数集：$\mathbb{N} = \{1, 2, 3, \ldots\}$
- 整数集：$\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$
- 有理数集：$\mathbb{Q} = \{\frac{p}{q} | p, q \in \mathbb{Z}, q \neq 0\}$
- 实数集：$\mathbb{R}$

### 与函数的联系
- 函数的定义域和值域都是集合
- 函数的图像是点集

### 与概率论的联系
- 样本空间是集合
- 事件是样本空间的子集

## 📖 学习要点

1. **理解集合的本质**：集合是抽象的概念，不依赖于具体的表示方法
2. **掌握集合的表示**：能够用不同方法表示同一个集合
3. **理解包含关系**：子集、真子集、相等的概念和性质
4. **建立集合思维**：用集合的观点看待数学问题
