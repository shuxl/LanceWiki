## 定时任务概念或介绍

Spring定时任务是Spring框架提供的任务调度功能，支持基于注解的声明式定时任务和编程式的任务调度。它提供了灵活的任务调度机制，支持Cron表达式、固定延迟、固定频率等多种调度方式。通过Spring的定时任务功能，开发者可以轻松实现定时数据同步、定时清理、定时报表生成等场景。

### 定时任务特点
1. **声明式调度**：通过@Scheduled注解实现声明式定时任务
2. **灵活表达式**：支持Cron表达式和多种调度策略
3. **线程池管理**：提供可配置的线程池管理
4. **动态调度**：支持运行时动态添加和修改定时任务
5. **异常处理**：提供完善的异常处理机制

### 设计思想

#### 1. 注解驱动
通过@Scheduled注解实现声明式定时任务配置。

#### 2. 策略模式
通过不同的Trigger实现灵活的任务调度策略。

#### 3. 线程池管理
使用线程池管理定时任务的执行，提高系统性能。

#### 4. 可扩展架构
提供丰富的扩展点，支持自定义调度逻辑。

## 动态定时任务

### 动态任务管理器
```java
@Component
public class DynamicTaskManager {
    
    @Autowired
    private TaskScheduler taskScheduler;
    
    private final Map<String, ScheduledFuture<?>> scheduledTasks = new ConcurrentHashMap<>();
    
    public void addTask(String taskName, Runnable task, String cronExpression) {
        CronTrigger trigger = new CronTrigger(cronExpression);
        ScheduledFuture<?> future = taskScheduler.schedule(task, trigger);
        scheduledTasks.put(taskName, future);
    }
    
    public void addFixedRateTask(String taskName, Runnable task, long period) {
        ScheduledFuture<?> future = taskScheduler.scheduleAtFixedRate(task, period);
        scheduledTasks.put(taskName, future);
    }
    
    public void addFixedDelayTask(String taskName, Runnable task, long delay) {
        ScheduledFuture<?> future = taskScheduler.scheduleWithFixedDelay(task, delay);
        scheduledTasks.put(taskName, future);
    }
    
    public void removeTask(String taskName) {
        ScheduledFuture<?> future = scheduledTasks.remove(taskName);
        if (future != null) {
            future.cancel(false);
        }
    }
    
    public void updateTask(String taskName, Runnable task, String cronExpression) {
        removeTask(taskName);
        addTask(taskName, task, cronExpression);
    }
    
    public Set<String> getTaskNames() {
        return scheduledTasks.keySet();
    }
    
    public boolean isTaskRunning(String taskName) {
        ScheduledFuture<?> future = scheduledTasks.get(taskName);
        return future != null && !future.isCancelled();
    }
}
```

### 动态任务控制器
```java

        Runnable task = () -> {
            System.out.println("Dynamic task '" + taskName + "' executed at: " + new Date());

        Runnable task = () -> {

            // 执行更新后的任务逻辑
        };
        
        taskManager.updateTask(taskName, task, cronExpression);
        return ResponseEntity.ok("Task updated successfully");
    }
    
    @GetMapping
    public ResponseEntity<Set<String>> getTaskNames() {
        return ResponseEntity.ok(taskManager.getTaskNames());
    }
    
    @GetMapping("/{taskName}/status")
    public ResponseEntity<Boolean> getTaskStatus(@PathVariable String taskName) {
        return ResponseEntity.ok(taskManager.isTaskRunning(taskName));
    }
}
```

### 异常处理任务
```java
@Service
public class ExceptionHandlingScheduledService {
    
    private static final Logger logger = LoggerFactory.getLogger(ExceptionHandlingScheduledService.class);
    
    @Scheduled(fixedRate = 60000)
    public void taskWithExceptionHandling() {
        try {
            logger.info("Task with exception handling executed at: {}", new Date());
            // 执行可能抛出异常的任务
            performRiskyOperation();
        } catch (Exception e) {
            logger.error("Task execution failed", e);
            // 处理异常，不中断任务调度
            handleTaskException(e);
        }
    }
    
    @Scheduled(fixedRate = 30000)
    public void taskWithRetry() {
        int maxRetries = 3;
        int retryCount = 0;
        
        while (retryCount < maxRetries) {
            try {
                logger.info("Task with retry executed at: {}", new Date());
                performOperation();
                break; // 成功执行，跳出重试循环
            } catch (Exception e) {
                retryCount++;
                logger.warn("Task execution failed, retry {} of {}", retryCount, maxRetries, e);
                
                if (retryCount >= maxRetries) {
                    logger.error("Task execution failed after {} retries", maxRetries, e);
                    handleFinalFailure(e);
                } else {
                    // 等待一段时间后重试
                    try {
                        Thread.sleep(1000 * retryCount);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }
        }
    }
    
    private void performRiskyOperation() {
        // 模拟可能抛出异常的操作
        if (Math.random() < 0.3) {
            throw new RuntimeException("Random task failure");
        }
    }
    
    private void performOperation() {
        // 模拟可能抛出异常的操作
        if (Math.random() < 0.5) {
            throw new RuntimeException("Operation failure");
        }
    }
    
    private void handleTaskException(Exception e) {
        // 处理任务异常
        logger.error("Handling task exception", e);
    }
    
    private void handleFinalFailure(Exception e) {
        // 处理最终失败
        logger.error("Handling final failure", e);
    }
}
```

### 分布式锁提供者
```java
@Component
public class RedisLockProvider implements LockProvider {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Override
    public boolean acquireLock(String lockKey, long timeoutSeconds) {
        String value = UUID.randomUUID().toString();
        Boolean result = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, value, Duration.ofSeconds(timeoutSeconds));
        return Boolean.TRUE.equals(result);
    }
    
    @Override
    public void releaseLock(String lockKey) {
        redisTemplate.delete(lockKey);
    }
}
```

### 任务指标收集
```java
@Component
public class TaskMetrics {
    
    private final Map<String, TaskExecutionStats> taskStats = new ConcurrentHashMap<>();
    
    public void recordTaskExecution(String taskName, long executionTime, boolean success) {
        taskStats.computeIfAbsent(taskName, k -> new TaskExecutionStats())
            .recordExecution(executionTime, success);
    }
    
    public TaskExecutionStats getTaskStats(String taskName) {
        return taskStats.get(taskName);
    }
    
    public Map<String, TaskExecutionStats> getAllTaskStats() {
        return new HashMap<>(taskStats);
    }
    
    public static class TaskExecutionStats {
        private AtomicLong totalExecutions = new AtomicLong(0);
        private AtomicLong successfulExecutions = new AtomicLong(0);
        private AtomicLong failedExecutions = new AtomicLong(0);
        private AtomicLong totalExecutionTime = new AtomicLong(0);
        private AtomicLong minExecutionTime = new AtomicLong(Long.MAX_VALUE);
        private AtomicLong maxExecutionTime = new AtomicLong(0);
        
        public void recordExecution(long executionTime, boolean success) {
            totalExecutions.incrementAndGet();
            if (success) {
                successfulExecutions.incrementAndGet();
            } else {
                failedExecutions.incrementAndGet();
            }
            
            totalExecutionTime.addAndGet(executionTime);
            
            // 更新最小执行时间
            minExecutionTime.updateAndGet(current -> Math.min(current, executionTime));
            
            // 更新最大执行时间
            maxExecutionTime.updateAndGet(current -> Math.max(current, executionTime));
        }
        
        // getters
        public long getTotalExecutions() { return totalExecutions.get(); }
        public long getSuccessfulExecutions() { return successfulExecutions.get(); }
        public long getFailedExecutions() { return failedExecutions.get(); }
        public double getAverageExecutionTime() {
            long total = totalExecutions.get();
            return total > 0 ? (double) totalExecutionTime.get() / total : 0;
        }
        public long getMinExecutionTime() { return minExecutionTime.get(); }
        public long getMaxExecutionTime() { return maxExecutionTime.get(); }
    }
}
```
