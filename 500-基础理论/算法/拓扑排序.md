# 拓扑排序-重点
- 拓扑排序是对有向无环图（DAG）进行线性排序的算法
- 保证所有有向边都从排序靠前的顶点指向排序靠后的顶点
- 使用Kahn算法（基于入度）或DFS算法实现
- 时间复杂度O(V+E)，空间复杂度O(V)
- 广泛应用于任务调度、编译系统、依赖管理等领域

# 拓扑排序概念或介绍

## 基本概念
拓扑排序（Topological Sorting）是对有向无环图（DAG）的顶点进行线性排序，使得对于图中的每一条有向边(u, v)，顶点u在排序中都出现在顶点v之前。

## 核心特征
1. **有向性**：只适用于有向图
2. **无环性**：图中不能存在环
3. **偏序性**：表示顶点之间的偏序关系
4. **不唯一性**：可能存在多种有效的拓扑排序

## 数学性质
- **偏序关系**：拓扑排序反映了图中的偏序关系
- **传递性**：如果A在B之前，B在C之前，则A在C之前
- **反自反性**：顶点不能在自己之前
- **线性化**：将偏序关系线性化

## DFS算法（基于深度优先搜索）
```python
def topological_sort_dfs(graph):
    """
    使用DFS算法进行拓扑排序
    """
    def dfs(vertex, visited, rec_stack, result):
        visited[vertex] = True
        rec_stack[vertex] = True
        
        # 递归访问所有邻居
        for neighbor in graph.get_neighbors(vertex):
            if not visited[neighbor]:
                if dfs(neighbor, visited, rec_stack, result):
                    return True  # 发现环
            elif rec_stack[neighbor]:
                return True  # 发现环
        
        rec_stack[vertex] = False
        result.append(vertex)  # 后序遍历
        return False
    
    visited = [False] * graph.vertices
    rec_stack = [False] * graph.vertices
    result = []
    
    # 对每个未访问的顶点进行DFS
    for vertex in range(graph.vertices):
        if not visited[vertex]:
            if dfs(vertex, visited, rec_stack, result):
                return None  # 存在环
    
    # 反转结果得到拓扑排序
    return result[::-1]
```

## 带权重的拓扑排序
```python
import heapq
def weighted_topological_sort(graph, weights):
    """
    带权重的拓扑排序算法实现
    基于Kahn算法的改进，引入权重优先级控制顶点处理顺序

    算法原理：
    1. 计算所有顶点的入度
    2. 使用优先队列（最小堆）存储入度为0的顶点，按权重升序排列
    3. 每次从队列中取出权重最小的顶点加入结果
    4. 减少该顶点邻居的入度，若邻居入度为0则加入优先队列
    5. 若结果长度不等于顶点总数，则图中存在环

    参数：
        graph: 图对象，需包含:
            - vertices: 顶点数量
            - get_neighbors(vertex): 返回顶点邻居列表的方法
        weights: 权重数组，索引对应顶点编号，值为权重

    返回：
        list: 按权重优先级排序的拓扑序列，存在环时返回None
    """
    # 初始化入度数组，大小等于顶点数量
    in_degree = [0] * graph.vertices
    
    # 遍历所有顶点，计算每个顶点的入度
    for vertex in range(graph.vertices):
        for neighbor in graph.get_neighbors(vertex):
            in_degree[neighbor] += 1
    
    # 创建优先队列（最小堆），存储(权重, 顶点)元组
    # 堆会自动按权重升序排列，权重越小的顶点优先处理
    priority_queue = []
    for vertex in range(graph.vertices):
        if in_degree[vertex] == 0:
            # 将入度为0的顶点加入优先队列
            heapq.heappush(priority_queue, (weights[vertex], vertex))
    
    # 存储拓扑排序结果
    result = []
    
    # 处理队列中的顶点
    while priority_queue:
        # 取出权重最小的顶点
        weight, vertex = heapq.heappop(priority_queue)
        result.append(vertex)
        
        # 遍历当前顶点的所有邻居
        for neighbor in graph.get_neighbors(vertex):
            # 减少邻居的入度
            in_degree[neighbor] -= 1
            # 若邻居入度为0，加入优先队列
            if in_degree[neighbor] == 0:
                heapq.heappush(priority_queue, (weights[neighbor], neighbor))
    
    # 检查是否所有顶点都被处理（判断是否有环）
    return result if len(result) == graph.vertices else None


class Graph:
    """有向图数据结构，用于拓扑排序测试"""
    def __init__(self, vertices):
        self.vertices = vertices  # 顶点数量
        self.adj_list = [[] for _ in range(vertices)]  # 邻接表
        
    def add_edge(self, u, v):
        """添加有向边 u -> v"""
        self.adj_list[u].append(v)
        
    def get_neighbors(self, vertex):
        """返回顶点的所有邻居"""
        return self.adj_list[vertex]
```

# 拓扑排序的变种算法

## 1. 所有可能的拓扑排序
```python
def all_topological_sorts(graph):
    """
    生成所有可能的拓扑排序
    """
    def backtrack(visited, in_degree, result, all_results):
        # 检查是否所有顶点都已访问
        if len(result) == graph.vertices:
            all_results.append(result[:])
            return
        
        # 尝试所有入度为0的顶点
        for vertex in range(graph.vertices):
            if not visited[vertex] and in_degree[vertex] == 0:
                visited[vertex] = True
                result.append(vertex)
                
                # 更新邻居的入度
                for neighbor in graph.get_neighbors(vertex):
                    in_degree[neighbor] -= 1
                
                backtrack(visited, in_degree, result, all_results)
                
                # 回溯
                for neighbor in graph.get_neighbors(vertex):
                    in_degree[neighbor] += 1
                result.pop()
                visited[vertex] = False
    
    # 初始化
    in_degree = [0] * graph.vertices
    for vertex in range(graph.vertices):
        for neighbor in graph.get_neighbors(vertex):
            in_degree[neighbor] += 1
    
    visited = [False] * graph.vertices
    all_results = []
    backtrack(visited, in_degree, [], all_results)
    
    return all_results
```

## 2. 分层拓扑排序
```python
def layered_topological_sort(graph):
    """
    分层拓扑排序
    将顶点按层次分组
    """
    # 计算入度
    in_degree = [0] * graph.vertices
    for vertex in range(graph.vertices):
        for neighbor in graph.get_neighbors(vertex):
            in_degree[neighbor] += 1
    
    layers = []
    remaining = set(range(graph.vertices))
    
    while remaining:
        # 找到当前层（入度为0的顶点）
        current_layer = []
        for vertex in list(remaining):
            if in_degree[vertex] == 0:
                current_layer.append(vertex)
                remaining.remove(vertex)
        
        if not current_layer:
            return None  # 存在环
        
        layers.append(current_layer)
        
        # 更新下一层的入度
        for vertex in current_layer:
            for neighbor in graph.get_neighbors(vertex):
                if neighbor in remaining:
                    in_degree[neighbor] -= 1
    
    return layers
```

- **增量更新**：支持动态添加边

- **预计算**：预计算常用的排序结果
- **增量排序**：只重新排序受影响的顶点
- **批量处理**：批量处理多个排序请求
