# 方差分析

## 重点内容

本文档详细介绍方差分析（ANOVA）的理论和方法，包括：
- 方差分析的基本概念和思想

## 方差分析基本概念

### 基本思想

**方差分析（ANOVA）**是用于比较多个总体均值是否相等的统计方法。

**核心思想**：将总变异分解为组间变异和组内变异，通过比较组间变异与组内变异的比值来判断均值差异的显著性。

### 方差分析的优势

**与多重t检验相比的优势**：
1. **控制第一类错误**：避免多重比较导致的错误率增加
2. **整体检验**：一次检验多个总体的均值差异
3. **效率更高**：利用所有数据信息进行检验

## 单因素方差分析

### 数学模型

**单因素方差分析模型**：
$$Y_{ij} = \mu + \alpha_i + \epsilon_{ij}$$

其中：
- $Y_{ij}$ 是第 $i$ 组第 $j$ 个观测值
- $\mu$ 是总体均值
- $\alpha_i$ 是第 $i$ 组的效应
- $\epsilon_{ij}$ 是随机误差，$\epsilon_{ij} \sim N(0, \sigma^2)$

### 假设条件

**方差分析的基本假设**：
1. **正态性**：各组观测值服从正态分布
2. **独立性**：观测值之间相互独立
3. **方差齐性**：各组方差相等

### 总平方和分解

**总平方和（SST）**：
$$SST = \sum_{i=1}^{k} \sum_{j=1}^{n_i} (Y_{ij} - \bar{Y}_{..})^2$$

**组间平方和（SSB）**：
$$SSB = \sum_{i=1}^{k} n_i(\bar{Y}_{i.} - \bar{Y}_{..})^2$$

**组内平方和（SSW）**：
$$SSW = \sum_{i=1}^{k} \sum_{j=1}^{n_i} (Y_{ij} - \bar{Y}_{i.})^2$$

**关系**：$SST = SSB + SSW$

### 均方和F统计量

**组间均方（MSB）**：
$$MSB = \frac{SSB}{k-1}$$

**组内均方（MSW）**：
$$MSW = \frac{SSW}{N-k}$$

其中 $N = \sum_{i=1}^{k} n_i$ 是总样本量。

**F统计量**：
$$F = \frac{MSB}{MSW} \sim F(k-1, N-k)$$

### 方差分析表

| 来源 | 平方和 | 自由度 | 均方 | F值 | p值 |
|------|--------|--------|------|-----|-----|
| 组间 | SSB | k-1 | MSB | F | p |
| 组内 | SSW | N-k | MSW | | |
| 总计 | SST | N-1 | | | |

## 双因素方差分析

### 无交互作用模型

**数学模型**：
$$Y_{ijk} = \mu + \alpha_i + \beta_j + \epsilon_{ijk}$$

其中：
- $\alpha_i$ 是因素A的第 $i$ 个水平的效应
- $\beta_j$ 是因素B的第 $j$ 个水平的效应

### 有交互作用模型

**数学模型**：
$$Y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \epsilon_{ijk}$$

其中 $(\alpha\beta)_{ij}$ 是交互作用效应。

### 平方和分解

**总平方和**：
$$SST = SSA + SSB + SSAB + SSE$$

其中：
- $SSA$：因素A的平方和
- $SSB$：因素B的平方和
- $SSAB$：交互作用平方和
- $SSE$：误差平方和

## 方差分析的假设检验

### 正态性检验

**Shapiro-Wilk检验**：
$$W = \frac{(\sum_{i=1}^{n} a_i Y_{(i)})^2}{\sum_{i=1}^{n} (Y_i - \bar{Y})^2}$$

**Anderson-Darling检验**：
$$A^2 = -n - \frac{1}{n}\sum_{i=1}^{n} (2i-1)[\ln F(Y_i) + \ln(1-F(Y_{n+1-i}))]$$

### 方差齐性检验

**Levene检验**：
$$W = \frac{(N-k)\sum_{i=1}^{k} n_i(\bar{Z}_i - \bar{Z})^2}{(k-1)\sum_{i=1}^{k} \sum_{j=1}^{n_i} (Z_{ij} - \bar{Z}_i)^2}$$

其中 $Z_{ij} = |Y_{ij} - \bar{Y}_i|$。

**Bartlett检验**：
$$\chi^2 = \frac{(N-k)\ln(s_p^2) - \sum_{i=1}^{k} (n_i-1)\ln(s_i^2)}{1 + \frac{1}{3(k-1)}(\sum_{i=1}^{k} \frac{1}{n_i-1} - \frac{1}{N-k})}$$

### 独立性检验

**Durbin-Watson检验**（用于时间序列数据）：
$$D = \frac{\sum_{i=2}^{n} (e_i - e_{i-1})^2}{\sum_{i=1}^{n} e_i^2}$$

## 多重比较方法

### LSD法（最小显著差异法）

**LSD统计量**：
$$LSD = t_{\alpha/2}(N-k) \sqrt{MSW(\frac{1}{n_i} + \frac{1}{n_j})}$$

**决策规则**：如果 $|\bar{Y}_i - \bar{Y}_j| > LSD$，则拒绝 $H_0: \mu_i = \mu_j$。

### Tukey法

**Tukey统计量**：
$$q = \frac{|\bar{Y}_i - \bar{Y}_j|}{\sqrt{MSW/n}}$$

**决策规则**：如果 $q > q_{\alpha}(k, N-k)$，则拒绝原假设。

### Scheffé法

**Scheffé统计量**：
$$S = \sqrt{(k-1)F_{\alpha}(k-1, N-k) \cdot MSW(\frac{1}{n_i} + \frac{1}{n_j})}$$

**优势**：适用于任意线性组合的比较。

### Bonferroni法

**Bonferroni校正**：$\alpha_{new} = \alpha/m$

其中 $m$ 是比较的次数。

## 方差分析的底层原理

### 线性模型理论

**方差分析**是线性模型的特例：

$$Y = X\beta + \epsilon$$

其中 $X$ 是设计矩阵，$\beta$ 是参数向量。

### 投影矩阵

**总平方和**：$SST = Y^T(I - \frac{1}{n}J)Y$

**组间平方和**：$SSB = Y^T(P_X - \frac{1}{n}J)Y$

**组内平方和**：$SSW = Y^T(I - P_X)Y$

其中 $P_X = X(X^TX)^{-1}X^T$ 是投影矩阵。

### 关键类和方法

1. **模型类型**：固定效应模型、随机效应模型、混合效应模型
2. **设计类型**：完全随机设计、随机区组设计、拉丁方设计
3. **分析方法**：参数法、非参数法、稳健方法

### 设计思想

方差分析的核心设计思想：
- **变异分解**：将总变异分解为可解释和不可解释部分
- **效应分离**：分离不同因素对响应变量的影响
- **整体检验**：在控制错误率的前提下进行多重比较

## 实际应用中的注意事项

### 样本量要求

**经验法则**：
- 每组至少5个观测值
- 总样本量至少为组数的5倍
- 平衡设计（各组样本量相等）效果更好

### 效应量

**效应量**衡量实际差异的大小：

**Eta平方**：$\eta^2 = \frac{SSB}{SST}$

**Omega平方**：$\omega^2 = \frac{SSB - (k-1)MSW}{SST + MSW}$

**Cohen's f**：$f = \sqrt{\frac{\eta^2}{1-\eta^2}}$

### 非参数替代方法

**Kruskal-Wallis检验**：单因素非参数方差分析

**Friedman检验**：双因素非参数方差分析

## 方差分析在实验设计中的应用

### 完全随机设计

**特点**：每个处理随机分配给实验单元。

**适用情况**：实验单元同质，无系统变异。

### 随机区组设计

**特点**：将实验单元分组，每组内随机分配处理。

**数学模型**：
$$Y_{ij} = \mu + \alpha_i + \beta_j + \epsilon_{ij}$$

其中 $\beta_j$ 是区组效应。

### 拉丁方设计

**特点**：两个区组因素，每个处理在每个区组中只出现一次。

**优势**：控制两个区组因素，提高实验效率。
