# 机器学习中的线性代数

## 重点内容

本文档介绍机器学习中线性代数的核心应用，包括：
- 线性回归中的线性代数
- 神经网络中的矩阵运算
- 支持向量机中的优化
- 主成分分析的应用
- 推荐系统中的矩阵分解

## 1. 线性回归

### 1.1 基本模型

**线性回归模型**：
$$y = \mathbf{w}^T\mathbf{x} + b$$

其中 $\mathbf{w}$ 是权重向量，$\mathbf{x}$ 是特征向量，$b$ 是偏置项。

**矩阵形式**：对于n个样本，可以写成：
$$\mathbf{y} = X\mathbf{w} + \mathbf{b}$$

其中 $X \in \mathbb{R}^{n \times p}$ 是特征矩阵，$\mathbf{y} \in \mathbb{R}^n$ 是目标向量。

### 1.2 最小二乘解

**目标函数**：
$$\min_{\mathbf{w}} \|\mathbf{y} - X\mathbf{w}\|^2$$

**解析解**：
$$\mathbf{w} = (X^TX)^{-1}X^T\mathbf{y}$$

**几何解释**：最小二乘解是 $\mathbf{y}$ 在 $X$ 的列空间上的投影。

### 1.3 正则化

**Ridge回归**：
$$\min_{\mathbf{w}} \|\mathbf{y} - X\mathbf{w}\|^2 + \lambda\|\mathbf{w}\|^2$$

**Lasso回归**：
$$\min_{\mathbf{w}} \|\mathbf{y} - X\mathbf{w}\|^2 + \lambda\|\mathbf{w}\|_1$$

**解析解（Ridge）**：
$$\mathbf{w} = (X^TX + \lambda I)^{-1}X^T\mathbf{y}$$

## 2. 神经网络

### 2.1 前向传播

**单层神经网络**：
$$\mathbf{z} = W\mathbf{x} + \mathbf{b}$$
$$\mathbf{a} = \sigma(\mathbf{z})$$

其中：
- $W$ 是权重矩阵
- $\mathbf{x}$ 是输入向量
- $\mathbf{b}$ 是偏置向量
- $\sigma$ 是激活函数

**多层神经网络**：
$$\mathbf{z}^{(l)} = W^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$$
$$\mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)})$$

### 2.2 反向传播

**梯度计算**：
$$\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial \mathbf{z}^{(l)}} \mathbf{a}^{(l-1)T}$$
$$\frac{\partial L}{\partial \mathbf{b}^{(l)}} = \frac{\partial L}{\partial \mathbf{z}^{(l)}}$$

**链式法则**：
$$\frac{\partial L}{\partial \mathbf{z}^{(l)}} = \frac{\partial L}{\partial \mathbf{a}^{(l)}} \odot \sigma'(\mathbf{z}^{(l)})$$

其中 $\odot$ 表示逐元素乘法。

### 2.3 矩阵运算优化

**批量处理**：使用矩阵运算同时处理多个样本：
$$Z = XW^T + \mathbf{b}$$

**GPU加速**：利用GPU的并行计算能力加速矩阵运算。

## 3. 支持向量机（SVM）

### 3.1 线性SVM

**优化问题**：
$$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2$$
$$\text{s.t. } y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1, \forall i$$

**对偶问题**：
$$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i,j=1}^{n} \alpha_i\alpha_j y_i y_j \mathbf{x}_i^T\mathbf{x}_j$$
$$\text{s.t. } \sum_{i=1}^{n} \alpha_i y_i = 0, \alpha_i \geq 0$$

### 3.2 核技巧

**核函数**：将内积替换为核函数：
$$K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T\phi(\mathbf{x}_j)$$

**常见核函数**：
- 线性核：$K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T\mathbf{x}_j$
- RBF核：$K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma\|\mathbf{x}_i - \mathbf{x}_j\|^2)$
- 多项式核：$K(\mathbf{x}_i, \mathbf{x}_j) = (\gamma\mathbf{x}_i^T\mathbf{x}_j + r)^d$

## 4. 主成分分析（PCA）

### 4.1 降维原理

**目标**：找到数据方差最大的投影方向。

**数学形式**：
$$\max_{\mathbf{w}} \mathbf{w}^T\Sigma\mathbf{w}$$
$$\text{s.t. } \|\mathbf{w}\| = 1$$

其中 $\Sigma$ 是协方差矩阵。

### 4.2 特征值分解

**解**：主成分是协方差矩阵的特征向量：
$$\Sigma = V\Lambda V^T$$

**投影**：数据在主成分上的投影：
$$X_{pca} = XV_k$$

其中 $V_k$ 是前k个特征向量。

### 4.3 应用

**数据预处理**：去除噪声，降低维度。

**特征提取**：提取主要特征模式。

**可视化**：将高维数据投影到2D或3D空间。

## 5. 推荐系统

### 5.1 矩阵分解

**问题**：给定用户-物品评分矩阵 $R$，预测缺失的评分。

**模型**：
$$R \approx UV^T$$

其中 $U$ 是用户特征矩阵，$V$ 是物品特征矩阵。

**优化目标**：
$$\min_{U,V} \sum_{(i,j) \in \Omega} (R_{ij} - \mathbf{u}_i^T\mathbf{v}_j)^2 + \lambda(\|U\|_F^2 + \|V\|_F^2)$$

### 5.2 协同过滤

**基于用户的协同过滤**：找到相似用户，推荐他们喜欢的物品。

**基于物品的协同过滤**：找到相似物品，推荐给喜欢类似物品的用户。

**相似度计算**：使用余弦相似度或皮尔逊相关系数。

## 6. 聚类分析

### 6.1 K-means聚类

**目标函数**：
$$\min_{C, \mu} \sum_{i=1}^{k} \sum_{\mathbf{x} \in C_i} \|\mathbf{x} - \mu_i\|^2$$

其中 $C_i$ 是第i个簇，$\mu_i$ 是第i个簇的中心。

**算法步骤**：
1. 随机初始化簇中心
2. 将每个样本分配到最近的簇中心
3. 更新簇中心为簇内样本的均值
4. 重复步骤2-3直到收敛

### 6.2 谱聚类

**相似度矩阵**：构建样本间的相似度矩阵 $S$。

**拉普拉斯矩阵**：$L = D - S$，其中 $D$ 是度矩阵。

**聚类**：对拉普拉斯矩阵的特征向量进行K-means聚类。

## 7. 深度学习中的线性代数

### 7.1 卷积神经网络（CNN）

**卷积运算**：
$$(f * g)(t) = \int_{-\infty}^{\infty} f(\tau)g(t-\tau)d\tau$$

**离散卷积**：
$$(f * g)[n] = \sum_{m=-\infty}^{\infty} f[m]g[n-m]$$

**矩阵形式**：卷积可以表示为Toeplitz矩阵的乘法。

### 7.2 循环神经网络（RNN）

**状态更新**：
$$\mathbf{h}_t = \tanh(W_h\mathbf{h}_{t-1} + W_x\mathbf{x}_t + \mathbf{b})$$

**输出**：
$$\mathbf{y}_t = W_o\mathbf{h}_t + \mathbf{b}_o$$

**梯度消失问题**：长期依赖关系导致梯度消失。

### 7.3 注意力机制

**注意力权重**：
$$\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{n} \exp(e_{ik})}$$

其中 $e_{ij} = \mathbf{q}_i^T\mathbf{k}_j$。

**注意力输出**：
$$\mathbf{c}_i = \sum_{j=1}^{n} \alpha_{ij}\mathbf{v}_j$$

## 8. 优化算法中的线性代数

### 8.1 梯度下降

**更新规则**：
$$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla f(\mathbf{w}_t)$$

**批量梯度下降**：使用所有样本计算梯度。

**随机梯度下降**：使用单个样本计算梯度。

**小批量梯度下降**：使用部分样本计算梯度。

### 8.2 牛顿法

**更新规则**：
$$\mathbf{w}_{t+1} = \mathbf{w}_t - H^{-1}\nabla f(\mathbf{w}_t)$$

其中 $H$ 是Hessian矩阵。

**优势**：收敛速度快，但计算Hessian矩阵的逆很昂贵。

### 8.3 拟牛顿法

**BFGS算法**：近似Hessian矩阵的逆。

**L-BFGS算法**：限制内存的BFGS算法。
