## 判别模型概念

### 1. 基本定义

判别模型（Discriminative Models）是一类机器学习模型，它们直接学习条件概率分布 $P(Y|X)$，即给定输入 $X$ 时输出 $Y$ 的概率分布。

**数学表示：**
$$P(Y|X) = \frac{P(X, Y)}{P(X)}$$

其中：
- $X$ 是输入特征
- $Y$ 是输出标签
- $P(Y|X)$ 是条件概率分布

### 2. 判别模型的核心思想

- **直接建模**：直接学习输入到输出的映射关系
- **决策边界**：学习最优的决策边界
- **条件概率**：建模条件概率分布
- **特征表示**：学习有效的特征表示

## 判别模型的类型

### 1. 线性判别模型

#### 逻辑回归 (Logistic Regression)
- **结构**：线性模型 + sigmoid激活函数
- **特点**：二分类问题，输出概率
- **数学表示**：$P(Y=1|X) = \frac{1}{1 + e^{-w^T x + b}}$

#### 线性判别分析 (Linear Discriminant Analysis, LDA)
- **结构**：基于类内和类间方差
- **特点**：降维和分类
- **数学表示**：$P(Y=k|X) = \frac{P(X|Y=k)P(Y=k)}{\sum_i P(X|Y=i)P(Y=i)}$

#### 支持向量机 (Support Vector Machine, SVM)
- **结构**：最大间隔分类器
- **特点**：寻找最优分离超平面
- **数学表示**：$f(x) = \text{sign}(\sum_i \alpha_i y_i K(x_i, x) + b)$

### 2. 非线性判别模型

#### 核方法
- **核SVM**：使用核技巧的非线性SVM
- **核逻辑回归**：核化的逻辑回归
- **核LDA**：核化的线性判别分析

#### 决策树
- **结构**：树形结构
- **特点**：可解释性强，处理非线性关系
- **数学表示**：基于if-then规则

#### 随机森林
- **结构**：多个决策树的集成
- **特点**：减少过拟合，提高泛化能力
- **数学表示**：$f(x) = \frac{1}{T} \sum_{t=1}^{T} f_t(x)$

### 3. 深度判别模型

#### 前馈神经网络
- **结构**：多层感知机
- **特点**：自动特征学习
- **数学表示**：$f(x) = \sigma(W_L \sigma(W_{L-1} ... \sigma(W_1 x + b_1) + b_{L-1}) + b_L)$

#### 卷积神经网络 (CNN)
- **结构**：卷积层 + 池化层 + 全连接层
- **特点**：处理图像数据
- **应用**：图像分类、目标检测

#### 循环神经网络 (RNN)
- **结构**：循环连接
- **特点**：处理序列数据
- **应用**：自然语言处理、语音识别

#### Transformer
- **结构**：自注意力机制
- **特点**：并行处理，长距离依赖
- **应用**：机器翻译、语言建模

## 判别模型的数学基础

### 1. 最大似然估计

$$\hat{\theta} = \arg\max_{\theta} \prod_{i=1}^{n} P(y_i|x_i, \theta)$$

### 2. 最大后验估计

$$\hat{\theta} = \arg\max_{\theta} P(\theta|D) = \arg\max_{\theta} P(D|\theta)P(\theta)$$

### 3. 经验风险最小化

$$\hat{f} = \arg\min_{f \in \mathcal{F}} \frac{1}{n} \sum_{i=1}^{n} L(f(x_i), y_i)$$

### 4. 结构风险最小化

$$\hat{f} = \arg\min_{f \in \mathcal{F}} \frac{1}{n} \sum_{i=1}^{n} L(f(x_i), y_i) + \lambda \Omega(f)$$

## 判别模型的训练方法

### 1. 监督学习

#### 梯度下降
- **目标**：最小化损失函数
- **方法**：迭代更新参数
- **变体**：SGD、Adam、RMSprop

#### 正则化
- **L1正则化**：$L1 = \lambda \sum_i |w_i|$
- **L2正则化**：$L2 = \lambda \sum_i w_i^2$
- **Dropout**：随机丢弃神经元

#### 交叉验证
- **K折交叉验证**：数据分成K份
- **留一法**：每次留一个样本
- **分层交叉验证**：保持类别比例

### 2. 半监督学习

#### 自训练
- 用有标签数据训练模型
- 对无标签数据进行预测
- 将高置信度预测加入训练集

#### 一致性正则化
- 对同一输入的不同扰动
- 要求输出保持一致
- 如Mean Teacher、UDA

### 3. 迁移学习

#### 预训练-微调
- 在大规模数据上预训练
- 在目标任务上微调
- 如BERT、GPT

#### 领域适应
- 源域到目标域的适应
- 减少域间差异
- 如DANN、MMD

## 判别模型的评估

### 1. 分类评估

#### 准确率指标
- **准确率**：$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$
- **精确率**：$\text{Precision} = \frac{TP}{TP + FP}$
- **召回率**：$\text{Recall} = \frac{TP}{TP + FN}$
- **F1分数**：$\text{F1} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$

#### ROC和AUC
- **ROC曲线**：TPR vs FPR
- **AUC**：ROC曲线下面积
- **PR曲线**：精确率 vs 召回率

### 2. 回归评估

#### 误差指标
- **均方误差**：$\text{MSE} = \frac{1}{n} \sum_i (y_i - \hat{y}_i)^2$
- **均方根误差**：$\text{RMSE} = \sqrt{\text{MSE}}$
- **平均绝对误差**：$\text{MAE} = \frac{1}{n} \sum_i |y_i - \hat{y}_i|$

#### 决定系数
- **R²**：$R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}$

### 3. 模型选择

#### 交叉验证
- **K折交叉验证**
- **留一法交叉验证**
- **分层交叉验证**

#### 信息准则
- **AIC**：$\text{AIC} = 2k - 2\ln(L)$
- **BIC**：$\text{BIC} = \ln(n)k - 2\ln(L)$

## 判别模型的优缺点

### 优点

1. **直接建模**：直接学习输入到输出的映射
2. **计算效率**：训练和推理速度快
3. **特征学习**：能够自动学习特征表示
4. **泛化能力**：在未见数据上表现良好
5. **可扩展性**：易于扩展到大规模数据

### 缺点

1. **数据依赖**：需要大量标注数据
2. **黑盒性质**：模型可解释性差
3. **过拟合风险**：容易在训练数据上过拟合
4. **分布偏移**：对数据分布变化敏感
5. **特征工程**：需要手工设计特征（传统方法）

### 3. 示例代码

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 简单的神经网络分类器
class Classifier(nn.Module):
    def __init__(self, input_dim, hidden_dim, num_classes):
        super(Classifier, self).__init__()
        
        self.layers = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(hidden_dim, num_classes),
            nn.Softmax(dim=1)
        )
    
    def forward(self, x):
        return self.layers(x)

# 训练函数
def train_model(model, train_loader, criterion, optimizer, num_epochs):
    model.train()
    for epoch in range(num_epochs):
        for batch_x, batch_y in train_loader:
            optimizer.zero_grad()
            outputs = model(batch_x)
            loss = criterion(outputs, batch_y)
            loss.backward()
            optimizer.step()
```
