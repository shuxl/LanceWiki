# 正交性

## 重点内容

本文档介绍向量正交性的核心概念，包括：
- 正交性的定义和性质
- 正交基和正交化
- 正交投影
- 正交性的应用

## 1. 正交性的定义

### 1.1 向量正交

**定义**：两个向量 $\mathbf{a}$ 和 $\mathbf{b}$ 正交当且仅当它们的点积为零：
$$\mathbf{a} \cdot \mathbf{b} = 0$$

**几何意义**：正交向量在几何上垂直。

**符号**：$\mathbf{a} \perp \mathbf{b}$ 表示向量 $\mathbf{a}$ 和 $\mathbf{b}$ 正交。

### 1.2 向量组正交

**定义**：向量组 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\}$ 正交当且仅当：
$$\mathbf{v}_i \cdot \mathbf{v}_j = 0, \quad \forall i \neq j$$

**性质**：
- 正交向量组线性无关
- 正交向量组的子集也是正交的

### 1.3 标准正交基

**定义**：向量组 $\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n\}$ 是标准正交基当且仅当：
$$\mathbf{e}_i \cdot \mathbf{e}_j = \delta_{ij}$$

其中 $\delta_{ij}$ 是克罗内克函数：
$$\delta_{ij} = \begin{cases} 
1 & \text{if } i = j \\
0 & \text{if } i \neq j
\end{cases}$$

## 2. 正交性的性质

### 2.1 基本性质

**性质**：
- 零向量与任何向量都正交
- 如果 $\mathbf{a} \perp \mathbf{b}$，则 $c\mathbf{a} \perp d\mathbf{b}$（$c, d \neq 0$）
- 如果 $\mathbf{a} \perp \mathbf{b}$ 且 $\mathbf{b} \perp \mathbf{c}$，则 $\mathbf{a}$ 与 $\mathbf{c}$ 不一定正交

### 2.2 几何性质

**二维空间**：两个向量正交当且仅当它们垂直。

**三维空间**：两个向量正交当且仅当它们垂直。

**高维空间**：正交性推广了垂直的概念。

### 2.3 代数性质

**线性组合**：如果 $\mathbf{a} \perp \mathbf{b}$，则：
$$(c\mathbf{a} + d\mathbf{b}) \cdot \mathbf{v} = c(\mathbf{a} \cdot \mathbf{v}) + d(\mathbf{b} \cdot \mathbf{v})$$

**范数关系**：对于正交向量 $\mathbf{a}$ 和 $\mathbf{b}$：
$$\|\mathbf{a} + \mathbf{b}\|^2 = \|\mathbf{a}\|^2 + \|\mathbf{b}\|^2$$

这推广了勾股定理。

## 3. 正交化方法

### 3.1 Gram-Schmidt正交化

**目标**：将线性无关的向量组 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ 正交化。

**算法步骤**：
1. $\mathbf{u}_1 = \mathbf{v}_1$
2. 对于 $i = 2, 3, \ldots, n$：
   $$\mathbf{u}_i = \mathbf{v}_i - \sum_{j=1}^{i-1} \frac{\mathbf{v}_i \cdot \mathbf{u}_j}{\|\mathbf{u}_j\|^2} \mathbf{u}_j$$
3. 归一化：$\mathbf{e}_i = \frac{\mathbf{u}_i}{\|\mathbf{u}_i\|}$

**示例**：正交化向量组 $\{(1, 1), (1, 0)\}$
1. $\mathbf{u}_1 = (1, 1)$
2. $\mathbf{u}_2 = (1, 0) - \frac{(1, 0) \cdot (1, 1)}{2} (1, 1) = (1, 0) - \frac{1}{2}(1, 1) = (\frac{1}{2}, -\frac{1}{2})$
3. $\mathbf{e}_1 = \frac{1}{\sqrt{2}}(1, 1)$，$\mathbf{e}_2 = \frac{1}{\sqrt{2}}(1, -1)$

### 3.2 改进的Gram-Schmidt

**问题**：标准Gram-Schmidt算法可能数值不稳定。

**改进方法**：在每一步重新正交化所有向量。

**算法步骤**：
1. $\mathbf{u}_1 = \mathbf{v}_1$
2. 对于 $i = 2, 3, \ldots, n$：
   - $\mathbf{u}_i = \mathbf{v}_i$
   - 对于 $j = 1, 2, \ldots, i-1$：
     $$\mathbf{u}_i = \mathbf{u}_i - \frac{\mathbf{u}_i \cdot \mathbf{u}_j}{\|\mathbf{u}_j\|^2} \mathbf{u}_j$$

### 3.3 Householder变换

**优势**：比Gram-Schmidt更数值稳定。

**基本思想**：使用Householder反射进行正交化。

**Householder矩阵**：
$$H = I - 2\frac{\mathbf{v}\mathbf{v}^T}{\|\mathbf{v}\|^2}$$

## 4. 正交投影

### 4.1 向量投影

**定义**：向量 $\mathbf{a}$ 在向量 $\mathbf{b}$ 上的正交投影为：
$$\text{proj}_{\mathbf{b}}\mathbf{a} = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|^2} \mathbf{b}$$

**性质**：
- $\text{proj}_{\mathbf{b}}\mathbf{a}$ 与 $\mathbf{b}$ 平行
- $\mathbf{a} - \text{proj}_{\mathbf{b}}\mathbf{a}$ 与 $\mathbf{b}$ 正交

### 4.2 子空间投影

**定义**：向量 $\mathbf{a}$ 在子空间 $S$ 上的正交投影是 $S$ 中与 $\mathbf{a}$ 最接近的向量。

**计算方法**：
1. 找到子空间 $S$ 的正交基 $\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_k\}$
2. 计算投影：
   $$\text{proj}_S\mathbf{a} = \sum_{i=1}^{k} (\mathbf{a} \cdot \mathbf{e}_i) \mathbf{e}_i$$

### 4.3 投影矩阵

**定义**：对于子空间 $S$ 的正交基矩阵 $V$，投影矩阵为：
$$P = VV^T$$

**性质**：
- $P^2 = P$（幂等性）
- $P^T = P$（对称性）
- $\text{proj}_S\mathbf{a} = P\mathbf{a}$

## 5. 正交性的应用

### 5.1 最小二乘问题

**问题**：$\min_{\mathbf{x}} \|A\mathbf{x} - \mathbf{b}\|^2$

**解**：最小二乘解是 $\mathbf{b}$ 在 $A$ 的列空间上的正交投影。

**几何解释**：残差向量 $\mathbf{b} - A\mathbf{x}$ 与 $A$ 的列空间正交。

### 5.2 傅里叶级数

**定义**：函数 $f(x)$ 的傅里叶级数展开：
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n\cos(nx) + b_n\sin(nx))$$

**正交性**：三角函数 $\{\cos(nx), \sin(nx)\}$ 在 $[0, 2\pi]$ 上正交。

**系数计算**：
$$a_n = \frac{1}{\pi} \int_0^{2\pi} f(x)\cos(nx) dx$$
$$b_n = \frac{1}{\pi} \int_0^{2\pi} f(x)\sin(nx) dx$$

### 5.3 主成分分析

**正交性**：PCA的主成分是正交的。

**几何意义**：主成分表示数据方差最大的正交方向。

**计算**：通过特征值分解得到正交的特征向量。

### 5.4 信号处理

**正交基**：使用正交基进行信号分解。

**小波变换**：小波函数构成正交基。

**滤波器组**：正交滤波器组用于信号分析。

## 6. 正交矩阵

### 6.1 定义和性质

**定义**：n阶方阵 $Q$ 是正交矩阵当且仅当：
$$Q^TQ = QQ^T = I$$

**性质**：
- $Q^T = Q^{-1}$
- $\det(Q) = \pm 1$
- $Q$ 的列向量构成标准正交基
- $Q$ 的行向量构成标准正交基

### 6.2 旋转矩阵

**二维旋转矩阵**：
$$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

**三维旋转矩阵**：绕x轴、y轴、z轴的旋转矩阵。

**性质**：旋转矩阵是正交矩阵，且行列式为1。

### 6.3 反射矩阵

**Householder矩阵**：
$$H = I - 2\frac{\mathbf{v}\mathbf{v}^T}{\|\mathbf{v}\|^2}$$

**性质**：
- $H^T = H$（对称）
- $H^2 = I$（幂等）
- $\det(H) = -1$

## 7. 正交性的数值计算

### 7.1 数值稳定性

**问题**：浮点运算可能导致正交性损失。

**解决方案**：
- 使用改进的Gram-Schmidt算法
- 使用Householder变换
- 定期重新正交化

### 7.2 正交性检验

**方法**：计算向量组的Gram矩阵：
$$G_{ij} = \mathbf{v}_i \cdot \mathbf{v}_j$$

**检验**：如果向量组正交，则Gram矩阵是对角矩阵。

### 7.3 正交化算法

**QR分解**：通过QR分解得到正交矩阵。

**SVD分解**：通过SVD分解得到正交矩阵。

**特征值分解**：对称矩阵的特征向量是正交的。
