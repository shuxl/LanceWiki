## 梯度下降的基本原理

### 基本思想

梯度下降法是一种一阶优化算法，通过沿着目标函数梯度的反方向进行迭代更新来寻找函数的最小值。

### 数学原理

对于目标函数 $f(x)$，梯度下降的迭代公式为：

$$x_{k+1} = x_k - \alpha \nabla f(x_k)$$

其中：
- $x_k$ 是第 $k$ 次迭代的参数值
- $\alpha$ 是学习率（步长）
- $\nabla f(x_k)$ 是目标函数在 $x_k$ 处的梯度

### 梯度方向的意义

梯度 $\nabla f(x)$ 指向函数增长最快的方向，因此 $-\nabla f(x)$ 指向函数下降最快的方向。

## 学习率的选择

### 学习率的重要性

学习率 $\alpha$ 是梯度下降算法中最重要的超参数之一：

- **过大：** 可能导致算法不收敛或震荡
- **过小：** 收敛速度慢，需要更多迭代次数

### 学习率选择策略

#### 1. 固定学习率

选择经验值，如 $\alpha = 0.01$ 或 $\alpha = 0.1$。

#### 2. 学习率衰减

$$\alpha_k = \frac{\alpha_0}{1 + \beta k}$$

其中 $\alpha_0$ 是初始学习率，$\beta$ 是衰减参数。

#### 3. 自适应学习率

根据梯度的变化自动调整学习率。

## 批量梯度下降（BGD）

### 算法描述

批量梯度下降使用所有训练数据计算梯度：

$$\nabla f(x) = \frac{1}{n} \sum_{i=1}^{n} \nabla f_i(x)$$

### 特点

**优点：**
- 梯度估计准确
- 收敛稳定

**缺点：**
- 计算量大
- 内存需求高
- 不适合大规模数据

### 代码示例

```python
def batch_gradient_descent(X, y, theta, alpha, num_iters):
    m = len(y)
    for i in range(num_iters):
        # 计算梯度
        gradient = (1/m) * X.T.dot(X.dot(theta) - y)
        # 更新参数
        theta = theta - alpha * gradient
    return theta
```

## 随机梯度下降（SGD）

### 算法描述

随机梯度下降每次只使用一个样本计算梯度：

$$\nabla f(x) = \nabla f_i(x)$$

其中 $i$ 是随机选择的样本索引。

### 特点

**优点：**
- 计算量小
- 内存需求低
- 适合大规模数据
- 有逃离局部最优的能力

**缺点：**
- 梯度估计有噪声
- 收敛不稳定
- 需要更多迭代次数

### 代码示例

```python
def stochastic_gradient_descent(X, y, theta, alpha, num_iters):
    m = len(y)
    for i in range(num_iters):
        # 随机选择一个样本
        idx = np.random.randint(0, m)
        x_i = X[idx:idx+1]
        y_i = y[idx:idx+1]
        
        # 计算梯度
        gradient = x_i.T.dot(x_i.dot(theta) - y_i)
        # 更新参数
        theta = theta - alpha * gradient
    return theta
```

## 小批量梯度下降（Mini-batch SGD）

### 算法描述

小批量梯度下降使用一小批数据计算梯度：

$$\nabla f(x) = \frac{1}{|B|} \sum_{i \in B} \nabla f_i(x)$$

其中 $B$ 是小批量样本的索引集合。

### 特点

结合了BGD和SGD的优点：
- 梯度估计相对准确
- 计算量适中
- 内存需求适中
- 收敛相对稳定

## 带动量的梯度下降

### 动量法原理

动量法通过引入速度项来加速收敛：

$$v_{k+1} = \beta v_k + \alpha \nabla f(x_k)$$
$$x_{k+1} = x_k - v_{k+1}$$

其中 $\beta$ 是动量系数，通常取 $0.9$。

### 物理意义

动量法模拟了物理中的惯性，可以帮助算法：
- 加速收敛
- 减少震荡
- 逃离局部最优

### 代码示例

```python
def momentum_gradient_descent(X, y, theta, alpha, beta, num_iters):
    m = len(y)
    v = np.zeros_like(theta)
    
    for i in range(num_iters):
        # 计算梯度
        gradient = (1/m) * X.T.dot(X.dot(theta) - y)
        
        # 更新速度
        v = beta * v + alpha * gradient
        
        # 更新参数
        theta = theta - v
    return theta
```

## 自适应学习率方法

### AdaGrad

AdaGrad根据历史梯度的平方和自适应调整学习率：

$$G_k = G_{k-1} + \nabla f(x_k)^2$$
$$x_{k+1} = x_k - \frac{\alpha}{\sqrt{G_k + \epsilon}} \nabla f(x_k)$$

### RMSprop

RMSprop使用指数移动平均来估计梯度的二阶矩：

$$E[g^2]_k = \rho E[g^2]_{k-1} + (1-\rho) \nabla f(x_k)^2$$
$$x_{k+1} = x_k - \frac{\alpha}{\sqrt{E[g^2]_k + \epsilon}} \nabla f(x_k)$$

### Adam

Adam结合了动量和自适应学习率：

$$m_k = \beta_1 m_{k-1} + (1-\beta_1) \nabla f(x_k)$$
$$v_k = \beta_2 v_{k-1} + (1-\beta_2) \nabla f(x_k)^2$$
$$\hat{m}_k = \frac{m_k}{1-\beta_1^k}$$
$$\hat{v}_k = \frac{v_k}{1-\beta_2^k}$$
$$x_{k+1} = x_k - \frac{\alpha}{\sqrt{\hat{v}_k} + \epsilon} \hat{m}_k$$

## 收敛性分析

### 收敛条件

对于凸函数，梯度下降在适当的学习率下能够收敛到全局最优解。

### 收敛速度

- **凸函数：** 收敛速度为 $O(1/k)$
- **强凸函数：** 收敛速度为 $O(\rho^k)$，其中 $\rho < 1$
