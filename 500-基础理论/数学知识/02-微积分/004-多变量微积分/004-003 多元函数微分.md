## 全微分

### 全微分的定义
对于二元函数 $f(x, y)$，如果存在常数 $A$ 和 $B$，使得：

$$f(x + \Delta x, y + \Delta y) - f(x, y) = A\Delta x + B\Delta y + \epsilon_1\Delta x + \epsilon_2\Delta y$$

其中 $\epsilon_1$ 和 $\epsilon_2$ 当 $(\Delta x, \Delta y) \to (0, 0)$ 时趋于零，则称函数 $f$ 在点 $(x, y)$ 可微，且：

$$df = A dx + B dy$$

### 可微的条件
函数 $f(x, y)$ 在点 $(a, b)$ 可微的充分条件是：
1. 偏导数 $\frac{\partial f}{\partial x}$ 和 $\frac{\partial f}{\partial y}$ 在点 $(a, b)$ 存在
2. 偏导数在点 $(a, b)$ 连续

### 全微分的计算
如果函数 $f(x, y)$ 可微，则：

$$df = \frac{\partial f}{\partial x} dx + \frac{\partial f}{\partial y} dy$$

**示例：**
计算 $f(x, y) = x^2 + xy + y^2$ 的全微分：

$$\frac{\partial f}{\partial x} = 2x + y, \quad \frac{\partial f}{\partial y} = x + 2y$$

因此：

$$df = (2x + y) dx + (x + 2y) dy$$

### 全微分的几何意义
全微分表示函数在点 $(a, b)$ 处的切平面与函数值的差。

## 多元复合函数求导

### 链式法则
对于复合函数 $f(x(t), y(t))$，其导数为：

$$\frac{df}{dt} = \frac{\partial f}{\partial x} \frac{dx}{dt} + \frac{\partial f}{\partial y} \frac{dy}{dt}$$

### 多元复合函数
对于复合函数 $f(x(u, v), y(u, v))$，偏导数为：

$$\frac{\partial f}{\partial u} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial u} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial u}$$

$$\frac{\partial f}{\partial v} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial v} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial v}$$

**示例：**
设 $f(x, y) = x^2 + y^2$，$x = r\cos\theta$，$y = r\sin\theta$，求 $\frac{\partial f}{\partial r}$ 和 $\frac{\partial f}{\partial \theta}$：

$$\frac{\partial f}{\partial x} = 2x, \quad \frac{\partial f}{\partial y} = 2y$$

$$\frac{\partial x}{\partial r} = \cos\theta, \quad \frac{\partial y}{\partial r} = \sin\theta$$

$$\frac{\partial x}{\partial \theta} = -r\sin\theta, \quad \frac{\partial y}{\partial \theta} = r\cos\theta$$

因此：

$$\frac{\partial f}{\partial r} = 2x\cos\theta + 2y\sin\theta = 2r\cos^2\theta + 2r\sin^2\theta = 2r$$

$$\frac{\partial f}{\partial \theta} = 2x(-r\sin\theta) + 2y(r\cos\theta) = -2r^2\cos\theta\sin\theta + 2r^2\sin\theta\cos\theta = 0$$

### 高阶复合函数求导
对于高阶偏导数，需要多次应用链式法则。

**示例：**
计算 $\frac{\partial^2 f}{\partial r^2}$：

$$\frac{\partial^2 f}{\partial r^2} = \frac{\partial}{\partial r}\left(\frac{\partial f}{\partial r}\right) = \frac{\partial}{\partial r}(2r) = 2$$

## 隐函数求导

### 一元隐函数求导
对于隐函数 $F(x, y) = 0$，如果 $\frac{\partial F}{\partial y} \neq 0$，则：

$$\frac{dy}{dx} = -\frac{\frac{\partial F}{\partial x}}{\frac{\partial F}{\partial y}}$$

**示例：**
对于方程 $x^2 + y^2 = 1$，求 $\frac{dy}{dx}$：

设 $F(x, y) = x^2 + y^2 - 1 = 0$

$$\frac{\partial F}{\partial x} = 2x, \quad \frac{\partial F}{\partial y} = 2y$$

因此：

$$\frac{dy}{dx} = -\frac{2x}{2y} = -\frac{x}{y}$$

### 多元隐函数求导
对于隐函数 $F(x, y, z) = 0$，如果 $\frac{\partial F}{\partial z} \neq 0$，则：

$$\frac{\partial z}{\partial x} = -\frac{\frac{\partial F}{\partial x}}{\frac{\partial F}{\partial z}}$$

$$\frac{\partial z}{\partial y} = -\frac{\frac{\partial F}{\partial y}}{\frac{\partial F}{\partial z}}$$

**示例：**
对于方程 $x^2 + y^2 + z^2 = 1$，求 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial z}{\partial y}$：

设 $F(x, y, z) = x^2 + y^2 + z^2 - 1 = 0$

$$\frac{\partial F}{\partial x} = 2x, \quad \frac{\partial F}{\partial y} = 2y, \quad \frac{\partial F}{\partial z} = 2z$$

因此：

$$\frac{\partial z}{\partial x} = -\frac{2x}{2z} = -\frac{x}{z}$$

$$\frac{\partial z}{\partial y} = -\frac{2y}{2z} = -\frac{y}{z}$$

## 多元函数的极值

### 极值的定义
函数 $f(x, y)$ 在点 $(a, b)$ 处取得局部极大值（极小值），如果存在邻域 $U$，使得对于所有 $(x, y) \in U$，有：

$$f(x, y) \leq f(a, b) \quad (\text{或} \quad f(x, y) \geq f(a, b))$$

### 极值的必要条件
如果函数 $f(x, y)$ 在点 $(a, b)$ 处取得极值，且在该点可微，则：

$$\frac{\partial f}{\partial x}(a, b) = 0, \quad \frac{\partial f}{\partial y}(a, b) = 0$$

### 极值的充分条件
设函数 $f(x, y)$ 在点 $(a, b)$ 处满足：

$$\frac{\partial f}{\partial x}(a, b) = 0, \quad \frac{\partial f}{\partial y}(a, b) = 0$$

记：

$$A = \frac{\partial^2 f}{\partial x^2}(a, b), \quad B = \frac{\partial^2 f}{\partial x \partial y}(a, b), \quad C = \frac{\partial^2 f}{\partial y^2}(a, b)$$

则：
1. 如果 $AC - B^2 > 0$ 且 $A > 0$，则 $f$ 在 $(a, b)$ 处取得局部极小值
2. 如果 $AC - B^2 > 0$ 且 $A < 0$，则 $f$ 在 $(a, b)$ 处取得局部极大值
3. 如果 $AC - B^2 < 0$，则 $f$ 在 $(a, b)$ 处不取得极值（鞍点）
4. 如果 $AC - B^2 = 0$，则需要进一步分析

**示例：**
求函数 $f(x, y) = x^2 + y^2$ 的极值：

$$\frac{\partial f}{\partial x} = 2x, \quad \frac{\partial f}{\partial y} = 2y$$

令偏导数为零：$2x = 0, 2y = 0$，得临界点 $(0, 0)$

$$\frac{\partial^2 f}{\partial x^2} = 2, \quad \frac{\partial^2 f}{\partial y^2} = 2, \quad \frac{\partial^2 f}{\partial x \partial y} = 0$$

在点 $(0, 0)$ 处：$A = 2, B = 0, C = 2$

$AC - B^2 = 4 > 0$ 且 $A = 2 > 0$，因此 $f$ 在 $(0, 0)$ 处取得局部极小值。

## 拉格朗日乘数法

### 约束极值问题
求函数 $f(x, y)$ 在约束条件 $g(x, y) = 0$ 下的极值。

### 拉格朗日乘数法
构造拉格朗日函数：

$$L(x, y, \lambda) = f(x, y) - \lambda g(x, y)$$

求解方程组：

$$\frac{\partial L}{\partial x} = 0, \quad \frac{\partial L}{\partial y} = 0, \quad \frac{\partial L}{\partial \lambda} = 0$$

即：

$$\frac{\partial f}{\partial x} - \lambda \frac{\partial g}{\partial x} = 0$$

$$\frac{\partial f}{\partial y} - \lambda \frac{\partial g}{\partial y} = 0$$

$$g(x, y) = 0$$

**示例：**
求函数 $f(x, y) = x^2 + y^2$ 在约束条件 $x + y = 1$ 下的极值：

构造拉格朗日函数：

$$L(x, y, \lambda) = x^2 + y^2 - \lambda(x + y - 1)$$

求解方程组：

$$\frac{\partial L}{\partial x} = 2x - \lambda = 0$$

$$\frac{\partial L}{\partial y} = 2y - \lambda = 0$$

$$\frac{\partial L}{\partial \lambda} = -(x + y - 1) = 0$$

解得：$x = y = \frac{1}{2}, \lambda = 1$

因此，函数在点 $(\frac{1}{2}, \frac{1}{2})$ 处取得约束极值。

### 多个约束条件
对于多个约束条件 $g_1(x, y) = 0, g_2(x, y) = 0$，构造拉格朗日函数：

$$L(x, y, \lambda_1, \lambda_2) = f(x, y) - \lambda_1 g_1(x, y) - \lambda_2 g_2(x, y)$$

### 拉格朗日乘数的几何意义
拉格朗日乘数 $\lambda$ 表示约束条件对目标函数极值的影响程度。

## 多元函数微分关联的其它知识

### 与单变量函数微分的关系
多元函数微分是单变量函数微分的推广，单变量函数的微分可以看作多元函数微分的特例。

### 与线性代数的关系
全微分与线性代数中的线性变换密切相关，雅可比矩阵就是全微分的矩阵表示。

### 与微分几何的关系
多元函数微分在微分几何中用于定义切空间、余切空间等几何概念。

### 与优化理论的关系
多元函数微分是优化理论的基础，梯度下降、牛顿法等优化算法都基于微分。

### 与物理学的关系
在物理学中，多元函数微分用于描述各种物理量的变化，如温度梯度、压力梯度等。

### 与机器学习的关系
在机器学习中，多元函数微分用于训练神经网络，反向传播算法就是基于链式法则的微分计算。
