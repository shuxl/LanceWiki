# 集合运算

## 📚 基本集合运算

集合运算是集合论的核心内容，包括并集、交集、差集、补集四种基本运算。这些运算为数学分析、概率论等高级数学分支提供了基础工具。

### 1.1 并集（Union）

#### 定义
设 $A$ 和 $B$ 是两个集合，它们的**并集**记作 $A \cup B$，定义为：
$$A \cup B = \{x | x \in A \text{ 或 } x \in B\}$$

#### 性质
- **交换律**：$A \cup B = B \cup A$
- **结合律**：$(A \cup B) \cup C = A \cup (B \cup C)$
- **幂等律**：$A \cup A = A$
- **单位元**：$A \cup \emptyset = A$

#### 示例
- $A = \{1, 2, 3\}$，$B = \{3, 4, 5\}$
- $A \cup B = \{1, 2, 3, 4, 5\}$

### 1.2 交集（Intersection）

#### 定义
设 $A$ 和 $B$ 是两个集合，它们的**交集**记作 $A \cap B$，定义为：
$$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$$

#### 性质
- **交换律**：$A \cap B = B \cap A$
- **结合律**：$(A \cap B) \cap C = A \cap (B \cap C)$
- **幂等律**：$A \cap A = A$
- **零元**：$A \cap \emptyset = \emptyset$

#### 示例
- $A = \{1, 2, 3\}$，$B = \{3, 4, 5\}$
- $A \cap B = \{3\}$

### 1.3 差集（Difference）

#### 定义
设 $A$ 和 $B$ 是两个集合，$A$ 与 $B$ 的**差集**记作 $A - B$ 或 $A \setminus B$，定义为：
$$A - B = \{x | x \in A \text{ 且 } x \notin B\}$$

#### 性质
- **非交换**：$A - B \neq B - A$（一般情况）
- **与空集**：$A - \emptyset = A$
- **与自身**：$A - A = \emptyset$

#### 示例
- $A = \{1, 2, 3, 4\}$，$B = \{3, 4, 5\}$
- $A - B = \{1, 2\}$
- $B - A = \{5\}$

### 1.4 补集（Complement）

#### 定义
设 $U$ 是全集，$A$ 是 $U$ 的子集，$A$ 的**补集**记作 $A^c$ 或 $\overline{A}$，定义为：
$$A^c = \{x | x \in U \text{ 且 } x \notin A\}$$

#### 性质
- **双重否定**：$(A^c)^c = A$
- **全集补集**：$U^c = \emptyset$
- **空集补集**：$\emptyset^c = U$

#### 示例
- 全集 $U = \{1, 2, 3, 4, 5\}$
- 集合 $A = \{1, 2, 3\}$
- $A^c = \{4, 5\}$

## 🔗 运算之间的关系

### 2.1 德摩根律（De Morgan's Laws）

#### 第一德摩根律
$$(A \cup B)^c = A^c \cap B^c$$

#### 第二德摩根律
$$(A \cap B)^c = A^c \cup B^c$$

#### 证明思路
- 使用集合相等的定义：两个集合相等当且仅当它们包含相同的元素
- 通过逻辑推理证明：$x \in (A \cup B)^c$ 等价于 $x \in A^c \cap B^c$

### 2.2 分配律（Distributive Laws）

#### 并集对交集的分配律
$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$

#### 交集对并集的分配律
$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

## 📖 集合运算的应用

### 3.1 在数集中的应用

#### 区间运算
- $[1, 3] \cup [2, 4] = [1, 4]$
- $[1, 3] \cap [2, 4] = [2, 3]$
- $[1, 3] - [2, 4] = [1, 2)$

#### 数集运算
- $\mathbb{N} \cup \{0\} = \mathbb{Z}^+$（非负整数）
- $\mathbb{Z} \cap \mathbb{Q} = \mathbb{Z}$（整数是有理数的子集）

### 3.2 在概率论中的应用

#### 事件运算
- $A \cup B$：事件A或事件B发生
- $A \cap B$：事件A和事件B同时发生
- $A - B$：事件A发生但事件B不发生
- $A^c$：事件A不发生

### 3.3 在逻辑学中的应用

#### 逻辑运算对应
- 并集 ↔ 逻辑或（OR）
- 交集 ↔ 逻辑与（AND）
- 补集 ↔ 逻辑非（NOT）

## 🔗 与其他数学概念的联系

### 与函数论的联系
- 函数的定义域和值域都是集合
- 函数的复合涉及集合的运算

### 与线性代数的联系
- 向量空间是集合，子空间是子集
- 线性变换的核和像都是集合

### 与拓扑学的联系
- 开集、闭集都是集合
- 集合运算在拓扑学中有重要应用

## 📖 学习要点

1. **掌握基本运算**：并集、交集、差集、补集的定义和性质
2. **理解运算律**：交换律、结合律、分配律、德摩根律
3. **熟练运算技巧**：能够进行复杂的集合运算
4. **应用能力**：在概率论、逻辑学等领域应用集合运算
