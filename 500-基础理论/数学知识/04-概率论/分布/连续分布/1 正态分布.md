# 正态分布

## 重点

- **定义**：连续概率分布，呈钟形曲线，由均值和标准差完全确定
- **中心极限定理**：大量独立随机变量和的极限分布
- **应用场景**：自然科学、社会科学、工程技术的几乎所有领域
- **数学性质**：对称性、68-95-99.7规则、线性变换保持正态性
- **标准化**：将任意正态分布转换为标准正态分布的方法

## 正态分布概念

正态分布（Normal Distribution），也称为高斯分布（Gaussian Distribution），是概率论和统计学中最重要的连续概率分布之一。它描述了自然界中许多随机现象的概率分布规律，具有钟形曲线的特征。

### 基本特征

正态分布具有以下基本特征：
- **对称性**：以均值为中心对称
- **单峰性**：只有一个峰值，位于均值处
- **钟形曲线**：概率密度函数呈钟形
- **渐近性**：曲线向两端无限延伸，但概率密度趋近于零

## 数学定义

### 概率密度函数

正态分布的概率密度函数为：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

其中：
- $\mu$：均值（期望值）
- $\sigma$：标准差
- $\sigma^2$：方差
- $e$：自然对数的底数
- $\pi$：圆周率

### 参数说明

- **均值μ**：分布的中心位置，决定了曲线的对称轴
- **标准差σ**：分布的离散程度，决定了曲线的宽度
- **方差σ²**：标准差的平方，衡量数据的变异性

### 累积分布函数

正态分布的累积分布函数为：

$$F(x) = \frac{1}{\sigma\sqrt{2\pi}} \int_{-\infty}^{x} e^{-\frac{(t-\mu)^2}{2\sigma^2}} dt$$

这个积分没有初等函数的解析解，通常通过数值方法或查表计算。

## 分布性质

### 1. 基本性质

- **对称性**：$f(\mu + x) = f(\mu - x)$
- **单峰性**：在 $x = \mu$ 处取得最大值
- **渐近性**：$\lim_{x \to \pm\infty} f(x) = 0$

### 2. 数字特征

- **期望值**：$E(X) = \mu$
- **方差**：$Var(X) = \sigma^2$
- **偏度**：$\gamma_1 = 0$（对称分布）
- **峰度**：$\gamma_2 = 0$（标准正态分布）

### 3. 68-95-99.7规则

对于正态分布，约：
- 68%的数据落在 $(\mu - \sigma, \mu + \sigma)$ 区间内
- 95%的数据落在 $(\mu - 2\sigma, \mu + 2\sigma)$ 区间内
- 99.7%的数据落在 $(\mu - 3\sigma, \mu + 3\sigma)$ 区间内

## 标准正态分布

### 定义

标准正态分布是均值为0、标准差为1的正态分布：

$$f(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$$

### 标准化变换

任意正态分布 $X \sim N(\mu, \sigma^2)$ 可以通过标准化变换转换为标准正态分布：

$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$

### 标准正态分布表

标准正态分布的累积分布函数值通常通过查表获得，记为 $\Phi(z)$：

$$\Phi(z) = P(Z \leq z) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{z} e^{-\frac{t^2}{2}} dt$$

## 中心极限定理

### 定理内容

设 $X_1, X_2, \ldots, X_n$ 是独立同分布的随机变量，期望为 $\mu$，方差为 $\sigma^2$，则当 $n$ 充分大时，标准化随机变量：

$$Z_n = \frac{\sum_{i=1}^{n} X_i - n\mu}{\sigma\sqrt{n}}$$

近似服从标准正态分布 $N(0, 1)$。

### 实际意义

中心极限定理解释了为什么正态分布在自然界中如此普遍：
- 许多现象是大量独立因素综合作用的结果
- 即使单个因素不服从正态分布，其和也近似正态分布
- 这为统计推断提供了理论基础

## 与其他分布的关系

### 1. 与二项分布的关系

当 $n$ 很大且 $p$ 不接近0或1时，二项分布 $B(n, p)$ 近似于正态分布 $N(np, np(1-p))$。

### 2. 与泊松分布的关系

当 $\lambda$ 很大时，泊松分布 $P(\lambda)$ 近似于正态分布 $N(\lambda, \lambda)$。

### 3. 与卡方分布的关系

标准正态分布的平方服从自由度为1的卡方分布：
$Z^2 \sim \chi^2(1)$

### 4. 与t分布的关系

t分布是标准正态分布与卡方分布的组合，用于小样本统计推断。

## 实际计算示例

### 示例1：标准化计算

**问题**：设 $X \sim N(100, 16)$，求 $P(95 \leq X \leq 105)$。

**解答**：
1. 标准化：$Z = \frac{X - 100}{4}$
2. $P(95 \leq X \leq 105) = P(-1.25 \leq Z \leq 1.25)$
3. $= \Phi(1.25) - \Phi(-1.25) = 2\Phi(1.25) - 1 \approx 0.7887$

### 示例2：分位数计算

**问题**：求标准正态分布的95%分位数。

**解答**：
- 需要找到 $z$ 使得 $P(Z \leq z) = 0.95$
- 查表得 $z \approx 1.645$

### 示例3：质量控制

**问题**：某产品的长度服从 $N(10, 0.04)$，规格为 $10 \pm 0.3$，求合格率。

**解答**：
1. 标准化：$Z = \frac{X - 10}{0.2}$
2. $P(9.7 \leq X \leq 10.3) = P(-1.5 \leq Z \leq 1.5)$
3. $= 2\Phi(1.5) - 1 \approx 0.8664$
