# 1 红黑树定义与性质

**本文重点：**
- 红黑树的五大性质及其意义
- 红黑树的旋转操作（左旋、右旋）
- 红黑树的插入和删除操作及修复过程
- 红黑树的Java代码实现
- 在Java集合框架中的应用场景

- 红黑树（Red-Black Tree）是一种自平衡二叉搜索树，广泛应用于Java集合（如TreeMap、TreeSet）。
- 主要性质：
  1. 每个节点要么是红色，要么是黑色。
  2. 根节点是黑色。
  3. 每个叶子节点（NIL）是黑色。
  4. 红色节点的子节点必须是黑色（不能有两个连续的红色节点）。
  5. 从任一节点到其所有后代叶子节点的路径上，均包含相同数目的黑色节点。

# 2 红黑树的操作（旋转、插入、删除）

## 2.1 旋转操作

### 左旋（Left Rotation）
左旋操作将某个节点向左旋转，使其右子节点成为新的父节点。

```
     y                    x
    / \                  / \
   x   C    左旋后      A   y
  / \                      / \
 A   B                    B   C
```

**左旋步骤：**
1. 将y的左子节点设为x的右子节点
2. 将x的父节点设为y的父节点
3. 将y设为x的右子节点
4. 更新相关节点的父节点引用

### 右旋（Right Rotation）
右旋操作将某个节点向右旋转，使其左子节点成为新的父节点。

```
     y                    x
    / \                  / \
   x   C    右旋后      A   y
  / \                      / \
 A   B                    B   C
```

**右旋步骤：**
1. 将x的右子节点设为y的左子节点
2. 将y的父节点设为x的父节点
3. 将x设为y的左子节点
4. 更新相关节点的父节点引用

## 2.2 插入操作

红黑树的插入操作分为两个阶段：
1. **普通BST插入**：按照二叉搜索树的规则插入新节点
2. **修复红黑树性质**：通过重新着色和旋转修复被破坏的性质

### 插入修复的三种情况

**情况1：叔节点是红色**
- 将父节点和叔节点都染成黑色
- 将祖父节点染成红色
- 将祖父节点作为当前节点继续修复

**情况2：叔节点是黑色，当前节点是右子节点**
- 将父节点作为当前节点
- 对当前节点进行左旋

**情况3：叔节点是黑色，当前节点是左子节点**
- 将父节点染成黑色，祖父节点染成红色
- 对祖父节点进行右旋

## 2.3 删除操作

红黑树的删除操作比插入更复杂，分为两个阶段：
1. **普通BST删除**：按照二叉搜索树的规则删除节点
2. **修复红黑树性质**：通过重新着色和旋转修复被破坏的性质

### 删除修复的四种情况

**情况1：兄弟节点是红色**
- 将兄弟节点染成黑色，父节点染成红色
- 对父节点进行左旋

**情况2：兄弟节点是黑色，兄弟的两个子节点都是黑色**
- 将兄弟节点染成红色
- 将父节点作为当前节点继续修复

**情况3：兄弟节点是黑色，兄弟的左子节点是红色，右子节点是黑色**
- 将兄弟节点染成红色，兄弟的左子节点染成黑色
- 对兄弟节点进行右旋

**情况4：兄弟节点是黑色，兄弟的右子节点是红色**
- 将兄弟节点染成父节点的颜色
- 将父节点和兄弟的右子节点都染成黑色
- 对父节点进行左旋

# 3 红黑树的代码

## 3.1 节点定义

```java
/**
 * 红黑树节点类
 * @param <K> 键类型
 * @param <V> 值类型
 */
class RBTreeNode<K, V> {
    K key;
    V value;
    RBTreeNode<K, V> left;
    RBTreeNode<K, V> right;
    RBTreeNode<K, V> parent;
    boolean isRed; // true表示红色，false表示黑色
    
    public RBTreeNode(K key, V value) {
        this.key = key;
        this.value = value;
        this.isRed = true; // 新插入的节点默认为红色
    }
}
```

## 3.2 红黑树基本结构

```java
/**
 * 红黑树实现
 * @param <K> 键类型
 * @param <V> 值类型
 */
public class RedBlackTree<K extends Comparable<K>, V> {
    private RBTreeNode<K, V> root;
    private int size;
    
    // 哨兵节点，所有叶子节点都指向它
    private final RBTreeNode<K, V> NIL = new RBTreeNode<>(null, null);
    
    public RedBlackTree() {
        NIL.isRed = false; // 哨兵节点为黑色
        root = NIL;
    }
    
    /**
     * 获取树的大小
     */
    public int size() {
        return size;
    }
    
    /**
     * 判断树是否为空
     */
    public boolean isEmpty() {
        return size == 0;
    }
}
```

## 3.3 旋转操作实现

```java
/**
 * 左旋操作
 * @param x 要旋转的节点
 */
private void leftRotate(RBTreeNode<K, V> x) {
    RBTreeNode<K, V> y = x.right;
    
    // 步骤1：将y的左子节点设为x的右子节点
    x.right = y.left;
    if (y.left != NIL) {
        y.left.parent = x;
    }
    
    // 步骤2：将x的父节点设为y的父节点
    y.parent = x.parent;
    if (x.parent == null) {
        root = y;
    } else if (x == x.parent.left) {
        x.parent.left = y;
    } else {
        x.parent.right = y;
    }
    
    // 步骤3：将y设为x的右子节点
    y.left = x;
    x.parent = y;
}

/**
 * 右旋操作
 * @param x 要旋转的节点
 */
private void rightRotate(RBTreeNode<K, V> x) {
    RBTreeNode<K, V> y = x.left;
    
    // 步骤1：将y的右子节点设为x的左子节点
    x.left = y.right;
    if (y.right != NIL) {
        y.right.parent = x;
    }
    
    // 步骤2：将x的父节点设为y的父节点
    y.parent = x.parent;
    if (x.parent == null) {
        root = y;
    } else if (x == x.parent.right) {
        x.parent.right = y;
    } else {
        x.parent.left = y;
    }
    
    // 步骤3：将y设为x的左子节点
    y.right = x;
    x.parent = y;
}
```

## 3.4 插入操作实现

```java
/**
 * 插入键值对
 * @param key 键
 * @param value 值
 */
public void put(K key, V value) {
    RBTreeNode<K, V> newNode = new RBTreeNode<>(key, value);
    newNode.left = NIL;
    newNode.right = NIL;
    
    // 普通BST插入
    RBTreeNode<K, V> y = null;
    RBTreeNode<K, V> x = root;
    
    while (x != NIL) {
        y = x;
        int cmp = key.compareTo(x.key);
        if (cmp < 0) {
            x = x.left;
        } else if (cmp > 0) {
            x = x.right;
        } else {
            // 键已存在，更新值
            x.value = value;
            return;
        }
    }
    
    newNode.parent = y;
    if (y == null) {
        root = newNode;
    } else if (key.compareTo(y.key) < 0) {
        y.left = newNode;
    } else {
        y.right = newNode;
    }
    
    size++;
    
    // 修复红黑树性质
    fixAfterInsertion(newNode);
}

/**
 * 插入后修复红黑树性质
 * @param node 新插入的节点
 */
private void fixAfterInsertion(RBTreeNode<K, V> node) {
    RBTreeNode<K, V> parent, uncle;
    
    // 当前节点为红色，且不是根节点
    while (node != root && node.parent.isRed) {
        parent = node.parent;
        
        if (parent == parent.parent.left) {
            // 父节点是左子节点
            uncle = parent.parent.right;
            
            if (uncle.isRed) {
                // 情况1：叔节点是红色
                parent.isRed = false;
                uncle.isRed = false;
                parent.parent.isRed = true;
                node = parent.parent;
            } else {
                if (node == parent.right) {
                    // 情况2：叔节点是黑色，当前节点是右子节点
                    node = parent;
                    leftRotate(node);
                    parent = node.parent;
                }
                // 情况3：叔节点是黑色，当前节点是左子节点
                parent.isRed = false;
                parent.parent.isRed = true;
                rightRotate(parent.parent);
            }
        } else {
            // 父节点是右子节点，对称处理
            uncle = parent.parent.left;
            
            if (uncle.isRed) {
                parent.isRed = false;
                uncle.isRed = false;
                parent.parent.isRed = true;
                node = parent.parent;
            } else {
                if (node == parent.left) {
                    node = parent;
                    rightRotate(node);
                    parent = node.parent;
                }
                parent.isRed = false;
                parent.parent.isRed = true;
                leftRotate(parent.parent);
            }
        }
    }
    
    // 确保根节点是黑色
    root.isRed = false;
}
```

## 3.5 删除操作实现

```java
/**
 * 删除指定键的节点
 * @param key 要删除的键
 * @return 被删除的值，如果键不存在返回null
 */
public V remove(K key) {
    RBTreeNode<K, V> node = findNode(key);
    if (node == null) {
        return null;
    }
    
    V oldValue = node.value;
    deleteNode(node);
    size--;
    return oldValue;
}

/**
 * 查找指定键的节点
 * @param key 键
 * @return 节点，如果不存在返回null
 */
private RBTreeNode<K, V> findNode(K key) {
    RBTreeNode<K, V> current = root;
    while (current != NIL) {
        int cmp = key.compareTo(current.key);
        if (cmp == 0) {
            return current;
        } else if (cmp < 0) {
            current = current.left;
        } else {
            current = current.right;
        }
    }
    return null;
}

/**
 * 删除指定节点
 * @param node 要删除的节点
 */
private void deleteNode(RBTreeNode<K, V> node) {
    RBTreeNode<K, V> y = node;
    RBTreeNode<K, V> x;
    boolean yOriginalColor = y.isRed;
    
    if (node.left == NIL) {
        x = node.right;
        transplant(node, node.right);
    } else if (node.right == NIL) {
        x = node.left;
        transplant(node, node.left);
    } else {
        y = minimum(node.right);
        yOriginalColor = y.isRed;
        x = y.right;
        
        if (y.parent == node) {
            x.parent = y;
        } else {
            transplant(y, y.right);
            y.right = node.right;
            y.right.parent = y;
        }
        
        transplant(node, y);
        y.left = node.left;
        y.left.parent = y;
        y.isRed = node.isRed;
    }
    
    if (!yOriginalColor) {
        fixAfterDeletion(x);
    }
}

/**
 * 用v替换u
 * @param u 被替换的节点
 * @param v 替换节点
 */
private void transplant(RBTreeNode<K, V> u, RBTreeNode<K, V> v) {
    if (u.parent == null) {
        root = v;
    } else if (u == u.parent.left) {
        u.parent.left = v;
    } else {
        u.parent.right = v;
    }
    v.parent = u.parent;
}

/**
 * 查找以node为根的子树中的最小节点
 * @param node 根节点
 * @return 最小节点
 */
private RBTreeNode<K, V> minimum(RBTreeNode<K, V> node) {
    while (node.left != NIL) {
        node = node.left;
    }
    return node;
}

/**
 * 删除后修复红黑树性质
 * @param node 当前节点
 */
private void fixAfterDeletion(RBTreeNode<K, V> node) {
    RBTreeNode<K, V> brother;
    
    while (node != root && !node.isRed) {
        if (node == node.parent.left) {
            brother = node.parent.right;
            
            if (brother.isRed) {
                // 情况1：兄弟节点是红色
                brother.isRed = false;
                node.parent.isRed = true;
                leftRotate(node.parent);
                brother = node.parent.right;
            }
            
            if (!brother.left.isRed && !brother.right.isRed) {
                // 情况2：兄弟节点是黑色，兄弟的两个子节点都是黑色
                brother.isRed = true;
                node = node.parent;
            } else {
                if (!brother.right.isRed) {
                    // 情况3：兄弟节点是黑色，兄弟的左子节点是红色，右子节点是黑色
                    brother.left.isRed = false;
                    brother.isRed = true;
                    rightRotate(brother);
                    brother = node.parent.right;
                }
                // 情况4：兄弟节点是黑色，兄弟的右子节点是红色
                brother.isRed = node.parent.isRed;
                node.parent.isRed = false;
                brother.right.isRed = false;
                leftRotate(node.parent);
                node = root;
            }
        } else {
            // 对称处理右子树
            brother = node.parent.left;
            
            if (brother.isRed) {
                brother.isRed = false;
                node.parent.isRed = true;
                rightRotate(node.parent);
                brother = node.parent.left;
            }
            
            if (!brother.right.isRed && !brother.left.isRed) {
                brother.isRed = true;
                node = node.parent;
            } else {
                if (!brother.left.isRed) {
                    brother.right.isRed = false;
                    brother.isRed = true;
                    leftRotate(brother);
                    brother = node.parent.left;
                }
                brother.isRed = node.parent.isRed;
                node.parent.isRed = false;
                brother.left.isRed = false;
                rightRotate(node.parent);
                node = root;
            }
        }
    }
    
    node.isRed = false;
}
```

## 3.6 查找操作

```java
/**
 * 根据键查找值
 * @param key 键
 * @return 值，如果键不存在返回null
 */
public V get(K key) {
    RBTreeNode<K, V> node = findNode(key);
    return node != null ? node.value : null;
}

/**
 * 判断是否包含指定键
 * @param key 键
 * @return 是否包含
 */
public boolean containsKey(K key) {
    return findNode(key) != null;
}
```

# 4 在Java集合中的应用
- **TreeMap** 和 **TreeSet** 的底层实现均为红黑树。
- 红黑树保证了集合元素的有序性和高效的查找/插入/删除。
- JDK8 之后，HashMap 在链表长度大于8时也会转为红黑树，提升极端情况下的性能。

# 5 面试易错点与陷阱
- 误以为红黑树是严格平衡二叉树，实际上是近似平衡。
- 红黑树的五大性质、插入/删除修复过程、旋转操作原理。
- 红黑树与AVL树的区别（红黑树插入/删除更快，旋转次数更少）。
- TreeSet/TreeMap 的有序性和性能依赖红黑树。

> **面试提醒：** 红黑树的性质、修复过程、在Java集合中的应用是高频考点。

---

# 6 实际开发建议
- 需要有序集合时优先考虑 TreeSet/TreeMap。
- 了解红黑树原理有助于理解集合的性能边界。
- 关注极端数据分布下的性能表现。
