# 数据库连接问题排查指南

## 问题现象

Langfuse 容器无法连接到 PostgreSQL 数据库，错误信息：
```
Error: P1001: Can't reach database server at `host.docker.internal:5433`
```

## 排查步骤

### 1. 检查 PostgreSQL 容器状态

```bash
docker ps | grep postgres
```

**预期结果**：容器应该处于 `Up` 状态

### 2. 检查端口映射

```bash
docker ps --format "table {{.Names}}\t{{.Ports}}" | grep postgres
```

**预期结果**：应该看到 `0.0.0.0:5433->5432/tcp`

### 3. 测试网络连接

从 Langfuse 容器内测试连接：

```bash
cd /path/to/langfuse
docker compose run --rm --entrypoint sh langfuse-web -c "nc -zv host.docker.internal 5433"
```

**预期结果**：应该显示 `open`，表示端口可达

### 4. 检查数据库是否存在

```bash
docker exec postgres-pgvector-17 psql -U postgres -c "\l" | grep langfuse
```

**如果数据库不存在**，需要创建：

```bash
# 创建数据库
docker exec postgres-pgvector-17 psql -U postgres -c "CREATE DATABASE langfuse;"

# 或者创建用户和数据库
docker exec postgres-pgvector-17 psql -U postgres << EOF
CREATE USER langfuse WITH PASSWORD 'your_password';
CREATE DATABASE langfuse OWNER langfuse;
GRANT ALL PRIVILEGES ON DATABASE langfuse TO langfuse;
EOF
```

### 5. 检查 .env 文件配置

确保 `.env` 文件中的 `DATABASE_URL` 配置正确：

```bash
# 格式：postgresql://用户名:密码@host.docker.internal:5433/数据库名
DATABASE_URL=postgresql://用户名:密码@host.docker.internal:5433/langfuse
DIRECT_URL=${DATABASE_URL}
```

**重要检查点**：
- ✅ 用户名是否正确
- ✅ 密码是否正确
- ✅ 端口是 **5433**（宿主机端口），不是 5432
- ✅ 数据库名是否存在

### 6. 测试数据库连接

使用 PostgreSQL 客户端测试连接：

```bash
# 从宿主机测试
psql "postgresql://用户名:密码@localhost:5433/langfuse" -c "SELECT 1;"

# 或者使用 docker exec
docker exec postgres-pgvector-17 psql -U 用户名 -d langfuse -c "SELECT 1;"
```

### 7. 检查 PostgreSQL 监听配置

确保 PostgreSQL 允许外部连接：

```bash
# 检查 PostgreSQL 配置
docker exec postgres-pgvector-17 cat /var/lib/postgresql/data/postgresql.conf | grep listen_addresses

# 检查 pg_hba.conf
docker exec postgres-pgvector-17 cat /var/lib/postgresql/data/pg_hba.conf | grep -v "^#"
```

**如果 PostgreSQL 只监听 localhost**，需要修改配置允许外部连接。

## 常见问题及解决方案

### 问题1：数据库不存在

**错误**：`database "langfuse" does not exist`

**解决方案**：
```bash
docker exec postgres-pgvector-17 psql -U postgres -c "CREATE DATABASE langfuse;"
```

### 问题2：用户名或密码错误

**错误**：`password authentication failed for user`

**解决方案**：
1. 检查 `.env` 文件中的用户名和密码
2. 或者创建新用户：
```bash
docker exec postgres-pgvector-17 psql -U postgres << EOF
CREATE USER langfuse WITH PASSWORD 'your_secure_password';
ALTER USER langfuse CREATEDB;
GRANT ALL PRIVILEGES ON DATABASE langfuse TO langfuse;
EOF
```

### 问题3：端口配置错误

**错误**：连接超时

**解决方案**：
- 确保使用宿主机端口 **5433**，不是容器内端口 5432
- 检查端口映射：`docker ps | grep postgres`

### 问题4：host.docker.internal 无法解析

**错误**：`getaddrinfo failed` 或 `Name or service not known`

**解决方案**：
- Mac 上 Docker Desktop 应该自动支持 `host.docker.internal`
- 如果不行，可以尝试使用 `172.17.0.1`（Docker 默认网关）
- 或者将 Langfuse 容器连接到 PostgreSQL 所在的网络

### 问题5：PostgreSQL 不允许外部连接

**错误**：连接被拒绝

**解决方案**：
1. 检查 `pg_hba.conf` 配置
2. 确保 PostgreSQL 监听所有接口：`listen_addresses = '*'`
3. 重启 PostgreSQL 容器

## 快速修复脚本

如果确认是数据库不存在的问题，可以使用以下脚本快速修复：

```bash
#!/bin/bash

# 设置变量（根据你的实际情况修改）
DB_USER="langfuse"
DB_PASSWORD="your_secure_password"
DB_NAME="langfuse"
POSTGRES_USER="postgres"

# 创建用户和数据库
docker exec postgres-pgvector-17 psql -U $POSTGRES_USER << EOF
-- 创建用户（如果不存在）
DO \$\$
BEGIN
  IF NOT EXISTS (SELECT FROM pg_user WHERE usename = '$DB_USER') THEN
    CREATE USER $DB_USER WITH PASSWORD '$DB_PASSWORD';
  END IF;
END
\$\$;

-- 创建数据库（如果不存在）
SELECT 'CREATE DATABASE $DB_NAME OWNER $DB_USER'
WHERE NOT EXISTS (SELECT FROM pg_database WHERE datname = '$DB_NAME')\gexec

-- 授予权限
GRANT ALL PRIVILEGES ON DATABASE $DB_NAME TO $DB_USER;
EOF

echo "数据库和用户创建完成！"
echo "请在 .env 文件中配置："
echo "DATABASE_URL=postgresql://$DB_USER:$DB_PASSWORD@host.docker.internal:5433/$DB_NAME"
```

## 验证连接

修复后，验证连接：

```bash
# 1. 测试从容器内连接
cd /path/to/langfuse
docker compose run --rm --entrypoint sh langfuse-web -c "nc -zv host.docker.internal 5433"

# 2. 测试数据库连接
docker exec postgres-pgvector-17 psql -U langfuse -d langfuse -c "SELECT 1;"

# 3. 重启 Langfuse 服务
docker compose restart langfuse-web

# 4. 查看日志
docker compose logs -f langfuse-web
```

## 推荐配置

### 方案1：使用现有 postgres 用户

如果你的 PostgreSQL 使用默认的 `postgres` 用户：

```bash
# .env 文件
DATABASE_URL=postgresql://postgres:你的密码@host.docker.internal:5433/langfuse
DIRECT_URL=${DATABASE_URL}
```

然后创建数据库：
```bash
docker exec postgres-pgvector-17 psql -U postgres -c "CREATE DATABASE langfuse;"
```

### 方案2：创建专用用户（推荐）

```bash
# 创建用户和数据库
docker exec postgres-pgvector-17 psql -U postgres << EOF
CREATE USER langfuse WITH PASSWORD 'secure_password_here';
CREATE DATABASE langfuse OWNER langfuse;
GRANT ALL PRIVILEGES ON DATABASE langfuse TO langfuse;
EOF
```

```bash
# .env 文件
DATABASE_URL=postgresql://langfuse:secure_password_here@host.docker.internal:5433/langfuse
DIRECT_URL=${DATABASE_URL}
```
