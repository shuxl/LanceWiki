# 2 期望和方差

## 重点
- 期望和方差的数学定义和基本性质
- 期望和方差的计算方法
- 期望和方差在统计学中的重要性
- 期望和方差在实际问题中的应用

## 2.1 期望的基本概念

### 2.1.1 期望的定义

**期望**（Expected Value）：对于随机变量X，其期望定义为：

**离散随机变量**：
$$E[X] = \sum_{x} x \cdot P(X = x) = \sum_{x} x \cdot p_X(x)$$

**连续随机变量**：
$$E[X] = \int_{-\infty}^{\infty} x \cdot f_X(x) dx$$

### 2.1.2 期望的直观理解

期望可以理解为：
- 随机变量取值的"平均"或"中心"
- 长期重复试验中观察值的平均值
- 随机变量的"重心"位置

**示例**：掷骰子
- 随机变量X：骰子的点数
- $E[X] = 1 \times \frac{1}{6} + 2 \times \frac{1}{6} + \cdots + 6 \times \frac{1}{6} = 3.5$

### 2.1.3 期望的性质

1. **线性性**：$E[aX + b] = aE[X] + b$
2. **可加性**：$E[X + Y] = E[X] + E[Y]$
3. **独立性**：如果X与Y独立，则 $E[XY] = E[X]E[Y]$
4. **单调性**：如果 $X \leq Y$，则 $E[X] \leq E[Y]$

## 2.2 期望的计算

### 2.2.1 离散随机变量的期望

**伯努利分布**：
$$E[X] = 1 \times p + 0 \times (1-p) = p$$

**二项分布**：
$$E[X] = np$$

**泊松分布**：
$$E[X] = \lambda$$

**几何分布**：
$$E[X] = \frac{1}{p}$$

### 2.2.2 连续随机变量的期望

**均匀分布**：
$$E[X] = \frac{a + b}{2}$$

**正态分布**：
$$E[X] = \mu$$

**指数分布**：
$$E[X] = \frac{1}{\lambda}$$

**伽马分布**：
$$E[X] = \frac{\alpha}{\lambda}$$

### 2.2.3 函数期望的计算

对于随机变量X和函数g：

**离散情况**：
$$E[g(X)] = \sum_{x} g(x) \cdot P(X = x)$$

**连续情况**：
$$E[g(X)] = \int_{-\infty}^{\infty} g(x) \cdot f_X(x) dx$$

## 2.3 方差的基本概念

### 2.3.1 方差的定义

**方差**（Variance）：对于随机变量X，其方差定义为：

$$Var(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

**标准差**（Standard Deviation）：
$$\sigma_X = \sqrt{Var(X)}$$

### 2.3.2 方差的直观理解

方差可以理解为：
- 随机变量取值偏离期望的程度
- 数据的离散程度或变异性
- 随机变量的"分散"程度

**示例**：比较两个分布
- 分布A：{1, 3, 5}，期望为3
- 分布B：{2, 3, 4}，期望为3
- 分布A的方差更大，因为数据更分散

### 2.3.3 方差的性质

1. **非负性**：$Var(X) \geq 0$
2. **线性变换**：$Var(aX + b) = a^2 Var(X)$
3. **独立性**：如果X与Y独立，则 $Var(X + Y) = Var(X) + Var(Y)$
4. **常数方差**：$Var(c) = 0$，其中c是常数

## 2.4 方差的计算

### 2.4.1 离散随机变量的方差

**伯努利分布**：
$$Var(X) = p(1-p)$$

**二项分布**：
$$Var(X) = np(1-p)$$

**泊松分布**：
$$Var(X) = \lambda$$

**几何分布**：
$$Var(X) = \frac{1-p}{p^2}$$

### 2.4.2 连续随机变量的方差

**均匀分布**：
$$Var(X) = \frac{(b-a)^2}{12}$$

**正态分布**：
$$Var(X) = \sigma^2$$

**指数分布**：
$$Var(X) = \frac{1}{\lambda^2}$$

**伽马分布**：
$$Var(X) = \frac{\alpha}{\lambda^2}$$

### 2.4.3 方差的计算公式

**计算步骤**：
1. 计算 $E[X]$
2. 计算 $E[X^2]$
3. 使用公式：$Var(X) = E[X^2] - (E[X])^2$

**示例**：掷骰子
- $E[X] = 3.5$
- $E[X^2] = 1^2 \times \frac{1}{6} + 2^2 \times \frac{1}{6} + \cdots + 6^2 \times \frac{1}{6} = \frac{91}{6}$
- $Var(X) = \frac{91}{6} - (3.5)^2 = \frac{35}{12} \approx 2.92$

## 2.5 矩和中心矩

### 2.5.1 矩的定义

**k阶矩**：
$$\mu_k = E[X^k]$$

**k阶中心矩**：
$$\mu_k' = E[(X - E[X])^k]$$

### 2.5.2 重要的矩

**一阶矩**：$\mu_1 = E[X]$ （期望）
**二阶中心矩**：$\mu_2' = Var(X)$ （方差）
**三阶中心矩**：$\mu_3' = E[(X - E[X])^3]$ （偏度）
**四阶中心矩**：$\mu_4' = E[(X - E[X])^4]$ （峰度）

### 2.5.3 偏度和峰度

**偏度**（Skewness）：
$$\gamma_1 = \frac{\mu_3'}{\sigma^3}$$

**峰度**（Kurtosis）：
$$\gamma_2 = \frac{\mu_4'}{\sigma^4} - 3$$

## 2.6 期望和方差的应用

### 2.6.1 在统计学中的应用

**样本均值**：样本 $X_1, X_2, \ldots, X_n$ 的均值：
$$\bar{X} = \frac{1}{n} \sum_{i=1}^{n} X_i$$

**样本方差**：
$$S^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \bar{X})^2$$

**无偏估计**：样本方差是总体方差的无偏估计。

### 2.6.2 在机器学习中的应用

**损失函数**：期望损失用于模型评估
**正则化**：方差控制用于防止过拟合
**特征选择**：基于方差的特征重要性

### 2.6.3 在金融中的应用

**投资组合**：期望收益和风险（方差）
**期权定价**：基于期望的定价模型
**风险管理**：VaR（Value at Risk）计算

## 2.7 切比雪夫不等式

### 2.7.1 切比雪夫不等式

对于任意随机变量X和正数k：

$$P(|X - E[X]| \geq k\sigma) \leq \frac{1}{k^2}$$

其中 $\sigma = \sqrt{Var(X)}$。

### 2.7.2 应用示例

**问题**：某产品的重量服从正态分布，期望为100g，标准差为5g。重量在90g到110g之间的概率至少是多少？

**解答**：
- $E[X] = 100$，$\sigma = 5$
- 区间 [90, 110] 对应 $|X - 100| \leq 10$
- 即 $|X - 100| \leq 2\sigma$
- 根据切比雪夫不等式：$P(|X - 100| > 2\sigma) \leq \frac{1}{4}$
- 因此：$P(|X - 100| \leq 2\sigma) \geq 1 - \frac{1}{4} = \frac{3}{4}$

## 2.8 条件期望

### 2.8.1 条件期望的定义

**条件期望**：在给定事件A的条件下，随机变量X的期望：

**离散情况**：
$$E[X|A] = \sum_{x} x \cdot P(X = x|A)$$

**连续情况**：
$$E[X|A] = \int_{-\infty}^{\infty} x \cdot f_{X|A}(x) dx$$

### 2.8.2 全期望公式

如果 $A_1, A_2, \ldots, A_n$ 构成样本空间的划分，则：

$$E[X] = \sum_{i=1}^{n} E[X|A_i] \cdot P(A_i)$$

### 2.8.3 条件期望的性质

1. **线性性**：$E[aX + bY|A] = aE[X|A] + bE[Y|A]$
2. **独立性**：如果X与A独立，则 $E[X|A] = E[X]$
3. **塔性质**：$E[E[X|Y]] = E[X]$
