## 1 微分方程的基本概念

### 1.1 微分方程的定义

**定义**：含有未知函数及其导数的方程称为**微分方程**。

**一般形式**：
$F(x, y, y', y'', ..., y^{(n)}) = 0$

其中：
- $x$ 是自变量
- $y$ 是未知函数
- $y', y'', ..., y^{(n)}$ 是 $y$ 的各阶导数

### 1.2 微分方程的分类

#### 1.2.1 按阶数分类
- **一阶微分方程**：最高阶导数为 $y'$
- **二阶微分方程**：最高阶导数为 $y''$
- **n阶微分方程**：最高阶导数为 $y^{(n)}$

#### 1.2.2 按线性性分类
- **线性微分方程**：未知函数及其导数都是一次的
- **非线性微分方程**：未知函数或其导数不是一次的

#### 1.2.3 按系数分类
- **常系数微分方程**：系数都是常数
- **变系数微分方程**：系数是自变量的函数

### 1.3 微分方程的解

**定义**：如果函数 $y = f(x)$ 满足微分方程，则称 $y = f(x)$ 是该微分方程的解。

**通解**：包含任意常数的解称为通解。

**特解**：给定初始条件后得到的确定解称为特解。

**例子**：
微分方程 $y' = 2x$ 的通解是 $y = x^2 + C$，其中 $C$ 是任意常数。

如果给定初始条件 $y(0) = 1$，则特解是 $y = x^2 + 1$。

## 2 一阶微分方程

### 2.1 可分离变量方程

**形式**：$\frac{dy}{dx} = f(x)g(y)$

**解法**：将方程变形为 $\frac{dy}{g(y)} = f(x)dx$，然后两边积分。

**例子**：求解微分方程 $\frac{dy}{dx} = xy$

**解**：
- 分离变量：$\frac{dy}{y} = x dx$
- 两边积分：$\int \frac{dy}{y} = \int x dx$
- 得到：$\ln |y| = \frac{x^2}{2} + C$
- 因此：$y = Ce^{x^2/2}$，其中 $C$ 是任意常数

### 2.2 齐次方程

**形式**：$\frac{dy}{dx} = f(\frac{y}{x})$

**解法**：令 $u = \frac{y}{x}$，则 $y = xu$，$\frac{dy}{dx} = u + x\frac{du}{dx}$。

**例子**：求解微分方程 $\frac{dy}{dx} = \frac{y}{x} + \frac{x}{y}$

**解**：
- 令 $u = \frac{y}{x}$，则 $y = xu$
- $\frac{dy}{dx} = u + x\frac{du}{dx} = u + \frac{1}{u}$
- 因此：$x\frac{du}{dx} = \frac{1}{u}$
- 分离变量：$u du = \frac{dx}{x}$
- 积分：$\frac{u^2}{2} = \ln |x| + C$
- 因此：$u = \sqrt{2\ln |x| + 2C}$
- 所以：$y = x\sqrt{2\ln |x| + 2C}$

### 2.3 线性微分方程

**形式**：$\frac{dy}{dx} + P(x)y = Q(x)$

**解法**：使用积分因子 $\mu(x) = e^{\int P(x)dx}$。

**例子**：求解微分方程 $\frac{dy}{dx} + 2y = e^x$

**解**：
- $P(x) = 2$，$Q(x) = e^x$
- 积分因子：$\mu(x) = e^{\int 2dx} = e^{2x}$
- 乘以积分因子：$e^{2x}\frac{dy}{dx} + 2e^{2x}y = e^{3x}$
- 左边是 $\frac{d}{dx}(e^{2x}y)$
- 因此：$\frac{d}{dx}(e^{2x}y) = e^{3x}$
- 积分：$e^{2x}y = \frac{1}{3}e^{3x} + C$
- 所以：$y = \frac{1}{3}e^x + Ce^{-2x}$

### 2.4 伯努利方程

**形式**：$\frac{dy}{dx} + P(x)y = Q(x)y^n$

**解法**：令 $u = y^{1-n}$，将方程化为线性方程。

**例子**：求解微分方程 $\frac{dy}{dx} + y = xy^2$

**解**：
- 这是伯努利方程，$n = 2$
- 令 $u = y^{-1}$，则 $y = u^{-1}$
- $\frac{dy}{dx} = -u^{-2}\frac{du}{dx}$
- 代入原方程：$-u^{-2}\frac{du}{dx} + u^{-1} = xu^{-2}$
- 乘以 $u^2$：$-\frac{du}{dx} + u = x$
- 整理：$\frac{du}{dx} - u = -x$
- 这是线性方程，解为：$u = x + 1 + Ce^x$
- 因此：$y = \frac{1}{x + 1 + Ce^x}$

## 3 二阶线性微分方程

### 3.1 二阶线性微分方程的标准形式

**标准形式**：$y'' + P(x)y' + Q(x)y = R(x)$

**分类**：
- **齐次方程**：$R(x) = 0$
- **非齐次方程**：$R(x) \neq 0$

### 3.2 齐次方程的解

**定理**：如果 $y_1(x)$ 和 $y_2(x)$ 是齐次方程的两个线性无关解，则通解为：

$y = C_1y_1(x) + C_2y_2(x)$

其中 $C_1$ 和 $C_2$ 是任意常数。

### 3.3 常系数齐次方程

**形式**：$ay'' + by' + cy = 0$

**特征方程**：$ar^2 + br + c = 0$

**解的判别**：
1. **两个不同实根** $r_1, r_2$：$y = C_1e^{r_1x} + C_2e^{r_2x}$
2. **重根** $r_1 = r_2$：$y = (C_1 + C_2x)e^{r_1x}$
3. **共轭复根** $r = \alpha \pm i\beta$：$y = e^{\alpha x}(C_1\cos \beta x + C_2\sin \beta x)$

**例子1**：求解 $y'' - 3y' + 2y = 0$

**解**：
- 特征方程：$r^2 - 3r + 2 = 0$
- 解得：$r_1 = 1$，$r_2 = 2$
- 通解：$y = C_1e^x + C_2e^{2x}$

**例子2**：求解 $y'' - 2y' + y = 0$

**解**：
- 特征方程：$r^2 - 2r + 1 = 0$
- 解得：$r_1 = r_2 = 1$（重根）
- 通解：$y = (C_1 + C_2x)e^x$

**例子3**：求解 $y'' + y = 0$

**解**：
- 特征方程：$r^2 + 1 = 0$
- 解得：$r = \pm i$（共轭复根）
- 通解：$y = C_1\cos x + C_2\sin x$

### 3.4 非齐次方程的解

**定理**：非齐次方程的通解等于对应的齐次方程的通解加上非齐次方程的一个特解。

**特解的求法**：
1. **待定系数法**：根据 $R(x)$ 的形式假设特解的形式
2. **参数变易法**：将齐次方程通解中的常数变为函数

**例子**：求解 $y'' - 3y' + 2y = e^x$

**解**：
- 齐次方程：$y'' - 3y' + 2y = 0$
- 齐次方程通解：$y_h = C_1e^x + C_2e^{2x}$
- 设特解：$y_p = Axe^x$（因为 $e^x$ 是齐次方程的解）
- 代入原方程：$(Axe^x + 2Ae^x) - 3(Axe^x + Ae^x) + 2Axe^x = e^x$
- 整理：$-Ae^x = e^x$
- 因此：$A = -1$
- 特解：$y_p = -xe^x$
- 通解：$y = C_1e^x + C_2e^{2x} - xe^x$

## 4 在物理和工程中的应用

### 4.1 弹簧振动

**弹簧振动方程**：$m\frac{d^2x}{dt^2} + c\frac{dx}{dt} + kx = F(t)$

其中：
- $m$ 是质量
- $c$ 是阻尼系数
- $k$ 是弹簧常数
- $F(t)$ 是外力

**无阻尼自由振动**：$m\frac{d^2x}{dt^2} + kx = 0$

**解**：
- 特征方程：$mr^2 + k = 0$
- 解得：$r = \pm i\sqrt{\frac{k}{m}}$
- 通解：$x = A\cos(\omega t) + B\sin(\omega t)$
- 其中 $\omega = \sqrt{\frac{k}{m}}$ 是自然频率

### 4.2 电路分析

**RLC电路方程**：$L\frac{d^2i}{dt^2} + R\frac{di}{dt} + \frac{1}{C}i = \frac{dE}{dt}$

其中：
- $L$ 是电感
- $R$ 是电阻
- $C$ 是电容
- $E(t)$ 是电源电压

**例子**：求解 $L\frac{d^2i}{dt^2} + R\frac{di}{dt} + \frac{1}{C}i = 0$

**解**：
- 特征方程：$Lr^2 + Rr + \frac{1}{C} = 0$
- 解得：$r = \frac{-R \pm \sqrt{R^2 - 4L/C}}{2L}$
- 根据判别式的符号，解的形式不同

### 4.3 人口增长模型

**马尔萨斯模型**：$\frac{dP}{dt} = kP$

其中 $P$ 是人口数量，$k$ 是增长率。

**解**：
- 分离变量：$\frac{dP}{P} = k dt$
- 积分：$\ln P = kt + C$
- 因此：$P = Ce^{kt}$

**逻辑斯蒂模型**：$\frac{dP}{dt} = kP(1 - \frac{P}{K})$

其中 $K$ 是环境承载能力。

**解**：
- 分离变量：$\frac{dP}{P(1 - P/K)} = k dt$
- 积分：$\ln \frac{P}{K - P} = kt + C$
- 因此：$P = \frac{K}{1 + Ce^{-kt}}$

## 5 总结

微分方程是描述自然界和工程问题中变化规律的重要数学工具。本章介绍了：

- **基本概念**：微分方程的定义、分类和解的概念
- **一阶微分方程**：可分离变量、齐次、线性、伯努利方程
- **二阶线性微分方程**：常系数齐次方程、非齐次方程
- **物理应用**：弹簧振动、电路分析、人口增长模型

这些概念为学习更高级的微分方程理论、数值方法和工程应用提供了重要的基础。
