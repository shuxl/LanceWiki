# 2 NIO概念或介绍

## 2.1 什么是NIO

NIO（New I/O）是Java 1.4引入的新IO API，提供了非阻塞IO操作。与传统的IO相比，NIO具有以下特点：

- **非阻塞**：线程不会因为IO操作而阻塞
- **面向缓冲区**：数据读写通过Buffer进行
- **多路复用**：一个线程可以管理多个连接
- **高性能**：适合高并发场景

## 2.2 NIO vs 传统IO

| 特性 | 传统IO | NIO |
|------|--------|-----|
| 阻塞性 | 阻塞 | 非阻塞 |
| 数据单位 | 流 | 缓冲区 |
| 线程模型 | 一个连接一个线程 | 一个线程多个连接 |
| 性能 | 适合连接数少 | 适合连接数多 |

# 3 Buffer（缓冲区）

## 3.1 Buffer的基本概念

Buffer是NIO的核心组件，用于存储数据。每个Buffer都有以下属性：

- **capacity**：容量，Buffer能够存储的最大数据量
- **position**：位置，下一个要读写的位置
- **limit**：限制，可读写的最大位置
- **mark**：标记，用于记录position的位置

## 3.2 Buffer的类型

```java

CharBuffer charBuffer = CharBuffer.allocate(1024);
IntBuffer intBuffer = IntBuffer.allocate(1024);

FloatBuffer floatBuffer = FloatBuffer.allocate(1024);
DoubleBuffer doubleBuffer = DoubleBuffer.allocate(1024);
```

## 3.3 Buffer的基本操作

```java
public class BufferExample {
    public static void main(String[] args) {
        // 创建Buffer
        ByteBuffer buffer = ByteBuffer.allocate(1024);
        
        // 写入数据
        buffer.put("Hello NIO".getBytes());
        
        // 切换到读模式
        buffer.flip();
        
        // 读取数据
        byte[] bytes = new byte[buffer.remaining()];
        buffer.get(bytes);
        System.out.println(new String(bytes));
        
        // 清空Buffer
        buffer.clear();
        
        // 重新写入
        buffer.put("New Data".getBytes());
        buffer.flip();
        
        // 读取
        while (buffer.hasRemaining()) {
            System.out.print((char) buffer.get());
        }
    }
}
```

# 4 Channel（通道）

## 4.1 Channel的基本概念

Channel是NIO中用于传输数据的通道，类似于传统IO中的流，但具有以下特点：

- 可以同时进行读写操作
- 可以异步读写
- 总是基于Buffer进行读写

## 4.2 FileChannel

```java
public class FileChannelExample {
    public static void main(String[] args) {
        // 读取文件
        try (FileChannel inChannel = new FileInputStream("input.txt").getChannel();
             FileChannel outChannel = new FileOutputStream("output.txt").getChannel()) {
            
            ByteBuffer buffer = ByteBuffer.allocate(1024);
            
            while (inChannel.read(buffer) != -1) {
                buffer.flip();
                outChannel.write(buffer);
                buffer.clear();
            }
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 4.5 ServerSocketChannel

```java
public class ServerSocketChannelExample {
    public static void serverExample() {
        try {
            // 创建ServerSocketChannel
            ServerSocketChannel serverSocketChannel = ServerSocketChannel.open();
            serverSocketChannel.configureBlocking(false);
            serverSocketChannel.bind(new InetSocketAddress(8080));
            
            // 创建Selector
            Selector selector = Selector.open();
            serverSocketChannel.register(selector, SelectionKey.OP_ACCEPT);
            
            while (true) {
                selector.select();
                
                Set<SelectionKey> selectedKeys = selector.selectedKeys();
                Iterator<SelectionKey> iterator = selectedKeys.iterator();
                
                while (iterator.hasNext()) {
                    SelectionKey key = iterator.next();
                    iterator.remove();
                    
                    if (key.isAcceptable()) {
                        // 接受连接
                        ServerSocketChannel server = (ServerSocketChannel) key.channel();
                        SocketChannel client = server.accept();
                        client.configureBlocking(false);
                        client.register(selector, SelectionKey.OP_READ);
                        
                        System.out.println("客户端连接: " + client.getRemoteAddress());
                    }
                    
                    if (key.isReadable()) {
                        // 读取数据
                        SocketChannel client = (SocketChannel) key.channel();
                        ByteBuffer buffer = ByteBuffer.allocate(1024);
                        int bytesRead = client.read(buffer);
                        
                        if (bytesRead > 0) {
                            buffer.flip();
                            String message = new String(buffer.array(), 0, bytesRead);
                            System.out.println("收到消息: " + message);
                            
                            // 发送响应
                            buffer.clear();
                            buffer.put("Hello Client".getBytes());
                            buffer.flip();
                            client.write(buffer);
                        }
                    }
                }
            }
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

# 5 Selector（选择器）

## 5.1 Selector的基本概念

Selector是NIO中实现多路复用的核心组件，它允许一个线程管理多个Channel。Selector的工作原理是：

1. **事件驱动**：Selector监听注册的Channel上的事件
2. **非阻塞**：当没有事件时，线程不会阻塞
3. **高效**：一个线程可以管理成千上万个连接

## 5.2 SelectionKey详解

SelectionKey是Selector和Channel之间的桥梁，包含了以下重要信息：

```java
public class SelectorMethods {
    public static void explainSelectorMethods() {
        // 1. select() - 阻塞等待事件，直到至少有一个事件就绪

    }
```

## 5.4 Selector的使用详解

```java
public class SelectorExample {
    public static void main(String[] args) {
        try {
            // 1. 创建Selector
            Selector selector = Selector.open();
            
            // 2. 创建ServerSocketChannel
            ServerSocketChannel serverSocketChannel = ServerSocketChannel.open();
            serverSocketChannel.configureBlocking(false);  // 必须设置为非阻塞
            serverSocketChannel.bind(new InetSocketAddress(8080));
            
            // 3. 注册到Selector，监听ACCEPT事件
            SelectionKey serverKey = serverSocketChannel.register(selector, SelectionKey.OP_ACCEPT);
            
            System.out.println("服务器启动，监听端口8080...");
            
            // 4. 事件循环
            while (true) {
                // 等待事件就绪（阻塞）
                int readyChannels = selector.select();
                System.out.println("就绪的Channel数量: " + readyChannels);
                
                if (readyChannels == 0) continue;
                
                // 5. 获取就绪的SelectionKey集合
                Set<SelectionKey> selectedKeys = selector.selectedKeys();
                Iterator<SelectionKey> iterator = selectedKeys.iterator();
                
                // 6. 处理每个就绪的事件
                while (iterator.hasNext()) {
                    SelectionKey key = iterator.next();
                    iterator.remove();  // 重要：必须移除，否则会重复处理
                    
                    // 检查事件类型
                    if (key.isAcceptable()) {
                        handleAccept(key, selector);
                    }
                    
                    if (key.isReadable()) {
                        handleRead(key);
                    }
                    
                    if (key.isWritable()) {
                        handleWrite(key);
                    }
                    
                    if (key.isConnectable()) {
                        handleConnect(key);
                    }
                }
            }
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    private static void handleAccept(SelectionKey key, Selector selector) throws IOException {
        System.out.println("=== 处理ACCEPT事件 ===");
        
        // 获取ServerSocketChannel
        ServerSocketChannel serverSocketChannel = (ServerSocketChannel) key.channel();
        
        // 接受客户端连接
        SocketChannel clientChannel = serverSocketChannel.accept();
        clientChannel.configureBlocking(false);  // 设置为非阻塞
        
        // 注册到Selector，监听READ事件
        SelectionKey clientKey = clientChannel.register(selector, SelectionKey.OP_READ);
        
        // 可以附加一些数据到SelectionKey
        clientKey.attach("客户端连接信息");
        
        System.out.println("接受新连接: " + clientChannel.getRemoteAddress());
        System.out.println("当前注册的Channel数量: " + selector.keys().size());
    }
    
    private static void handleRead(SelectionKey key) throws IOException {
        System.out.println("=== 处理READ事件 ===");
        
        SocketChannel socketChannel = (SocketChannel) key.channel();
        ByteBuffer buffer = ByteBuffer.allocate(1024);
        
        // 读取数据
        int bytesRead = socketChannel.read(buffer);
        
        if (bytesRead > 0) {
            // 有数据可读
            buffer.flip();
            byte[] data = new byte[buffer.remaining()];
            buffer.get(data);
            String message = new String(data);
            
            System.out.println("收到消息: " + message);
            System.out.println("来自: " + socketChannel.getRemoteAddress());
            
            // 注册写事件，准备响应
            key.interestOps(SelectionKey.OP_WRITE);
            
            // 保存消息到attachment
            key.attach(message);
            
        } else if (bytesRead == -1) {
            // 客户端断开连接
            System.out.println("客户端断开连接: " + socketChannel.getRemoteAddress());
            socketChannel.close();
            key.cancel();
        } else if (bytesRead == 0) {
            // 没有数据可读，但连接仍然活跃
            System.out.println("没有数据可读");
        }
    }
    
    private static void handleWrite(SelectionKey key) throws IOException {
        System.out.println("=== 处理WRITE事件 ===");
        
        SocketChannel socketChannel = (SocketChannel) key.channel();
        
        // 获取之前保存的消息
        String originalMessage = (String) key.attachment();
        
        // 构造响应
        String response = "服务器响应: " + originalMessage;
        ByteBuffer buffer = ByteBuffer.wrap(response.getBytes());
        
        // 写入数据
        int bytesWritten = socketChannel.write(buffer);
        System.out.println("发送响应: " + response);
        System.out.println("发送字节数: " + bytesWritten);
        
        // 重新注册读事件
        key.interestOps(SelectionKey.OP_READ);
    }
    
    private static void handleConnect(SelectionKey key) throws IOException {
        System.out.println("=== 处理CONNECT事件 ===");
        
        SocketChannel socketChannel = (SocketChannel) key.channel();
        
        if (socketChannel.finishConnect()) {
            System.out.println("连接建立成功");
            // 连接成功后，可以注册读事件
            key.interestOps(SelectionKey.OP_READ);
        } else {
            System.out.println("连接建立失败");
            socketChannel.close();
        }
    }
}
```

### 5.6.3 使用Attachment存储状态

```java
public class AttachmentExample {
    public static class ConnectionState {
        private ByteBuffer readBuffer;
        private ByteBuffer writeBuffer;
        private String clientId;
        
        public ConnectionState(String clientId) {
            this.clientId = clientId;
            this.readBuffer = ByteBuffer.allocate(1024);
            this.writeBuffer = ByteBuffer.allocate(1024);
        }
        
        // getter和setter方法
        public ByteBuffer getReadBuffer() { return readBuffer; }
        public ByteBuffer getWriteBuffer() { return writeBuffer; }
        public String getClientId() { return clientId; }
    }
    
    public static void demonstrateAttachment() {
        try {
            Selector selector = Selector.open();
            ServerSocketChannel serverSocketChannel = ServerSocketChannel.open();
            serverSocketChannel.configureBlocking(false);
            serverSocketChannel.bind(new InetSocketAddress(8080));
            
            // 注册时附加状态对象
            serverSocketChannel.register(selector, SelectionKey.OP_ACCEPT);
            
            while (true) {
                selector.select();
                
                Set<SelectionKey> selectedKeys = selector.selectedKeys();
                Iterator<SelectionKey> iterator = selectedKeys.iterator();
                
                while (iterator.hasNext()) {
                    SelectionKey key = iterator.next();
                    iterator.remove();
                    
                    if (key.isAcceptable()) {
                        handleAcceptWithAttachment(key, selector);
                    }
                    
                    if (key.isReadable()) {
                        handleReadWithAttachment(key);
                    }
                }
            }
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    private static void handleAcceptWithAttachment(SelectionKey key, Selector selector) throws IOException {
        ServerSocketChannel serverSocketChannel = (ServerSocketChannel) key.channel();
        SocketChannel clientChannel = serverSocketChannel.accept();
        clientChannel.configureBlocking(false);
        
        // 为每个连接创建状态对象
        String clientId = "client-" + System.currentTimeMillis();
        ConnectionState state = new ConnectionState(clientId);
        
        // 注册时附加状态对象
        clientChannel.register(selector, SelectionKey.OP_READ, state);
        
        System.out.println("新连接: " + clientId);
    }
    
    private static void handleReadWithAttachment(SelectionKey key) throws IOException {
        SocketChannel channel = (SocketChannel) key.channel();
        ConnectionState state = (ConnectionState) key.attachment();
        
        ByteBuffer buffer = state.getReadBuffer();
        int bytesRead = channel.read(buffer);
        
        if (bytesRead > 0) {
            buffer.flip();
            String message = new String(buffer.array(), 0, buffer.remaining());
            System.out.println("来自 " + state.getClientId() + ": " + message);
            
            // 准备响应
            ByteBuffer writeBuffer = state.getWriteBuffer();
            writeBuffer.clear();
            writeBuffer.put(("Echo: " + message).getBytes());
            writeBuffer.flip();
            
            // 注册写事件
            key.interestOps(SelectionKey.OP_WRITE);
        }
    }
}
```

# 6 NIO网络编程示例

## 6.1 完整的Echo服务器

```java
public class NIOEchoServer {
    private static final int PORT = 8080;
    private static final int BUFFER_SIZE = 1024;
    
    public static void main(String[] args) {
        try (Selector selector = Selector.open();
             ServerSocketChannel serverSocketChannel = ServerSocketChannel.open()) {
            
            // 配置服务器
            serverSocketChannel.configureBlocking(false);
            serverSocketChannel.bind(new InetSocketAddress(PORT));
            serverSocketChannel.register(selector, SelectionKey.OP_ACCEPT);
            
            System.out.println("Echo服务器启动，监听端口: " + PORT);
            
            while (true) {
                selector.select();
                
                Set<SelectionKey> selectedKeys = selector.selectedKeys();
                Iterator<SelectionKey> iterator = selectedKeys.iterator();
                
                while (iterator.hasNext()) {
                    SelectionKey key = iterator.next();
                    iterator.remove();
                    
                    if (key.isAcceptable()) {
                        acceptConnection(key, selector);
                    }
                    
                    if (key.isReadable()) {
                        echoMessage(key);
                    }
                }
            }
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    private static void acceptConnection(SelectionKey key, Selector selector) throws IOException {
        ServerSocketChannel serverSocketChannel = (ServerSocketChannel) key.channel();
        SocketChannel clientChannel = serverSocketChannel.accept();
        clientChannel.configureBlocking(false);
        clientChannel.register(selector, SelectionKey.OP_READ);
        
        System.out.println("客户端连接: " + clientChannel.getRemoteAddress());
    }
    
    private static void echoMessage(SelectionKey key) throws IOException {
        SocketChannel clientChannel = (SocketChannel) key.channel();
        ByteBuffer buffer = ByteBuffer.allocate(BUFFER_SIZE);
        
        int bytesRead = clientChannel.read(buffer);
        
        if (bytesRead > 0) {
            buffer.flip();
            byte[] data = new byte[buffer.remaining()];
            buffer.get(data);
            String message = new String(data);
            
            System.out.println("收到: " + message);
            
            // 回显消息
            buffer.clear();
            buffer.put(("Echo: " + message).getBytes());
            buffer.flip();
            clientChannel.write(buffer);
            
        } else if (bytesRead == -1) {
            System.out.println("客户端断开连接: " + clientChannel.getRemoteAddress());
            clientChannel.close();
        }
    }
}
```

# 7 NIO性能优化

## 7.1 使用直接缓冲区

```java
// 对于大文件传输，使用直接缓冲区可以提高性能
public static void copyLargeFile(String source, String target) throws IOException {
    try (FileChannel sourceChannel = new FileInputStream(source).getChannel();
         FileChannel targetChannel = new FileOutputStream(target).getChannel()) {
        
        // 使用直接缓冲区
        ByteBuffer buffer = ByteBuffer.allocateDirect(8192);
        
        while (sourceChannel.read(buffer) != -1) {
            buffer.flip();
            targetChannel.write(buffer);
            buffer.clear();
        }
    }
}
```

## 7.2 批量操作

```java
// 使用批量操作提高性能
public static void batchWrite(SocketChannel channel, String[] messages) throws IOException {
    ByteBuffer[] buffers = new ByteBuffer[messages.length];
    
    for (int i = 0; i < messages.length; i++) {
        buffers[i] = ByteBuffer.wrap(messages[i].getBytes());
    }
    
    // 批量写入
    channel.write(buffers);
}
```
