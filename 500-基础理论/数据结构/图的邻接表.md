图的邻接表（Adjacency List）是一种常用的数据结构，用于表示图（Graph）中**顶点之间的连接关系**，特别适用于 **稀疏图（边远少于顶点平方）** 的场景。

---

# **一、邻接表的基本定义**
**邻接表的核心思想：**
- 图中每个顶点都维护一个**列表**，该列表中存储着**所有与该顶点相邻的顶点（即有边连接的顶点）**。

---

# **二、邻接表的结构（以无向图为例）**
假设图 G 有 4 个顶点：A、B、C、D，边如下：
- A - B
- A - C
- B - D

邻接表的表示如下：

```
A → B → C  
B → A → D  
C → A  
D → B  
```

> 每个顶点对应一个链表或数组，存储它连接的其他顶点。

---

# **三、邻接表的存储方式（代码实现思路）**
## **1. Java/Python 中常见实现方式：**
- 使用哈希表或数组，键是顶点编号，值是一个列表/链表。

```
Python 示例（无向图）
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A'],
    'D': ['B']
}
```

或者 Java 中：

```
Map<String, List<String>> graph = new HashMap<>();
graph.put("A", Arrays.asList("B", "C"));
graph.put("B", Arrays.asList("A", "D"));
graph.put("C", Arrays.asList("A"));
graph.put("D", Arrays.asList("B"));
```

---

# **四、邻接表 vs 邻接矩阵（对比）**

|**特性**|**邻接表**|**邻接矩阵**|
|---|---|---|
|空间复杂度|O(V + E)|O(V²)|
|适合类型|稀疏图|稠密图|
|查找相邻点|快（O(度)）|全部遍历（O(V)）|
|判断是否连接|慢（O(度)）|快（O(1)）|

---

# **五、邻接表的应用**
- 图的遍历（DFS、BFS）
- 拓扑排序
- 最短路径（如 Dijkstra）
- 图算法如 Kruskal、Prim（配合边集）
