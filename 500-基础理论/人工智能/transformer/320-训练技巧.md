# 2 学习率调度策略

## 2.1 核心原理

### 2.1.1 学习率的重要性
学习率是训练过程中最重要的超参数之一，直接影响模型的收敛速度和最终性能。

**关键作用：**
- **过大**：导致训练不稳定，可能发散
- **过小**：收敛缓慢，容易陷入局部最优
- **合适**：快速收敛到全局最优

### 2.1.2 动态调度的必要性
- **训练初期**：需要较大学习率快速探索
- **训练中期**：需要适中学习率稳定收敛
- **训练后期**：需要较小学习率精细调优

## 2.2 预热策略（Warmup）

### 2.2.1 预热原理
```python
class WarmupScheduler:
    def __init__(self, optimizer, d_model, warmup_steps):
        self.optimizer = optimizer
        self.d_model = d_model
        self.warmup_steps = warmup_steps
        self.step_count = 0
        
    def step(self):
        self.step_count += 1
        lr = self.get_lr()
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
            
    def get_lr(self):
        # 预热阶段：学习率从0线性增长到目标值
        if self.step_count < self.warmup_steps:
            return self.d_model ** (-0.5) * self.step_count * self.warmup_steps ** (-1.5)
        else:
            # 预热后：学习率按步数衰减
            return self.d_model ** (-0.5) * self.step_count ** (-0.5)
```

### 2.2.2 预热设计思想
- **目的**：防止训练初期梯度不稳定
- **机制**：学习率从0逐渐增加到目标值
- **时长**：通常为总步数的1-10%

### 2.2.3 数学原理
预热阶段的学习率计算：
$$lr = d_{\text{model}}^{-0.5} \times \min(\text{step} \times \text{warmup\_steps}^{-1.5}, \text{step}^{-0.5})$$

**设计思想：**
- **$d_{\text{model}}^{-0.5}$**：与模型维度相关的基础学习率
- **线性增长**：预热阶段学习率线性增长
- **平方根衰减**：预热后按步数的平方根衰减

## 2.3 余弦退火调度

### 2.3.1 实现原理

### 2.3.2 余弦退火优势
- **平滑衰减**：学习率平滑衰减，避免突变
- **周期性**：可以设置多个周期
- **精细调优**：后期学习率很小，适合精细调优

## 2.4 自适应学习率

### 2.4.1 Adam优化器
```python
class AdamOptimizer:
    def __init__(self, params, lr=1e-4, betas=(0.9, 0.999), eps=1e-8):
        self.params = params
        self.lr = lr
        self.betas = betas
        self.eps = eps
        self.m = {}  # 一阶矩估计
        self.v = {}  # 二阶矩估计
        self.t = 0   # 时间步
        
    def step(self, gradients):
        self.t += 1
        for param, grad in zip(self.params, gradients):
            if param not in self.m:
                self.m[param] = torch.zeros_like(param)
                self.v[param] = torch.zeros_like(param)
            
            # 更新一阶矩估计
            self.m[param] = self.betas[0] * self.m[param] + (1 - self.betas[0]) * grad
            
            # 更新二阶矩估计
            self.v[param] = self.betas[1] * self.v[param] + (1 - self.betas[1]) * grad ** 2
            
            # 偏差修正
            m_hat = self.m[param] / (1 - self.betas[0] ** self.t)
            v_hat = self.v[param] / (1 - self.betas[1] ** self.t)
            
            # 参数更新
            param.data -= self.lr * m_hat / (torch.sqrt(v_hat) + self.eps)
```

### 2.4.2 AdamW优化器
```python
class AdamWOptimizer(AdamOptimizer):
    def __init__(self, params, lr=1e-4, weight_decay=0.01, **kwargs):
        super().__init__(params, lr, **kwargs)
        self.weight_decay = weight_decay
        
    def step(self, gradients):
        # 应用权重衰减
        for param in self.params:
            param.data -= self.lr * self.weight_decay * param.data
            
        # 调用父类的step方法
        super().step(gradients)
```

# 3 标签平滑（Label Smoothing）

## 3.1 核心原理

### 3.1.1 问题背景
传统的交叉熵损失使用硬标签（one-hot编码），可能导致：
- **过拟合**：模型过于自信
- **泛化差**：对噪声敏感
- **训练不稳定**：梯度变化剧烈

### 3.1.2 标签平滑思想
将硬标签转换为软标签，在正确类别上分配高概率，在其他类别上分配小概率。

## 3.2 实现方法

### 3.2.1 标签平滑实现
```python
class LabelSmoothingLoss(nn.Module):
    def __init__(self, vocab_size, smoothing=0.1, ignore_index=None):
        super().__init__()
        self.vocab_size = vocab_size
        self.smoothing = smoothing
        self.ignore_index = ignore_index
        
    def forward(self, pred, target):
        # 创建平滑标签
        smooth_target = torch.zeros_like(pred)
        smooth_target.fill_(self.smoothing / (self.vocab_size - 1))
        smooth_target.scatter_(1, target.unsqueeze(1), 1.0 - self.smoothing)
        
        # 处理忽略的索引
        if self.ignore_index is not None:
            smooth_target[target == self.ignore_index] = 0
            
        # 计算交叉熵损失
        log_prob = F.log_softmax(pred, dim=-1)
        loss = -torch.sum(smooth_target * log_prob, dim=-1)
        
        return loss.mean()
```

### 3.2.2 数学原理
对于正确类别 $y$，标签平滑后的概率分布为：
$$P(y) = 1 - \epsilon + \frac{\epsilon}{K-1}$$
$$P(i) = \frac{\epsilon}{K-1}, \quad i \neq y$$

其中 $\epsilon$ 是平滑参数，$K$ 是类别数。

## 3.3 设计思想

### 3.3.1 正则化效果
- **防止过拟合**：减少模型对训练数据的过度自信
- **提高泛化**：增强模型对噪声的鲁棒性
- **稳定训练**：平滑梯度变化

### 3.3.2 参数选择
- **$\epsilon = 0.1$**：常用值，平衡效果和性能
- **$\epsilon = 0.05$**：轻微平滑，适合高质量数据
- **$\epsilon = 0.2$**：强平滑，适合噪声数据

# 4 梯度裁剪（Gradient Clipping）

## 4.1 核心原理

### 4.1.1 梯度爆炸问题
在深度网络中，梯度可能变得非常大，导致：
- **训练不稳定**：参数更新过大
- **数值溢出**：导致NaN或无穷大
- **收敛困难**：模型无法收敛

### 4.1.2 梯度裁剪作用
限制梯度的范数，防止梯度爆炸，保持训练稳定性。

## 4.2 实现方法

### 4.2.1 全局梯度裁剪
```python
def clip_gradients(model, max_norm):
    """全局梯度裁剪"""
    total_norm = 0
    for p in model.parameters():
        if p.grad is not None:
            param_norm = p.grad.data.norm(2)
            total_norm += param_norm.item() ** 2
    total_norm = total_norm ** (1. / 2)
    
    clip_coef = max_norm / (total_norm + 1e-6)
    if clip_coef < 1:
        for p in model.parameters():
            if p.grad is not None:
                p.grad.data.mul_(clip_coef)
                
    return total_norm
```

### 4.2.2 分层梯度裁剪
```python
def clip_gradients_by_layer(model, max_norm):
    """分层梯度裁剪"""
    for name, module in model.named_modules():
        if hasattr(module, 'weight') and module.weight.grad is not None:
            # 计算该层的梯度范数
            param_norm = module.weight.grad.data.norm(2)
            
            # 如果超过阈值，进行裁剪
            if param_norm > max_norm:
                clip_coef = max_norm / param_norm
                module.weight.grad.data.mul_(clip_coef)
```

## 4.3 设计思想

### 4.3.1 裁剪策略选择
- **全局裁剪**：所有参数使用相同的裁剪阈值
- **分层裁剪**：不同层使用不同的裁剪策略
- **自适应裁剪**：根据梯度分布动态调整阈值

### 4.3.2 阈值设置
- **$\text{max\_norm} = 1.0$**：常用值，适合大多数情况
- **$\text{max\_norm} = 0.5$**：保守设置，适合不稳定模型
- **$\text{max\_norm} = 5.0$**：宽松设置，适合稳定模型

# 5 正则化技巧

## 5.1 Dropout正则化

### 5.1.1 实现原理
```python
class TransformerDropout(nn.Module):
    def __init__(self, dropout_rate=0.1):
        super().__init__()
        self.dropout_rate = dropout_rate
        
    def forward(self, x):
        if self.training:
            # 训练时应用dropout
            mask = torch.bernoulli(torch.ones_like(x) * (1 - self.dropout_rate))
            x = x * mask / (1 - self.dropout_rate)
        return x
```

### 5.1.2 设计思想
- **随机失活**：随机将部分神经元输出设为0
- **集成效果**：相当于训练多个子网络
- **防止过拟合**：减少神经元间的共适应

## 5.3 早停（Early Stopping）

### 5.3.1 实现原理
```python
class EarlyStopping:
    def __init__(self, patience=10, min_delta=0):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = float('inf')
        
    def __call__(self, val_loss):
        if val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.counter = 0
        else:
            self.counter += 1
            
        return self.counter >= self.patience
```

# 6 训练稳定性优化

## 6.1 梯度累积

### 6.1.1 实现原理
```python
class GradientAccumulator:
    def __init__(self, accumulation_steps=4):
        self.accumulation_steps = accumulation_steps
        self.counter = 0
        
    def accumulate(self, loss, model):
        # 缩放损失
        loss = loss / self.accumulation_steps
        loss.backward()
        
        self.counter += 1
        
        # 每accumulation_steps步更新一次参数
        if self.counter % self.accumulation_steps == 0:
            optimizer.step()
            optimizer.zero_grad()
```

### 6.1.2 设计思想
- **模拟大批次**：通过累积梯度模拟大批次训练
- **内存优化**：减少GPU内存使用
- **稳定性提升**：大批次训练通常更稳定

## 6.2 混合精度训练

### 6.2.1 实现原理

```python
from torch.cuda.amp import autocast, GradScaler

class MixedPrecisionTrainer:
    def __init__(self, model, optimizer):
        self.model = model
        self.optimizer = optimizer
        self.scaler = GradScaler()
        
    def train_step(self, data):
        self.optimizer.zero_grad()
        
        # 使用混合精度
        with autocast():
            output = self.model(data)
            loss = self.criterion(output, target)
```

## 6.3 学习率预热和衰减

### 6.3.1 完整调度器
```python
class TransformerScheduler:
    def __init__(self, optimizer, d_model, warmup_steps, total_steps):
        self.optimizer = optimizer
        self.d_model = d_model
        self.warmup_steps = warmup_steps
        self.total_steps = total_steps
        self.step_count = 0
        
    def step(self):
        self.step_count += 1
        lr = self.get_lr()
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
            
    def get_lr(self):
        if self.step_count < self.warmup_steps:
            # 预热阶段：线性增长
            return self.d_model ** (-0.5) * self.step_count * self.warmup_steps ** (-1.5)
```
