## 🎯 学习路径建议

### 入门路径（基础 → 应用）
1. **基础数学** → **线性代数** → **微积分** → **概率论** → **统计学**
2. **应用数学**（机器学习、深度学习相关）

### 进阶路径（按应用领域）
- **机器学习方向**：线性代数 → 微积分 → 概率论 → 优化算法
- **深度学习方向**：微积分 → 线性代数 → 数值计算 → 应用数学
- **数据科学方向**：概率论 → 统计学 → 线性代数 → 应用数学

## 📖 重点内容

### 核心概念
- **微积分**：导数、偏导数、梯度、链式法则
- **线性代数**：矩阵运算、特征值分解、SVD
- **概率论**：贝叶斯定理、常见分布
- **优化**：梯度下降、拉格朗日乘数法

### 应用场景
- **机器学习**：损失函数、反向传播、正则化
- **深度学习**：自动求导、激活函数、权重更新
- **数据科学**：降维、聚类、回归分析
