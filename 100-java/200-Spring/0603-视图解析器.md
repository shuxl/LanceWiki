## 视图解析器概念或介绍

### 什么是视图解析器
视图解析器是Spring MVC框架中负责将控制器返回的逻辑视图名称解析为实际视图对象的组件。它是MVC模式中View层的重要组成部分，连接控制器和视图技术。

**视图解析器的职责：**
- 解析逻辑视图名称
- 创建视图对象
- 支持多种视图技术
- 提供视图缓存机制

### 视图解析器设计模式
Spring MVC视图解析器采用多种设计模式：

1. **策略模式**：不同的视图解析器处理不同类型的视图
2. **模板方法模式**：定义了视图解析的标准流程
3. **责任链模式**：多个视图解析器组成解析链

## 视图解析器类型

### 1. 内置视图解析器

#### InternalResourceViewResolver
```java
@Configuration
public class WebConfig {
    
    @Bean
    public ViewResolver viewResolver() {
        InternalResourceViewResolver resolver = new InternalResourceViewResolver();
        resolver.setPrefix("/WEB-INF/views/");
        resolver.setSuffix(".jsp");
        resolver.setViewClass(JstlView.class);
        return resolver;
    }
}
```

**底层实现：**
```java
public class InternalResourceViewResolver extends UrlBasedViewResolver {
    
    @Override
    protected View createView(String viewName, Locale locale) throws Exception {
        // 创建InternalResourceView
        InternalResourceView view = new InternalResourceView();
        view.setUrl(getPrefix() + viewName + getSuffix());
        return view;
    }
    
    @Override
    protected boolean canHandle(String viewName, Locale locale) {
        // 检查是否支持该视图名称
        return viewName.startsWith("redirect:") || viewName.startsWith("forward:");
    }
}
```

#### ContentNegotiatingViewResolver
```java

public class WebConfig {
```

**底层实现：**
```java
public class ContentNegotiatingViewResolver implements ViewResolver, Ordered {
    
    @Override
    public View resolveViewName(String viewName, Locale locale) throws Exception {
        // 1. 获取所有候选视图
        List<View> candidateViews = getCandidateViews(viewName, locale, requestedMediaTypes);
        
        // 2. 选择最佳视图
        View bestView = getBestView(candidateViews, requestedMediaTypes);
        
        return bestView;
    }
    
    private List<View> getCandidateViews(String viewName, Locale locale, 
                                       List<MediaType> requestedMediaTypes) throws Exception {
        List<View> candidateViews = new ArrayList<>();
        
        // 遍历所有视图解析器
        for (ViewResolver viewResolver : this.viewResolvers) {
            View view = viewResolver.resolveViewName(viewName, locale);
            if (view != null) {
                candidateViews.add(view);
            }
        }
        
        return candidateViews;
    }
}
```

## 视图解析器工作原理

### 1. ViewResolver接口

#### 核心接口定义
```java
public interface ViewResolver {
    // 解析视图名称，返回View对象
    View resolveViewName(String viewName, Locale locale) throws Exception;
}
```

#### 视图解析器链
```java
public class ViewResolverComposite implements ViewResolver, Ordered {
    
    private List<ViewResolver> viewResolvers = new ArrayList<>();
    
    @Override
    public View resolveViewName(String viewName, Locale locale) throws Exception {
        // 按顺序遍历所有视图解析器
        for (ViewResolver viewResolver : this.viewResolvers) {
            View view = viewResolver.resolveViewName(viewName, locale);
            if (view != null) {
                return view;
            }
        }
        return null;
    }
}
```

### 2. View接口

#### View接口定义
```java
public interface View {
    // 获取内容类型
    String getContentType();
    
    // 渲染视图
    void render(Map<String, ?> model, HttpServletRequest request, 
                HttpServletResponse response) throws Exception;
}
```

#### 常用View实现
```java
// 1. JstlView - JSP视图
public class JstlView extends InternalResourceView {
    
    @Override
    protected void renderMergedOutputModel(Map<String, Object> model,
                                         HttpServletRequest request,
                                         HttpServletResponse response) throws Exception {
        // 设置模型属性到请求中
        exposeModelAsRequestAttributes(model, request);
        
        // 转发到JSP页面
        RequestDispatcher rd = request.getRequestDispatcher(getUrl());
        rd.forward(request, response);
    }
}

// 2. MappingJackson2JsonView - JSON视图
public class MappingJackson2JsonView extends AbstractView {
    
    @Override
    protected void renderMergedOutputModel(Map<String, Object> model,
                                         HttpServletRequest request,
                                         HttpServletResponse response) throws Exception {
        // 序列化模型为JSON
        ObjectMapper mapper = new ObjectMapper();
        String json = mapper.writeValueAsString(model);
        
        // 写入响应
        response.setContentType(getContentType());
        response.setCharacterEncoding("UTF-8");
        response.getWriter().write(json);
    }
}
```

### 3. 视图解析流程

#### 解析流程详解
```java
// 1. DispatcherServlet.processDispatchResult()
protected void processDispatchResult(HttpServletRequest request,
                                   HttpServletResponse response,
                                   HandlerExecutionChain mappedHandler,
                                   ModelAndView mv,
                                   Exception exception) throws Exception {
    
    // 处理视图
    if (mv != null && !mv.wasCleared()) {
        render(mv, request, response);
    }
}

// 2. DispatcherServlet.render()
protected void render(ModelAndView mv, HttpServletRequest request,
                     HttpServletResponse response) throws Exception {
    
    // 解析视图名称
    View view = resolveViewName(mv.getViewName(), mv.getModel(), locale, request);
    
    // 渲染视图
    view.render(mv.getModelInternal(), request, response);
}

// 3. DispatcherServlet.resolveViewName()
protected View resolveViewName(String viewName, Map<String, Object> model,
                             Locale locale, HttpServletRequest request) throws Exception {
    
    // 遍历所有视图解析器
    for (ViewResolver viewResolver : this.viewResolvers) {
        View view = viewResolver.resolveViewName(viewName, locale);
        if (view != null) {
            return view;
        }
    }
    return null;
}
```

## 自定义视图解析器

### 1. 实现ViewResolver接口
```java
@Component
public class CustomViewResolver implements ViewResolver, Ordered {
    
    @Override
    public View resolveViewName(String viewName, Locale locale) throws Exception {
        // 检查是否支持该视图名称
        if (!viewName.startsWith("custom:")) {
            return null;
        }
        
        // 解析视图名称
        String templateName = viewName.substring("custom:".length());
        
        // 创建自定义视图
        return new CustomView(templateName);
    }
    
    @Override
    public int getOrder() {
        return 1; // 优先级
    }
}
```

### 2. 实现View接口
```java
public class CustomView implements View {
    
    private final String templateName;
    
    public CustomView(String templateName) {
        this.templateName = templateName;
    }
    
    @Override
    public String getContentType() {
        return "text/html; charset=UTF-8";
    }
    
    @Override
    public void render(Map<String, ?> model, HttpServletRequest request,
                      HttpServletResponse response) throws Exception {
        
        // 设置响应头
        response.setContentType(getContentType());
        
        // 获取模板内容
        String template = loadTemplate(templateName);
        
        // 替换模板变量
        String content = processTemplate(template, model);
        
        // 写入响应
        response.getWriter().write(content);
    }
    
    private String loadTemplate(String templateName) {
        // 从文件系统或数据库加载模板
        return "Hello, ${name}!";
    }
    
    private String processTemplate(String template, Map<String, ?> model) {
        String result = template;
        for (Map.Entry<String, ?> entry : model.entrySet()) {
            result = result.replace("${" + entry.getKey() + "}", 
                                  String.valueOf(entry.getValue()));
        }
        return result;
    }
}
```

## 视图缓存机制

### 1. 视图缓存实现
```java
public abstract class AbstractCachingViewResolver extends WebApplicationObjectSupport
        implements ViewResolver, Ordered {
    
    // 视图缓存
    private final Map<Object, View> viewCache = new ConcurrentHashMap<>();
    
    @Override
    public View resolveViewName(String viewName, Locale locale) throws Exception {
        // 生成缓存键
        Object cacheKey = getCacheKey(viewName, locale);
        
        // 从缓存获取视图
        View view = this.viewCache.get(cacheKey);
        if (view != null) {
            return view;
        }
        
        // 创建新视图
        synchronized (this.viewCache) {
            view = this.viewCache.get(cacheKey);
            if (view == null) {
                view = createView(viewName, locale);
                if (view != null) {
                    this.viewCache.put(cacheKey, view);
                }
            }
        }
        
        return view;
    }
    
    protected abstract View createView(String viewName, Locale locale) throws Exception;
}
```

```java
@Component
public class AsyncViewResolver implements ViewResolver {
    
    @Async
    public CompletableFuture<View> resolveViewNameAsync(String viewName, Locale locale) {
        return CompletableFuture.supplyAsync(() -> {
            try {
                return resolveViewName(viewName, locale);
            } catch (Exception e) {
                throw new RuntimeException(e);
            }
        });
    }
}
```
