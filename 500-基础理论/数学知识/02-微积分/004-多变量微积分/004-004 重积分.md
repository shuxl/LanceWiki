## 二重积分

### 二重积分的定义
对于二元函数 $f(x, y)$ 在有界闭区域 $D$ 上的二重积分定义为：

$$\iint_D f(x, y) dA = \lim_{n \to \infty} \sum_{i=1}^n f(\xi_i, \eta_i) \Delta A_i$$

其中 $\Delta A_i$ 是第 $i$ 个小区域的面积，$(\xi_i, \eta_i)$ 是该区域内的任意点。

### 二重积分的几何意义
二重积分 $\iint_D f(x, y) dA$ 表示函数 $f(x, y)$ 在区域 $D$ 上与 $xy$ 平面围成的体积：
- 当 $f(x, y) \geq 0$ 时，表示正体积
- 当 $f(x, y) \leq 0$ 时，表示负体积
- 总体积为各部分体积的代数和

### 二重积分的性质

#### 线性性质
$$\iint_D [cf(x, y) + dg(x, y)] dA = c\iint_D f(x, y) dA + d\iint_D g(x, y) dA$$

#### 区域可加性
如果区域 $D$ 可以分解为 $D_1$ 和 $D_2$，且 $D_1 \cap D_2 = \emptyset$，则：

$$\iint_D f(x, y) dA = \iint_{D_1} f(x, y) dA + \iint_{D_2} f(x, y) dA$$

#### 积分中值定理
如果函数 $f(x, y)$ 在区域 $D$ 上连续，则存在点 $(\xi, \eta) \in D$，使得：

$$\iint_D f(x, y) dA = f(\xi, \eta) \cdot \text{Area}(D)$$

## 二重积分的计算方法

### 累次积分法
将二重积分转化为两次单重积分：

$$\iint_D f(x, y) dA = \int_a^b \left[\int_{g_1(x)}^{g_2(x)} f(x, y) dy\right] dx$$

或：

$$\iint_D f(x, y) dA = \int_c^d \left[\int_{h_1(y)}^{h_2(y)} f(x, y) dx\right] dy$$

**示例：**
计算 $\iint_D (x + y) dA$，其中 $D$ 是由 $x = 0, x = 1, y = 0, y = 1$ 围成的矩形：

$$\iint_D (x + y) dA = \int_0^1 \int_0^1 (x + y) dy dx = \int_0^1 \left[xy + \frac{y^2}{2}\right]_0^1 dx = \int_0^1 (x + \frac{1}{2}) dx = \left[\frac{x^2}{2} + \frac{x}{2}\right]_0^1 = 1$$

### 极坐标下的二重积分
在极坐标下，二重积分为：

$$\iint_D f(x, y) dA = \iint_D f(r\cos\theta, r\sin\theta) r dr d\theta$$

**示例：**
计算 $\iint_D e^{-(x^2 + y^2)} dA$，其中 $D$ 是整个平面：

$$\iint_D e^{-(x^2 + y^2)} dA = \int_0^{2\pi} \int_0^{\infty} e^{-r^2} r dr d\theta = 2\pi \int_0^{\infty} e^{-r^2} r dr = 2\pi \left[-\frac{1}{2}e^{-r^2}\right]_0^{\infty} = \pi$$

### 变量替换
对于变量替换 $x = x(u, v), y = y(u, v)$，二重积分为：

$$\iint_D f(x, y) dA = \iint_{D'} f(x(u, v), y(u, v)) |J| du dv$$

其中 $J$ 是雅可比行列式：

$$J = \begin{vmatrix}
\frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\
\frac{\partial y}{\partial u} & \frac{\partial y}{\partial v}
\end{vmatrix}$$

## 三重积分

### 三重积分的定义
对于三元函数 $f(x, y, z)$ 在有界闭区域 $E$ 上的三重积分定义为：

$$\iiint_E f(x, y, z) dV = \lim_{n \to \infty} \sum_{i=1}^n f(\xi_i, \eta_i, \zeta_i) \Delta V_i$$

### 三重积分的计算方法

#### 累次积分法
$$\iiint_E f(x, y, z) dV = \int_a^b \int_{g_1(x)}^{g_2(x)} \int_{h_1(x,y)}^{h_2(x,y)} f(x, y, z) dz dy dx$$

**示例：**
计算 $\iiint_E (x + y + z) dV$，其中 $E$ 是由 $x = 0, x = 1, y = 0, y = 1, z = 0, z = 1$ 围成的立方体：

$$\iiint_E (x + y + z) dV = \int_0^1 \int_0^1 \int_0^1 (x + y + z) dz dy dx = \int_0^1 \int_0^1 \left[xz + yz + \frac{z^2}{2}\right]_0^1 dy dx$$

$$= \int_0^1 \int_0^1 (x + y + \frac{1}{2}) dy dx = \int_0^1 \left[xy + \frac{y^2}{2} + \frac{y}{2}\right]_0^1 dx = \int_0^1 (x + \frac{1}{2} + \frac{1}{2}) dx = \frac{3}{2}$$

### 柱坐标下的三重积分
在柱坐标 $(r, \theta, z)$ 下：

$$\iiint_E f(x, y, z) dV = \iiint_E f(r\cos\theta, r\sin\theta, z) r dr d\theta dz$$

### 球坐标下的三重积分
在球坐标 $(r, \theta, \phi)$ 下：

$$\iiint_E f(x, y, z) dV = \iiint_E f(r\sin\phi\cos\theta, r\sin\phi\sin\theta, r\cos\phi) r^2\sin\phi dr d\theta d\phi$$

**示例：**
计算球体 $x^2 + y^2 + z^2 \leq R^2$ 的体积：

$$V = \iiint_E dV = \int_0^{2\pi} \int_0^{\pi} \int_0^R r^2\sin\phi dr d\phi d\theta$$

$$= 2\pi \int_0^{\pi} \sin\phi d\phi \int_0^R r^2 dr = 2\pi \cdot 2 \cdot \frac{R^3}{3} = \frac{4}{3}\pi R^3$$

## 极坐标和球坐标积分

### 极坐标积分
在极坐标下，面积元素为 $dA = r dr d\theta$。

**常见区域：**
- 圆：$0 \leq r \leq R, 0 \leq \theta \leq 2\pi$
- 扇形：$0 \leq r \leq R, \alpha \leq \theta \leq \beta$
- 环形：$R_1 \leq r \leq R_2, 0 \leq \theta \leq 2\pi$

**示例：**
计算圆 $x^2 + y^2 \leq R^2$ 的面积：

$$A = \iint_D dA = \int_0^{2\pi} \int_0^R r dr d\theta = 2\pi \int_0^R r dr = 2\pi \cdot \frac{R^2}{2} = \pi R^2$$

### 球坐标积分
在球坐标下，体积元素为 $dV = r^2\sin\phi dr d\theta d\phi$。

**常见区域：**
- 球体：$0 \leq r \leq R, 0 \leq \theta \leq 2\pi, 0 \leq \phi \leq \pi$
- 半球：$0 \leq r \leq R, 0 \leq \theta \leq 2\pi, 0 \leq \phi \leq \frac{\pi}{2}$

## 重积分的应用

### 面积计算
区域 $D$ 的面积为：

$$A = \iint_D dA$$

### 体积计算
区域 $E$ 的体积为：

$$V = \iiint_E dV$$

### 质量计算
如果密度函数为 $\rho(x, y)$，则质量为：

$$M = \iint_D \rho(x, y) dA$$

### 质心计算
质心坐标为：

$$\bar{x} = \frac{1}{M} \iint_D x\rho(x, y) dA$$

$$\bar{y} = \frac{1}{M} \iint_D y\rho(x, y) dA$$

### 转动惯量
绕 $z$ 轴的转动惯量为：

$$I_z = \iint_D (x^2 + y^2)\rho(x, y) dA$$

**示例：**
计算半径为 $R$ 的均匀圆盘绕其中心的转动惯量：

设密度为 $\rho$，则：

$$I = \iint_D (x^2 + y^2)\rho dA = \rho \int_0^{2\pi} \int_0^R r^2 \cdot r dr d\theta = 2\pi\rho \int_0^R r^3 dr = 2\pi\rho \cdot \frac{R^4}{4} = \frac{\pi\rho R^4}{2}$$

由于质量 $M = \pi R^2\rho$，所以：

$$I = \frac{MR^2}{2}$$

### 概率密度函数
对于二维随机变量 $(X, Y)$，概率密度函数 $f(x, y)$ 满足：

$$\iint_{\mathbb{R}^2} f(x, y) dA = 1$$

概率计算：

$$P((X, Y) \in D) = \iint_D f(x, y) dA$$

## 重积分关联的其它知识

### 与单重积分的关系
重积分是单重积分的推广，单重积分可以看作一维重积分。

### 与线性代数的关系
重积分与线性代数中的行列式、雅可比矩阵等概念密切相关。

### 与微分几何的关系
重积分在微分几何中用于计算曲面的面积、体积等几何量。

### 与物理学的关系
在物理学中，重积分用于计算质量、电荷、能量等物理量的分布。

### 与概率论的关系
在概率论中，重积分用于计算多维随机变量的概率分布和期望值。

### 与机器学习的关系
在机器学习中，重积分用于计算多维概率分布、信息熵等统计量。
