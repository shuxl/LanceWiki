# 2 AIO概念或介绍

## 2.1 什么是AIO

AIO（Asynchronous I/O）是Java 7引入的异步IO API，提供了真正的异步非阻塞IO操作。与NIO相比，AIO具有以下特点：

- **真正的异步**：IO操作完成后会主动通知应用程序
- **基于回调**：通过CompletionHandler处理IO完成事件
- **简化编程**：不需要手动管理Selector和事件循环
- **高性能**：适合高并发、高吞吐量场景

## 2.2 AIO vs NIO vs 传统IO

| 特性 | 传统IO | NIO | AIO |
|------|--------|-----|-----|
| 阻塞性 | 阻塞 | 非阻塞 | 异步非阻塞 |
| 通知机制 | 同步 | 轮询 | 回调 |
| 编程复杂度 | 简单 | 复杂 | 中等 |
| 适用场景 | 连接数少 | 连接数多 | 高并发高吞吐 |

## 2.3 AIO的核心组件

1. **AsynchronousFileChannel**：异步文件通道
2. **AsynchronousSocketChannel**：异步Socket通道
3. **AsynchronousServerSocketChannel**：异步服务器Socket通道
4. **CompletionHandler**：完成处理器
5. **Future**：异步操作的结果

# 3 AsynchronousFileChannel

## 3.1 基本文件操作

```java
public class AsynchronousFileChannelExample {
    public static void main(String[] args) {
        // 异步读取文件
        readFileAsync();
        
        // 异步写入文件
        writeFileAsync();
    }
    
    public static void readFileAsync() {
        try {
            Path path = Paths.get("input.txt");
            AsynchronousFileChannel fileChannel = AsynchronousFileChannel.open(path, StandardOpenOption.READ);
            
            ByteBuffer buffer = ByteBuffer.allocate(1024);
            
            // 使用CompletionHandler异步读取
            fileChannel.read(buffer, 0, buffer, new CompletionHandler<Integer, ByteBuffer>() {
                @Override
                public void completed(Integer result, ByteBuffer attachment) {
                    if (result != -1) {
                        attachment.flip();
                        byte[] data = new byte[attachment.remaining()];
                        attachment.get(data);
                        System.out.println("异步读取完成: " + new String(data));
                    }
                    
                    try {
                        fileChannel.close();
                    } catch (IOException e) {
                        e.printStackTrace();
                    }
                }
                
                @Override
                public void failed(Throwable exc, ByteBuffer attachment) {
                    System.err.println("异步读取失败: " + exc.getMessage());
                    try {
                        fileChannel.close();
                    } catch (IOException e) {
                        e.printStackTrace();
                    }
                }
            });
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    public static void writeFileAsync() {
        try {
            Path path = Paths.get("output.txt");
            AsynchronousFileChannel fileChannel = AsynchronousFileChannel.open(
                path, 
                StandardOpenOption.CREATE, 
                StandardOpenOption.WRITE
            );
            
            ByteBuffer buffer = ByteBuffer.wrap("Hello AIO".getBytes());
            
            // 使用CompletionHandler异步写入
            fileChannel.write(buffer, 0, buffer, new CompletionHandler<Integer, ByteBuffer>() {
                @Override
                public void completed(Integer result, ByteBuffer attachment) {
                    System.out.println("异步写入完成，写入字节数: " + result);
                    try {
                        fileChannel.close();
                    } catch (IOException e) {
                        e.printStackTrace();
                    }
                }
                
                @Override
                public void failed(Throwable exc, ByteBuffer attachment) {
                    System.err.println("异步写入失败: " + exc.getMessage());
                    try {
                        fileChannel.close();
                    } catch (IOException e) {
                        e.printStackTrace();
                    }
                }
            });
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

```java
public class AsynchronousFileChannelFutureExample {
    public static void main(String[] args) {
        try {
            Path path = Paths.get("input.txt");
            AsynchronousFileChannel fileChannel = AsynchronousFileChannel.open(path, StandardOpenOption.READ);
            
            ByteBuffer buffer = ByteBuffer.allocate(1024);
            
            // 使用Future模式异步读取
            Future<Integer> future = fileChannel.read(buffer, 0);
            
            // 等待操作完成
            Integer result = future.get();
            
            if (result != -1) {
                buffer.flip();
                byte[] data = new byte[buffer.remaining()];
                buffer.get(data);
                System.out.println("Future模式读取完成: " + new String(data));
            }
            
            fileChannel.close();
            
        } catch (IOException | InterruptedException | ExecutionException e) {
            e.printStackTrace();
        }
    }
}
```

## 3.3 文件复制示例

```java
public class AsynchronousFileCopyExample {
    public static void copyFileAsync(String source, String target) {
        try {
            Path sourcePath = Paths.get(source);
            Path targetPath = Paths.get(target);
            
            AsynchronousFileChannel sourceChannel = AsynchronousFileChannel.open(sourcePath, StandardOpenOption.READ);
            AsynchronousFileChannel targetChannel = AsynchronousFileChannel.open(
                targetPath, 
                StandardOpenOption.CREATE, 
                StandardOpenOption.WRITE
            );
            
            ByteBuffer buffer = ByteBuffer.allocate(8192);
            
            // 异步复制
            copyChunk(sourceChannel, targetChannel, buffer, 0);
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    private static void copyChunk(AsynchronousFileChannel source, AsynchronousFileChannel target, 
                                 ByteBuffer buffer, long position) {
        source.read(buffer, position, buffer, new CompletionHandler<Integer, ByteBuffer>() {
            @Override
            public void completed(Integer result, ByteBuffer attachment) {
                if (result > 0) {
                    attachment.flip();
                    
                    target.write(attachment, position, attachment, new CompletionHandler<Integer, ByteBuffer>() {
                        @Override
                        public void completed(Integer writeResult, ByteBuffer writeAttachment) {
                            attachment.clear();
                            // 继续复制下一块
                            copyChunk(source, target, attachment, position + result);
                        }
                        
                        @Override
                        public void failed(Throwable exc, ByteBuffer writeAttachment) {
                            System.err.println("写入失败: " + exc.getMessage());
                            closeChannels();
                        }
                    });
                } else {
                    // 复制完成
                    System.out.println("文件复制完成");
                    closeChannels();
                }
            }
            
            @Override
            public void failed(Throwable exc, ByteBuffer attachment) {
                System.err.println("读取失败: " + exc.getMessage());
                closeChannels();
            }
            
            private void closeChannels() {
                try {
                    source.close();
                    target.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        });
    }
}
```

```java
public class AsynchronousSocketChannelClientExample {
    public static void main(String[] args) {
        try {
            AsynchronousSocketChannel client = AsynchronousSocketChannel.open();
            
            // 异步连接
            Future<Void> connectFuture = client.connect(new InetSocketAddress("localhost", 8080));
            connectFuture.get(); // 等待连接完成
            
            System.out.println("连接到服务器成功");
            
            // 异步发送数据
            ByteBuffer writeBuffer = ByteBuffer.wrap("Hello Server".getBytes());
            Future<Integer> writeFuture = client.write(writeBuffer);
            writeFuture.get();
            
            // 异步读取响应
            ByteBuffer readBuffer = ByteBuffer.allocate(1024);
            Future<Integer> readFuture = client.read(readBuffer);
            readFuture.get();
            
            readBuffer.flip();
            byte[] data = new byte[readBuffer.remaining()];
            readBuffer.get(data);
            System.out.println("收到响应: " + new String(data));
            
            client.close();
            
        } catch (IOException | InterruptedException | ExecutionException e) {
            e.printStackTrace();
        }
    }
}
```

```java
                                            client.close();
```

# 5 AsynchronousServerSocketChannel

## 5.1 异步服务器

```java
public class AsynchronousServerSocketChannelExample {
    private static final int PORT = 8080;
    
    public static void main(String[] args) {
        try {
            AsynchronousServerSocketChannel server = AsynchronousServerSocketChannel.open();
            server.bind(new InetSocketAddress(PORT));
            
            System.out.println("异步服务器启动，监听端口: " + PORT);
            
            // 异步接受连接
            server.accept(null, new CompletionHandler<AsynchronousSocketChannel, Void>() {
                @Override
                public void completed(AsynchronousSocketChannel client, Void attachment) {
                    // 继续接受下一个连接
                    server.accept(null, this);
                    
                    System.out.println("客户端连接: " + client.getRemoteAddress());
                    
                    // 处理客户端连接
                    handleClient(client);
                }
                
                @Override
                public void failed(Throwable exc, Void attachment) {
                    System.err.println("接受连接失败: " + exc.getMessage());
                }
            });
            
            // 保持服务器运行
            Thread.currentThread().join();
            
        } catch (IOException | InterruptedException e) {
            e.printStackTrace();
        }
    }
    
    private static void handleClient(AsynchronousSocketChannel client) {
        ByteBuffer buffer = ByteBuffer.allocate(1024);
        
        // 异步读取客户端数据
        client.read(buffer, buffer, new CompletionHandler<Integer, ByteBuffer>() {
            @Override
            public void completed(Integer result, ByteBuffer attachment) {
                if (result > 0) {
                    attachment.flip();
                    byte[] data = new byte[attachment.remaining()];
                    attachment.get(data);
                    String message = new String(data);
                    
                    System.out.println("收到消息: " + message);
                    
                    // 发送响应
                    ByteBuffer responseBuffer = ByteBuffer.wrap(("Echo: " + message).getBytes());
                    client.write(responseBuffer, responseBuffer, new CompletionHandler<Integer, ByteBuffer>() {
                        @Override
                        public void completed(Integer result, ByteBuffer attachment) {
                            // 继续读取下一个消息
                            attachment.clear();
                            client.read(attachment, attachment, this);
                        }
                        
                        @Override
                        public void failed(Throwable exc, ByteBuffer attachment) {
                            System.err.println("发送响应失败: " + exc.getMessage());
                            closeClient();
                        }
                    });
                } else {
                    // 客户端断开连接
                    System.out.println("客户端断开连接");
                    closeClient();
                }
            }
            
            @Override
            public void failed(Throwable exc, ByteBuffer attachment) {
                System.err.println("读取数据失败: " + exc.getMessage());
                closeClient();
            }
            
            private void closeClient() {
                try {
                    client.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        });
    }
}
```

# 6 完整的AIO Echo服务器

```java
public class AIOEchoServer {
    private static final int PORT = 8080;
    private final AsynchronousServerSocketChannel server;
    private final ExecutorService executorService;
    
    public AIOEchoServer() throws IOException {
        server = AsynchronousServerSocketChannel.open();
        server.bind(new InetSocketAddress(PORT));
        executorService = Executors.newCachedThreadPool();
    }
    
    public void start() {
        System.out.println("AIO Echo服务器启动，监听端口: " + PORT);
        
        server.accept(null, new CompletionHandler<AsynchronousSocketChannel, Void>() {
            @Override
            public void completed(AsynchronousSocketChannel client, Void attachment) {
                // 继续接受下一个连接
                server.accept(null, this);
                
                if (client != null && client.isOpen()) {
                    System.out.println("客户端连接: " + client.getRemoteAddress());
                    
                    // 为每个客户端创建一个处理器
                    ClientHandler handler = new ClientHandler(client);
                    handler.start();
                }
            }
            
            @Override
            public void failed(Throwable exc, Void attachment) {
                System.err.println("接受连接失败: " + exc.getMessage());
            }
        });
    }
    
    private class ClientHandler {
        private final AsynchronousSocketChannel client;
        private final ByteBuffer buffer;
        
        public ClientHandler(AsynchronousSocketChannel client) {
            this.client = client;
            this.buffer = ByteBuffer.allocate(1024);
        }
        
        public void start() {
            read();
        }
        
        private void read() {
            client.read(buffer, buffer, new CompletionHandler<Integer, ByteBuffer>() {
                @Override
                public void completed(Integer result, ByteBuffer attachment) {
                    if (result > 0) {
                        attachment.flip();
                        byte[] data = new byte[attachment.remaining()];
                        attachment.get(data);
                        String message = new String(data);
                        
                        System.out.println("收到: " + message);
                        
                        // 回显消息
                        write("Echo: " + message);
                    } else {
                        closeClient();
                    }
                }
                
                @Override
                public void failed(Throwable exc, ByteBuffer attachment) {
                    System.err.println("读取失败: " + exc.getMessage());
                    closeClient();
                }
            });
        }
        
        private void write(String message) {
            ByteBuffer writeBuffer = ByteBuffer.wrap(message.getBytes());
            client.write(writeBuffer, writeBuffer, new CompletionHandler<Integer, ByteBuffer>() {
                @Override
                public void completed(Integer result, ByteBuffer attachment) {
                    // 继续读取下一个消息
                    buffer.clear();
                    read();
                }
                
                @Override
                public void failed(Throwable exc, ByteBuffer attachment) {
                    System.err.println("写入失败: " + exc.getMessage());
                    closeClient();
                }
            });
        }
        
        private void closeClient() {
            try {
                System.out.println("客户端断开连接: " + client.getRemoteAddress());
                client.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
    
    public static void main(String[] args) {
        try {
            AIOEchoServer echoServer = new AIOEchoServer();
            echoServer.start();
            
            // 保持服务器运行
            Thread.currentThread().join();
            
        } catch (IOException | InterruptedException e) {
            e.printStackTrace();
        }
    }
}
```

```java
// 批量异步操作
public class AIOBatchOperation {
    public static void batchWrite(AsynchronousFileChannel channel, List<String> messages) {
        List<ByteBuffer> buffers = messages.stream()
            .map(msg -> ByteBuffer.wrap(msg.getBytes()))
            .collect(Collectors.toList());
        
        // 批量写入
        for (int i = 0; i < buffers.size(); i++) {
            final int index = i;
            channel.write(buffers.get(i), i * 1024, buffers.get(i), 
                new CompletionHandler<Integer, ByteBuffer>() {
                    @Override
                    public void completed(Integer result, ByteBuffer attachment) {
                        System.out.println("批量写入完成: " + index);
                    }
                    
                    @Override
                    public void failed(Throwable exc, ByteBuffer attachment) {
                        System.err.println("批量写入失败: " + index + ", " + exc.getMessage());
                    }
                });
        }
    }
}
```
