# 基与坐标

## 重点内容

本文档介绍向量空间的基与坐标的核心概念，包括：
- 基的定义和性质
- 坐标的表示和计算
- 基变换和坐标变换
- 基与坐标的应用

## 1. 基的定义

### 1.1 基的概念

**定义**：向量空间 $V$ 的基是 $V$ 的线性无关的生成集。

**等价定义**：向量组 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ 是 $V$ 的基当且仅当：
1. $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ 线性无关
2. $V = \text{span}\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$

### 1.2 基的性质

**性质**：
- 基中的向量个数等于向量空间的维度
- 任何向量都可以唯一地表示为基向量的线性组合
- 基的任意子集都是线性无关的
- 基的任意超集都是生成集

### 1.3 标准基

**定义**：$\mathbb{R}^n$ 的标准基为：
$$\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n\}$$

其中 $\mathbf{e}_i = (0, \ldots, 0, 1, 0, \ldots, 0)$（1在第i个位置）。

**性质**：
- 标准基是正交的
- 标准基是单位向量
- 任意向量在标准基下的坐标就是其分量

## 2. 坐标的表示

### 2.1 坐标的定义

**定义**：对于向量空间 $V$ 的基 $\mathcal{B} = \{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$，向量 $\mathbf{v} \in V$ 的坐标定义为：
$$\mathbf{v} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_n\mathbf{v}_n$$

其中 $[c_1, c_2, \ldots, c_n]^T$ 是 $\mathbf{v}$ 在基 $\mathcal{B}$ 下的坐标。

**记法**：$[\mathbf{v}]_{\mathcal{B}} = [c_1, c_2, \ldots, c_n]^T$

### 2.2 坐标的计算

**方法**：对于向量 $\mathbf{v}$ 和基 $\mathcal{B} = \{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$，坐标可以通过求解线性方程组得到：

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_n\mathbf{v}_n = \mathbf{v}$$

**矩阵形式**：$B\mathbf{c} = \mathbf{v}$，其中 $B = [\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n]$。

**解**：$\mathbf{c} = B^{-1}\mathbf{v}$

### 2.3 坐标的唯一性

**定理**：在给定基下，任何向量的坐标表示都是唯一的。

**证明**：假设 $\mathbf{v} = c_1\mathbf{v}_1 + \cdots + c_n\mathbf{v}_n = d_1\mathbf{v}_1 + \cdots + d_n\mathbf{v}_n$，则：
$$(c_1 - d_1)\mathbf{v}_1 + \cdots + (c_n - d_n)\mathbf{v}_n = \mathbf{0}$$

由于基向量线性无关，所以 $c_i = d_i$ 对所有 $i$ 成立。

## 3. 基变换

### 3.1 基变换矩阵

**定义**：设 $\mathcal{B}_1 = \{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ 和 $\mathcal{B}_2 = \{\mathbf{w}_1, \mathbf{w}_2, \ldots, \mathbf{w}_n\}$ 是 $V$ 的两个基，基变换矩阵 $P$ 定义为：
$$P = [[\mathbf{w}_1]_{\mathcal{B}_1}, [\mathbf{w}_2]_{\mathcal{B}_1}, \ldots, [\mathbf{w}_n]_{\mathcal{B}_1}]$$

**性质**：
- $P$ 是可逆矩阵
- $P^{-1}$ 是从 $\mathcal{B}_2$ 到 $\mathcal{B}_1$ 的基变换矩阵

### 3.2 坐标变换

**定理**：对于向量 $\mathbf{v} \in V$，在不同基下的坐标满足：
$$[\mathbf{v}]_{\mathcal{B}_2} = P^{-1}[\mathbf{v}]_{\mathcal{B}_1}$$

**证明**：
$$\mathbf{v} = B_1[\mathbf{v}]_{\mathcal{B}_1} = B_2[\mathbf{v}]_{\mathcal{B}_2}$$

其中 $B_1$ 和 $B_2$ 分别是基 $\mathcal{B}_1$ 和 $\mathcal{B}_2$ 的矩阵表示。

由于 $B_2 = B_1P$，所以：
$$B_1[\mathbf{v}]_{\mathcal{B}_1} = B_1P[\mathbf{v}]_{\mathcal{B}_2}$$

因此 $[\mathbf{v}]_{\mathcal{B}_1} = P[\mathbf{v}]_{\mathcal{B}_2}$，即 $[\mathbf{v}]_{\mathcal{B}_2} = P^{-1}[\mathbf{v}]_{\mathcal{B}_1}$。

### 3.3 线性变换的矩阵表示

**定义**：设 $T: V \rightarrow V$ 是线性变换，$\mathcal{B}$ 是 $V$ 的基，$T$ 在基 $\mathcal{B}$ 下的矩阵表示为：
$$[T]_{\mathcal{B}} = [[T(\mathbf{v}_1)]_{\mathcal{B}}, [T(\mathbf{v}_2)]_{\mathcal{B}}, \ldots, [T(\mathbf{v}_n)]_{\mathcal{B}}]$$

**坐标变换**：对于不同基下的矩阵表示：
$$[T]_{\mathcal{B}_2} = P^{-1}[T]_{\mathcal{B}_1}P$$

## 4. 特殊基

### 4.1 正交基

**定义**：基 $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ 是正交基当且仅当：
$$\mathbf{v}_i \cdot \mathbf{v}_j = 0, \quad \forall i \neq j$$

**性质**：
- 正交基中的向量线性无关
- 正交基便于计算坐标
- 可以通过Gram-Schmidt正交化构造

### 4.2 标准正交基

**定义**：基 $\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n\}$ 是标准正交基当且仅当：
$$\mathbf{e}_i \cdot \mathbf{e}_j = \delta_{ij}$$

**性质**：
- 标准正交基是单位向量
- 坐标计算简单：$c_i = \mathbf{v} \cdot \mathbf{e}_i$
- 标准正交基在数值计算中很稳定

### 4.3 特征基

**定义**：如果线性变换 $T$ 有n个线性无关的特征向量，则这些特征向量构成特征基。

**性质**：
- 在特征基下，$T$ 的矩阵表示是对角矩阵
- 特征基便于分析线性变换的性质

## 5. 基与坐标的应用

### 5.1 线性方程组的求解

**基变换方法**：
1. 选择适当的基
2. 在基下表示线性变换
3. 求解坐标
4. 转换回原坐标系

**优势**：选择合适的基可以简化问题。

### 5.2 对角化

**目标**：将矩阵对角化，即找到基使得矩阵在该基下是对角矩阵。

**方法**：
1. 求特征值和特征向量
2. 构造特征基
3. 计算基变换矩阵

### 5.3 主成分分析

**基变换**：PCA通过基变换找到数据方差最大的方向。

**新基**：主成分构成新的正交基。

**坐标**：数据在新基下的坐标是主成分得分。

### 5.4 傅里叶变换

**基函数**：三角函数构成函数空间的正交基。

**坐标**：函数的傅里叶系数是该函数在三角函数基下的坐标。

**应用**：信号处理、图像压缩等。

## 6. 基的构造

### 6.1 扩展基

**问题**：给定线性无关的向量组，如何扩展为基。

**方法**：
1. 将向量组与标准基合并
2. 使用Gram-Schmidt正交化
3. 去除线性相关的向量

### 6.2 子空间的基

**定义**：子空间 $W$ 的基是 $W$ 的线性无关的生成集。

**构造方法**：
1. 找到 $W$ 的生成集
2. 使用Gram-Schmidt正交化
3. 去除零向量

### 6.3 正交补空间的基

**定义**：$W^{\perp}$ 是 $W$ 的正交补空间。

**构造方法**：
1. 找到 $W$ 的正交基
2. 使用Gram-Schmidt正交化扩展为全空间的正交基
3. 不属于 $W$ 的基向量构成 $W^{\perp}$ 的基

## 7. 数值计算

### 7.1 基变换的计算

**Python实现**：
```python
import numpy as np

def basis_change_matrix(basis1, basis2):
    """计算从basis1到basis2的基变换矩阵"""
    B1 = np.array(basis1).T
    B2 = np.array(basis2).T
    
    # P = B2 @ B1^(-1)
    P = B2 @ np.linalg.inv(B1)
    return P

def coordinate_transform(vector, basis1, basis2):
    """计算向量在不同基下的坐标变换"""
    P = basis_change_matrix(basis1, basis2)
    coords_basis1 = np.linalg.solve(np.array(basis1).T, vector)
    coords_basis2 = np.linalg.solve(P, coords_basis1)
    return coords_basis2
```

### 7.2 数值稳定性

**问题**：基变换可能数值不稳定。

**解决方案**：
- 使用正交基
- 使用条件数小的基变换矩阵
- 使用SVD分解

### 7.3 稀疏基

**优势**：稀疏基可以减少存储和计算量。

**应用**：在信号处理中使用小波基。
