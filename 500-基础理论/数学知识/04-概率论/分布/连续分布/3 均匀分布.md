# 均匀分布

## 重点

- **定义**：连续概率分布，在有限区间内概率密度恒为常数
- **应用场景**：随机数生成、蒙特卡洛模拟、质量控制、几何概率
- **数学性质**：对称性、期望为区间中点、方差与区间长度相关
- **与其他分布关系**：其他分布的变换基础、贝塔分布的特例
- **随机数生成**：计算机随机数生成的基础分布

## 均匀分布概念

均匀分布（Uniform Distribution）是最简单的连续概率分布，它描述的是在有限区间内，所有可能取值具有相同概率密度的随机变量。均匀分布是概率论和统计学的基础分布，也是其他复杂分布的构建基础。

### 基本思想

均匀分布描述的是：在区间 $[a, b]$ 内，随机变量 $X$ 取任意值的概率密度都相等。这意味着在区间内的任何子区间，概率与该子区间的长度成正比。

## 数学定义

### 概率密度函数

均匀分布的概率密度函数为：

$$f(x) = \begin{cases}
\frac{1}{b-a}, & \text{if } a \leq x \leq b \\
0, & \text{otherwise}
\end{cases}$$

其中：
- $a$：下界参数
- $b$：上界参数
- $b > a$：确保区间有效

### 参数说明

- **下界a**：随机变量的最小值
- **上界b**：随机变量的最大值
- **区间长度**：$b - a$，决定了分布的离散程度

### 累积分布函数

均匀分布的累积分布函数为：

$$F(x) = \begin{cases}
0, & \text{if } x < a \\
\frac{x-a}{b-a}, & \text{if } a \leq x \leq b \\
1, & \text{if } x > b
\end{cases}$$

**解释**：$F(x)$ 表示随机变量小于等于 $x$ 的概率，在区间内呈线性增长。

## 分布性质

### 1. 基本性质

- **定义域**：$x \in [a, b]$（有限区间）
- **概率密度**：在区间内恒为常数 $\frac{1}{b-a}$
- **对称性**：以区间中点 $\frac{a+b}{2}$ 为对称中心
- **连续性**：在区间端点处连续

### 2. 数字特征

- **期望值**：$E(X) = \frac{a + b}{2}$
- **方差**：$Var(X) = \frac{(b-a)^2}{12}$
- **标准差**：$\sigma = \frac{b-a}{2\sqrt{3}}$
- **偏度**：$\gamma_1 = 0$（对称分布）
- **峰度**：$\gamma_2 = -\frac{6}{5}$（比正态分布更平坦）

### 3. 线性变换性质

如果 $X \sim U(a, b)$，则对于任意常数 $c$ 和 $d$：

$$Y = cX + d \sim U(c \cdot a + d, c \cdot b + d)$$

**特殊情况**：标准化变换
$$Z = \frac{X - a}{b - a} \sim U(0, 1)$$

## 应用场景

### 1. 随机数生成

**计算机随机数**：
- 伪随机数生成器的基础
- 蒙特卡洛模拟的输入
- 密码学中的随机性

**示例**：
```python
import numpy as np
# 生成[0,1]区间上的均匀分布随机数
random_numbers = np.random.uniform(0, 1, 1000)
```

### 2. 蒙特卡洛模拟

**数值积分**：
- 计算复杂函数的定积分
- 估计多维空间的体积
- 求解微分方程的数值解

**示例**：
```python
# 使用蒙特卡洛方法计算π
import numpy as np
n_points = 1000000
x = np.random.uniform(-1, 1, n_points)
y = np.random.uniform(-1, 1, n_points)
inside_circle = np.sum(x**2 + y**2 <= 1)
pi_estimate = 4 * inside_circle / n_points
```

### 3. 质量控制

**测量误差**：
- 仪器测量误差的建模
- 制造公差的分析
- 校准过程的误差估计

### 4. 几何概率

**几何问题**：
- 随机点在平面区域内的分布
- 随机线段长度的分布
- 随机角度的大小分布

### 5. 金融建模

**期权定价**：
- 股票价格在特定区间内的分布
- 利率变化的建模
- 风险因子的随机性

## 与其他分布的关系

### 1. 与贝塔分布的关系

均匀分布是贝塔分布的特例：
- 均匀分布：$X \sim U(0, 1)$
- 贝塔分布：$X \sim Beta(1, 1)$

### 2. 与其他分布的变换关系

**逆变换法**：通过均匀分布生成其他分布
- 如果 $U \sim U(0, 1)$，$F$ 是任意分布的累积分布函数
- 则 $X = F^{-1}(U)$ 服从分布 $F$

**示例**：
```python
# 生成指数分布随机数
def generate_exponential(lambda_param, size):
    u = np.random.uniform(0, 1, size)
    return -np.log(1 - u) / lambda_param
```

### 3. 与正态分布的关系

**Box-Muller变换**：通过均匀分布生成正态分布
- 如果 $U_1, U_2 \sim U(0, 1)$ 且独立
- 则 $Z_1 = \sqrt{-2\ln U_1} \cos(2\pi U_2)$ 和 $Z_2 = \sqrt{-2\ln U_1} \sin(2\pi U_2)$ 服从标准正态分布

### 4. 与三角分布的关系

三角分布可以看作是均匀分布的加权组合。

## 参数估计

### 极大似然估计

对于样本 $x_1, x_2, \ldots, x_n$，均匀分布参数的极大似然估计为：

$$\hat{a} = \min(x_1, x_2, \ldots, x_n)$$
$$\hat{b} = \max(x_1, x_2, \ldots, x_n)$$

**解释**：参数估计值就是样本的最小值和最大值。

### 置信区间

对于大样本，参数的置信区间可以通过样本统计量计算。

## 实际计算示例

### 示例1：随机数生成

**问题**：生成区间 $[2, 8]$ 上的均匀分布随机数。

**解答**：
```python
import numpy as np
# 方法1：直接生成
x = np.random.uniform(2, 8, 1000)

# 方法2：通过标准化变换
u = np.random.uniform(0, 1, 1000)
x = 2 + (8 - 2) * u
```

### 示例2：概率计算

**问题**：设 $X \sim U(0, 10)$，求 $P(3 \leq X \leq 7)$。

**解答**：
1. 区间长度：$7 - 3 = 4$
2. 总区间长度：$10 - 0 = 10$
3. $P(3 \leq X \leq 7) = \frac{4}{10} = 0.4$

### 示例3：期望和方差

**问题**：设 $X \sim U(-5, 5)$，求 $E(X)$ 和 $Var(X)$。

**解答**：
1. 期望：$E(X) = \frac{-5 + 5}{2} = 0$
2. 方差：$Var(X) = \frac{(5 - (-5))^2}{12} = \frac{100}{12} \approx 8.33$

### 示例4：线性变换

**问题**：设 $X \sim U(0, 1)$，求 $Y = 2X + 3$ 的分布。

**解答**：
- $Y \sim U(3, 5)$
- 期望：$E(Y) = 4$
- 方差：$Var(Y) = \frac{(5-3)^2}{12} = \frac{1}{3}$
