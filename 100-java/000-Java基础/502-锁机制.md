## 1.1 什么是锁

锁是并发编程中用于控制多个线程对共享资源访问的同步机制。通过锁可以确保在同一时刻只有一个线程能够访问被保护的资源，从而保证数据的一致性和线程安全。

## 1.2 锁的分类

1. **按性质分类**：
   - 悲观锁：认为冲突会经常发生，先加锁再操作
   - 乐观锁：认为冲突很少发生，先操作再检查

2. **按粒度分类**：
   - 对象锁：锁定整个对象
   - 类锁：锁定整个类
   - 方法锁：锁定特定方法

3. **按特性分类**：
   - 可重入锁：同一个线程可以多次获取同一把锁
   - 不可重入锁：同一个线程不能重复获取同一把锁

# 2 synchronized关键字

## 2.1 基本用法

```java
public class SynchronizedExample {
    private int count = 0;
    
    // 实例方法同步
    public synchronized void increment() {
        count++;
    }
    
    // 静态方法同步
    public static synchronized void staticMethod() {
        // 静态方法同步
    }
    
    // 代码块同步
    public void blockMethod() {
        synchronized (this) {
            count++;
        }
    }
    
    // 类锁
    public void classLock() {
        synchronized (SynchronizedExample.class) {
            // 类级别的同步
        }
    }
}
```

## 2.2 synchronized原理

synchronized是基于JVM的monitor机制实现的：

```java
public class MonitorExample {
    private final Object lock = new Object();
    
    public void method() {
        synchronized (lock) {
            // 临界区代码
        }
    }
}

// 等价于以下字节码
/*
monitorenter  // 获取锁
try {
    // 临界区代码
} finally {
    monitorexit   // 释放锁
}
*/
```

## 2.3 锁升级机制

synchronized的锁升级过程：
1. **无锁状态**：对象刚创建时
2. **偏向锁**：第一次获取锁时，记录线程ID
3. **轻量级锁**：发生竞争时，使用CAS自旋
4. **重量级锁**：自旋失败后，升级为重量级锁

# 3 ReentrantLock可重入锁

## 3.1 基本用法

```java
import java.util.concurrent.locks.ReentrantLock;

public class ReentrantLockExample {
    private final ReentrantLock lock = new ReentrantLock();
    private int count = 0;
    
    public void increment() {
        lock.lock(); // 获取锁
        try {
            count++;
        } finally {
            lock.unlock(); // 释放锁
        }
    }
    
    // 可重入特性
    public void recursiveMethod() {
        lock.lock();
        try {
            System.out.println("第一次获取锁");
            recursiveMethod2();
        } finally {
            lock.unlock();
        }
    }
    
    private void recursiveMethod2() {
        lock.lock(); // 同一个线程可以再次获取锁
        try {
            System.out.println("第二次获取锁");
        } finally {
            lock.unlock();
        }
    }
}
```

## 3.2 公平锁与非公平锁

```java
// 非公平锁（默认）
ReentrantLock unfairLock = new ReentrantLock();

// 公平锁
ReentrantLock fairLock = new ReentrantLock(true);
```

## 3.3 可中断锁

```java
public class InterruptibleLockExample {
    private final ReentrantLock lock = new ReentrantLock();
    
    public void interruptibleMethod() {
        try {
            lock.lockInterruptibly(); // 可中断的获取锁
            // 临界区代码
        } catch (InterruptedException e) {
            // 处理中断
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

## 3.4 限时锁

```java
public class TimedLockExample {
    private final ReentrantLock lock = new ReentrantLock();
    
    public boolean tryLockMethod() {
        try {
            // 尝试在1秒内获取锁
            if (lock.tryLock(1, TimeUnit.SECONDS)) {
                try {
                    // 临界区代码
                    return true;
                } finally {
                    lock.unlock();
                }
            }
        } catch (InterruptedException e) {
            // 处理中断
        }
        return false;
    }
}
```

# 4 读写锁（ReadWriteLock）

## 4.1 基本用法

```java
import java.util.concurrent.locks.ReadWriteLock;
import java.util.concurrent.locks.ReentrantReadWriteLock;

public class ReadWriteLockExample {
    private final ReadWriteLock lock = new ReentrantReadWriteLock();
    private final ReentrantReadWriteLock.ReadLock readLock = lock.readLock();
    private final ReentrantReadWriteLock.WriteLock writeLock = lock.writeLock();
    
    private String data = "初始数据";
    
    // 读操作
    public String read() {
        readLock.lock();
        try {
            return data;
        } finally {
            readLock.unlock();
        }
    }
    
    // 写操作
    public void write(String newData) {
        writeLock.lock();
        try {
            data = newData;
        } finally {
            writeLock.unlock();
        }
    }
}
```

## 4.2 读写锁特性

1. **读读共享**：多个线程可以同时获取读锁
2. **读写互斥**：读锁和写锁不能同时持有
3. **写写互斥**：多个写锁不能同时持有
4. **写优先**：写锁优先于读锁

# 5 条件变量（Condition）

## 5.1 基本用法

```java
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class ConditionExample {
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition notEmpty = lock.newCondition();
    private final Condition notFull = lock.newCondition();
    
    private final Object[] items = new Object[10];
    private int count = 0;
    private int putIndex = 0;
    private int takeIndex = 0;
    
    // 生产者
    public void put(Object item) throws InterruptedException {
        lock.lock();
        try {
            while (count == items.length) {
                notFull.await(); // 等待不满条件
            }
            items[putIndex] = item;
            if (++putIndex == items.length) {
                putIndex = 0;
            }
            count++;
            notEmpty.signal(); // 通知不空条件
        } finally {
            lock.unlock();
        }
    }
    
    // 消费者
    public Object take() throws InterruptedException {
        lock.lock();
        try {
            while (count == 0) {
                notEmpty.await(); // 等待不空条件
            }
            Object item = items[takeIndex];
            if (++takeIndex == items.length) {
                takeIndex = 0;
            }
            count--;
            notFull.signal(); // 通知不满条件
            return item;
        } finally {
            lock.unlock();
        }
    }
}
```

# 6 原子类

## 6.1 基本原子类

```java
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.atomic.AtomicBoolean;

public class AtomicExample {
    private AtomicInteger counter = new AtomicInteger(0);
    private AtomicLong longCounter = new AtomicLong(0L);
    private AtomicBoolean flag = new AtomicBoolean(false);
    
    public void increment() {
        counter.incrementAndGet(); // 原子递增
    }
    
    public void compareAndSet() {
        // CAS操作
        counter.compareAndSet(0, 1);
    }
    
    public void update() {
        // 原子更新
        counter.updateAndGet(x -> x + 2);
    }
}
```

## 6.2 数组原子类

```java
import java.util.concurrent.atomic.AtomicIntegerArray;
import java.util.concurrent.atomic.AtomicReferenceArray;

public class AtomicArrayExample {
    private AtomicIntegerArray intArray = new AtomicIntegerArray(10);
    private AtomicReferenceArray<String> refArray = new AtomicReferenceArray<>(10);
    
    public void updateArray() {
        intArray.set(0, 100); // 原子设置
        intArray.addAndGet(0, 50); // 原子增加
        refArray.set(0, "Hello"); // 原子设置引用
    }
}
```

# 7 锁的性能优化

## 7.1 锁分离

```java
public class LockSeparationExample {
    private final Object readLock = new Object();
    private final Object writeLock = new Object();
    
    private int readCount = 0;
    private int writeCount = 0;
    
    public void read() {
        synchronized (readLock) {
            readCount++;
        }
    }
    
    public void write() {
        synchronized (writeLock) {
            writeCount++;
        }
    }
}
```

## 7.2 锁粗化

```java
public class LockCoarseningExample {
    private final Object lock = new Object();
    
    public void method() {
        // 编译器可能会将多个synchronized块合并
        synchronized (lock) {
            // 操作1
        }
        synchronized (lock) {
            // 操作2
        }
        synchronized (lock) {
            // 操作3
        }
    }
}
```

## 7.3 锁消除

```java
public class LockEliminationExample {
    public String method() {
        StringBuffer sb = new StringBuffer();
        // 编译器可能会消除这里的锁，因为sb是局部变量
        sb.append("Hello");
        sb.append("World");
        return sb.toString();
    }
}
```

# 8 死锁及预防

## 8.1 死锁示例

```java
public class DeadlockExample {
    private final Object lock1 = new Object();
    private final Object lock2 = new Object();
    
    public void method1() {
        synchronized (lock1) {
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            synchronized (lock2) {
                // 操作
            }
        }
    }
    
    public void method2() {
        synchronized (lock2) {
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            synchronized (lock1) {
                // 操作
            }
        }
    }
}
```
