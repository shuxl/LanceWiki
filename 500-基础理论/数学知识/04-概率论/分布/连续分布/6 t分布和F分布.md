# t分布和F分布

## 重点

- **t分布**：小样本统计推断的核心分布，基于正态分布和卡方分布
- **F分布**：方差分析和回归分析的基础分布，两个卡方分布的比值
- **应用场景**：假设检验、置信区间、方差分析、回归分析
- **数学性质**：自由度参数、对称性（t分布）、右偏性（F分布）
- **与其他分布关系**：t分布大样本下近似正态，F分布与t分布平方相关

## t分布概念

t分布（Student's t-Distribution）是连续概率分布的一种，主要用于小样本统计推断。它是由威廉·戈塞特（William Gosset）在1908年以笔名"Student"发表的，因此也称为学生t分布。

### 基本思想

t分布描述的是：当总体标准差未知时，样本均值与总体均值之差的标准化统计量的分布。它比正态分布有更重的尾部，适用于小样本情况。

## t分布数学定义

### 概率密度函数

t分布的概率密度函数为：

$$f(x) = \frac{\Gamma(\frac{\nu+1}{2})}{\sqrt{\nu\pi} \Gamma(\frac{\nu}{2})} \left(1 + \frac{x^2}{\nu}\right)^{-(\nu+1)/2}$$

其中：
- $\nu > 0$：自由度（degrees of freedom）
- $\Gamma(\cdot)$：伽马函数
- $\pi$：圆周率

### 参数说明

- **自由度ν**：通常为样本大小减1（$n-1$）
- **定义域**：$x \in (-\infty, \infty)$
- **对称性**：关于 $x = 0$ 对称

### 累积分布函数

t分布的累积分布函数没有初等函数的解析解，通常通过数值方法或查表计算。

## t分布性质

### 1. 基本性质

- **对称性**：关于 $x = 0$ 对称
- **形状**：类似正态分布，但尾部更重
- **自由度影响**：自由度越大，越接近正态分布
- **渐近性**：$\lim_{x \to \pm\infty} f(x) = 0$

### 2. 数字特征

- **期望值**：$E(X) = 0$（当 $\nu > 1$）
- **方差**：$Var(X) = \frac{\nu}{\nu-2}$（当 $\nu > 2$）
- **偏度**：$\gamma_1 = 0$（对称分布）
- **峰度**：$\gamma_2 = \frac{6}{\nu-4}$（当 $\nu > 4$）

### 3. 与正态分布的关系

当自由度 $\nu \to \infty$ 时，t分布收敛于标准正态分布：
$$\lim_{\nu \to \infty} t(\nu) = N(0, 1)$$

## F分布概念

F分布（F-Distribution）是连续概率分布的一种，主要用于方差分析和回归分析。它描述的是两个独立卡方分布随机变量比值的分布。

### 基本思想

F分布描述的是：两个独立卡方分布随机变量除以各自自由度后的比值分布。它在比较两个方差时特别有用。

## F分布数学定义

### 概率密度函数

F分布的概率密度函数为：

$$f(x) = \frac{\Gamma(\frac{\nu_1+\nu_2}{2})}{\Gamma(\frac{\nu_1}{2}) \Gamma(\frac{\nu_2}{2})} \left(\frac{\nu_1}{\nu_2}\right)^{\nu_1/2} x^{\nu_1/2-1} \left(1 + \frac{\nu_1 x}{\nu_2}\right)^{-(\nu_1+\nu_2)/2}$$

其中：
- $\nu_1, \nu_2 > 0$：自由度
- $\Gamma(\cdot)$：伽马函数
- $x > 0$：定义域

### 参数说明

- **自由度ν₁**：分子卡方分布的自由度
- **自由度ν₂**：分母卡方分布的自由度
- **定义域**：$x > 0$（非负实数）

## F分布性质

### 1. 基本性质

- **非负性**：$x > 0$
- **右偏性**：分布右偏
- **形状**：随着自由度变化而变化
- **渐近性**：$\lim_{x \to \infty} f(x) = 0$

### 2. 数字特征

- **期望值**：$E(X) = \frac{\nu_2}{\nu_2-2}$（当 $\nu_2 > 2$）
- **方差**：$Var(X) = \frac{2\nu_2^2(\nu_1+\nu_2-2)}{\nu_1(\nu_2-2)^2(\nu_2-4)}$（当 $\nu_2 > 4$）

### 3. 倒数性质

如果 $X \sim F(\nu_1, \nu_2)$，则：
$$\frac{1}{X} \sim F(\nu_2, \nu_1)$$

## 应用场景

### 1. t分布应用

**单样本t检验**：
- 检验总体均值是否等于某个值
- 小样本情况下的统计推断
- 配对样本的差异检验

**示例**：
```python
import numpy as np
from scipy import stats

# 单样本t检验
sample = np.random.normal(100, 15, 20)
t_stat, p_value = stats.ttest_1samp(sample, 95)
```

**置信区间**：
- 总体均值的置信区间估计
- 回归系数的置信区间
- 预测区间的构建

### 2. F分布应用

**方差分析（ANOVA）**：
- 比较多个总体的均值
- 检验组间方差与组内方差的比值
- 多因素实验设计

**示例**：
```python
# 单因素方差分析
from scipy import stats
group1 = np.random.normal(10, 2, 30)
group2 = np.random.normal(12, 2, 30)
group3 = np.random.normal(11, 2, 30)
f_stat, p_value = stats.f_oneway(group1, group2, group3)
```

**回归分析**：
- 检验回归模型的显著性
- 比较嵌套模型的拟合优度
- 多重共线性的诊断

### 3. 统计推断

**假设检验**：
- 均值差异检验
- 方差比检验
- 模型比较检验

**置信区间**：
- 均值差异的置信区间
- 方差比的置信区间
- 预测区间

## 与其他分布的关系

### 1. t分布与其他分布的关系

**与正态分布**：
- 大样本下t分布近似正态分布
- 标准正态分布是t分布的自由度无穷大时的极限

**与卡方分布**：
- 如果 $Z \sim N(0, 1)$ 和 $X \sim \chi^2(\nu)$ 独立
- 则 $T = \frac{Z}{\sqrt{X/\nu}} \sim t(\nu)$

**与F分布**：
- 如果 $T \sim t(\nu)$，则 $T^2 \sim F(1, \nu)$

### 2. F分布与其他分布的关系

**与卡方分布**：
- 如果 $X_1 \sim \chi^2(\nu_1)$ 和 $X_2 \sim \chi^2(\nu_2)$ 独立
- 则 $F = \frac{X_1/\nu_1}{X_2/\nu_2} \sim F(\nu_1, \nu_2)$

**与t分布**：
- 如果 $T \sim t(\nu)$，则 $T^2 \sim F(1, \nu)$

**与贝塔分布**：
- F分布与贝塔分布有变换关系

## 统计检验应用

### 1. t检验

**单样本t检验**：
$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} \sim t(n-1)$$

**双样本t检验**：
$$t = \frac{(\bar{x}_1 - \bar{x}_2) - (\mu_1 - \mu_2)}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} \sim t(df)$$

**配对t检验**：
$$t = \frac{\bar{d}}{s_d/\sqrt{n}} \sim t(n-1)$$

### 2. F检验

**方差比检验**：
$$F = \frac{s_1^2}{s_2^2} \sim F(n_1-1, n_2-1)$$

**方差分析**：
$$F = \frac{MS_{between}}{MS_{within}} \sim F(k-1, N-k)$$

**回归分析**：
$$F = \frac{MS_{regression}}{MS_{residual}} \sim F(p, n-p-1)$$

## 实际计算示例

### 示例1：t检验

**问题**：某班级20名学生的平均成绩为85分，标准差为10分。检验该班级平均成绩是否显著高于80分。

**解答**：
1. 检验统计量：$t = \frac{85 - 80}{10/\sqrt{20}} = 2.236$
2. 自由度：$\nu = 19$
3. $P(t > 2.236) = 0.018$（查表）
4. 结论：在5%水平下拒绝原假设，平均成绩显著高于80分

### 示例2：F检验

**问题**：比较两个班级的成绩方差，班级A（n₁=15, s₁²=25），班级B（n₂=20, s₂²=16）。

**解答**：
1. 检验统计量：$F = \frac{25}{16} = 1.563$
2. 自由度：$\nu_1 = 14, \nu_2 = 19$
3. $P(F > 1.563) = 0.15$（查表）
4. 结论：不能拒绝原假设，两个班级方差无显著差异

### 示例3：置信区间

**问题**：基于样本均值85分，标准差10分，样本大小20，求总体均值的95%置信区间。

**解答**：
1. 自由度：$\nu = 19$
2. t临界值：$t_{0.025, 19} = 2.093$
3. 置信区间：$85 \pm 2.093 \times \frac{10}{\sqrt{20}} = [80.32, 89.68]$

### 示例4：方差分析

**问题**：三个班级的成绩方差分别为：班级A（s₁²=25, n₁=15），班级B（s₂²=20, n₂=15），班级C（s₃²=30, n₃=15）。

**解答**：
1. 计算F统计量
2. 自由度：$\nu_1 = 2, \nu_2 = 42$
3. 比较F临界值判断显著性
