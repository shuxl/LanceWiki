# 复合函数与反函数

## 📚 复合函数

### 1.1 复合函数的定义

设 $f: A \rightarrow B$ 和 $g: B \rightarrow C$ 是两个函数，则它们的**复合函数**定义为：

$$(g \circ f)(x) = g(f(x))$$

其中 $g \circ f$ 读作"g复合f"。

### 1.2 复合函数的性质

- **定义域**：$\text{dom}(g \circ f) = \{x \in \text{dom}(f) | f(x) \in \text{dom}(g)\}$
- **结合律**：$(h \circ g) \circ f = h \circ (g \circ f)$
- **非交换性**：一般地，$g \circ f \neq f \circ g$

### 1.3 示例

```python
def f(x):
    return x**2

def g(x):
    return x + 1

# 复合函数 g ∘ f
def composite_function(x):
    return g(f(x))  # g(f(x)) = g(x²) = x² + 1
```

## 🔗 反函数

### 2.1 反函数的定义

如果函数 $f: A \rightarrow B$ 是双射，则存在**反函数** $f^{-1}: B \rightarrow A$，满足：

$$f^{-1}(f(x)) = x \text{ 且 } f(f^{-1}(y)) = y$$

### 2.2 反函数的性质

- **唯一性**：双射函数的反函数是唯一的
- **对称性**：$(f^{-1})^{-1} = f$
- **复合性质**：$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$

### 2.3 示例

```python
def f(x):
    return 2*x + 3

def f_inverse(y):
    return (y - 3) / 2

# 验证
x = 5
y = f(x)  # 13
x_recovered = f_inverse(y)  # 5
```
