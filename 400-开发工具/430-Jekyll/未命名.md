以下是用Jekyll部署项目到GitHub Pages的完整流程，结合官方文档和最佳实践整理而成，适用于Mac系统：

---

### 0.1.1 🛠 一、环境准备（Mac）

1. ​**安装Ruby与Bundler**​
    
    ```
    # Mac自带Ruby，但建议更新
    brew install ruby
    gem install bundler jekyll
    ```
    
    - ​**验证安装**​：`jekyll -v`（需Ruby ≥ 2.5.0）
    - ​**国内用户加速**​：替换RubyGems源
        
        ```
        gem sources --add https://gems.ruby-china.com/ --remove https://rubygems.org/
        ```
        

---

### 0.1.2 ⚙️ 二、创建GitHub仓库（关键！）

1. ​**仓库命名规则**​
    
    - 用户/组织站点：`username.github.io`（如 `john.github.io`）
    - 项目站点：任意名称（如 `my-project`）
    - ​**注意**​：用户名需全小写，否则无法识别
2. ​**开启GitHub Pages**​
    
    - 仓库 → Settings → Pages → 选择部署分支（`main`或`gh-pages`）
    - 保存后访问 `https://username.github.io` 验证

---

### 0.1.3 🧱 三、本地构建Jekyll项目

1. ​**初始化站点**​
    
    ```
    jekyll new my-site  # 创建新项目
    cd my-site
    ```
    
    - 目录结构说明：
        - `_posts/`：存放Markdown文章（命名格式 `YYYY-MM-DD-title.md`）
        - `_config.yml`：全局配置（标题、URL等）
        - `_site/`：生成的静态文件（勿手动修改）
2. ​**主题配置（可选）​**​
    
    - 修改 `_config.yml` 添加主题：
        
        ```
        theme: minima  # 默认主题
        ```
        
    - 或从[Jekyll Themes](http://jekyllthemes.org/)下载主题包（如Chirpy），替换`_layouts`、`_includes`目录
3. ​**本地预览**​
    
    ```
    bundle exec jekyll serve
    ```
    
    - 访问 `http://localhost:4000` 实时调试

---

### 0.1.4 🚀 四、部署到GitHub Pages

1. ​**推送代码到仓库**​
    
    ```
    git init
    git remote add origin https://github.com/username/username.github.io.git
    git add .
    git commit -m "Initial commit"
    git push -u origin main  # 或 gh-pages
    ```
    
2. ​**触发自动构建**​
    
    - GitHub会自动检测Jekyll项目并构建：
        - 日志查看：仓库 → Actions → Pages build
        - 部署成功：访问 `https://username.github.io`
3. ​**自定义域名（可选）​**​
    
    - 仓库根目录创建 `CNAME` 文件，写入域名（如 `blog.example.com`）
    - DNS解析添加CNAME记录指向 `username.github.io`

---

### 0.1.5 ⚠️ 五、常见问题解决

|​**问题**​|​**解决方案**​|
|---|---|
|​**构建失败**​|检查Actions日志，常见于Ruby版本冲突 → 在`Gemfile`指定`gem "github-pages"`|
|​**本地样式异常**​|运行`bundle update`更新依赖，或删除`Gemfile.lock`重装|
|​**文章未显示**​|确保Markdown文件在`_posts/`目录，且文件名含日期前缀|
|​**评论系统**​|使用[giscus](https://giscus.app/)（基于GitHub Discussions），配置见|

---

### 0.1.6 💡 六、进阶优化

1. ​**自动化工作流**​
    - 通过GitHub Actions实现自动构建（示例配置见）
2. ​**SEO增强**​
    - 在`_config.yml`添加描述和关键词，使用[jekyll-seo-tag](https://github.com/jekyll/jekyll-seo-tag)插件
3. ​**数据统计**​
    - 集成Google Analytics：在配置文件中添加跟踪ID

---

### 0.1.7 ✅ 总结流程

1. 安装Ruby → 2. 创建GitHub仓库 → 3. 本地建站 → 4. 推送代码 → 5. 开启Pages服务  
    ​**部署成功后，专注内容创作即可**​：

- 文章放在 `_posts/`，按 `2025-07-08-hello-world.md` 格式命名
- 每次推送后等待1-10分钟，页面自动更新

遇到问题可查阅[Jekyll官方文档](https://jekyllrb.com/docs/)或GitHub Pages日志。
