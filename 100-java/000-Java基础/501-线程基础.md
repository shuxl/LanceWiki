

# 1 线程概念或介绍

**本文重点：**
- 理解线程的基本概念和与进程的区别
- 掌握Java中创建线程的多种方式
- 熟悉线程的生命周期和状态转换
- 了解线程间通信的基本机制
- 掌握线程安全和同步的基本概念

## 1.1 什么是线程

线程是程序执行的最小单位，是进程中的一个实际运行单位。一个进程可以包含多个线程，这些线程共享进程的资源，但每个线程都有自己独立的执行栈。

**线程 vs 进程：**
- 进程是资源分配的基本单位，线程是CPU调度的基本单位
- 进程间相互独立，线程间共享进程资源
- 进程切换开销大，线程切换开销小
- 进程间通信复杂，线程间通信相对简单

## 1.2 线程的优势

1. **提高程序响应性**：GUI程序可以保持界面响应
2. **资源共享**：多个线程共享进程资源，节省系统资源
3. **经济性**：创建和销毁线程的开销比进程小
4. **多处理器利用**：可以充分利用多核CPU

# 2 线程的创建方式

## 2.1 继承Thread类

```java
public class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("线程执行: " + Thread.currentThread().getName());
    }
}

// 使用方式
MyThread thread = new MyThread();
thread.start();
```

## 2.2 实现Runnable接口

```java
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("线程执行: " + Thread.currentThread().getName());
    }
}

// 使用方式
Thread thread = new Thread(new MyRunnable());
thread.start();
```

## 2.3 使用Lambda表达式

```java
// 直接使用Lambda表达式
Thread thread = new Thread(() -> {
    System.out.println("Lambda线程执行: " + Thread.currentThread().getName());
});
thread.start();
```

## 2.4 实现Callable接口（有返回值）

```java
import java.util.concurrent.Callable;
import java.util.concurrent.FutureTask;

public class MyCallable implements Callable<String> {
    @Override
    public String call() throws Exception {
        return "Callable线程执行结果";
    }
}

// 使用方式
FutureTask<String> futureTask = new FutureTask<>(new MyCallable());
Thread thread = new Thread(futureTask);
thread.start();

// 获取结果
String result = futureTask.get(); // 阻塞等待结果
```

# 3 线程的生命周期

## 3.1 线程状态

Java线程有6种状态：

1. **NEW（新建）**：线程被创建但尚未启动
2. **RUNNABLE（可运行）**：线程正在运行或等待CPU分配时间片
3. **BLOCKED（阻塞）**：线程等待获取锁
4. **WAITING（等待）**：线程等待其他线程通知
5. **TIMED_WAITING（计时等待）**：线程等待指定时间
6. **TERMINATED（终止）**：线程执行完毕

## 3.2 状态转换

```java
// 状态转换示例
Thread thread = new Thread(() -> {
    try {
        Thread.sleep(1000); // TIMED_WAITING
        synchronized (this) {
            wait(); // WAITING
        }
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
});

thread.start(); // NEW -> RUNNABLE
// 线程执行完毕后变为 TERMINATED
```

# 4 线程的基本操作

## 4.1 线程启动

```java
Thread thread = new Thread(() -> {
    System.out.println("线程启动");
});
thread.start(); // 启动线程
```

## 4.2 线程休眠

```java
try {
    Thread.sleep(1000); // 休眠1秒
} catch (InterruptedException e) {
    e.printStackTrace();
}
```

## 4.3 线程让步

```java
Thread.yield(); // 让出CPU，让其他线程有机会执行
```

## 4.4 线程等待

```java
// 等待其他线程完成
thread.join(); // 等待thread线程完成
thread.join(1000); // 最多等待1秒
```

## 4.5 线程中断

```java
thread.interrupt(); // 中断线程

// 在线程中检查中断状态
if (Thread.currentThread().isInterrupted()) {
    // 处理中断
    break;
}
```

# 5 线程间通信

## 5.1 共享变量

```java
public class SharedVariable {
    private volatile boolean flag = false;
    
    public void setFlag(boolean flag) {
        this.flag = flag;
    }
    
    public boolean getFlag() {
        return flag;
    }
}
```

## 5.2 wait/notify机制

```java
public class WaitNotifyExample {
    private final Object lock = new Object();
    private boolean ready = false;
    
    public void producer() {
        synchronized (lock) {
            ready = true;
            lock.notify(); // 通知等待的线程
        }
    }
    
    public void consumer() {
        synchronized (lock) {
            while (!ready) {
                try {
                    lock.wait(); // 等待通知
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
            }
            // 处理数据
        }
    }
}
```

## 5.3 管道通信

```java
import java.io.PipedInputStream;
import java.io.PipedOutputStream;

PipedInputStream input = new PipedInputStream();
PipedOutputStream output = new PipedOutputStream(input);

// 一个线程写入
output.write("Hello".getBytes());

// 另一个线程读取
int data = input.read();
```

# 6 线程安全

## 6.1 什么是线程安全

线程安全是指多线程环境下，程序能够正确执行，不会出现数据不一致或异常情况。

## 6.2 线程安全问题示例

```java
public class Counter {
    private int count = 0;
    
    public void increment() {
        count++; // 非原子操作，存在竞态条件
    }
    
    public int getCount() {
        return count;
    }
}
```

## 6.3 解决方案

1. **使用synchronized关键字**
2. **使用volatile关键字**
3. **使用原子类**
	+ **原子类**（Atomic classes）是 java.util.concurrent.atomic 包下提供的一组用于**无锁线程安全编程**的类。它们通过底层的 **CAS（Compare-And-Swap）机制**，提供了一种比 synchronized 更高效的方式来实现线程安全。
		1. **AtomicInteger**
		2. **AtomicLong**
		3. **AtomicBoolean**
		4. **AtomicReference**
		5. **AtomicIntegerArray** / **AtomicLongArray** / **AtomicReferenceArray**
4. **使用锁机制**

# 10 线程异常处理

```java
Thread thread = new Thread(() -> {
    throw new RuntimeException("线程异常");
});

thread.setUncaughtExceptionHandler((t, e) -> {
    System.out.println("线程 " + t.getName() + " 发生异常: " + e.getMessage());
});

thread.start();
```
