# Langfuse 批量导出功能配置说明

## 问题描述

当尝试使用 Langfuse 的数据导出功能时，出现以下错误：

```
Error: Batch export is not enabled. Configure environment variables to use this feature.
```

这是因为批量导出（Batch Export）功能需要单独配置环境变量才能启用。

## 解决方案

### 1. 已添加的配置

已在 `docker-compose.yml` 中添加了以下批量导出相关的环境变量：

```yaml
# 批量导出配置（Batch Export）
LANGFUSE_S3_BATCH_EXPORT_ENABLED: true
LANGFUSE_S3_BATCH_EXPORT_BUCKET: langfuse-exports
LANGFUSE_S3_BATCH_EXPORT_ENDPOINT: http://minio:9000
LANGFUSE_S3_BATCH_EXPORT_ACCESS_KEY_ID: minioadmin
LANGFUSE_S3_BATCH_EXPORT_SECRET_ACCESS_KEY: minioadmin
LANGFUSE_S3_BATCH_EXPORT_FORCE_PATH_STYLE: "true"
LANGFUSE_S3_BATCH_EXPORT_REGION: us-east-1
LANGFUSE_S3_BATCH_EXPORT_PREFIX: exports/
```

### 2. 环境变量说明

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `LANGFUSE_S3_BATCH_EXPORT_ENABLED` | 启用批量导出功能 | `true` |
| `LANGFUSE_S3_BATCH_EXPORT_BUCKET` | 批量导出文件的存储桶名称 | `langfuse-exports` |
| `LANGFUSE_S3_BATCH_EXPORT_ENDPOINT` | S3 端点地址（MinIO） | `http://minio:9000` |
| `LANGFUSE_S3_BATCH_EXPORT_ACCESS_KEY_ID` | S3 访问密钥 ID | `minioadmin` |
| `LANGFUSE_S3_BATCH_EXPORT_SECRET_ACCESS_KEY` | S3 访问密钥 | `minioadmin` |
| `LANGFUSE_S3_BATCH_EXPORT_FORCE_PATH_STYLE` | 强制使用路径样式 | `true` |
| `LANGFUSE_S3_BATCH_EXPORT_REGION` | S3 区域 | `us-east-1` |
| `LANGFUSE_S3_BATCH_EXPORT_PREFIX` | 导出文件的前缀路径 | `exports/` |

### 3. MinIO 存储桶

已自动创建了 `langfuse-exports` 存储桶用于存放批量导出文件。

### 4. 应用配置

配置已添加到 `langfuse-web` 和 `langfuse-worker` 两个服务中，确保两个服务都能使用批量导出功能。

## 使用步骤

### 1. 重启服务

配置更新后，需要重启服务使配置生效：

```bash
cd /path/to/langfuse
docker compose restart langfuse-web langfuse-worker
```

或者完全重启：

```bash
docker compose down
docker compose up -d
```

### 2. 验证配置

检查环境变量是否已加载：

```bash
# 检查 web 服务
docker compose exec langfuse-web env | grep LANGFUSE_S3_BATCH_EXPORT

# 检查 worker 服务
docker compose exec langfuse-worker env | grep LANGFUSE_S3_BATCH_EXPORT
```

### 3. 查看日志

重启后查看日志，确认没有错误：

```bash
docker compose logs -f langfuse-worker
```

### 4. 测试导出功能

在 Langfuse Web UI 中尝试导出数据，应该不再出现 "Batch export is not enabled" 错误。

## 自定义配置

如果需要自定义配置，可以在 `.env` 文件中设置：

```bash
# 启用/禁用批量导出
LANGFUSE_S3_BATCH_EXPORT_ENABLED=true

# 自定义存储桶名称
LANGFUSE_S3_BATCH_EXPORT_BUCKET=my-custom-exports

# 自定义前缀
LANGFUSE_S3_BATCH_EXPORT_PREFIX=my-exports/
```

然后在 `docker-compose.yml` 中会读取这些环境变量。

## 查看导出文件

导出文件会存储在 MinIO 的 `langfuse-exports` 存储桶中：

1. 访问 MinIO 控制台：http://localhost:9001
2. 登录（默认用户名：`minioadmin`，密码：`minioadmin`）
3. 找到 `langfuse-exports` 存储桶
4. 在 `exports/` 前缀下查看导出的文件

## 故障排除

### 问题1：仍然提示 "Batch export is not enabled"

**解决方案**：
1. 确认已重启 `langfuse-worker` 服务
2. 检查环境变量是否正确加载：`docker compose exec langfuse-worker env | grep BATCH_EXPORT`
3. 确认 `LANGFUSE_S3_BATCH_EXPORT_ENABLED=true`

### 问题2：导出失败，提示 S3 连接错误

**解决方案**：
1. 检查 MinIO 服务是否运行：`docker compose ps minio`
2. 检查存储桶是否存在：访问 MinIO 控制台查看
3. 检查访问密钥是否正确

### 问题3：导出文件找不到

**解决方案**：
1. 检查 MinIO 存储桶：http://localhost:9001
2. 查看 `langfuse-exports` 存储桶
3. 检查文件是否在 `exports/` 前缀下

## 注意事项

1. **存储空间**：批量导出文件会占用 MinIO 存储空间，注意定期清理
2. **性能影响**：大量数据导出可能影响系统性能，建议在低峰期进行
3. **文件格式**：导出文件通常是 CSV 或 JSON 格式
4. **访问权限**：确保 MinIO 的访问密钥配置正确，否则无法写入导出文件
