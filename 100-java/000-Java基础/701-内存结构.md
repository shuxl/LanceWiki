# 2 JVM内存结构概念或介绍

JVM内存结构是Java虚拟机运行时数据区域的划分，主要包括堆、栈、方法区、程序计数器、本地方法栈等区域。每个区域都有其特定的职责和生命周期管理机制。

## 2.1 内存区域概览
JVM内存主要分为以下几个区域：
- **堆内存（Heap）**：存储对象实例，是垃圾回收的主要区域
- **栈内存（Stack）**：存储局部变量、操作数栈、方法出口等信息
- **方法区（Method Area）**：存储类信息、常量、静态变量等
- **程序计数器（Program Counter Register）**：记录当前线程执行的位置
- **本地方法栈（Native Method Stack）**：为本地方法服务

# 3 JVM内存区域详解

## 3.1 堆内存（Heap）
堆内存是JVM中最大的一块内存区域，用于存储对象实例。

### 3.1.1 堆内存特点
- **线程共享**：所有线程共享堆内存
- **垃圾回收重点**：是垃圾回收器的主要工作区域
- **分代管理**：分为新生代和老年代

### 3.1.2 堆内存分代结构
```
堆内存
├── 新生代（Young Generation）
│   ├── Eden区（伊甸园）
│   ├── Survivor区（幸存者区）
│   │   ├── From区
│   │   └── To区
└── 老年代（Old Generation）
```

### 3.1.3 新生代特点
- **Eden区**：新创建的对象首先分配在Eden区
- **Survivor区**：经过一次垃圾回收后存活的对象进入Survivor区
- **默认比例**：Eden:From:To = 8:1:1

### 3.1.4 老年代特点
- 存储长期存活的对象
- 垃圾回收频率较低
- 空间较大，适合存储大对象

## 3.2 栈内存（Stack）
栈内存是线程私有的内存区域，每个线程都有自己的栈。

### 3.2.1 栈内存特点
- **线程私有**：每个线程都有独立的栈空间
- **LIFO结构**：后进先出的数据结构
- **自动管理**：栈帧的创建和销毁由JVM自动管理

### 3.2.2 栈帧结构
每个方法调用都会创建一个栈帧，包含：
- **局部变量表**：存储方法参数和局部变量
- **操作数栈**：存储计算过程中的临时数据
- **动态链接**：指向运行时常量池的引用
- **方法出口**：记录方法返回的地址

### 3.2.3 栈内存大小
- **默认大小**：1MB（64位系统）
- **可配置**：通过`-Xss`参数调整
- **栈溢出**：当栈深度超过限制时抛出StackOverflowError

## 3.3 方法区（Method Area）
方法区存储类的元数据信息，在JDK8之前称为永久代。

### 3.3.1 方法区存储内容
- **类信息**：类的完整信息，包括字段、方法等
- **常量池**：编译期生成的各种字面量和符号引用
- **静态变量**：类的静态成员变量
- **运行时常量池**：运行时的常量信息

### 3.3.2 方法区特点
- **线程共享**：所有线程共享方法区
- **垃圾回收**：可以回收无用的类信息
- **内存限制**：可以通过参数限制大小

## 3.4 程序计数器（Program Counter Register）
程序计数器是线程私有的小内存区域。

### 3.4.1 程序计数器特点
- **线程私有**：每个线程都有独立的程序计数器
- **字节码行号**：记录当前线程执行到的字节码行号
- **唯一不溢出**：是唯一不会发生OutOfMemoryError的内存区域

### 3.4.2 程序计数器作用
- **线程切换**：线程切换时保存执行位置
- **分支跳转**：支持条件分支和循环跳转
- **异常处理**：记录异常处理的字节码位置

## 3.5 本地方法栈（Native Method Stack）
为本地方法服务的内存区域。

### 3.5.1 本地方法栈特点
- **线程私有**：每个线程都有独立的本地方法栈
- **本地方法**：为JNI（Java Native Interface）方法服务
- **平台相关**：不同平台可能有不同的实现

# 4 内存分配策略

## 4.1 对象分配流程
1. **Eden区分配**：新对象首先尝试在Eden区分配
2. **大对象直接进入老年代**：大对象（如大数组）直接进入老年代
3. **长期存活对象进入老年代**：经过多次GC后存活的对象进入老年代

## 4.2 内存分配参数
- `-Xms`：初始堆大小
- `-Xmx`：最大堆大小
- `-Xmn`：新生代大小
- `-XX:NewRatio`：新生代与老年代的比例
- `-XX:SurvivorRatio`：Eden区与Survivor区的比例

# 5 内存溢出问题

## 5.1 常见内存溢出类型
1. **堆内存溢出（OutOfMemoryError: Java heap space）**
   - 原因：对象过多，堆内存不足
   - 解决：增加堆内存大小或优化代码

2. **栈内存溢出（StackOverflowError）**
   - 原因：方法调用层次过深
   - 解决：增加栈大小或优化递归

3. **方法区溢出（OutOfMemoryError: Metaspace）**
   - 原因：类信息过多
   - 解决：增加方法区大小或减少动态类生成

## 5.2 内存溢出排查方法
1. **使用JVM参数**：`-XX:+HeapDumpOnOutOfMemoryError`
2. **分析堆转储文件**：使用MAT等工具分析
3. **监控内存使用**：使用JConsole、VisualVM等工具
