# 卡方分布

## 重点

- **定义**：连续概率分布，描述标准正态分布随机变量平方和的分布
- **应用场景**：统计推断、假设检验、方差分析、拟合优度检验
- **数学性质**：自由度参数、可加性、非负性、右偏分布
- **与其他分布关系**：伽马分布的特例、t分布的基础、F分布的基础
- **统计推断**：方差检验、独立性检验、拟合优度检验的核心分布

## 卡方分布概念

卡方分布（Chi-Square Distribution）是连续概率分布的一种，它描述的是标准正态分布随机变量平方和的分布。卡方分布在统计学中具有重要地位，是许多统计检验的基础分布。

### 基本思想

卡方分布描述的是：如果 $Z_1, Z_2, \ldots, Z_\nu$ 是独立的标准正态分布随机变量，则它们的平方和服从自由度为 $\nu$ 的卡方分布：

$$X = Z_1^2 + Z_2^2 + \cdots + Z_\nu^2 \sim \chi^2(\nu)$$

## 数学定义

### 概率密度函数

卡方分布的概率密度函数为：

$$f(x) = \frac{x^{\nu/2-1} e^{-x/2}}{2^{\nu/2} \Gamma(\nu/2)}, \quad x > 0$$

其中：
- $\nu > 0$：自由度（degrees of freedom）
- $\Gamma(\nu/2)$：伽马函数
- $e$：自然对数的底数

### 参数说明

- **自由度ν**：独立标准正态分布随机变量的个数
- **定义域**：$x > 0$（非负实数）
- **伽马函数**：当ν为偶数时，$\Gamma(\nu/2) = (\nu/2-1)!$

### 累积分布函数

卡方分布的累积分布函数为：

$$F(x) = \frac{\gamma(\nu/2, x/2)}{\Gamma(\nu/2)}$$

其中 $\gamma(\nu/2, x/2)$ 是不完全伽马函数。

## 分布性质

### 1. 基本性质

- **定义域**：$x > 0$（非负实数）
- **形状**：右偏分布，随着自由度增加逐渐对称
- **峰值**：当 $\nu > 2$ 时，峰值位于 $x = \nu - 2$
- **渐近性**：$\lim_{x \to \infty} f(x) = 0$

### 2. 数字特征

- **期望值**：$E(X) = \nu$
- **方差**：$Var(X) = 2\nu$
- **标准差**：$\sigma = \sqrt{2\nu}$
- **偏度**：$\gamma_1 = \sqrt{8/\nu}$（右偏）
- **峰度**：$\gamma_2 = 12/\nu$

### 3. 可加性（Additivity）

如果 $X_1 \sim \chi^2(\nu_1)$ 和 $X_2 \sim \chi^2(\nu_2)$ 独立，则：

$$X_1 + X_2 \sim \chi^2(\nu_1 + \nu_2)$$

**解释**：自由度相加。

### 4. 再生性（Reproductivity）

卡方分布具有再生性，即独立卡方分布随机变量的和仍服从卡方分布。

## 应用场景

### 1. 统计推断

**方差检验**：
- 检验总体方差是否等于某个值
- 比较两个总体的方差
- 方差分析（ANOVA）

**示例**：
```python
import numpy as np
from scipy import stats

# 检验样本方差是否等于理论方差
sample = np.random.normal(0, 1, 100)
sample_var = np.var(sample, ddof=1)
n = len(sample)
chi2_stat = (n-1) * sample_var / 1  # 理论方差为1
p_value = 1 - stats.chi2.cdf(chi2_stat, n-1)
```

### 2. 拟合优度检验

**分布拟合**：
- 检验数据是否服从某个理论分布
- 分类数据的独立性检验
- 列联表的分析

**示例**：
```python
# 卡方拟合优度检验
observed = [10, 15, 20, 25, 30]
expected = [20, 20, 20, 20, 20]
chi2_stat = np.sum((observed - expected)**2 / expected)
p_value = 1 - stats.chi2.cdf(chi2_stat, len(observed)-1)
```

### 3. 回归分析

**模型诊断**：
- 残差分析
- 模型拟合优度
- 参数显著性检验

### 4. 信号处理

**噪声分析**：
- 信号功率的分布
- 频谱分析
- 滤波器设计

### 5. 金融建模

**风险分析**：
- 投资组合的风险度量
- 波动率建模
- 极值理论

## 与其他分布的关系

### 1. 与正态分布的关系

标准正态分布的平方服从自由度为1的卡方分布：
$$Z^2 \sim \chi^2(1)$$

### 2. 与伽马分布的关系

卡方分布是伽马分布的特例：
- 卡方分布：$X \sim \chi^2(\nu)$
- 伽马分布：$X \sim Gamma(\nu/2, 2)$

### 3. 与t分布的关系

t分布与卡方分布有重要关系：
- 如果 $Z \sim N(0, 1)$ 和 $X \sim \chi^2(\nu)$ 独立
- 则 $T = \frac{Z}{\sqrt{X/\nu}} \sim t(\nu)$

### 4. 与F分布的关系

F分布是两个独立卡方分布随机变量的比值：
- 如果 $X_1 \sim \chi^2(\nu_1)$ 和 $X_2 \sim \chi^2(\nu_2)$ 独立
- 则 $F = \frac{X_1/\nu_1}{X_2/\nu_2} \sim F(\nu_1, \nu_2)$

### 5. 与指数分布的关系

自由度为2的卡方分布是指数分布：
$$\chi^2(2) = Exponential(1/2)$$

## 统计检验应用

### 1. 单样本方差检验

**检验统计量**：
$$\chi^2 = \frac{(n-1)s^2}{\sigma_0^2} \sim \chi^2(n-1)$$

其中：
- $s^2$：样本方差
- $\sigma_0^2$：假设的总体方差
- $n$：样本大小

### 2. 拟合优度检验

**检验统计量**：
$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i} \sim \chi^2(k-1-p)$$

其中：
- $O_i$：观察频数
- $E_i$：期望频数
- $k$：类别数
- $p$：估计的参数个数

### 3. 独立性检验

**列联表检验**：
$$\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \sim \chi^2((r-1)(c-1))$$

其中：
- $O_{ij}$：观察频数
- $E_{ij}$：期望频数
- $r$：行数
- $c$：列数

## 实际计算示例

### 示例1：方差检验

**问题**：某工厂生产的零件长度方差不应超过0.04。从100个零件中测得样本方差为0.05，检验方差是否超标。

**解答**：
1. 检验统计量：$\chi^2 = \frac{99 \times 0.05}{0.04} = 123.75$
2. 自由度：$\nu = 99$
3. $P(\chi^2 > 123.75) = 0.023$（查表）
4. 结论：在5%水平下拒绝原假设，方差超标

### 示例2：拟合优度检验

**问题**：掷骰子100次，各点数出现频数为：15, 18, 20, 16, 14, 17。检验骰子是否均匀。

**解答**：
1. 期望频数：$E_i = 100/6 = 16.67$
2. 检验统计量：$\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i} = 1.2$
3. 自由度：$\nu = 5$
4. $P(\chi^2 > 1.2) = 0.95$（查表）
5. 结论：不能拒绝原假设，骰子可能是均匀的

### 示例3：期望和方差

**问题**：设 $X \sim \chi^2(10)$，求 $E(X)$ 和 $Var(X)$。

**解答**：
1. 期望：$E(X) = 10$
2. 方差：$Var(X) = 2 \times 10 = 20$

### 示例4：可加性验证

**问题**：设 $X_1 \sim \chi^2(5)$ 和 $X_2 \sim \chi^2(3)$ 独立，求 $X_1 + X_2$ 的分布。

**解答**：
- $X_1 + X_2 \sim \chi^2(8)$
- 期望：$E(X_1 + X_2) = 8$
- 方差：$Var(X_1 + X_2) = 16$
