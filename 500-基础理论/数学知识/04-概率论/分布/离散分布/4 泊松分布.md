# 4 泊松分布

## 重点
- 泊松分布的数学定义和基本性质
- 泊松分布的概率质量函数和分布函数
- 泊松分布的期望、方差和矩
- 泊松分布在实际问题中的应用

## 4.1 泊松分布的基本概念

### 4.1.1 泊松分布的定义

**泊松分布**（Poisson Distribution）：对于参数λ（λ > 0），随机变量X服从泊松分布，如果：

$$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \ldots$$

记作：$X \sim Poisson(\lambda)$

### 4.1.2 泊松过程

**泊松过程**：满足以下条件的随机过程：
1. **独立性**：在不相交的时间区间内发生的事件相互独立
2. **平稳性**：在任意时间区间内发生事件的概率只依赖于区间长度
3. **稀有性**：在很短的时间内，发生多个事件的概率可以忽略

**示例**：
- 电话呼叫到达
- 放射性衰变
- 交通事故发生

### 4.1.3 泊松分布的直观理解

泊松分布描述的是：
- 在固定时间或空间内发生稀有事件的次数
- 参数λ表示平均发生次数
- 适用于"稀有事件"的计数

## 4.2 泊松分布的概率质量函数

### 4.2.1 PMF的定义

**概率质量函数**：
$$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \ldots$$

### 4.2.2 PMF的性质

1. **非负性**：$P(X = k) \geq 0$ 对于所有k
2. **归一性**：$\sum_{k=0}^{\infty} P(X = k) = 1$
3. **递推关系**：$P(X = k+1) = \frac{\lambda}{k+1} P(X = k)$

### 4.2.3 PMF的图形特征

泊松分布的PMF图形特征：
- 当λ较小时，分布右偏
- 当λ较大时，分布近似正态
- 众数在λ附近（如果λ是整数，则众数为λ；否则为⌊λ⌋）

## 4.3 泊松分布的分布函数

### 4.3.1 CDF的定义

**分布函数**：
$$F_X(x) = P(X \leq x) = \sum_{k=0}^{\lfloor x \rfloor} \frac{\lambda^k e^{-\lambda}}{k!}$$

其中 $\lfloor x \rfloor$ 表示x的整数部分。

### 4.3.2 CDF的性质

1. **阶梯函数**：在整数点有跳跃
2. **右连续**：在跳跃点右连续
3. **单调非减**：随着x增加，F(x)不减少

### 4.3.3 CDF的计算

**递推公式**：
$$P(X = k+1) = \frac{\lambda}{k+1} P(X = k)$$

**起始值**：$P(X = 0) = e^{-\lambda}$

## 4.4 泊松分布的矩

### 4.4.1 期望

**期望**：
$$E[X] = \lambda$$

**证明**：
$$E[X] = \sum_{k=0}^{\infty} k \cdot \frac{\lambda^k e^{-\lambda}}{k!} = \lambda$$

### 4.4.2 方差

**方差**：
$$Var(X) = \lambda$$

**证明**：
$$Var(X) = E[X^2] - (E[X])^2 = \lambda$$

### 4.4.3 高阶矩

**三阶中心矩**：$\mu_3 = \lambda$
**四阶中心矩**：$\mu_4 = \lambda + 3\lambda^2$

### 4.4.4 偏度和峰度

**偏度**：
$$\gamma_1 = \frac{1}{\sqrt{\lambda}}$$

**峰度**：
$$\gamma_2 = \frac{1}{\lambda}$$

## 4.5 泊松分布的矩母函数

### 4.5.1 矩母函数的定义

**矩母函数**：
$$M_X(t) = E[e^{tX}] = \sum_{k=0}^{\infty} e^{tk} \cdot \frac{\lambda^k e^{-\lambda}}{k!} = e^{\lambda(e^t - 1)}$$

### 4.5.2 矩母函数的性质

1. **存在性**：对于所有实数t都存在
2. **连续性**：在实数域上连续
3. **凸性**：$\log M_X(t)$ 是凸函数

### 4.5.3 从矩母函数求矩

**一阶导数**：$M_X'(t) = \lambda e^t e^{\lambda(e^t - 1)}$
**二阶导数**：$M_X''(t) = \lambda e^t e^{\lambda(e^t - 1)} + \lambda^2 e^{2t} e^{\lambda(e^t - 1)}$

在t=0处求值：
- $E[X] = M_X'(0) = \lambda$
- $E[X^2] = M_X''(0) = \lambda + \lambda^2$

## 4.6 泊松分布的可加性

### 4.6.1 可加性定理

**定理**：如果 $X_1 \sim Poisson(\lambda_1)$ 和 $X_2 \sim Poisson(\lambda_2)$ 独立，则：

$$X_1 + X_2 \sim Poisson(\lambda_1 + \lambda_2)$$

### 4.6.2 可加性的证明

**证明**：使用矩母函数
$$M_{X_1 + X_2}(t) = M_{X_1}(t) \cdot M_{X_2}(t) = e^{\lambda_1(e^t - 1)} \cdot e^{\lambda_2(e^t - 1)} = e^{(\lambda_1 + \lambda_2)(e^t - 1)}$$

### 4.6.3 可加性的应用

**应用**：
- 合并多个泊松过程
- 分析复杂系统的计数
- 简化计算

## 4.7 泊松分布的应用

### 4.7.1 在统计学中的应用

**参数估计**：
- 最大似然估计：$\hat{\lambda} = \bar{X}$
- 贝叶斯估计：使用伽马先验分布

**假设检验**：
- 检验λ是否等于某个特定值
- 比较两个泊松分布的λ值

### 4.7.2 在排队论中的应用

**到达过程**：
- 建模顾客到达
- 分析服务系统性能

**服务时间**：
- 建模服务完成时间
- 优化资源配置

### 4.7.3 在可靠性工程中的应用

**故障建模**：
- 建模设备故障次数
- 分析系统可靠性

**维护计划**：
- 预测维护需求
- 优化维护策略

### 4.7.4 在金融中的应用

**风险建模**：
- 建模极端事件
- 分析操作风险

**保险精算**：
- 建模索赔次数
- 计算保险费率

### 4.7.5 在生物学中的应用

**基因突变**：
- 建模突变事件
- 分析遗传变异

**种群动态**：
- 建模出生死亡过程
- 分析种群变化

## 4.8 泊松分布与其他分布的关系

### 4.8.1 与二项分布的关系

**关系**：当n很大，p很小时，二项分布近似泊松分布
- 设λ = np，当n→∞，p→0时
- $Binomial(n, p) \approx Poisson(\lambda)$

**条件**：通常要求n ≥ 20，p ≤ 0.05

### 4.8.2 与正态分布的关系

**关系**：当λ很大时，泊松分布近似正态分布
- 中心极限定理的应用
- $Poisson(\lambda) \approx N(\lambda, \lambda)$

**条件**：通常要求λ ≥ 10

### 4.8.3 与指数分布的关系

**关系**：泊松过程的事件间隔服从指数分布
- 如果事件按泊松过程发生，则间隔时间服从指数分布
- 参数为λ的指数分布

### 4.8.4 与伽马分布的关系

**关系**：泊松过程中第r个事件的发生时间服从伽马分布
- 参数为(r, λ)的伽马分布
- r=1时退化为指数分布

## 4.9 泊松分布的计算

### 4.9.1 概率计算

**单个概率**：
$$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

**累积概率**：
$$P(X \leq k) = \sum_{i=0}^{k} \frac{\lambda^i e^{-\lambda}}{i!}$$

**计算技巧**：
- 使用递推公式
- 利用软件包（如R的ppois函数）
- 对于大λ，使用正态近似

### 4.9.2 参数估计

**最大似然估计**：
$$\hat{\lambda} = \bar{X}$$

**矩估计**：
$$\hat{\lambda} = \bar{X}$$

**贝叶斯估计**：
- 先验：$\lambda \sim Gamma(\alpha, \beta)$
- 后验：$\lambda|X \sim Gamma(\alpha + \sum X_i, \beta + n)$

### 4.9.3 置信区间

**正态近似**：
$$\hat{\lambda} \pm z_{\alpha/2} \sqrt{\frac{\hat{\lambda}}{n}}$$

**精确方法**：使用卡方分布

## 4.10 泊松分布的扩展

### 4.10.1 复合泊松分布

**定义**：泊松分布与另一个分布的复合
- 事件次数服从泊松分布
- 每个事件的"大小"服从另一个分布

### 4.10.2 负二项分布

**定义**：泊松分布的推广
- 允许方差大于均值
- 适用于过度分散的数据

### 4.10.3 零膨胀泊松分布

**定义**：包含额外零点的泊松分布
- 适用于有过多零值的数据
- 常用于生态学和经济学
