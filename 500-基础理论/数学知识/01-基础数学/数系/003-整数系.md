# 整数系

## 📚 整数系概述

整数系是自然数系的扩展，包含了自然数、零和负整数。整数系解决了自然数系中减法运算不封闭的问题，是数学发展的重要里程碑。

## 🔗 整数的定义

### 1.1 直观定义
整数包括：
- **正整数**：1, 2, 3, 4, 5, ...
- **零**：0
- **负整数**：-1, -2, -3, -4, -5, ...

### 1.2 符号表示
整数集记作：$\mathbb{Z} = \{\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots\}$

### 1.3 构造定义
整数可以通过自然数的有序对来构造：
- 整数 $(a, b)$ 表示 $a - b$
- 两个有序对 $(a, b)$ 和 $(c, d)$ 相等当且仅当 $a + d = b + c$

## 📖 整数的性质

### 2.1 基本性质
- **有序性**：整数有大小关系
- **离散性**：相邻整数之间没有其他整数
- **无限性**：整数向正负两个方向无限延伸

### 2.2 运算性质

#### 加法运算
- **封闭性**：两个整数的和仍是整数
- **交换律**：$a + b = b + a$
- **结合律**：$(a + b) + c = a + (b + c)$
- **单位元**：$a + 0 = a$
- **逆元**：$a + (-a) = 0$

#### 乘法运算
- **封闭性**：两个整数的积仍是整数
- **交换律**：$a \times b = b \times a$
- **结合律**：$(a \times b) \times c = a \times (b \times c)$
- **分配律**：$a \times (b + c) = a \times b + a \times c$
- **单位元**：$a \times 1 = a$
- **零元**：$a \times 0 = 0$

#### 减法运算
- **定义**：$a - b = a + (-b)$
- **封闭性**：两个整数的差仍是整数

### 2.3 序的性质
- **自反性**：$a \leq a$
- **反对称性**：如果 $a \leq b$ 且 $b \leq a$，则 $a = b$
- **传递性**：如果 $a \leq b$ 且 $b \leq c$，则 $a \leq c$
- **完全性**：任意非空有下界的整数集合都有最小元素

## 🔗 整除理论

### 3.1 整除的定义
对于整数 $a$ 和 $b$，如果存在整数 $k$ 使得 $a = kb$，则称 $b$ **整除** $a$，记作 $b | a$。

### 3.2 整除的性质
- **传递性**：如果 $a | b$ 且 $b | c$，则 $a | c$
- **线性组合**：如果 $a | b$ 且 $a | c$，则 $a | (mb + nc)$
- **符号无关**：$a | b$ 当且仅当 $(-a) | b$ 当且仅当 $a | (-b)$

### 3.3 最大公约数（GCD）
两个整数 $a$ 和 $b$ 的**最大公约数**是能同时整除 $a$ 和 $b$ 的最大正整数，记作 $\gcd(a, b)$。

#### 性质
- $\gcd(a, b) = \gcd(b, a)$
- $\gcd(a, b) = \gcd(a, b - ka)$（对任意整数 $k$）
- $\gcd(a, 0) = |a|$

#### 欧几里得算法
```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return abs(a)
```

### 3.4 最小公倍数（LCM）
两个整数 $a$ 和 $b$ 的**最小公倍数**是能同时被 $a$ 和 $b$ 整除的最小正整数，记作 $\text{lcm}(a, b)$。

#### 关系
$$\gcd(a, b) \times \text{lcm}(a, b) = |a \times b|$$

## 📖 质数与合数

### 4.1 质数的定义
大于1的整数，除了1和自身外没有其他正整数因子的数称为**质数**。

### 4.2 质数的性质
- **唯一分解定理**：每个大于1的整数都可以唯一地表示为质数的乘积
- **无穷性**：质数有无穷多个
- **分布**：质数在整数中的分布不规则

### 4.3 质数判定
#### 试除法
```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
```

## 🔗 模运算

### 5.1 同余的定义
对于整数 $a$、$b$ 和正整数 $m$，如果 $m | (a - b)$，则称 $a$ 与 $b$ **模 $m$ 同余**，记作 $a \equiv b \pmod{m}$。

### 5.2 同余的性质
- **自反性**：$a \equiv a \pmod{m}$
- **对称性**：如果 $a \equiv b \pmod{m}$，则 $b \equiv a \pmod{m}$
- **传递性**：如果 $a \equiv b \pmod{m}$ 且 $b \equiv c \pmod{m}$，则 $a \equiv c \pmod{m}$

### 5.3 模运算的性质
- $(a + b) \bmod m = ((a \bmod m) + (b \bmod m)) \bmod m$
- $(a \times b) \bmod m = ((a \bmod m) \times (b \bmod m)) \bmod m$

## 📖 整数的应用

### 6.1 在数论中的应用
- **费马小定理**：如果 $p$ 是质数，则 $a^p \equiv a \pmod{p}$
- **中国剩余定理**：解决同余方程组
- **二次剩余**：研究二次同余方程

### 6.2 在密码学中的应用
- **RSA加密**：基于大整数分解的困难性
- **椭圆曲线密码**：基于椭圆曲线上的整数点
- **哈希函数**：利用模运算的性质

### 6.3 在计算机科学中的应用
- **位运算**：整数的二进制表示和运算
- **数组索引**：使用整数作为数组下标
- **循环控制**：使用整数控制循环次数

## 🔗 与其他数系的联系

### 7.1 与自然数系的联系
- 自然数是整数的子集
- 整数是自然数系的扩展

### 7.2 与有理数系的联系
- 整数是有理数的子集
- 整数可以表示为分数：$n = \frac{n}{1}$

### 7.3 与实数系的联系
- 整数是实数的子集
- 整数在实数轴上是离散的点

## 📖 学习要点

1. **理解整数的构造**：从自然数扩展到整数
2. **掌握整除理论**：最大公约数、最小公倍数
3. **熟悉模运算**：同余、模运算的性质
4. **应用能力**：在数论、密码学、计算机科学中应用整数
