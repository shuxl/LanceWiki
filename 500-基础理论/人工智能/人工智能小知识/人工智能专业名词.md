# 1 AI与AGI
+ AI（Artificial Intelligence，人工智能）是指由计算机系统模拟人类智能的技术，能够执行通常需要人类智能的任务，如学习、推理、决策、语言理解等。
+ AGI（Artificial General Intelligence，通用人工智能）指具备与人类相当或超越人类的广泛认知能力的AI，能够自主学习、适应不同任务，并像人类一样思考和解决问题。

# 2 大模型
大模型（Large Models）是指参数量巨大（通常达到亿级甚至万亿级）、基于深度学习（尤其是Transformer架构）训练的人工智能模型。它们通过海量数据和算力训练，具备强大的语言理解、生成和推理能力，例如GPT-4、PaLM、Claude等。

| **对比维度**  | **大模型（Large Models）**           | **常规模型（Traditional Models）** |
| --------- | ------------------------------- | ---------------------------- |
| **参数量**   | 亿级到万亿级（如GPT-3：1750亿参数）          | 通常百万级以下（如BERT-base：1.1亿参数）   |
| **训练数据量** | 海量（千亿级token，如Common Crawl、全网文本） | 较小（百万到千万级数据，依赖标注数据）          |
| **算力需求**  | 超高（需GPU/TPU集群，训练成本数百万美元）        | 低（单卡或小型服务器可训练）               |
| **架构**    | 基于Transformer，自注意力机制            | 多样（CNN、RNN、小型Transformer等）   |
| **训练方式**  | 预训练（无监督）+ 微调（有监督）               | 直接有监督训练                      |
| **泛化能力**  | 极强（零样本/小样本学习，跨任务迁移）             | 有限（需针对任务专门训练）                |

# 4 大模型的幻觉、实效性
+ 幻觉（Hallucination）：大模型生成与事实不符、逻辑错误或凭空捏造的内容。
+ 时效性（Timeliness）：模型知识更新的滞后性，无法实时反映最新信息。
# 5 大模型的函数功能
>Function Calling（函数调用）是 Tools（工具） 之前的叫法，可以统一称为函数功能。

Tools（工具）是 OpenAI 为 ChatGPT 等模型提供的一种能力，允许大模型在对话过程中动态调用外部工具或API，以获取实时数据或执行特定任务。
1. 用户提问 
2.  模型返回需调用的函数及参数
3. 开发者执行函数
4. 返回结果给模型
5. 生成最终回复。
大模型本身没有调用这些API，而是从自然语言中对传入的API进行了选择，并通过API的参数进行了解析，得到了需要调用的函数及参数。

# 6 数字人
数字人，也称为虚拟数字人或虚拟形象，是一种以数字形式存在于数字空间中的虚拟人物。它们通常具有拟人或真人的外貌、行为特点，并具备一定的智能和情感，可以进行交互和表达。
# 7 具身智能
具身智能，指的是具有物理实体的智能体，通过与物理环境的交互来感知、理解、决策和行动，从而实现智能。

# 9 训练集、验证机和测试集
![](img/Pasted%20image%2020250708175104.png)

[https://scikit-learn.org/stable/api/sklearn.model_selection.html#splitters](https://scikit-learn.org/stable/api/sklearn.model_selection.html#splitters)

| **特性/方法**       | **简单随机划分 (Simple Random Split)**  | **分层抽样 (Stratified Sampling)**          | **K折交叉验证 (K-Fold Cross-Validation)**         |
| --------------- | --------------------------------- | --------------------------------------- | -------------------------------------------- |
| **核心思想**        | 随机将数据打乱并按比例分配                     | 确保各子集类别比例与原始数据集一致                       | 将数据分成K份，轮流用作验证集，其余作训练集                       |
| **适用场景**        | 数据量大，数据分布均匀的场景                    | **类别不平衡**的数据集（分类问题尤其重要）                 | **数据量较小**，或需要更稳定、全面的模型评估时                    |
| **优点**          | **实现最简单、容易理解**                    | **保持数据分布代表性、有助于模型学习稀有类别**               | **更充分利用数据、评估结果更稳定可靠**                        |
| **训练/验证/测试集关系** | 通常一次性划分出训练、验证、测试集                 | 通常一次性划分出训练、验证、测试集                       | **不直接划分出独立的测试集**（或预留一部分作为最终测试集），主要在训练和验证阶段使用 |
| **代码实现**        | `train_test_split` (scikit-learn) | `StratifiedShuffleSplit` (scikit-learn) | `KFold`, `StratifiedKFold` (scikit-learn)    |
# 10 用户画像

用户画像（User Persona）是基于对目标用户的数据分析和研究，构建出的一个虚拟的、典型用户形象。它不是一个真实存在的个体，而是对一群具有相似行为、需求和特征的用户的高度概括和抽象。
