# Java 集合框架面试易错点与高频考点梳理

---

## 1. 集合体系结构与常见误区
- List、Set、Map 是三大核心接口，注意它们的继承关系和实现类的差异
- List 有序可重复，Set 无序不可重复，Map 键唯一
- 常见误区：`ArrayList` 和 `LinkedList` 的性能差异、`HashSet` 和 `TreeSet` 的底层实现

    - [HashSet 和 TreeSet 的底层实现](../001-Java扩展/HashSet%20和%20TreeSet%20的底层实现.md)

## 2. 底层原理与源码关注点
- ArrayList：底层是动态数组，扩容机制（1.5倍扩容），随机访问快，插入/删除慢
- LinkedList：双向链表，插入/删除快，随机访问慢
- HashMap：JDK8 之前是数组+链表，JDK8 之后链表长度大于8转为红黑树，负载因子默认0.75，初始容量默认16
- HashSet：底层其实是 HashMap，只用 key
- TreeMap/TreeSet：底层是红黑树，元素有序
    - [红黑树](../../500-基础理论/数据结构/红黑树.md)
- ConcurrentHashMap：分段锁（JDK7），CAS+链表/红黑树（JDK8）

> **面试提醒：** HashMap 的扩容、hash 冲突、红黑树转换、线程安全问题是高频考点。

---

## 3. equals() 与 hashCode() 的重要性
- HashMap/HashSet 判断元素唯一性依赖 hashCode 和 equals
- 自定义对象作为 key 或 set 元素时，必须重写这两个方法，否则会出现逻辑错误
- 常见 bug：只重写了 equals 或 hashCode 导致集合行为异常

---

## 4. 集合与泛型
- 泛型保证类型安全，避免强制类型转换
- 原生类型（raw type）会导致类型安全隐患
- 通配符（? extends / ? super）在集合中的实际应用
- 泛型数组不能直接创建

---

## 5. 集合与并发
- ArrayList/HashMap 线程不安全，面试常考
- 线程安全集合：Vector、Hashtable（已过时）、Collections.synchronizedXXX、ConcurrentHashMap
- CopyOnWriteArrayList 适合读多写少场景
- fail-fast 机制：遍历时结构被修改会抛 ConcurrentModificationException
- fail-safe 机制：如 ConcurrentHashMap，遍历时不会抛异常

> **面试提醒：** 并发场景下集合的选择、fail-fast 原理、ConcurrentHashMap 的实现细节是高频考点。

---

## 6. 集合常见陷阱与易错点
- 使用 remove 时的下标越界、并发修改异常
- HashMap key 为 null 的特殊处理（允许一个 null key）
- TreeMap/TreeSet 元素必须可比较，否则抛异常
- 集合转数组时类型问题：`toArray(new T[0])` 推荐写法
- 集合判等：List/Set/Map 的 equals 行为不同

---

## 7. 集合选择建议
- 读多写少：ArrayList、HashMap
- 写多读少：LinkedList
- 需要排序：TreeSet、TreeMap
- 线程安全：优先考虑并发包下的集合
- 元素唯一性：Set
- 需要键值对：Map

---

## 8. 面试高频源码关注点
- ArrayList 扩容机制、add/remove 的复杂度
- HashMap put/get 流程、hash 冲突解决、resize 过程
- ConcurrentHashMap 的分段锁、CAS、红黑树转换
- fail-fast 的实现原理（modCount）

---

> **建议：**
> - 重点掌握集合底层原理、常见实现类的优缺点、线程安全问题
> - 多看源码，关注集合的扩容、遍历、并发处理细节
> - 面试时注意结合实际场景分析集合的选择和使用陷阱
