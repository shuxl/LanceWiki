## 贝叶斯统计基础

### 基本思想

**贝叶斯统计**的核心思想是将参数视为随机变量，通过观测数据更新对参数的信念。

**贝叶斯哲学**：
- 参数具有不确定性，可以用概率分布描述
- 观测数据用于更新对参数的认识
- 最终估计基于后验分布

### 贝叶斯定理

**贝叶斯定理**是贝叶斯统计的基础：

$$P(\theta|X) = \frac{P(X|\theta)P(\theta)}{P(X)}$$

其中：
- $P(\theta)$ 是**先验分布**：在观测数据之前的参数分布
- $P(X|\theta)$ 是**似然函数**：给定参数下数据的概率
- $P(\theta|X)$ 是**后验分布**：观测数据后的参数分布
- $P(X)$ 是**边际似然**：数据的概率（归一化常数）

### 后验分布

**后验分布**是贝叶斯估计的核心，它综合了先验知识和观测数据：

$$P(\theta|X) \propto P(X|\theta)P(\theta)$$

## 贝叶斯估计方法

### 点估计

常用的贝叶斯点估计包括：

1. **后验均值**：$\hat{\theta}_{Bayes} = E[\theta|X]$
2. **后验中位数**：$\hat{\theta}_{Bayes} = \text{median}(\theta|X)$
3. **后验众数**：$\hat{\theta}_{Bayes} = \arg\max_{\theta} P(\theta|X)$

### 区间估计

**贝叶斯置信区间**（可信区间）：
$$P(a \leq \theta \leq b|X) = 1-\alpha$$

### 预测分布

**预测分布**用于预测新的观测值：
$$P(X_{new}|X) = \int P(X_{new}|\theta)P(\theta|X)d\theta$$

## 常见分布的贝叶斯估计

### 伯努利分布 $B(1, p)$

**似然函数**：$P(X|p) = p^{\sum x_i}(1-p)^{n-\sum x_i}$

**共轭先验**：Beta分布 $Beta(\alpha, \beta)$
$$P(p) = \frac{p^{\alpha-1}(1-p)^{\beta-1}}{B(\alpha, \beta)}$$

**后验分布**：$Beta(\alpha + \sum x_i, \beta + n - \sum x_i)$

**贝叶斯估计**：
$$\hat{p}_{Bayes} = \frac{\alpha + \sum x_i}{\alpha + \beta + n}$$

### 正态分布 $N(\mu, \sigma^2)$（已知方差）

**似然函数**：$P(X|\mu) \propto \exp\left(-\frac{n}{2\sigma^2}(\bar{x} - \mu)^2\right)$

**共轭先验**：正态分布 $N(\mu_0, \sigma_0^2)$

**后验分布**：$N(\mu_1, \sigma_1^2)$
其中：
$$\mu_1 = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{n\bar{x}}{\sigma^2}}{\frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}}$$
$$\frac{1}{\sigma_1^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}$$

### 泊松分布 $Pois(\lambda)$

**似然函数**：$P(X|\lambda) \propto \lambda^{\sum x_i}e^{-n\lambda}$

**共轭先验**：Gamma分布 $Gamma(\alpha, \beta)$
$$P(\lambda) = \frac{\beta^\alpha}{\Gamma(\alpha)}\lambda^{\alpha-1}e^{-\beta\lambda}$$

**后验分布**：$Gamma(\alpha + \sum x_i, \beta + n)$

**贝叶斯估计**：
$$\hat{\lambda}_{Bayes} = \frac{\alpha + \sum x_i}{\beta + n}$$

## 先验分布的选择

### 共轭先验

**共轭先验**是指先验分布与后验分布属于同一分布族。

**优势**：
- 计算简便
- 后验分布有解析解
- 便于理解

**常见共轭对**：
- 伯努利分布 ↔ Beta分布
- 正态分布 ↔ 正态分布
- 泊松分布 ↔ Gamma分布
- 指数分布 ↔ Gamma分布

### 无信息先验

**无信息先验**表示对参数没有先验知识。

**常见选择**：
- **均匀先验**：$P(\theta) \propto 1$
- **Jeffreys先验**：$P(\theta) \propto \sqrt{I(\theta)}$
- **参考先验**：基于Fisher信息量

### 层次先验

**层次先验**用于复杂模型，先验参数本身也有先验分布：

$$P(\theta|\phi)P(\phi)$$

## 贝叶斯估计与频率学派对比

### 哲学差异

| 方面 | 频率学派 | 贝叶斯学派 |
|------|----------|------------|
| 参数性质 | 固定未知常数 | 随机变量 |
| 概率解释 | 长期频率 | 主观信念 |
| 推断基础 | 样本分布 | 后验分布 |
| 不确定性 | 置信区间 | 可信区间 |

### 估计方法对比

**最大似然估计 vs 贝叶斯估计**：

1. **MLE**：$\hat{\theta}_{MLE} = \arg\max_{\theta} P(X|\theta)$
2. **贝叶斯**：$\hat{\theta}_{Bayes} = E[\theta|X]$

**优势对比**：
- **MLE**：计算简单，大样本下性质良好
- **贝叶斯**：小样本下更稳定，可融入先验知识

## 贝叶斯估计的底层原理

### 决策理论

贝叶斯估计可以基于**决策理论**框架：

**损失函数**：$L(\theta, \hat{\theta})$

**贝叶斯风险**：$R(\hat{\theta}) = E[L(\theta, \hat{\theta})]$

**最优估计**：$\hat{\theta}^* = \arg\min_{\hat{\theta}} R(\hat{\theta})$

### 关键类和方法

1. **先验分布类**：共轭先验、无信息先验、层次先验
2. **后验计算方法**：解析解、数值积分、MCMC
3. **估计方法**：后验均值、后验中位数、后验众数

### 设计思想

贝叶斯估计的核心设计思想：
- **不确定性量化**：将参数不确定性建模为概率分布
- **知识更新**：通过观测数据更新先验信念
- **决策优化**：基于后验分布进行最优决策

## 机器学习中的应用

### 贝叶斯线性回归

**模型**：$Y = X^T\beta + \epsilon, \epsilon \sim N(0, \sigma^2)$

**先验**：$\beta \sim N(0, \sigma^2(X^TX)^{-1})$

**后验**：$\beta|X,Y \sim N(\hat{\beta}, \sigma^2(X^TX)^{-1})$

其中 $\hat{\beta} = (X^TX)^{-1}X^TY$

### 贝叶斯神经网络

**权重先验**：$W \sim N(0, \sigma_w^2I)$

**后验近似**：使用变分推断或MCMC方法

### 贝叶斯优化

**目标函数**：$f(x) \sim GP(\mu(x), k(x,x'))$

**采集函数**：期望改进、置信上界等

## 计算贝叶斯方法

### 马尔可夫链蒙特卡罗（MCMC）

**Metropolis-Hastings算法**：
1. 从当前状态 $\theta^{(t)}$ 生成候选 $\theta^*$
2. 计算接受概率：$\alpha = \min\left(1, \frac{P(\theta^*|X)}{P(\theta^{(t)}|X)}\right)$
3. 以概率 $\alpha$ 接受候选

### 变分推断

**变分分布**：$q(\theta) \approx P(\theta|X)$

**目标**：最小化KL散度 $KL(q(\theta)||P(\theta|X))$

### 期望最大化（EM）

**E步**：计算期望 $Q(\theta|\theta^{(t)}) = E_{Z|X,\theta^{(t)}}[\ln P(X,Z|\theta)]$

**M步**：最大化 $Q(\theta|\theta^{(t)})$
