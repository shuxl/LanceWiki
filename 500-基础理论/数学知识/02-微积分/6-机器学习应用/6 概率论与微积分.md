## 概率论与微积分概念或介绍

### 概率论与微积分的关系

概率论与微积分密切相关，概率密度函数通过积分计算概率，期望和方差通过积分定义，而最大似然估计等统计方法则依赖于导数计算。

### 核心概念

1. **概率密度函数**：通过积分计算概率
2. **期望和方差**：通过积分定义
3. **最大似然估计**：通过导数求解
4. **贝叶斯推断**：涉及积分计算

## 概率密度函数的积分

### 概率密度函数的定义

连续随机变量$X$的概率密度函数$f(x)$满足：

$$\int_{-\infty}^{\infty} f(x) dx = 1$$

对于任意区间$[a, b]$，概率为：

$$P(a \leq X \leq b) = \int_a^b f(x) dx$$

### 常见概率密度函数

#### 1. 正态分布

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

#### 2. 指数分布

$$f(x) = \lambda e^{-\lambda x}, \quad x \geq 0$$

#### 3. 均匀分布

$$f(x) = \frac{1}{b-a}, \quad a \leq x \leq b$$

### 代码实现

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import integrate

def normal_pdf(x, mu=0, sigma=1):
    """正态分布概率密度函数"""
    return (1 / np.sqrt(2 * np.pi * sigma**2)) * np.exp(-(x - mu)**2 / (2 * sigma**2))

def exponential_pdf(x, lambda_param=1):
    """指数分布概率密度函数"""
    return lambda_param * np.exp(-lambda_param * x) * (x >= 0)

def uniform_pdf(x, a=0, b=1):
    """均匀分布概率密度函数"""
    return np.where((x >= a) & (x <= b), 1/(b-a), 0)

# 计算概率
def calculate_probability(pdf_func, a, b, **kwargs):
    """计算区间[a, b]的概率"""
    result, error = integrate.quad(pdf_func, a, b, args=tuple(kwargs.values()))
    return result

# 示例
x = np.linspace(-3, 3, 100)
y_normal = normal_pdf(x)

# 计算正态分布在[-1, 1]的概率
prob = calculate_probability(normal_pdf, -1, 1)
print(f"正态分布在[-1, 1]的概率: {prob:.4f}")

# 可视化
plt.figure(figsize=(10, 6))
plt.plot(x, y_normal, label='正态分布', linewidth=2)
plt.fill_between(x[(x >= -1) & (x <= 1)], 
                 y_normal[(x >= -1) & (x <= 1)], 
                 alpha=0.3, label=f'P(-1 ≤ X ≤ 1) = {prob:.4f}')
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('正态分布概率密度函数')
plt.legend()
plt.grid(True)
plt.show()
```

## 期望和方差的积分表示

### 期望的定义

连续随机变量$X$的期望：

$$E[X] = \int_{-\infty}^{\infty} x f(x) dx$$

### 方差的定义

连续随机变量$X$的方差：

$$\text{Var}(X) = E[(X - E[X])^2] = \int_{-\infty}^{\infty} (x - E[X])^2 f(x) dx$$

### 期望和方差的计算

```python
def calculate_expectation(pdf_func, **kwargs):
    """计算期望"""
    def integrand(x):
        return x * pdf_func(x, **kwargs)
    
    result, error = integrate.quad(integrand, -np.inf, np.inf)
    return result

def calculate_variance(pdf_func, **kwargs):
    """计算方差"""
    expectation = calculate_expectation(pdf_func, **kwargs)
    
    def integrand(x):
        return (x - expectation)**2 * pdf_func(x, **kwargs)
    
    result, error = integrate.quad(integrand, -np.inf, np.inf)
    return result

# 示例：正态分布的期望和方差
mu, sigma = 0, 1
expectation = calculate_expectation(normal_pdf, mu=mu, sigma=sigma)
variance = calculate_variance(normal_pdf, mu=mu, sigma=sigma)

print(f"正态分布期望: {expectation:.4f}")
print(f"正态分布方差: {variance:.4f}")
print(f"理论期望: {mu}")
print(f"理论方差: {sigma**2}")
```

### 条件期望

条件期望的定义：

$$E[X|Y=y] = \int_{-\infty}^{\infty} x f_{X|Y}(x|y) dx$$

其中$f_{X|Y}(x|y)$是条件概率密度函数。

## 最大似然估计的导数

### 最大似然估计原理

最大似然估计通过最大化似然函数来估计参数：

$$\hat{\theta} = \arg\max_{\theta} L(\theta) = \arg\max_{\theta} \prod_{i=1}^{n} f(x_i|\theta)$$

通常取对数似然函数：

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^{n} \log f(x_i|\theta)$$

### 正态分布的最大似然估计

对于正态分布$N(\mu, \sigma^2)$，对数似然函数：

$$\ell(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(x_i - \mu)^2$$

#### 对$\mu$求导

$$\frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^{n}(x_i - \mu)$$

令导数为0：

$$\hat{\mu} = \frac{1}{n}\sum_{i=1}^{n}x_i$$

#### 对$\sigma^2$求导

$$\frac{\partial \ell}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum_{i=1}^{n}(x_i - \mu)^2$$

令导数为0：

$$\hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \hat{\mu})^2$$

### 代码实现

```python
def normal_log_likelihood(x, mu, sigma):
    """正态分布的对数似然函数"""
    n = len(x)
    return -n/2 * np.log(2*np.pi) - n/2 * np.log(sigma**2) - 1/(2*sigma**2) * np.sum((x - mu)**2)

def normal_mle(x):
    """正态分布的最大似然估计"""
    mu_mle = np.mean(x)
    sigma_mle = np.sqrt(np.mean((x - mu_mle)**2))
    return mu_mle, sigma_mle

def normal_score_function(x, mu, sigma):
    """正态分布的得分函数（对数似然的导数）"""
    n = len(x)
    
    # 对mu的导数
    d_mu = np.sum(x - mu) / sigma**2
    
    # 对sigma的导数
    d_sigma = -n/sigma + np.sum((x - mu)**2) / sigma**3
    
    return d_mu, d_sigma

# 示例
np.random.seed(42)
true_mu, true_sigma = 2, 1.5
x = np.random.normal(true_mu, true_sigma, 100)

mu_mle, sigma_mle = normal_mle(x)
print(f"真实参数: μ={true_mu}, σ={true_sigma}")
print(f"MLE估计: μ={mu_mle:.4f}, σ={sigma_mle:.4f}")

# 计算得分函数
score_mu, score_sigma = normal_score_function(x, mu_mle, sigma_mle)
print(f"得分函数: ∂ℓ/∂μ={score_mu:.6f}, ∂ℓ/∂σ={score_sigma:.6f}")
```

## 贝叶斯定理中的积分

### 贝叶斯定理

贝叶斯定理：

$$P(\theta|D) = \frac{P(D|\theta)P(\theta)}{P(D)}$$

其中：
- $P(\theta|D)$ 是后验概率
- $P(D|\theta)$ 是似然函数
- $P(\theta)$ 是先验概率
- $P(D)$ 是证据（归一化常数）

### 证据的计算

证据通过积分计算：

$$P(D) = \int P(D|\theta)P(\theta) d\theta$$

### 后验期望

后验期望：

$$E[\theta|D] = \int \theta P(\theta|D) d\theta$$

### 代码实现

```python
def bayesian_inference(likelihood_func, prior_func, theta_range, data):
    """贝叶斯推断"""
    # 计算似然函数
    likelihood = likelihood_func(data, theta_range)
    
    # 计算先验
    prior = prior_func(theta_range)
    
    # 计算后验（未归一化）
    posterior = likelihood * prior
    
    # 归一化
    evidence = np.trapz(posterior, theta_range)
    posterior_normalized = posterior / evidence
    
    return posterior_normalized, evidence

def calculate_posterior_expectation(posterior, theta_range):
    """计算后验期望"""
    return np.trapz(theta_range * posterior, theta_range)

# 示例：正态分布的贝叶斯推断
def normal_likelihood(data, theta):
    """正态分布似然函数"""
    mu, sigma = theta, 1.0  # 假设sigma已知
    return np.prod(normal_pdf(data, mu, sigma))

def normal_prior(theta):
    """正态先验"""
    return normal_pdf(theta, mu=0, sigma=2)

# 生成数据
np.random.seed(42)
true_mu = 1.5
data = np.random.normal(true_mu, 1, 10)

# 贝叶斯推断
theta_range = np.linspace(-3, 6, 100)
posterior, evidence = bayesian_inference(normal_likelihood, normal_prior, theta_range, data)

# 计算后验期望
posterior_expectation = calculate_posterior_expectation(posterior, theta_range)

print(f"真实均值: {true_mu}")
print(f"样本均值: {np.mean(data):.4f}")
print(f"后验期望: {posterior_expectation:.4f}")
print(f"证据: {evidence:.6f}")
```

## 在统计学习中的应用

### 1. 线性回归

线性回归模型：

$$y = X\beta + \epsilon, \quad \epsilon \sim N(0, \sigma^2)$$

最大似然估计：

$$\hat{\beta} = (X^TX)^{-1}X^Ty$$

### 2. 逻辑回归

逻辑回归模型：

$$P(y=1|x) = \frac{1}{1 + e^{-x^T\beta}}$$

对数似然函数：

$$\ell(\beta) = \sum_{i=1}^{n} [y_i \log(p_i) + (1-y_i)\log(1-p_i)]$$

### 3. 高斯混合模型

高斯混合模型：

$$f(x) = \sum_{k=1}^{K} \pi_k N(x|\mu_k, \Sigma_k)$$

其中$\pi_k$是混合权重。

### 代码实现

```python
def linear_regression_mle(X, y):
    """线性回归的最大似然估计"""
    beta_mle = np.linalg.inv(X.T @ X) @ X.T @ y
    return beta_mle

def logistic_regression_mle(X, y, max_iter=1000, learning_rate=0.01):
    """逻辑回归的最大似然估计（梯度上升）"""
    n_features = X.shape[1]
    beta = np.zeros(n_features)
    
    for _ in range(max_iter):
        # 计算预测概率
        z = X @ beta
        p = 1 / (1 + np.exp(-z))
        
        # 计算梯度
        gradient = X.T @ (y - p)
        
        # 更新参数
        beta += learning_rate * gradient
    
    return beta

# 示例：线性回归
np.random.seed(42)
n_samples = 100
X = np.random.randn(n_samples, 2)
true_beta = np.array([1.5, -0.8])
y = X @ true_beta + np.random.normal(0, 0.5, n_samples)

beta_mle = linear_regression_mle(X, y)
print(f"真实参数: {true_beta}")
print(f"MLE估计: {beta_mle}")
```
