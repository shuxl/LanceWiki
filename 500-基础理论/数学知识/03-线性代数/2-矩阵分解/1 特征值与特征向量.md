# 特征值与特征向量

## 重点内容

本文档介绍特征值与特征向量的核心概念，包括：
- 特征值与特征向量的定义
- 特征多项式和特征方程
- 特征值的性质
- 对角化理论

## 1. 特征值与特征向量的定义

### 1.1 基本定义

**定义**：设 $A$ 是n阶方阵，如果存在非零向量 $\mathbf{v}$ 和标量 $\lambda$，使得：
$$A\mathbf{v} = \lambda\mathbf{v}$$

则称 $\lambda$ 为矩阵 $A$ 的**特征值**，$\mathbf{v}$ 为对应的**特征向量**。

### 1.2 几何意义

特征向量表示在线性变换 $A$ 下方向不变的向量，特征值表示该向量被拉伸或压缩的倍数。

- 如果 $\lambda > 1$，向量被拉伸
- 如果 $0 < \lambda < 1$，向量被压缩
- 如果 $\lambda < 0$，向量方向改变

## 2. 特征多项式与特征方程

### 2.1 特征多项式

**定义**：矩阵 $A$ 的特征多项式定义为：
$$p_A(\lambda) = \det(A - \lambda I)$$

其中 $I$ 是单位矩阵。

### 2.2 特征方程

**定义**：特征方程是：
$$\det(A - \lambda I) = 0$$

特征值就是特征方程的根。

### 2.3 特征值的计算

**步骤**：
1. 构造矩阵 $A - \lambda I$
2. 计算行列式 $\det(A - \lambda I)$
3. 解特征方程 $\det(A - \lambda I) = 0$
4. 对每个特征值 $\lambda_i$，求解 $(A - \lambda_i I)\mathbf{v} = \mathbf{0}$

**示例**：对于矩阵 $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$

1. $A - \lambda I = \begin{pmatrix} 2-\lambda & 1 \\ 1 & 2-\lambda \end{pmatrix}$
2. $\det(A - \lambda I) = (2-\lambda)^2 - 1 = \lambda^2 - 4\lambda + 3$
3. 特征方程：$\lambda^2 - 4\lambda + 3 = 0$
4. 解得：$\lambda_1 = 1$，$\lambda_2 = 3$

## 3. 特征值的性质

### 3.1 基本性质

**性质**：
- 特征值的和等于矩阵的迹：$\sum_{i=1}^{n} \lambda_i = \text{tr}(A)$
- 特征值的积等于矩阵的行列式：$\prod_{i=1}^{n} \lambda_i = \det(A)$
- 如果 $A$ 可逆，则 $A^{-1}$ 的特征值是 $\frac{1}{\lambda_i}$
- $A^k$ 的特征值是 $\lambda_i^k$

### 3.2 特殊矩阵的特征值

**对角矩阵**：对角矩阵的特征值就是其对角元素。

**对称矩阵**：对称矩阵的特征值都是实数。

**正交矩阵**：正交矩阵的特征值的模都等于1。

**幂等矩阵**：幂等矩阵的特征值只能是0或1。

## 4. 特征向量的性质

### 4.1 基本性质

**性质**：
- 特征向量不是唯一的，如果 $\mathbf{v}$ 是特征向量，则 $c\mathbf{v}$（$c \neq 0$）也是特征向量
- 不同特征值对应的特征向量线性无关
- 特征向量张成的子空间在变换下保持不变

### 4.2 特征空间

**定义**：对于特征值 $\lambda$，特征空间定义为：
$$E_\lambda = \{\mathbf{v} : A\mathbf{v} = \lambda\mathbf{v}\}$$

**性质**：
- $E_\lambda$ 是向量空间
- $\dim(E_\lambda) \leq$ 特征值 $\lambda$ 的代数重数

## 5. 对角化理论

### 5.1 可对角化的定义

**定义**：n阶方阵 $A$ 称为可对角化的，如果存在可逆矩阵 $P$ 和对角矩阵 $D$，使得：
$$A = PDP^{-1}$$

### 5.2 对角化的条件

**定理**：矩阵 $A$ 可对角化当且仅当：
1. $A$ 有n个线性无关的特征向量
2. $A$ 的特征多项式的所有根都在数域中，且每个特征值的几何重数等于代数重数

### 5.3 对角化的步骤

**步骤**：
1. 求特征值 $\lambda_1, \lambda_2, \ldots, \lambda_n$
2. 求对应的特征向量 $\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n$
3. 构造矩阵 $P = [\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n]$
4. 构造对角矩阵 $D = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$
5. 验证 $A = PDP^{-1}$

## 6. 特征值分解的应用

### 6.1 矩阵幂的计算

如果 $A = PDP^{-1}$，则：
$$A^k = PD^kP^{-1}$$

其中 $D^k = \text{diag}(\lambda_1^k, \lambda_2^k, \ldots, \lambda_n^k)$

### 6.2 矩阵函数的计算

对于函数 $f$，如果 $A = PDP^{-1}$，则：
$$f(A) = Pf(D)P^{-1}$$

其中 $f(D) = \text{diag}(f(\lambda_1), f(\lambda_2), \ldots, f(\lambda_n))$

### 6.3 稳定性分析

在动力系统中，矩阵的特征值决定了系统的稳定性：
- 如果所有特征值的实部都小于0，系统是稳定的
- 如果存在特征值的实部大于0，系统是不稳定的

## 7. 特征值分解的应用

### 7.1 主成分分析（PCA）

PCA利用协方差矩阵的特征值和特征向量进行降维。

### 7.2 图像处理

特征值分解用于图像压缩和特征提取。

### 7.3 量子力学

在量子力学中，算符的特征值对应可观测量的可能取值。
