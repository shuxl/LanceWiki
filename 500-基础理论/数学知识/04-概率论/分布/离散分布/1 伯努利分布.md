# 1 伯努利分布

## 重点
- 伯努利分布的数学定义和基本性质
- 伯努利分布的概率质量函数和分布函数
- 伯努利分布的期望、方差和矩
- 伯努利分布在实际问题中的应用

## 1.1 伯努利分布的基本概念

### 1.1.1 伯努利分布的定义

**伯努利分布**（Bernoulli Distribution）：对于参数p（0 ≤ p ≤ 1），随机变量X服从伯努利分布，如果：

$$P(X = 1) = p, \quad P(X = 0) = 1 - p$$

记作：$X \sim Bernoulli(p)$

### 1.1.2 伯努利试验

**伯努利试验**：只有两种可能结果的随机试验。
- **成功**：通常编码为1，概率为p
- **失败**：通常编码为0，概率为1-p

**示例**：
- 抛硬币：正面（成功）或反面（失败）
- 产品质量检测：合格（成功）或不合格（失败）
- 医学检测：阳性（成功）或阴性（失败）

### 1.1.3 伯努利分布的直观理解

伯努利分布是最简单的离散分布：
- 只有两个取值：0和1
- 一个参数p控制成功概率
- 是其他离散分布的基础

## 1.2 伯努利分布的概率质量函数

### 1.2.1 PMF的定义

**概率质量函数**：
$$P(X = x) = \begin{cases}
p, & x = 1 \\
1-p, & x = 0 \\
0, & \text{其他}
\end{cases}$$

或者更简洁地：
$$P(X = x) = p^x(1-p)^{1-x}, \quad x = 0, 1$$

### 1.2.2 PMF的性质

1. **非负性**：$P(X = x) \geq 0$ 对于所有x
2. **归一性**：$\sum_{x} P(X = x) = p + (1-p) = 1$
3. **概率性**：$0 \leq P(X = x) \leq 1$

### 1.2.3 PMF的图形表示

伯努利分布的PMF是一个简单的柱状图：
- 在x=0处有高度为1-p的柱
- 在x=1处有高度为p的柱
- 其他位置为0

## 1.3 伯努利分布的分布函数

### 1.3.1 CDF的定义

**分布函数**：
$$F_X(x) = P(X \leq x) = \begin{cases}
0, & x < 0 \\
1-p, & 0 \leq x < 1 \\
1, & x \geq 1
\end{cases}$$

### 1.3.2 CDF的性质

1. **阶梯函数**：在x=0和x=1处有跳跃
2. **右连续**：在跳跃点右连续
3. **单调非减**：随着x增加，F(x)不减少

### 1.3.3 CDF的图形表示

伯努利分布的CDF是一个阶梯函数：
- x < 0时，F(x) = 0
- 0 ≤ x < 1时，F(x) = 1-p
- x ≥ 1时，F(x) = 1

## 1.4 伯努利分布的矩

### 1.4.1 期望

**期望**：
$$E[X] = 1 \cdot p + 0 \cdot (1-p) = p$$

**解释**：期望等于成功概率p

### 1.4.2 方差

**方差**：
$$Var(X) = E[X^2] - (E[X])^2 = p - p^2 = p(1-p)$$

**计算过程**：
- $E[X^2] = 1^2 \cdot p + 0^2 \cdot (1-p) = p$
- $Var(X) = p - p^2 = p(1-p)$

### 1.4.3 高阶矩

**二阶矩**：$E[X^2] = p$
**三阶矩**：$E[X^3] = p$
**四阶矩**：$E[X^4] = p$

**一般形式**：对于任意正整数k，$E[X^k] = p$

### 1.4.4 偏度和峰度

**偏度**：
$$\gamma_1 = \frac{E[(X - \mu)^3]}{\sigma^3} = \frac{p(1-p)(1-2p)}{[p(1-p)]^{3/2}} = \frac{1-2p}{\sqrt{p(1-p)}}$$

**峰度**：
$$\gamma_2 = \frac{E[(X - \mu)^4]}{\sigma^4} - 3 = \frac{p(1-p)(1-3p+3p^2)}{[p(1-p)]^2} - 3$$

## 1.5 伯努利分布的矩母函数

### 1.5.1 矩母函数的定义

**矩母函数**：
$$M_X(t) = E[e^{tX}] = e^{t \cdot 1} \cdot p + e^{t \cdot 0} \cdot (1-p) = pe^t + (1-p)$$

### 1.5.2 矩母函数的性质

1. **存在性**：对于所有实数t都存在
2. **连续性**：在实数域上连续
3. **凸性**：$\log M_X(t)$ 是凸函数

### 1.5.3 从矩母函数求矩

**一阶导数**：$M_X'(t) = pe^t$
**二阶导数**：$M_X''(t) = pe^t$

在t=0处求值：
- $E[X] = M_X'(0) = p$
- $E[X^2] = M_X''(0) = p$

## 1.6 伯努利分布的应用

### 1.6.1 在统计学中的应用

**参数估计**：
- 最大似然估计：$\hat{p} = \frac{1}{n} \sum_{i=1}^{n} X_i$
- 贝叶斯估计：使用贝塔先验分布

**假设检验**：
- 检验p是否等于某个特定值
- 比较两个伯努利分布的p值

### 1.6.2 在机器学习中的应用

**二分类问题**：
- 伯努利分布是二分类的基础
- 逻辑回归使用伯努利似然函数

**特征工程**：
- 将分类变量编码为伯努利变量
- 创建二元特征

### 1.6.3 在实际问题中的应用

**质量控制**：
- 产品合格/不合格的建模
- 缺陷检测的概率分析

**医学诊断**：
- 疾病检测的阳性/阴性结果
- 治疗效果的评估

**金融风险**：
- 违约/不违约的建模
- 投资成功/失败的概率

## 1.7 伯努利分布与其他分布的关系

### 1.7.1 与二项分布的关系

**关系**：伯努利分布是二项分布的特例
- 当n=1时，二项分布退化为伯努利分布
- $Bernoulli(p) = Binomial(1, p)$

**证明**：
- 二项分布：$P(X = k) = \binom{n}{k} p^k(1-p)^{n-k}$
- 当n=1时：$P(X = k) = \binom{1}{k} p^k(1-p)^{1-k}$
- 对于k=0,1，得到伯努利分布

### 1.7.2 与几何分布的关系

**关系**：几何分布描述伯努利试验中首次成功所需的试验次数
- 如果X ~ Geometric(p)，则每次试验都服从Bernoulli(p)

### 1.7.3 与负二项分布的关系

**关系**：负二项分布描述伯努利试验中获得r次成功所需的试验次数
- 每次试验都服从Bernoulli(p)

## 1.8 伯努利分布的扩展

### 1.8.1 多项伯努利分布

**定义**：多个独立的伯努利随机变量的联合分布

**应用**：
- 多标签分类问题
- 多特征二元编码

### 1.8.2 条件伯努利分布

**定义**：在给定条件下，随机变量服从伯努利分布

**应用**：
- 条件概率建模
- 分层分析

### 1.8.3 混合伯努利分布

**定义**：多个伯努利分布的加权混合

**应用**：
- 聚类分析
- 异常检测

## 1.9 伯努利分布的计算

### 1.9.1 概率计算

**单个概率**：
- $P(X = 1) = p$
- $P(X = 0) = 1-p$

**累积概率**：
- $P(X \leq 0) = 1-p$
- $P(X \leq 1) = 1$

### 1.9.2 参数估计

**最大似然估计**：
$$\hat{p} = \frac{\text{成功次数}}{\text{总试验次数}}$$

**贝叶斯估计**：
- 先验：$p \sim Beta(\alpha, \beta)$
- 后验：$p|X \sim Beta(\alpha + \sum X_i, \beta + n - \sum X_i)$

### 1.9.3 置信区间

**正态近似**：
$$\hat{p} \pm z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

**精确方法**：使用二项分布的精确置信区间
