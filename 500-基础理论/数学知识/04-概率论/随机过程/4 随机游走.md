## 随机游走基本概念

### 定义

**随机游走**是描述在空间或时间中随机移动的数学模型。

**数学定义**：对于离散时间随机过程 $\{X_n: n \geq 0\}$，如果满足：
$$X_n = X_{n-1} + \epsilon_n$$

其中 $\{\epsilon_n\}$ 是独立同分布的随机变量序列，则称 $\{X_n\}$ 为随机游走。

### 基本性质

**增量独立性**：$\epsilon_1, \epsilon_2, ..., \epsilon_n$ 相互独立

**增量同分布**：$\epsilon_i \sim F$ 对所有 $i$ 成立

**初始条件**：$X_0$ 是给定的初始位置

## 随机游走的分类

### 按维度分类

#### 一维随机游走

**定义**：在实数轴上的随机游走。

**数学表达**：$X_n = X_{n-1} + \epsilon_n$，其中 $\epsilon_n \in \mathbb{R}$

**示例**：
- 简单随机游走：$\epsilon_n \in \{-1, 1\}$
- 高斯随机游走：$\epsilon_n \sim N(0, \sigma^2)$

#### 多维随机游走

**定义**：在 $\mathbb{R}^d$ 空间中的随机游走。

**数学表达**：$\mathbf{X}_n = \mathbf{X}_{n-1} + \boldsymbol{\epsilon}_n$

**示例**：
- 二维简单随机游走：$\boldsymbol{\epsilon}_n \in \{(1,0), (-1,0), (0,1), (0,-1)\}$
- 三维高斯随机游走：$\boldsymbol{\epsilon}_n \sim N(\mathbf{0}, \mathbf{\Sigma})$

### 按增量分布分类

#### 简单随机游走

**定义**：增量只取有限个值的随机游走。

**一维简单随机游走**：
- $\epsilon_n \in \{-1, 1\}$
- $P(\epsilon_n = 1) = p$，$P(\epsilon_n = -1) = 1-p$

**性质**：
- 当 $p = 1/2$ 时，称为对称随机游走
- 当 $p \neq 1/2$ 时，称为有偏随机游走

#### 高斯随机游走

**定义**：增量服从正态分布的随机游走。

**数学表达**：$\epsilon_n \sim N(\mu, \sigma^2)$

**性质**：
- $X_n \sim N(X_0 + n\mu, n\sigma^2)$
- 具有连续样本路径的极限

### 按边界条件分类

#### 无界随机游走

**定义**：在无限空间中的随机游走。

**性质**：
- 可能永远不回到起点
- 可能到达任意远的位置

#### 有界随机游走

**定义**：在有限空间中的随机游走。

**边界类型**：
- **吸收边界**：到达边界后停止
- **反射边界**：到达边界后反弹
- **周期边界**：边界连接（如环形）

## 随机游走的数学分析

### 期望和方差

**期望**：$E[X_n] = X_0 + nE[\epsilon_1]$

**方差**：$Var[X_n] = nVar[\epsilon_1]$

**协方差**：$Cov(X_m, X_n) = \min(m, n)Var[\epsilon_1]$

### 首达时间

**首达时间**：$T_a = \min\{n: X_n = a\}$

**首达概率**：$P(T_a < \infty)$

**一维简单随机游走的首达概率**：
- 对于 $a > 0$：$P(T_a < \infty) = \min(1, (q/p)^a)$
- 对于 $a < 0$：$P(T_a < \infty) = \min(1, (p/q)^{-a})$

其中 $p = P(\epsilon_n = 1)$，$q = 1-p$。

### 返回概率

**返回概率**：$P(X_n = X_0 \text{ for some } n > 0)$

**一维简单随机游走**：
- 对称情况（$p = 1/2$）：返回概率为1
- 非对称情况（$p \neq 1/2$）：返回概率小于1

### 极限行为

#### 大数定律

**大数定律**：$\frac{X_n}{n} \xrightarrow{P} E[\epsilon_1]$

#### 中心极限定理

**中心极限定理**：$\frac{X_n - nE[\epsilon_1]}{\sqrt{nVar[\epsilon_1]}} \xrightarrow{d} N(0, 1)$

#### 重对数律

**重对数律**：$\limsup_{n \to \infty} \frac{X_n}{\sqrt{2n\ln\ln n}} = \sqrt{Var[\epsilon_1]}$

## 随机游走的底层原理

### 马尔可夫性质

**随机游走**具有马尔可夫性质：
$$P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ..., X_0 = i_0) = P(X_{n+1} = j | X_n = i)$$

### 鞅性质

**对称随机游走**是鞅：
$$E[X_{n+1} | X_0, X_1, ..., X_n] = X_n$$

### 关键类和方法

1. **游走类型**：简单游走、高斯游走、Levy游走、分数随机游走
2. **分析方法**：概率方法、代数方法、分析几何方法
3. **计算技术**：蒙特卡罗模拟、解析解、数值方法

### 设计思想

随机游走建模的核心思想：
- **随机性**：通过随机增量描述不确定性
- **累积性**：当前位置是历史增量的累积
- **预测性**：基于当前状态预测未来行为

## 随机游走在物理中的应用

### 布朗运动

**布朗运动**是随机游走的连续时间极限。

**数学表达**：$dX_t = \mu dt + \sigma dW_t$

**性质**：
- 增量独立
- 增量服从正态分布
- 样本路径连续但不可微

### 扩散过程

**扩散方程**：
$$\frac{\partial p}{\partial t} = D \frac{\partial^2 p}{\partial x^2}$$

其中 $p(x, t)$ 是粒子在位置 $x$ 和时间 $t$ 的概率密度。

### 聚合物物理

**聚合物链**可以用随机游走建模。

**末端距分布**：对于长链，末端距服从正态分布。

### 量子力学

**路径积分**：量子粒子的路径可以用随机游走表示。

**费曼路径积分**：$K(x, t; x_0, 0) = \int e^{iS[x(t)]/\hbar} Dx(t)$

## 随机游走在金融中的应用

### 资产价格建模

**几何随机游走**：
$$\frac{dS_t}{S_t} = \mu dt + \sigma dW_t$$

**解**：$S_t = S_0 e^{(\mu-\frac{1}{2}\sigma^2)t + \sigma W_t}$

### 期权定价

**Black-Scholes模型**基于几何布朗运动。

**风险中性定价**：$V(S, t) = e^{-r(T-t)} E[V(S_T, T)]$

### 投资组合优化

**Markowitz模型**：基于随机游走建模资产收益。

**有效前沿**：在给定风险下最大化期望收益。

### 风险管理

**VaR计算**：基于随机游走模拟资产价格变化。

**压力测试**：模拟极端市场条件下的损失。

## 随机游走在算法中的应用

### 随机算法

**随机化算法**：使用随机性提高算法效率。

**Monte Carlo方法**：基于随机采样求解问题。

### 优化算法

**模拟退火**：基于随机游走的全局优化算法。

**算法**：
1. 生成邻域解
2. 计算接受概率：$P(accept) = \min(1, e^{-\Delta E/T})$
3. 更新温度：$T = \alpha T$

### 机器学习

**随机梯度下降**：基于随机采样的梯度下降。

**随机森林**：基于随机采样的集成学习。

### 图算法

**随机游走采样**：在图结构中随机游走采样节点。

**PageRank算法**：基于随机游走的网页排名算法。

## 随机游走在网络科学中的应用

### 网络传播

**传染病传播**：基于随机游走建模信息或疾病传播。

**SIR模型**：易感者-感染者-恢复者模型。

### 社区检测

**随机游走聚类**：基于随机游走检测网络社区。

**算法**：
1. 从每个节点开始随机游走
2. 计算节点间的相似度
3. 基于相似度聚类

### 网络嵌入

**Node2Vec**：基于随机游走的网络嵌入方法。

**目标**：学习节点的低维表示。

## 随机游走的扩展

### 分数随机游走

**定义**：增量的方差随时间增长。

**数学表达**：$Var[X_n] \propto n^{2H}$

其中 $H$ 是Hurst指数。

### Levy游走

**定义**：增量服从Levy分布的随机游走。

**性质**：
- 可能有大跳跃
- 具有重尾分布

### 自回避随机游走

**定义**：不允许访问已访问过的位置。

**应用**：聚合物物理、蛋白质折叠。
