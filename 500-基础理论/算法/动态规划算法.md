# 动态规划算法

## 重点
- 动态规划是一种通过把原问题分解为相对简单的子问题来解决复杂问题的算法思想
- 核心特征：最优子结构、重叠子问题、状态转移方程
- 实现方式：自顶向下（记忆化递归）和自底向上（迭代）
- 适用场景：最优化问题、计数问题、存在性问题
- 时间复杂度通常为O(n²)到O(n³)，空间复杂度可通过优化降低

## 动态规划概念或介绍

### 基本概念
动态规划（Dynamic Programming，DP）是一种在数学、管理科学、计算机科学、经济学和生物信息学中使用的，通过把原问题分解为相对简单的子问题来解决复杂问题的方法。

### 核心思想
动态规划的核心思想是：
1. **分治思想**：将大问题分解为小问题
2. **最优子结构**：问题的最优解包含其子问题的最优解
3. **重叠子问题**：子问题会被重复计算
4. **状态转移**：通过状态转移方程描述问题间的递推关系

### 解题步骤
1. **定义状态**：明确dp数组的含义
2. **确定状态转移方程**：找到子问题之间的关系
3. **确定初始状态**：设置边界条件
4. **确定计算顺序**：自底向上或自顶向下
5. **优化空间复杂度**：压缩状态空间

## 动态规划的实现方式

### 自顶向下（记忆化递归）
```python
def fibonacci_memo(n, memo=None):
    """
    斐波那契数列 - 记忆化递归实现
    """
    if memo is None:
        memo = {}
    
    # 基础情况
    if n <= 1:
        return n
    
    # 检查是否已经计算过
    if n in memo:
        return memo[n]
    
    # 递归计算并存储结果
    memo[n] = fibonacci_memo(n-1, memo) + fibonacci_memo(n-2, memo)
    return memo[n]
```

### 自底向上（迭代）
```python
def fibonacci_dp(n):
    """
    斐波那契数列 - 动态规划迭代实现
    """
    if n <= 1:
        return n
    
    # 定义状态数组
    dp = [0] * (n + 1)
    dp[1] = 1
    
    # 状态转移
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]
```

### 空间优化版本
```python
def fibonacci_optimized(n):
    """
    斐波那契数列 - 空间优化版本
    """
    if n <= 1:
        return n
    
    prev, curr = 0, 1
    for i in range(2, n + 1):
        prev, curr = curr, prev + curr
    
    return curr
```

## 经典动态规划问题

### 1. 爬楼梯问题
```python
def climb_stairs(n):
    """
    爬楼梯问题：每次可以爬1或2个台阶，爬到n阶有多少种方法
    """
    if n <= 2:
        return n
    
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]
```

### 2. 最大子数组和
```python
def max_subarray_sum(nums):
    """
    最大子数组和问题
    """
    if not nums:
        return 0
    
    dp = [0] * len(nums)
    dp[0] = nums[0]
    max_sum = dp[0]
    
    for i in range(1, len(nums)):
        dp[i] = max(nums[i], dp[i-1] + nums[i])
        max_sum = max(max_sum, dp[i])
    
    return max_sum
```

### 3. 最长递增子序列
```python
def length_of_lis(nums):
    """
    最长递增子序列长度
    """
    if not nums:
        return 0
    
    dp = [1] * len(nums)
    
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[i] > nums[j]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)
```

### 4. 0-1背包问题
```python
def knapsack_01(weights, values, capacity):
    """
    0-1背包问题
    """
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w-weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    
    return dp[n][capacity]
```

### 5. 编辑距离
```python
def edit_distance(word1, word2):
    """
    编辑距离：将word1转换为word2所需的最少操作数
    """
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 初始化边界
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    
    # 状态转移
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
    
    return dp[m][n]
```

## 动态规划优化技巧

### 1. 状态压缩
```python
def tsp_dp_compressed(dist):
    """
    旅行商问题 - 状态压缩优化
    """
    n = len(dist)
    dp = [[float('inf')] * n for _ in range(1 << n)]
    dp[1][0] = 0  # 从城市0开始
    
    for state in range(1 << n):
        for i in range(n):
            if not (state & (1 << i)):
                continue
            for j in range(n):
                if state & (1 << j):
                    dp[state][i] = min(dp[state][i], 
                                     dp[state ^ (1 << i)][j] + dist[j][i])
    
    return min(dp[(1 << n) - 1][i] + dist[i][0] for i in range(1, n))
```

### 2. 滚动数组优化
```python
def fibonacci_rolling(n):
    """
    斐波那契数列 - 滚动数组优化
    """
    if n <= 1:
        return n
    
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    
    return b
```

### 3. 单调队列优化
```python
from collections import deque

def max_sliding_window(nums, k):
    """
    滑动窗口最大值 - 单调队列优化
    """
    if not nums or k == 0:
        return []
    
    dq = deque()
    result = []
    
    for i in range(len(nums)):
        # 移除窗口外的元素
        while dq and dq[0] < i - k + 1:
            dq.popleft()
        
        # 移除小于当前元素的元素
        while dq and nums[dq[-1]] < nums[i]:
            dq.pop()
        
        dq.append(i)
        
        if i >= k - 1:
            result.append(nums[dq[0]])
    
    return result
```

def memoization_template(n, memo=None):
    """
    记忆化搜索模板
    """
    if memo is None:
        memo = {}
    
    # 基础情况
    if n <= 1:
        return n
    
    # 检查缓存
    if n in memo:
        return memo[n]
