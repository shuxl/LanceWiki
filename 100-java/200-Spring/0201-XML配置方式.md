
# 1 Spring XML配置方式概念或介绍

**本文重点：**
- 理解Spring XML配置的核心概念和优势
- 掌握XML配置的基本结构和常用元素
- 学习bean定义、依赖注入、作用域等XML配置方法
- 了解XML配置与注解配置的区别和选择
- 掌握XML配置的最佳实践和注意事项

## 1.1 什么是XML配置方式

Spring XML配置方式是Spring框架最早支持的配置方式，通过XML文件来定义Bean的创建、依赖关系、作用域等配置信息。XML配置提供了声明式的配置方式，将配置信息与业务代码分离，便于管理和维护。

## 1.2 XML配置的优势

1. **配置与代码分离**：配置信息独立于Java代码，便于管理
2. **可视化配置**：XML结构清晰，便于查看和理解
3. **动态配置**：可以在不修改代码的情况下调整配置
4. **团队协作**：配置变更不会影响代码版本控制
5. **向后兼容**：Spring早期版本的主要配置方式

# 2 XML配置文件结构

## 2.1 基本配置文件结构

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xmlns:aop="http://www.springframework.org/schema/aop"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd
                           http://www.springframework.org/schema/context
                           http://www.springframework.org/schema/context/spring-context.xsd
                           http://www.springframework.org/schema/aop
                           http://www.springframework.org/schema/aop/spring-aop.xsd">

    <!-- Bean定义 -->
    <bean id="userService" class="com.example.service.UserService">
        <!-- 配置内容 -->
    </bean>

</beans>
```

## 2.2 命名空间说明

- **beans**：核心命名空间，用于定义Bean
- **context**：上下文命名空间，用于注解扫描等
- **aop**：AOP命名空间，用于面向切面编程
- **tx**：事务命名空间，用于事务管理

# 13 XML配置与注解配置对比

## 13.1 配置方式对比

| 特性 | XML配置 | 注解配置 |
|------|---------|----------|
| 配置位置 | 外部XML文件 | 代码中 |
| 可读性 | 结构清晰 | 分散在代码中 |
| 修改便利性 | 无需重新编译 | 需要重新编译 |
| 团队协作 | 配置变更不影响代码 | 配置变更影响代码 |
| 学习成本 | 需要学习XML语法 | 需要学习注解 |
| 向后兼容 | 完全兼容 | 需要Spring版本支持 |

### 15.1.2 核心类详解

**1. XmlBeanDefinitionReader**
```java
public class XmlBeanDefinitionReader extends AbstractBeanDefinitionReader {
    
    // XML文档解析器
    private DocumentLoader documentLoader = new DefaultDocumentLoader();
    
    // 命名空间处理器解析器

    }
```

**2. DefaultDocumentLoader**
```java
public class DefaultDocumentLoader implements DocumentLoader {
    
    @Override
    public Document loadDocument(InputSource inputSource, EntityResolver entityResolver,
            ErrorHandler errorHandler, int validationMode, boolean namespaceAware) throws Exception {
        
        DocumentBuilderFactory factory = createDocumentBuilderFactory(validationMode, namespaceAware);
        DocumentBuilder builder = createDocumentBuilder(factory, entityResolver, errorHandler);
        return builder.parse(inputSource);
    }
}
```

**3. BeanDefinitionParserDelegate**
```java
public class BeanDefinitionParserDelegate {
    
    // 解析bean元素的核心方法
    public BeanDefinitionHolder parseBeanDefinitionElement(Element ele, BeanDefinition containingBean) {
        String id = ele.getAttribute(ID_ATTRIBUTE);
        String nameAttr = ele.getAttribute(NAME_ATTRIBUTE);
        
        // 解析bean名称
        List<String> aliases = new ArrayList<>();
        if (StringUtils.hasLength(nameAttr)) {
            String[] nameArr = StringUtils.tokenizeToStringArray(nameAttr, BEAN_NAME_DELIMITERS);
            aliases.addAll(Arrays.asList(nameArr));
        }
        
        // 创建BeanDefinition
        AbstractBeanDefinition beanDefinition = parseBeanDefinitionElement(ele, beanName, containingBean);
        
        return new BeanDefinitionHolder(beanDefinition, beanName, aliases.toArray(new String[0]));
    }
    
    // 解析bean定义元素
    public AbstractBeanDefinition parseBeanDefinitionElement(Element ele, String beanName, BeanDefinition containingBean) {
        // 解析class属性
        String className = null;
        if (ele.hasAttribute(CLASS_ATTRIBUTE)) {
            className = ele.getAttribute(CLASS_ATTRIBUTE).trim();
        }
        
        // 解析parent属性
        String parent = null;
        if (ele.hasAttribute(PARENT_ATTRIBUTE)) {
            parent = ele.getAttribute(PARENT_ATTRIBUTE);
        }
        
        try {
            // 创建BeanDefinition
            AbstractBeanDefinition bd = createBeanDefinition(className, parent);
            
            // 解析其他属性
            parseBeanDefinitionAttributes(ele, beanName, containingBean, bd);
            parseMetaElements(ele, bd);
            parseLookupOverrideElements(ele, bd.getMethodOverrides());
            parseReplacedMethodElements(ele, bd.getMethodOverrides());
            
            // 解析构造器参数
            parseConstructorArgElements(ele, bd);
            // 解析属性
            parsePropertyElements(ele, bd);
            // 解析限定符
            parseQualifierElements(ele, bd);
            
            bd.setResource(this.readerContext.getResource());
            bd.setSource(extractSource(ele));
            
            return bd;
        } catch (ClassNotFoundException ex) {
            error("Bean class [" + className + "] not found", ele, ex);
        }
        return null;
    }
}
```

## 15.2 XML解析流程详解

### 15.2.1 解析流程图

```
XML配置文件
    ↓
XmlBeanDefinitionReader.loadBeanDefinitions()
    ↓
DefaultDocumentLoader.loadDocument()
    ↓
DocumentBuilder.parse() - DOM解析
    ↓
BeanDefinitionParserDelegate.parseBeanDefinitionElement()
    ↓
创建BeanDefinition对象
    ↓
注册到BeanDefinitionRegistry
    ↓
BeanFactory使用BeanDefinition创建Bean
```

### 15.2.2 关键解析步骤

**1. XML文档加载**
```java
// XmlBeanDefinitionReader中的关键方法
public int loadBeanDefinitions(Resource resource) throws BeanDefinitionStoreException {
    return loadBeanDefinitions(new EncodedResource(resource));
}

public int loadBeanDefinitions(EncodedResource encodedResource) throws BeanDefinitionStoreException {
    // 获取输入流
    InputStream inputStream = encodedResource.getResource().getInputStream();
    InputSource inputSource = new InputSource(inputStream);
    
    // 设置编码
    if (encodedResource.getEncoding() != null) {
        inputSource.setEncoding(encodedResource.getEncoding());
    }
    
    // 执行实际的加载
    return doLoadBeanDefinitions(inputSource, encodedResource.getResource());
}
```

**2. DOM文档解析**
```java
protected Document doLoadDocument(InputSource inputSource, Resource resource) throws Exception {
    return this.documentLoader.loadDocument(inputSource, getEntityResolver(), this.errorHandler,
            getValidationModeForResource(resource), isNamespaceAware());
}
```

**3. Bean定义解析**
```java
// 解析<bean>元素
protected void processBeanDefinition(Element ele, BeanDefinitionParserDelegate delegate) {
    // 解析bean定义
    BeanDefinitionHolder bdHolder = delegate.parseBeanDefinitionElement(ele);
    if (bdHolder != null) {
        // 装饰bean定义
        bdHolder = delegate.decorateBeanDefinitionIfRequired(ele, bdHolder);
        try {
            // 注册bean定义
            BeanDefinitionReaderUtils.registerBeanDefinition(bdHolder, getReaderContext().getRegistry());
        } catch (BeanDefinitionStoreException ex) {
            getReaderContext().fireComponentRegistered(ex);
        }
        // 发送注册事件
        getReaderContext().fireComponentRegistered(new BeanComponentDefinition(bdHolder));
    }
}
```

## 15.3 命名空间处理机制

### 15.3.1 命名空间处理器架构

```java
// 命名空间处理器接口
public interface NamespaceHandler {
    void init();
    BeanDefinition parse(Element element, ParserContext parserContext);
}

// 默认命名空间处理器解析器
public class DefaultNamespaceHandlerResolver implements NamespaceHandlerResolver {
    
    private final ClassLoader classLoader;
    private final Map<String, Object> handlerMappings = new ConcurrentHashMap<>();
    
    @Override
    public NamespaceHandler resolve(String namespaceUri) {
        // 从META-INF/spring.handlers文件中查找处理器
        Map<String, Object> handlerMappings = getHandlerMappings();
        Object handlerOrClassName = handlerMappings.get(namespaceUri);
        
        if (handlerOrClassName instanceof NamespaceHandler) {
            return (NamespaceHandler) handlerOrClassName;
        } else if (handlerOrClassName instanceof String) {
            // 创建处理器实例
            try {
                Class<?> handlerClass = ClassUtils.forName((String) handlerOrClassName, this.classLoader);
                NamespaceHandler namespaceHandler = (NamespaceHandler) BeanUtils.instantiateClass(handlerClass);
                namespaceHandler.init();
                handlerMappings.put(namespaceUri, namespaceHandler);
                return namespaceHandler;
            } catch (ClassNotFoundException ex) {
                throw new FatalBeanException("Could not find NamespaceHandler class [" + handlerOrClassName + 
                    "] for namespace [" + namespaceUri + "]", ex);
            }
        }
        return null;
    }
}
```

## 15.4 属性解析机制

### 15.4.1 属性值解析器体系

```java
// 属性值解析器接口
public interface BeanDefinitionValueResolver {
    Object resolveValueIfNecessary(Object argName, Object value);
}

// 默认属性值解析器
public class BeanDefinitionValueResolver {
    
    private final AbstractBeanFactory beanFactory;
    private final String beanName;
    private final BeanDefinition beanDefinition;
    
    public Object resolveValueIfNecessary(Object argName, Object value) {
        // 处理运行时Bean引用
        if (value instanceof RuntimeBeanReference) {
            RuntimeBeanReference ref = (RuntimeBeanReference) value;
            return resolveReference(argName, ref);
        }
        // 处理内部Bean定义
        else if (value instanceof BeanDefinitionHolder) {
            BeanDefinitionHolder bdHolder = (BeanDefinitionHolder) value;
            return resolveInnerBean(argName, bdHolder.getBeanName(), bdHolder.getBeanDefinition());
        }
        // 处理集合
        else if (value instanceof ManagedList) {
            return resolveManagedList(argName, (ManagedList<?>) value);
        }
        // 处理Map
        else if (value instanceof ManagedMap) {
            return resolveManagedMap(argName, (ManagedMap<?, ?>) value);
        }
        // 处理其他类型
        else {
            return value;
        }
    }
}
```

```java
// List属性解析
private List<?> resolveManagedList(Object argName, List<?> ml, Class<?> elementType) {
    List<Object> resolved = new ArrayList<>(ml.size());
    for (int i = 0; i < ml.size(); i++) {
        Object element = ml.get(i);
        Object resolvedElement = resolveValueIfNecessary(
            new KeyedArgName(argName, i), element);
        resolved.add(resolvedElement);
    }
    return resolved;
}

// Map属性解析
private Map<?, ?> resolveManagedMap(Object argName, Map<?, ?> mm, Class<?> keyType, Class<?> valueType) {
    Map<Object, Object> resolved = new LinkedHashMap<>(mm.size());
    for (Map.Entry<?, ?> entry : mm.entrySet()) {
        Object resolvedKey = resolveValueIfNecessary(argName, entry.getKey());
        Object resolvedValue = resolveValueIfNecessary(
            new KeyedArgName(argName, entry.getKey()), entry.getValue());
        resolved.put(resolvedKey, resolvedValue);
    }
    return resolved;
}
```
